# ABYSS DOMINION Build365 / v3.1.45

Build364適用済みのゲームに重ねる差し替えパッチです。
ZIP内のファイルを同じ階層へ上書きし、公開後に再読み込みしてください。
設定画面で v3.1.45 を確認できます。オンラインサーバー更新は不要です。

## バフ・デバフ

- ラベルの文字・余白を縮小し、幅に応じて横に2〜3個並べやすくしました。
- 残りターンは「3T」のように短縮しています。
- 必要なだけ折り返し、長い固有効果も省略しません。
- 色分け、盾の条件付き表示、タップからの詳細表示を維持しています。

## 自動戦闘の停止対策

- 十神・深淵の特殊技が実行時に使えない場合、自動操作は通常攻撃へ切り替えます。敵は同じ特殊技を再選択せず通常のAI行動へ戻ります。
- 自動アイテム使用が不要／使用不可になった場合、操作待ちアラートではなく通常攻撃へ切り替えます。
- 行動完了後にbusy状態を解除してから次の行動へ渡します。
- 自動操作の待機中に自動OFF・行動順変更・戦闘切替が起きた場合、古い予約操作を実行しません。
- HP・MPゲージの描画コールバックが届かない場合にも演出待ちを終えます。完了後の遅延コールバックは無視します。ダメージや回復の再適用、戦闘結果の強制変更は行いません。

今回の写真の停止をiPhone上で再現したわけではありません。コード上で確認した停止経路と、演出待ち・行動遷移の不備への対策です。

## 勇者の記憶再戦・勝利報酬

| 段階 | 各員EXP | GOLD | 魔晶石 |
|---|---:|---:|---:|
| 1 | 120,000 | 250,000 | 100 |
| 2 | 138,000 | 287,500 | 125 |
| 3 | 158,700 | 330,625 | 150 |

- EXPとGOLDは段階ごとに15%増加（各上限1兆）。魔晶石は段階ごとに25個増加（上限5,000個）。
- EXPは戦闘不能を含めた出撃4体が対象です。控えには配布しません。
- 既存の使用物資返却後に勝利報酬を加算します。
- 敗北・撤退には報酬を配布せず、段階も進みません。
- 勝利後にEXP、各員のレベル変化、GOLD、魔晶石の結果画面を表示します。
- 報酬は結果画面を開く前に保存済みです。「受取」ボタンを押す必要はありません。
- 玉座の「前回の勝利報酬を見る」で再確認できます。再表示で再配布されません。
- セーブ失敗時は報酬を巻き戻し、保存再試行で一度だけ付与します。
- Build364以前の勝利に対するGOLD・魔晶石の遡及配布はありません。

勇者・味方の強さ、既存スキルの効果、再戦の難度上昇率は変更していません。
