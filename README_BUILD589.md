# Build589 / v3.1.268 — 仲間とつなぐ、４つの冒険

Build588適用済みの本体へ上書きする差分です。「とびだせ！魔界ランナーズ」に仲間ジャンプ・壁キック・協力コースと新しい仕掛けを追加しました。

## 適用

1. ZIPの中身をプロジェクトのルートへ、同じフォルダ構成で上書きしてください。本体の`src`と`online-server/src`を両方更新します。
2. 配信ファイルを更新し、`online-server`を再起動してください。追加の依存パッケージはありません。
3. 参加者全員がページを再読み込みし、v3.1.268 / Build589にそろえてください。新しい物理処理を使うため、以前のランナーズとは混在できません。古い試合の保存データは準備画面へ戻して更新します。

ZIPは差分なので、空のフォルダでは動きません。既存の保存データ・環境設定は含めていません。GitHubへのpush・公開サイトへのデプロイは行っていません。

## コースの選び方

ゲームの準備画面で、部屋主が４枚のコースカードから選びます。変更すると全員の準備OKを解除するので、相棒を選んで準備し直してください。「もう一度」では同じコースを引き継ぎます。

| コース | 遊び方 | 仕掛け・制限時間 |
| --- | --- | --- |
| こもれびアドベンチャー | レース | 従来の森〜遺跡〜魔王城。仲間ジャンプも利用可能。75秒 |
| 風車の空中庭園 | レース | 追い風・向かい風、左右に流れるコンベア、大バネ、移動足場。75秒 |
| つながるスイッチ遺跡 | 協力 | 対岸の３つのスイッチで共有の橋を開通。全員でゴール。120秒 |
| カチコチ時計塔 | レース | 壁キックで登る柱、崩れる足場、予告つきの蒸気トラップ。90秒 |

レースは点数制ではなく、ゴールしたタイム順。未ゴールは最も進んだ距離で順位が決まります。最初のゴールから残り16秒。各コースでハートは３つです。

## 新しい操作

- **仲間ジャンプ**：仲間の頭に上から着地すると、通常より高く跳びます。相手へのダメージや押し出しはありません。横から重なってもミスにはなりません。
- **壁キック**：壁に向かってジャンプし、壁に触れたらジャンプを離して押し直します。反対側へ蹴り出し、高い壁を登れます。壁へ向かって移動を押すと、落下がゆっくりになります。押しっぱなしの自動連続ジャンプや、壁のない空中での追加ジャンプはできません。
- これまで通り、左右のボタン上で指を滑らせて方向転換。もう片方の指でジャンプできます。PCは←→／A・Dで移動、スペース／↑／Wでジャンプです。

## 協力スイッチと救助

大バネや足場で先に対岸へ渡り、光る床スイッチを踏んでください。橋が共有され、後ろの仲間が歩いて渡れるようになります。橋は一度開くと、その試合中は閉じません。飛び越えるだけではスイッチは入りません。

未作動のスイッチを初めて踏むと、脱落している仲間全員をハート１つで近くの旗から救助します。すでに作動したスイッチを踏み直しても、追加の救助は起きません。３つのスイッチを開き、空席AIを含む４人全員がゴールするとチーム成功です。協力では最初のゴールによる残り16秒への短縮はありません。

空席と切断中はAIが操作します。協力AIは操作中の仲間から大きく離れると安全な足場で待ち、全員が脱落した場合などは先へ進んで救助を試みます。

## その他の仕掛け

- コンベアは乗っている間に流されます。風は表示されたエリア内で空中にいるときに作用します。
- ひび割れた足場は乗ると警告し、0.9秒後に崩れます。作動から4秒で戻ります。
- 蒸気は噴く前に「!」で予告します。止まるまで待つか、ジャンプで越えてください。旗からの復帰直後には接触保護があります。
- 新しいコースごとに配色・背景の装飾・壁・スイッチ・橋・警告表示を描画しています。背景画像と相棒画像は既存素材を利用しています。
