ABYSS DOMINION — Build337 / v3.1.18
勇者遭遇の手動選択・勇者一行の表示修正

【適用】
Build336適用済みのゲームが対象です。
先にゲームの設定からセーブを書き出し、現在のゲームファイルも控えてください。
ZIPを解凍し、index.html と src フォルダー内の同じパスを上書きしてください。
既存の assets や ZIPにないファイルは削除しないでください。
更新後に再読み込みし、ホーム／設定の v3.1.18 を確認してください。
サーバー側の更新は不要です。

【変更点】
1. 勇者出現時に自動探索と移動経路を停止。
   「今すぐ戦う」「手動で逃げる」を選ぶまで追跡は進みません。
   ×・Esc・時間経過で逃走が勝手に選ばれることはありません。
   「今すぐ戦う」はその勇者との戦闘を開始します。
   「手動で逃げる」は追跡中のフィールドへ戻り、プレイヤーが退路を操作します。
   勇者に接触すると戦闘になります。戦闘中の自動設定は従来どおりです。
   遭遇が終わるまでは自動探索を再開できません。終了後は手動でONにできます。
   選択待ちで再読み込みしても選択を求めます。旧データの追跡途中にも対応。

2. 「同じ頃、勇者一行は」の出演者を台詞の有無から切り離しました。
   4人が健在なら、ひでを含む4人全員が登場します。
   無傷の帰還・逃走後にも、ひでの台詞を追加しました。
   他の勇者の帰還時のよりの台詞も追加しました。
   撃破済みの仲間は復活させず、残り人数に合わせた会話にします。

【保持するもの】
セーブの初期化、報酬の再配布、遭遇結果の巻き戻しは行いません。
既に逃走が成立した遭遇は、その結果を保持します。
既に予言録へ保存された旧会話は当時の記録を保持し、今後の会話に修正が反映されます。
Build336の通路修正と、その他のゲーム仕様は保持しています。
