# ABYSS DOMINION Build360 / v3.1.40

## 差し替え方法
Build359を導入済みのゲームへ、このZIPの中身をフォルダー構成ごと上書きしてください。assets内の新しい王室画像も必須です。セーブの初期化は不要です。再読み込み後、バージョンがv3.1.40になっていることを確認してください。
オンライン用Nodeサーバーを運用している場合は、ソース差し替え後に再起動してください。

## 王室と最終決戦
100階の出口から「魔王城-王室」へ進みます。専用画像に合わせた1区画を、普段の探索と同じ操作で歩けます。途中で倒した勇者は現れず、生存者の傷は持ち越します。
勇者に近づくと会話が始まり、会話終了後はフィールドへ戻ります。もう一度近づくと最終戦です。
勝利後は会話を経て玉座へ歩くと結末を迎えます。全勇者を道中で撃退した場合にも専用の会話を用意しています。
敗北後はサイラーンが狭い王室で動けず倒され、リオネルが最終奥義「終頁返し」を発動します。サイラーンとの追加戦闘はありません。
100階の出口付近へ戻り、仲間のHP・MPを回復。決戦で使用した戦闘消耗品とGOLD、勇者の状態は決戦開始前へ戻します。道中の撃退や負傷、踏破記録は維持します。
旧版の王室画面で止まっていたデータも、再読み込み後に新しい王室へ進めます。

## クリア後
拠点へ戻って探索・育成を続けられます。ホームの王室入口から再入場できます。
玉座の「決戦の記憶」は健康な勇者4人との再戦です。本編の勇者記録は変更せず、使用した物資は勝敗を問わず返却します。初勝利で王室に称号「四勇を越えし者」を記録します。
既存の任意の輪廻も選べます。自動で周回を開始することはありません。輪廻の詳細と確認はゲーム内の既存画面に従います。

## 表示・探索の修正
- ホームの各キャラクターの属性ロゴを前面へ配置。
- 戦闘中の味方側の十神・深淵の拡大率を縮小。敵側の大型ボス表示は維持。
- 盾を薄い金色の追加ゲージへ変更。最大HPを基準に表示し、盾の有無でカードの高さが変わらない構成に変更。
- 勇者の物語画面右側に出ていた四角い重ね画像を除去。
- 通常探索の敵の魔法陣装着率を段階的に上げ、40階以降は全員装着。階層相応の魔法陣レベルを使用。専用構成の勇者戦は従来どおり。
今回のパッチはBuild359の勇者能力調整を維持しています。
