# Build421 / v3.1.100 — スキル選択画面の即時クローズ

**Build420（v3.1.99）へ上書きする差分ZIP。** ZIPの中身を、既存ゲームのindex.htmlがあるフォルダーへ同じ構成のまま上書きする。既存assetsなどは残す。再読み込み後にホームの表示がv3.1.100になったことを確認する。セーブ初期化は不要。

## 修正

スキルの使用が確定した時点で、選択画面を攻撃演出より先に閉じる。従来は内部のskillMenuだけをfalseにし、表示の更新が演出後になっていた。

通常スキル、勇者の専用スキル、深淵・十神の奥義、および冬眠などで行動を置き換える場合の表示を処理する。MP不足・クールダウン中など使用できない選択では一覧を残す。二重タップを止める既存の行動ロックは維持する。

スキル性能・消費MP・クールダウン・セーブ形式は変更しない。①〜③の統合修正も引き継ぐ。

## 検証

既存256件＋追加4件、合計260件の自動テストに成功。Build420へZIPを上書きした構成でも同じテストを実行した。

- 第一章・第二章で、スキル演出開始時に選択画面のHTMLが消えていることを確認。
- 演出を待っている間の二重タップでMP・ターンを二重消費しない。
- MP不足・クールダウン中は画面とターンを維持。
- 勇者・奥義の専用処理も、演出関数を呼ぶ前に画面を閉じる。

追加テストは本体のスキル処理とBattleScreenのHTML生成を使用する。専用スキルの表示順確認では能力処理を模擬する。実ブラウザー・iPhone実機での描画／タッチ確認は未実施。

記録はdocs/build421/、追加テストはtests/build421-skill-close.test.mjs。開発環境では `node --test tests/*.test.mjs` で再実行できる。
