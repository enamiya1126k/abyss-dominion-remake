# Build461 / v3.1.140 — 大きなコースを追いかけるレースカメラ

Build460までを含む累積上書き版です。ゲームの同名ファイルへ上書きして読み込み直してください。セーブ・サーバー保存データ・既存画像は残してください。Build459以降のサーバーは変更・再起動不要です。

Build458以前から更新する場合は、同梱のサーバーも更新・再起動し、新しい部屋を作ってください。新しい追尾表示は距離・周回に対応したルール7の部屋で使えます。

## 今回の修正

前回の、重なりを避けるために魔物の表示位置をずらす仕組みを撤去しました。点と線による位置表示も出しません。

**魔物を実際の走行位置へ置き、コース・柵・魔物を一つのカメラで映します。**

- 標準は「追尾カメラ」。コースは画面より大きく描き、集団が進む方向へカメラを動かします。
- 先頭・最後尾を含む全8匹の姿と番号札が収まるよう、位置と倍率を調整します。集団が広がると引き、詰まると寄ります。
- 魔物同士の重なりは許容します。各レーンの走行位置を保ち、空いた場所へ魔物を飛ばしません。
- 「コース全体」は任意の俯瞰表示です。追尾へ戻すと再び集団を追います。
- 「拡大表示」はブラウザ内を広く使う表示です。順位と操作ボタンを残し、結果へ進むと解除します。戻したときのスクロール位置も保持します。
- 500m・1000mの直線と、1600m・3000mの周回の両方に対応します。

## 新しいゲーム素材

画像生成ツール（built-in image_gen）で新規作成した3点を実際のコースへ組み込みました。

| ファイル | 用途 |
| --- | --- |
| `assets/race461/turf.webp` | 芝コースの路面 |
| `assets/race461/sand.webp` | 砂コースの路面 |
| `assets/race461/arena.webp` | 俯瞰の観客席、紫の旗、灯り、競技場の周辺 |

柵とスタート／ゴール線はコース座標に合わせて描画します。元の魔物画像は継続して使います。生成した画像はWebP形式に変換して容量を抑えています。生成時のプロンプト全文は `docs/build461/asset-prompts.json` に収録しました。

## 継続する改善

コンパクトな距離選択、システム出走の簡易ステータス、詳細記事の能力バー、パレード横のシンプルな三角ボタンはそのままです。5回の叩く操作、倍率、精算、報酬、近走履歴、なつき度のルールも変更していません。

## 検証

カメラの自動テストでは4距離・5画面寸法・4種類の集団の広がりを通して、24,080フレーム分の全8匹の表示範囲と座標を確認しました。カメラの滑らかな追従、コースが画面からはみ出す拡大、重なりを許容すること、元の位置データを変更しないことも確認しています。

ブラウザでは元の魔物画像を使い、追尾、コース全体への切替、縦・横画面の拡大、5回の操作、結果への遷移を確認しました。記録は `docs/build461/` に収録しています。実機iPhone Safariは未確認です。公開サイト・GitHubへの反映は行っていません。
