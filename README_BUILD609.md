# Build609 — 魔界渡りの暴走船

Build608に重ねる更新パッチ。アプリ3.1.288、魔界ランナーズ通信ルール19。

## 追加内容

コース一覧の魔王城の手前に「魔界渡りの暴走船」を追加。既存12コースの配置・内容を維持し、2人必須の魔王城は最後に置く。新コースは人間1〜4人、AIなし、制限600秒、全3航路、スター3個。

同じ船に乗り、砲弾・炎棒・振り子・吊り天井を避けながら島へ上陸する。島を攻略した後は、移動を続ける船へ飛び乗る。島の横では27秒間減速し、残り6秒で出航予告、その後に再加速する。画面右上と船の下に出航・帰還の残り秒数を表示する。

| 航路 | 島の攻略条件 | 帰還 |
| --- | --- | --- |
| 砲火を抜ける船出 | 階段状の浮島を登り、頂上の航路鍵に触れる | 反対側の足場から船へ戻る |
| 番兵島の追走 | 頂上の斧投げ番兵2体を倒す | 残り時間を見ながら帰還する |
| 封印灯台への最終便 | 頂上の封印装置を攻撃で破壊する | 船で最終桟橋へ到着し、ゴールする |

船首の台を踏んでいる間、後方に救援足場が出現する。複数人では先に帰った人が、遅れた仲間の乗船を補助できる。通常ジャンプだけで上陸・登頂・帰還でき、風属性や仲間ジャンプは必須ではない。星はさらに上の寄り道に配置する。

## 再挑戦・同期

- 島を攻略せず乗り続けても、次の航路やゴールは開かない。
- 死亡・乗り遅れ・島の攻略未完了は、現在の航路から船と参加者をまとめて再出発する。再出発前に短い猶予を設ける。
- 死亡・乗り遅れの本人のみ死亡回数を加算する。再出発に同行するだけの仲間や、単なる攻略時間切れには加算しない。
- 過去の航路の攻略と取得した星は維持する。現在の島の番兵と封印装置は戻す。
- 全員が中断した場合は船もゲーム時間も停止する。再開・再接続時は船の位置を共有する。
- 船の移動計算をサーバー・当たり判定・予測表示で共用する。攻略・次の航路・再挑戦イベントで状態を保存する。
