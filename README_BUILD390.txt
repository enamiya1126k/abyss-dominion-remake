更新方法
このZIPはBuild389 / v3.1.69へ上書きする差分パッチ。
単体で起動するゲーム一式ではない。Build388以前なら先にBuild389まで適用する。
1. ZIPを展開し、中身を既存の abyss-dominion-remake フォルダーへコピーする。
2. src・assetsなどを既存フォルダーへ統合し、同名ファイルを上書きする。
   srcの中へさらにsrcを作らないこと。
3. GitHub Desktopで変更を確認し、コミット → Push origin。
4. 公開更新後に再読み込みし、v3.1.70を確認する。
セーブ初期化は不要。所持魔物・装備・物語・鍵・宝物庫報酬を維持する。
新部隊に会うには進行中の戦闘を終え、拠点から踏破済み地域の再探索へ入り直す。

・氷絹の外套／MP16／再使用待ち3ターン：味方全体に最大HP12%の障壁、命中15%上昇（2ターン）。
攻略：単体凍結から双子の連撃を強化する。浄化や凍結耐性で粉砕の準備を崩せる。

専用ペア共鳴：今回3組、合計18組
同じ陣営で2人とも生存中、通常攻撃・固有技・支援技のあとに相方が連携する。
各キャラ1ラウンド1回、1組で最大2回。追加MPなし。追撃から共鳴は再発動しない。
同じキャラの複数個体、同ラウンドの蘇生やセーブ再開では回数は増えない。
戦闘不能・捕獲・隔離・追加行動の封印で停止。敵も同じ連携を使用する。

■ 双晶・氷紋粉砕（イゼル＋ヴィレル）
単体へ1.15倍×3連撃、防御25%無視。凍結中の標的には各打撃1.955倍。相方の攻撃・魔力の高い方で判定。先に氷紋で凍らせて粉砕する。

■ 双誓・黒盾紅剣（ロスティア＋アルテア）
単体へ物理1.70倍、防御20%無視。姉妹にHP18%障壁・被ダメージ25%軽減（2ターン）。この護誓中に攻撃を受けると、攻撃行動後に相方が攻撃者へ2.40倍の反撃（防御25%無視）。各姉妹の被弾につき1ラウンド1回、合計最大2回。反撃から反撃・共鳴は連鎖しない。

■ 双星・星門詠唱（セフィラ＋アストレル）
共鳴1・2回目は魔力を1つ蓄積し、生存味方全体にHP12%障壁。3回目は蓄積を消費して敵全体へ魔法5.50倍、防御35%無視、全体HP20%障壁。蓄積はラウンドをまたいで保持。各キャラ1ラウンド1回のため、最速で2ラウンド目に合体魔法。

双晶はイゼルが凍らせ、ヴィレルの大槌と3連撃で粉砕する。凍結の浄化・耐性が対策になる。
連撃中に標的が倒れた場合、次の生存敵へ切り替え、凍結による追加威力も判定し直す。
双誓は共鳴で姉妹に付いた「被ダメージ25%軽減」が反撃の条件になる。
障壁が全ダメージを吸収しても、攻撃が命中していれば反撃の対象になる。回避・毒などの継続ダメージは対象外。
反撃は攻撃行動後に相方が元の攻撃者へ返す。反撃の回数は通常の共鳴とは別枠で合計最大2回。
反撃前に姉妹が倒れる・捕獲される・部隊を離れる・隔離される・凍結や睡眠などで行動不能になると停止する。
攻撃者が既に倒れている場合や、被弾側の護誓が解除された場合も反撃しない。
双星は最初の2回は追加攻撃を行わず、魔力を蓄積して障壁を張る。3回目に5.50倍の全体合体魔法を放つ。
1組の共鳴は1ラウンド最大2回のため、合体魔法は最速でも2ラウンド目。発動後は蓄積0から繰り返す。
蓄積は戦闘中・ラウンドをまたいで保持。片方が倒れている間は増えず、再び揃うと再開できる。
味方と敵で蓄積は別管理。戦闘チェックポイントには蓄積・使用回数・反撃予約を保存する。
新支援役は、相方がHP32%以下なら有効な全体回復で救援を優先する。
