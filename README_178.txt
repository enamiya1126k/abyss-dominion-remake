ABYSS DOMINION REMAKE release178 / build237

これは release177 に上書きする「差し替え部分だけ」の更新です。
ゲーム全体は含まれていません。

主な更新:
- ギルド遠征予定から、主催者の現在のロビーで当日の集合を開始
- 予定作成者本人かつ、その部屋の部屋主・リーダーである場合だけ開催可能
- 予定30分前から予定2時間後まで開催可能
- 早めの開催は予定30分後まで、開始後の開催は原則30分、最長でも予定2時間後まで掲載
- ギルドメンバーは予定カードの「部屋へ参加」から1回の操作で参加
- 参加表明がなくても、同じギルドのメンバーなら参加可能
- 目的、遊び方、階層、メモはクライアント入力ではなく保存済み予定を使用
- 同一要求の再送、予定取消、期限切れ、切断、出発時の重複・残留を防止
- 集合情報はサーバーの一時情報だけで、guilds.jsonには保存しない
- 自動部屋作成、自動入室、自動出発、開催報酬は行わない

適用方法:
1. 更新前の `online-server/data/guilds.json` を別の場所へバックアップします。
2. ZIPを展開し、中の `abyss-dominion-remake-main` フォルダを開きます。
3. その「中身」を、release177適用済みの `abyss-dominion-remake-main` フォルダへ同じ階層で上書きします。
4. `online-server/data` フォルダと既存のJSON保存ファイルは削除しません。
5. オンラインサーバーを再起動します。
6. ブラウザを再読み込みします。

注意:
- ZIP内の階層を崩さずに上書きしてください。
- 差分ZIPには画像・音声などのゲーム素材、`online-server/node_modules`、実際の`online-server/data/*.json`は含まれていません。
- 集合を開始する前に、予定作成者本人がオンライン部屋を作り、その部屋の部屋主・リーダーである必要があります。
- 予定から新しい部屋を自動作成せず、プレイヤーを自動入室・自動出発させません。
- 参加時は所属ギルド、募集期限、空き枠、部屋状態をサーバーで再確認します。
- 開催・参加だけでアイテム、GOLD、魔晶石、週間共闘Pt、活動履歴などの報酬は発生しません。
- `guilds.json`はbuild236と同じversion 3、オンライン通信はprotocol 1.16.0、通常セーブはschema 58のままです。

詳しい仕様は BUILD237_GUILD_PLAN_GATHERING_UPDATE.md を確認してください。
