# Build552 — 人間ピンボール大運動会 / v3.1.231

Build551 適用済みの本体・online-server に重ねる差分パッチです。

## 今回の内容

- 専用の宝石カーニバル盤面、９種類の仕掛け画像、開幕／最終結果のイラストを追加。
- ３色の宝石ピンを集め、王冠に当たると共有プールから JACKPOT。
  勝者の宝石だけ消費し、他の選手はそのまま。王冠は大当たり後６秒で再チャージ。
- 全員の宝石ピンへの接触36回で、５秒間の得点２倍フィーバー。
- 回転バーは当たり判定付き。表面の動く向きと速度が、選手の勢いに伝わります。
- 2.3秒以内の衝突が連鎖。３連鎖ごとに加速し、連鎖得点倍率は最大２倍。
- 投資の能力に、各回の獲得点×15%×レベルの利息を追加。従来の配当も加算。
- MAXの強い発射を維持。高速時だけ減速が増え、上限速度に張り付く状態を緩和。
- 装備選択を下のトレイへ移し、選択前後で盤面の位置・大きさが変わらない構成に。
- 12種類の能力画像と真鍮のカード枠を使用。重ね取りと組み合わせの目安を表示。
- 宝石ごとに異なる衝突音、短い金属音、大当たりのファンファーレ。
- 大きく育った点数は対戦中の小さいスコア欄で「万」表示。最終結果は正確な点数。

8／16回を通して位置・勢い・能力・充電・宝石・壁倍率を維持します。
途中の結果画面はなく、最後だけ順位を表示します。未発射の選手も衝突対象です。
動かされながら引き、離すと、その時点の勢いに自分の発射が加わります。
引っ張りの表示は手元のグリップと短い方向マークだけ。未来の軌道・着地点は表示しません。

## 適用

1. 既存の Build551 をバックアップし、ZIP の内容を同じ階層へ上書きしてください。
2. 静的ファイル（index.html / src / assets / offline 関連）と online-server の両方を更新。
3. online-server を再起動し、参加者全員が本体を再読み込みしてください。

通信の `ricochetVersion550` と保存ルール `rules550` は 3 です。
古いクライアントは新ルールへ参加できません。旧ルールの保存対戦は準備画面へ戻り、
全員の準備OKから開始します。本体表示は v3.1.231 です。
公開サイトへのデプロイ、公開サーバーの再起動はこの差分作成には含まれません。

## 検証

以下のコマンドで、物理・新ギミック・通信・部屋管理・既存カート操作を検証できます。

```sh
node --test tests/build552-*.test.mjs tests/build547-cart-sling.test.mjs tests/build549-cart-physics.test.mjs
python3 tools/build552/static-check.py --baseline /path/to/build551
```

- 自動テスト69件：待機中の衝突、勢いの加算、MAXすり抜け、回転バー、ジャックポット排他、
  フィーバー、宝箱の復活、利息、全８／16回の持ち越し、通信の入力検証など。
- 実際の対象ゲームモジュール・入力・描画・クライアント受信処理・サーバー処理を接続。
  ４つのローカル WebSocket ブラウザで最終結果の一致と途中画面のない進行を確認。
- 320×690、390×664、430×932、844×390 の装備選択／対戦／結果を確認。
- 複数シードで８回の自動対戦を確認。新しい仕掛けが実際の衝突から発火することを確認。

この作業用環境は既存プロジェクトの部分構成です。対象外の依存はテスト用アダプターで
置き換えています。ゲーム本体全体の起動、実機 iPhone / Safari、公開ネットワークは未検証です。
検証結果と実行スクリプトは docs/build552 と tools/build552 にあります。
