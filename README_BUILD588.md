# Build588 / v3.1.267 — 魔界ランナーズ 操作・コース・描画の改善

Build587 適用済みの本体に上書きする差分ZIPです。

## 適用方法

1. ZIPの中身を、プロジェクトのルートへ同じフォルダ構成で上書きしてください。`src` と `online-server/src` の両方を更新します。
2. 本体の配信ファイルを更新し、`online-server` を再起動してください。依存パッケージの追加はありません。
3. 参加者全員がページを再読み込みし、v3.1.267 / Build588 にそろえてください。ランナーズの物理ルールが変わるため、Build587以前の参加者は準備・開始できません。

差分なので、空のフォルダへの展開では動きません。サーバーの保存データ・環境設定は含みません。GitHubへのpushと公開サイトの更新は行っていません。

## 変わったところ

- 方向ボタンを押した指を左右に滑らせて方向転換できます。中央は停止、外側へ大きく離すと移動を解除。もう片方の指でジャンプしたまま操作できます。
- 加速・ブレーキ・空中での方向調整を改善。短押しでも最初の穴を越えられるジャンプにし、長押しでは高く跳べます。足場を離れて125ms以内と、着地直前150msのジャンプ入力を補助します。
- 敵の配置と穴の間隔を調整し、敵を越えた先に着地する余地を確保。上昇中に敵の頭を越えた場合の接触判定も見た目に合わせました。
- 森に高い足場を追加し、宝石を取りながら穴を越える上段ルートを強化。バネの位置と中間の旗を調整し、スタートを含む6か所から再開できます。
- キャラクターを大きくし、足場の縁、石積み、甲虫、バネを描き直しました。森・遺跡・城の配色、着地の砂ぼこり、ジャンプ・着地の伸び縮みを追加しました。
- 進行方向を広く見せるカメラと、高いジャンプを追う縦移動を調整。加速の残り時間、画面外の仲間、ゴールまでの距離も表示します。
- ミスの理由を表示し、順位の同着判定を試合中と結果画面で統一。Shiftを離す順番によってキーボード移動が止まらなくなるケースも修正しました。

## 基本ルール

4人の横スクロールレースです。空席はAI。75秒制限、最初のゴールから残り16秒。ハートは3つで、なくなると脱落します。点数制ではなく、ゴールしたタイム順、未ゴールは最も進んだ距離で順位を決めます。

移動とジャンプを2本指で同時操作できます。PCは←→／A・D、スペース／↑／W。甲虫を上から踏むと倒してバウンドし、横から当たるとミス。バネは自動で跳び、緑の宝石は2.6秒の加速です。
