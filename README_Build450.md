# Build450 / v3.1.129

全体ランキングから、相手の保存済みパーティーとAI模擬戦を行えます。

- 既存の金・銀・銅のランキングカードを維持し、他プレイヤーの行に紫と金の「対戦する」ボタンを追加。カード本体からは従来どおり公開パーティーを確認できます。
- サーバーに保存された最後の編成・実ステータス・装備由来の効果・設定済みスキル・魔法陣を対戦用データとして取得します。相手本人のリアルタイム操作やプレイ傾向を再現する機能ではありません。
- 既存の戦闘画面・演出・手動操作・オートを使用。相手AIは回復、蘇生、強化、攻撃、MP、再使用待ちを判断します。切り札は既存の発動条件に従います。
- 模擬戦は何度でも挑戦できます。勝敗による報酬やランキング変動はなく、本編のHP・MP・所持品・GOLD・進行・育成結果は変更しません。戦闘終了後は活躍表と結果を表示し、ランキングへ戻ります。
- 100ラウンドを終えて決着しなければ引き分け。戦闘中は右上からいつでも終了できます。再読み込み時は模擬戦を破棄します。
- 対戦用データがない旧記録は「更新待ち」。相手が最新版で接続して編成を送信すると対戦可能になります。送信後は相手がオフラインでも挑戦できます。挑戦する側は相手データ取得のためサーバー接続が必要です。

## 更新方法

Build449以前の変更も含む累積上書きZIPです。ゲームフォルダーに展開して上書きしてください。**今回はゲーム本体とオンラインサーバーの両方の更新・サーバー再起動が必要です。** 永続データフォルダーやアカウントデータはZIPに含めていません。既存データを保ったまま更新してください。

更新後の表示バージョンは `v3.1.129` です。ランキング参加者が最新版で再接続するまで、旧記録には対戦用編成がありません。セーブ形式は84のまま、戦力計算式とランキングの順位計算は変更していません。

## 実装と確認

模擬戦は同一オリジンの独立したフレーム内で本編セーブのコピーを使います。SaveServiceは一時保存に切り替え、ストレージとWebSocketも本編から分離します。相手の公開データに本編セーブ、所持品一覧、認証情報を含めません。

新機能と現行の戦力計算テスト21件に合格。サーバー保存・再起動・旧記録読み込み、AIのMPと待ち時間、魔法陣の障壁と蘇生、100ラウンド制限を確認しました。Chromiumのモバイル設定で、実際のランキングボタンからの起動、勝利・敗北・撤退・途中終了、元セーブとストレージの不変、320/393/709px幅でのボタンと戦力表示の分離を確認しています。実機Safariでの検証は未実施です。

Build253の旧補助テストには更新前のBuild449でも再現する失敗が4件あり、全旧テストの合格は主張しません。現行仕様の検証結果は `docs/build450/browser-results.json` と `tests/build450-practice.test.mjs` を参照してください。

既存のランキングカード装飾と生成済みボタン画像を再利用しています。固定されたオンラインレイドのruntime430/runtime443は変更していません。
