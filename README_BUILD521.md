# Build521 / v3.1.200

Build520適用済みの完全なプロジェクトへ重ねる差分ZIP。単独では動作しない。

## 変更

- 落とす側は、床から脱出口まで全20段が最初から見える全体表示に固定する。拡大表示への切り替えボタンは出さない。生存者の高さによって盤面が上下に動かなくなる。
- 逃げる側は従来の全幅表示・追従カメラ・四角ボタンを維持する。任意の全体表示切り替えも維持する。
- フィールドを16段から20段へ、超ジャンプを５段から４段へ変更する。通常ジャンプ２段、再使用15秒、初回から使用可能、仲間の頭を踏み台にできる仕様は維持する。
- 単独の超ジャンプで脱出できる足場の目安は16段。15段からは届かない。通常ジャンプなら18段から脱出できる。空中での任意のジャンプ追加はできない。
- 高さ・超ジャンプ量を共通定義にし、物理、AI、封鎖判定、上限判定、予告、背景目盛り、全体図、残り段数に反映する。全体表示は上部54px以上を確保する配置とし、床を下部に収める。
- 塔ゲームの通信バージョンを4へ更新する。旧Build520の予測物理と混在しないよう、更新を案内する。

他のミニゲーム、〇×AIと問題集、戦闘、育成、所持キャラ、セーブ形式は変更しない。画像・音声の追加はない。

## 適用

1. 動作中の完全なBuild520をバックアップし、このZIPをルートに上書きする。
2. フロント側の index.html / src / Build521オフライン関連ファイルを反映する。
3. **サーバー側も online-server/src と共有のルート src を反映し、Nodeサーバーを再起動する。** online-serverフォルダだけの更新では不足する。
4. 全参加者が再読み込みする。アプリの表示版は v3.1.200。塔ゲームの通信バージョンは4。

旧対戦が保存されていた場合、再開時に新しい高さ・ジャンプ量へ移行する。Build520の超ジャンプ再使用時刻は維持する。進行中の対戦がないタイミングでの反映を推奨する。

## 検証とバランス

既存150項目と追加８項目、計158項目成功。AI100試合すべて終了、逃げる側６勝・落とす側94勝。

今回の設定は早期脱出を抑える方向であり、AI同士では落とす側が有利である。人間３人の協力プレイのクリア時間・勝率は未実測であり、最適な対人バランスを保証する結果ではない。

３人が初めから重なって同時に超ジャンプするケースでは、各１回ずつしか発動せず、20段へ即到達しないことを確認した。あらゆる協力手順に対する到達時間の数学的証明ではない。

実ブラウザー・実iPhone・物理マルチタッチでの再確認は未実施。DOMイベントはfixture、描画は製品描画コードをネイティブCanvasへ出力して確認した。

引き継ぎ元で欠けている species.js / endgameCharacters.js / MonsterVisual.js は、既存テストのメモリー内fixtureのみで補っている。製品用の代用品は含めていない。
