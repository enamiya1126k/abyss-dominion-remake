## 魔王

基礎HP48。既存の人数補正により2人70、3人91、4人113となる。第2形態は残HP2/3以下、第3形態は1/3以下である。警告時間は600→500→420ms、突進速度は240→260→280へ変化する（既存のHP半分以下の加速25を別途加算する）。ガード中の頭を踏んでも死亡せず弾かれる仕様を維持する。

弾、パンチ、踏みつけ、蹴った氷は同じ協力ダメージ判定を通す。同じ人の連射や1秒を超えた攻撃の組み合わせは無効である。仲間が離脱・待機中の場合も単独では結界を破れない。
