# ABYSS DOMINION — Build537 / v3.1.216

Build536へ上書きする更新パッチです。本体とonline-serverを同時に更新し、Nodeサーバーを再起動してください。各プレイヤーもページを再読み込みします。

## 海賊の隠れ港

- 魔王のかくれんぼを、2900×2900の広いランダムフィールドへ変更しました。
- 酒場・船長室・台所・倉庫・砲台・漁師の桟橋・作戦広場・昼寝の入り江・中庭の9エリア。部屋の配置、広さ、角の形、中央の接続、置き物の配置が毎回変わります。外周は一周でき、中央に2〜4本の近道があります。
- 宝箱、樽、木箱、ロープ、瓶、壺、やかん、麻袋、魚かご、腰かけ、ランタン、ヤシの鉢の12種類。場所に合った小物を約160個配置。大砲、ハンモック、机、武器棚、積み荷、かまども配置しました。
- 隠れる側は毎回ランダムな2候補から変身を選択。20秒の準備中に変更でき、開始後は固定。未選択なら左の候補になります。最初は集合地点にいるので、自分で紛れる場所まで移動します。
- 本番開始から30・60・90・120秒に、生存している隠れる側全員が2.4秒間揺れます。移動していても必ず発生。全体に位置を知らせる通知は出しません。揺れるまでのカウントを表示します。
- いつでも変身姿のまま移動できます。床タップで障害物を回り込む移動／スティック操作／矢印・WASD操作に対応。「止まる」で即停止します。
- 鬼・隠れる側とも移動速度は230、斜め移動でも加速しません。鬼は広めのカメラ・視認範囲で探索できます。大きな家具や陸地の角で視線が遮られます。
- 港の地図で通路と現在地を確認でき、床をタップすると移動できます。他チームの居場所は地図に表示しません。
- 鬼は12回の攻撃で3人全員を捕まえると勝利。150秒後に1人でも生存していれば隠れるチームの勝利。
- 旧ルールの「同じ場所に20秒」「自由な6種切替」「煙幕」「索敵」は、新しい変身・視界・周期的な揺れのルールに置き換えました。
- 海と大きな家具は通れません。小さな置き物は移動を妨げません。
- 空席と通信切断時はAIが担当。AIも同じ移動・衝突・視界ルールで行動します。

## 更新・継続

既存の育成データ、所持キャラ、ほかのミニゲームのルールは変更しません。進行中の旧Build536かくれんぼは、更新後にメンバー・キャラ選択・部屋を保ったまま準備画面へ戻ります。新しい準備OKで再開してください。新旧クライアントを同じ対戦に混在させないため、かくれんぼの通信バージョンを2へ更新しています。
