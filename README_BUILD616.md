# Build616 — 船から跳び降り、仕掛けを越えて、船へ戻る航海

アプリ 3.1.295 / ランナーズ通信ルール 24。
**Build613・614・615のいずれにも上書きできる累積パッチ**です。Build614の入室修正とBuild615の参加者側のカクつき対策も含みます。

## 今回の変更

- **誰かが甲板に着地した瞬間に出航。** 時刻による出航カウントダウンを廃止しました。次の島の船も乗船まで待ちます。出航後は、降りても止まらず、折り返しも再便もありません。
- **1区間目：振り子の海峡と炎の門。** 船の進路を横切る2本の振り子斧。炎の柱の手前で上空の足場へ移り、炎を越えて、進み続ける船へ戻る配置です。終盤には設置型の砲台もあります。
- **2区間目：砲台の谷と甲板の大岩。** 船は上昇してから谷へ下降。警告の後に敵が甲板へ落ち、着地後も船に乗って歩きます。大岩が甲板の右から左へ転がる場所では、上空の足場へ逃げられます。途中の足場にも敵がいて、後半には砲台と回転する炎があります。
- **3区間目：天空を昇る最後の航路。** 大きく上昇し、炎の門を上から越えた後、船が下降します。上の足場に残りすぎると船を逃します。斧、回転する炎、落下する敵、大岩も組み合わせています。
- 上空の足場は一部の区間だけです。各島から最初の退避足場まで大きな海の隙間を残し、風の連続ジャンプだけで次の島へ渡れないことを確認しました。全区間をつなぐ空中の道にはしていません。
- 航行中に飛んでいた従来の出所のない横弾・雨弾を廃止しました。砲撃は設置された砲台から発射されます。
- 宝星は引き続き任意です。島の「8秒以内の三連封印」「12秒以内の番兵戦」を維持し、最後の宝星は上昇・上空への退避・下降中の4つの輪を順番に取る配置に変更しました。通常ルートを進むだけでは4つの輪はそろいません。
- ゴールは本人の到達で成立します。船の到着、宝星、出航記録は条件にしません。中間地点で世界や画角を再初期化しません。
- 参加者の画面で船が止まって追いつく動きを減らすため、出航済みの確定した航路は短い通信途切れの間も同じ時刻で描画します。自分・他の乗員・甲板の敵・大岩を船と合わせます。全員が一時停止している部屋では止まります。長い切断時の予測は1秒で打ち切ります。

## 適用

今回は船の出航判定・上下移動・敵・当たり判定も変わるため、**本体とサーバーの両方の更新が必要**です。

1. Build613以降のプロジェクトのルートへ、ZIPの中身を同じ階層で上書きしてください。ルート直下の `src/` と `online-server/src/` の両方が対象です。
2. Web本体を公開先へ反映してください。
3. サーバー側にもこの更新を反映し、既存の運用方法で再起動してください。サーバーが共有するルートの `src/` も更新対象です。`online-server/` だけのコピーでは不足します。
4. 参加者全員がページを再読み込みし、ゲームを選び直してください。旧ルールで開始したランナーズの進行中データはそのまま継続できません。

本体とサーバーの通信ルールを24へそろえ、パーティーからのゲーム選択、入室、準備完了、ランナーズ画面の互換判定も更新しました。Build616専用のキャッシュを使用します。セーブ形式は変更していません。

このZIPの作成までを実施しています。公開サイトへの反映や稼働中サーバーの再起動は実施していません。

## 検証

- Node上の自動テスト **290件通過**。乗船判定、片道航行、上下移動、乗り遅れ、全員停止、保存・再開、落下する敵、大岩、宝星、ゴール、ゲーム選択、更新互換性、既存のボス・協力ギミック・通信描画を確認しました。
- 本番と同じ入力・物理・敵・当たり判定を使った自動操作で、スタートから3区間を通り、上空の足場へ退避して船へ戻り、**死亡0回でゴール**しました。敵や仕掛けの無効化、無敵化、途中の座標移動は行っていません。
- 別の自動操作で、最後の空中リング4つと宝星を取って、死亡0回でゴールしました。
- 島内の9つの足場間ジャンプも確認しました。
- 2人・4人分の乗員で、上下する船の物理計算と遅延した受信データを使用しました。通常90〜230msの遅延に加え、一時的にさらに600ms遅らせてまとめて届ける条件でも、乗員が甲板からずれないことを確認しました。この条件の60Hz描画における最大フレーム間移動は2.14ワールドピクセルでした。実機FPSの値ではありません。
- `docs/build616/voyage-preview.png` は自動操作中の状態を本番Canvas描画で確認した画像です。実機・Safariのスクリーンショットではありません。描画環境に日本語フォントがないため、この確認画像だけラベルを英語にし、HTML表示のアバター部分には既存素材を重ねています。ゲームの表示は日本語のままです。

iPhone Safari実機や、公開中のサーバーへ複数端末を接続した確認は未実施です。
