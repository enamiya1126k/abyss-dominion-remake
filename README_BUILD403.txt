ABYSS DOMINION — Build403 / v3.1.83
① 共通UI・スクロール修正

【適用方法】
Build402（v3.1.82）適用済みのゲーム用・差分パッチです。
ZIP内の index.html と src フォルダーを、ゲームの同じ場所へまとめて上書きしてください。
既存の assets やその他のファイルは必要です。このZIPだけでは起動できません。
反映後、ページを再読み込みし、ホーム画面の表示が v3.1.83 になったことを確認してください。
オンラインサーバー側の更新は不要です。

【今回の変更】
・共通モーダル内の紫色の丸いボタンを、既存の黒・金のフレーム素材へ統一。
  選択中は金色で示し、キャラクターやレア度の画像は従来どおり表示。
・共通モーダルの本文がスクロールする構造へ整理。閉じるボタンと見出しの重なりを解消。
・戦闘中のスキル一覧を、開いている間だけ画面下部に十分な高さのあるパネルとして表示。
  一覧の末尾までスクロールできる構造へ変更し、最後のスキルの下にも余白を確保。
・魔法陣の「新しい魔法陣3個を受け取る」を一覧の先頭に配置。
  一覧に隠れる独立した段をなくし、一覧内の各行が縮まないよう調整。
・ランキングはタブ下全体を一つのスクロール領域に変更。
  末尾の行を表示するための余白を確保し、更新・タブ切り替え時の位置を保持。
・ランキングの見出しと更新ボタンを一列に小型化。プレイヤー名と週間報酬の表示も圧縮。

【検証】
新規の操作ロジック・HTML出力の検証6件と、既存の関連検証14件、計20件に合格。
変更したJavaScript7ファイルの構文チェック、読み込み順・バージョン参照、ZIP整合性を確認。
iPhone/Safariの実機表示・タッチ操作と、ブラウザー上のレイアウトは未確認です。
詳細は TEST_BUILD403.txt を参照してください。

セーブキー・セーブ形式のバージョンは変更していません。
戦闘計算、ランキング順位の計算、魔法陣の価格や効果は変更していません。
