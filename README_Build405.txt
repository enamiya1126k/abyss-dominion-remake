ABYSS DOMINION — Build405 / v3.1.85
③ 戦闘表示・魔法陣の操作改善

適用方法
Build404 適用済みのゲームに、この ZIP 内の index.html と src/ の中身を同じ場所へ上書きしてください。
src/ フォルダを削除せず、中身を結合して上書きします。差分パッチなので、この ZIP 単独では起動できません。
更新後にページを再読み込みし、ホーム右下の v3.1.85 を確認してください。

修正内容
・敵カードの「装備6枠・レア度・装備Lv・装備強化値」を非表示にしました。敵の装備効果や能力計算は保持しています。
・味方／敵のペア共鳴を高さ28pxの1段に整理しました。長い情報は左右のスワイプで確認できます。
・共鳴欄と戦闘エリアを別のグリッド行に配置し、重なりを解消する構成にしました。
・戦闘更新時に、行動順と共鳴欄のスクロール位置を保持します。
・キャラの位置・サイズ調整後に、透明余白と左右反転を考慮して魔法陣をキャラの中心へ合わせます。
・魔法陣の明るさと輪郭を調整しました。「魔法陣なし」は控えめな表示です。
・第二章の BOSS 表示は1個とし、その隣にキャラクターの実際のレア度を表示します。
・GOLD強化で画面を開き直さず、押したボタンとスクロール面を保持してレベル・次回費用・所持GOLDを更新します。
・1タップにつき1段階、最新の費用で強化します。所持GOLD不足とLv.99ではボタンを無効にします。
・装着変更や研究受取も同じ画面内で更新します。保存失敗時はGOLD・レベル・装着状態などを戻し、その場で再試行できます。
