可愛い顔と約4頭身、精緻な金装飾、黒金のフードと白金の聖鎧の雰囲気を引き継いで7体を追加しました。

更新方法
このZIPはBuild388 / v3.1.68へ上書きする差分パッチです。
単体で起動するゲーム一式ではありません。Build387以前なら先にBuild388まで適用してください。
1. ZIPを展開し、中身を既存の abyss-dominion-remake フォルダーへコピー。
2. src・assetsなどを既存フォルダーへ統合し、同名ファイルを上書き。
   srcの中へさらにsrcを作らないでください。
3. GitHub Desktopで変更を確認し、コミット → Push origin。
4. 公開更新後に再読み込みし、v3.1.69を確認。
セーブ初期化は不要です。所持魔物・装備・物語・鍵・宝物庫報酬を維持します。
新部隊に会うには進行中の戦闘を終え、拠点から踏破済み地域の再探索へ入り直してください。

届かなかった手紙から生まれた封書の精霊。封樹に絡む呪いを小剣でほどき、忘れられた言葉を持ち主へ返す。

・封蝋をほどく剣／MP13／再使用待ち3ターン：生存味方全体の状態異常と弱体を浄化。

・風筆の追い書き／MP10／再使用待ち1ターン：風属性1.15倍。命中低下中には威力1.35倍。
攻略：低ランクでも全体浄化を持つ支援役。浄化の再使用待ちを狙って弱体を重ねる。

境界の森・再探索「西の封印樹」
封印樹の陰に咲く藤から生まれた双子の姉。呪毒を編んだ鎖で逃げ道を閉じ、妹エルミナが断つべき根を示す。
・藤影・呪毒の鎖／MP12／再使用待ち2ターン：闇属性1.00倍。85%で毒を3ターン付与。
・藤鎖の縫い留め／MP14／再使用待ち2ターン：闇属性1.05倍。回避18%低下（2ターン）。
・鎖刃の引き裂き／MP14／再使用待ち1ターン：闇属性1.30倍。毒状態の敵には威力1.45倍。
・影藤の外套／MP15／再使用待ち3ターン：自身に最大HP16%の障壁、回避18%上昇（2ターン）。
攻略：毒を入れてから双子の連撃を強める。毒を治すか、鎖役を先に捕獲・撃破して連携を断つ。

SR 白藤の鎌姫エルミナ
境界の森・再探索「西の封印樹」
白藤の花に宿る双子の妹。姉の鎖が縫い留めた呪いを、大きな翠鎌で根元から刈り取る。
・白藤・呪根刈り／MP16／再使用待ち1ターン：風属性1.45倍。毒状態の敵には威力1.50倍。
・花鎌の旋風／MP19／再使用待ち2ターン：敵全体に風属性0.90倍、防御20%無視。
・枯れ藤の切断／MP16／再使用待ち2ターン：風属性1.10倍。受けるHP回復30%低下（2ターン）。
・白藤の覚悟／MP17／再使用待ち3ターン：自身に最大HP16%の障壁、攻撃18%上昇（2ターン）。

天律の聖域・再探索「因果の聖壇」
天律の雷を槍へ閉じ込めた蒼き姉。妹ソレーヌの盾が避雷針となるとき、ふたりの雷は天空を穿つ一条へ変わる。

・雷槍の散華／MP26／再使用待ち2ターン：敵全体に雷属性0.95倍、防御20%無視。

中枢の閉じた記録を守る冥鍵の姉。妹エリゼルと対になる鍵剣で、偽りの加護だけを選んで断ち切る。

記録の門を開く聖鍵の妹。失われた王冠を受け継ぎ、姉の鍵剣と同時に回すことで中枢の封界を解く。
・聖鍵・静謐の勅令／MP29／再使用待ち2ターン：光属性1.15倍の魔法攻撃。攻撃22%低下（2ターン）。

・聖鍵の解呪／MP28／再使用待ち3ターン：生存味方全体の状態異常と弱体を浄化。
攻略：攻撃低下で姉の強打を助け、障壁・回復・浄化で連携を維持。蘇生封印と回復阻害を使い分けて二人を分断する。

専用ペア共鳴：今回3組、合計15組
同じ陣営で2人とも生存中、通常攻撃・固有技・支援技のあとに相方が追撃します。
各キャラ1ラウンド1回、1組で最大2回。追加MPなし。追撃から再発動しません。
同じキャラの複数個体、同ラウンドの蘇生やセーブ再開では回数は増えません。
戦闘不能・捕獲・隔離・追加行動の封印で停止。敵も同じ連携を使用します。

■ 双藤・毒鎖の刈舞（ネヴィア＋エルミナ）
相方が単体へ物理1.10倍×3連撃、防御20%無視。毒状態の敵には各打撃1.76倍。命中した敵の受けるHP回復25%低下（2ターン）。毒を先に付けると大幅強化。

■ 双雷・天穿の連星（カリスタ＋ソレーヌ）
1回目は敵全体へ物理2.00倍、全体にHP8%障壁・速度15%上昇（2ターン）。同ラウンド2回目は「天穿の終雷」：全体4.40倍、防御35%無視、HP18%障壁。同じキャラの複数個体では2回目を発動できない。

■ 双鍵・封界解放（メリオラ＋エリゼル）
最初の対象の解除可能な強化を1つ剥がし、相方が単体へ1.10倍×4連撃、防御40%無視。高い方の攻撃・魔力を使用。生存味方全体HP12%回復・HP14%障壁。倒すと残りの打撃は別の生存敵へ。

双藤は先に毒を付け、エルミナの大鎌と連携の3連撃へつなぐ編成です。
毒の浄化で追加威力を抑えられます。回復阻害は命中した標的だけに付与します。
双雷は同ラウンドの2人目の連携で大技を放ちます。カリスタ／ソレーヌの行動順は問いません。
連携の状態表示には「次は双雷・天穿の終雷」と実際の大技名を出します。
双鍵は最初の標的の強化を1つ解除して4連撃。倒すと残りの打撃を別の生存敵へ向けます。
回復阻害・片方への集中攻撃・行動封印が対策になります。
新ペアの味方オートは相方がHP32%以下なら、有効な全体回復で救援を優先します。
全体回復・障壁は生存者のみ。連携の支援効果は同じ効果を無限加算しません。
