release179 差分パッチ

対象: release178 適用済みのゲームフォルダ
内容: release178 から変更・追加されたファイルだけ
削除対象: なし

ZIPを展開し、中の`abyss-dominion-remake-main`フォルダの「中身」を、release178の同名フォルダへ階層を保ったまま上書きしてください。
ゲーム全体の再配置は不要です。

更新前に確認すること:
- release178が適用済みであること
- 進行中の交換を終え、オンラインサーバーを停止する
- `online-server/data`フォルダ全体を別の場所へバックアップする
- `online-server/data`フォルダと既存JSONを削除しない
- 上書き後にオンラインサーバーを起動する
- ブラウザを再読み込みする

この差分ZIPには、画像・音声などのゲーム素材、利用中のオンライン保存データ、`online-server/node_modules`、実行時生成物、一時ファイル、旧差分マニフェスト、ZIPファイルを含めません。

build238では、ギルド遠征の30分前と集合開始中をゲーム内で案内します。同じ予定・同じ段階のトーストは端末ごとに1回だけで、OS通知、通知音、自動入室、自動出発は行いません。主催者は集合だけを終了でき、遠征予定と参加表明は残ります。

交換の受渡し状態と未受取報酬は、既定の`online-server/data/settlements.json`へ原子的に保存します。サーバー再起動後も未確認側だけを同じIDで復旧し、端末キーと再接続キーは照合用ハッシュだけを保存します。保存先を変える場合は`SETTLEMENT_STATE_FILE`を指定してください。

詳しい変更は README_179.txt と BUILD238_GUILD_REMINDERS_AND_SETTLEMENT_DURABILITY_UPDATE.md を確認してください。
