# Build445 / v3.1.124 — 育成差が伝わる戦力表示

Build444までを含む累積上書きZIPです。既存のゲームフォルダへ、フォルダ構成を維持して上書きしてください。新規インストール用のリポジトリ全体ではありません。

## 変更

表示用の戦力を、各キャラクターの旧戦力を基準に `四捨五入(旧戦力²÷100)` で算出します。総戦力は新しい各キャラクターの戦力を合計します。能力値の0.32乗による圧縮を0.64乗相当へ緩め、育成差を数字に反映します。到達階層だけによる水増しは行いません。

参考画像の4人は、次の表示になります。

| 旧戦力 | 新戦力 |
|---:|---:|
| 5697 | 324558 |
| 5408 | 292465 |
| 6060 | 367236 |
| 6487 | 420812 |
| 合計 23652 | 合計 1405071（表示：140.5万） |

- 6桁までは数字をそのまま表示し、大きな値は「万・億・兆」で表示します。
- ホーム、編成、装備、探索、戦力記録、オンラインランキングで新基準を使用します。
- ランキングは保存済みの各メンバーの旧戦力から正確に換算して並べ直します。未ログインのプレイヤーも対象です。
- 旧基準の自己ベストと履歴は「旧基準の戦力記録」へ保存し、新基準の自己ベストを現在の編成から開始します。過去の総戦力だけでは各メンバーの内訳を復元できないため、推定値で履歴を書き換えません。
- 更新前のサーバーや古いオフラインキャッシュのランキングには「旧基準」を表示します。サーバー更新後の取得で新基準へ切り替わります。
- HP、攻撃力、ダメージ計算など実際の戦闘能力は変更しません。オンラインの戦闘用プロフィールの戦力値も従来どおりです。
