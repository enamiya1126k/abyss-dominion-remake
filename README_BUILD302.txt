ABYSS DOMINION REMAKE — Build302 緊急修正パッチ
=================================================

対象
----
Build301 にのみ適用してください。

適用方法
--------
ZIPを展開し、中にあるファイルとフォルダーをBuild301のルートへそのまま上書きしてください。
ブラウザ側と online-server 側は必ず同時に差し替えてください。

※ online-server/data はこのパッチに含まれていません。既存のセーブ・部屋・フレンド等の運用データは上書きしません。

バージョン
----------
App: 3.0.2
Build: 302
Save schema: 72

修正内容
--------
1. ボス討伐状態の保存
   - 討伐結果を階層進行の正本として保存します。
   - 古い探索スナップショットでボスが復活しないよう照合します。
   - 保存失敗時は勝利画面から離脱させず、保存を再試行できます。

2. 戦利品宝箱は鍵3本必須
   - 鍵が0～2本の間は開封できません。
   - 3本をまとめて消費し、1回だけ報酬を受け取ります。

3. 二重取得防止とBuild301旧データ救済
   - オフライン・オンラインの両方で、報酬付与と取得済み台帳を一体で確定します。
   - 再接続、再入場、画面再読込、演出エラーでも再取得できません。
   - Build301で途中まで解錠していたデータは、取得済みの欠片分を保持したまま3鍵式へ移行します。
   - すでに完全取得済みのデータは取得済みとして復元します。

4. 攻略率100％の誤表示修正
   - 古い探索率ではなく、その予言日の実際のボス討伐数を表示します。
   - 未討伐の旧汚染データは100％扱いにしません。

5. 自動攻略ボタン復活
   - 探索画面に「自動攻略」を復活しました。
   - 鍵、未探索区画、ボス、戦利品宝箱、温泉、次階層の順に判断します。
   - 手動操作や帰還で安全に停止し、旧AUTO設定も新方式へ移行します。

6. 閉じられないカジノ修正
   - 右上×、下部の閉じる、背景タップ、Escapeで閉じられます。
   - iPhoneのセーフエリア内に×を固定し、閉じた後の画面位置とフォーカスを復元します。
   - スピン中の多重操作と、閉じて再度開いた際の処理競合を防ぎます。

検証
----
- Build302専用・Build301/300互換テスト: 110 / 110 成功
- ESM構文検査: 108ファイル成功
- 全履歴テスト: Build301基準から新規回帰なし
- Build301への上書き適用後、対象ファイルの完全一致を検証済み
