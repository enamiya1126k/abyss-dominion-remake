# ABYSS DOMINION — Build440 / v3.1.119

Build439までを含む累積上書き版です。Build424以降の既存ゲームフォルダーへ適用します。

## 更新方法

1. 現在のゲームフォルダーとセーブをバックアップします。
2. ZIPの中身を既存ゲームフォルダーへ上書きします。既存素材・セーブ・サーバーの `data/` と設定ファイルは残してください。
3. `online-server/` と同じ階層の `src/` も更新し、Nodeサーバーを通常の方法で再起動します。HP変更はサーバー再起動時に反映されます。
4. 公開先を更新して画面を再読み込みし、バージョン **3.1.119** を確認します。

このZIPは単独起動版ではありません。公開中のゲームには自動反映されません。

## 今回の変更

- **スキル選択の見切れを修正。** 一覧のスクロールをひとつにし、長い効果説明・熟練度・MP・CT・SLOT表示をカード内に収めました。十神I「時間」の最後のスキルまで表示して選択できます。カテゴリ絞り込みと別SLOTの重複禁止は維持しています。
- **レイド3体の最大HPを一律50,000,000へ変更。** 新しいボスにも、現在進行中のボスにも適用します。既に削ったHP・消費したシールド、累計ダメージ、ランキング、残り挑戦回数を保持します。例えば最初の蘇生前に14,550,631削っていた場合、残HPは35,449,369です。
- **既存のレイド魔法陣は維持。** 1体目は一度だけHP70%で蘇生、2体目はHP相当のシールドがあります。そのため開始から必要な総ダメージは、それぞれ最大8,500万・1億、3体目は5,000万です。参加人数と与ダメージで討伐日数が変わり、3日を保証する調整ではありません。
- HP縮小時点で十分なダメージが蓄積していた場合は討伐扱いで次のボスへ進みます。順位報酬は従来どおり確定し、移行処理に架空の「最後の一撃」は付けません。取得済みオフライン挑戦権は元の戦闘条件で再現・送信でき、未送信分の報酬待ちと二重反映防止も維持しています。
- **属性相関図を見やすく。** 既存の属性アイコンを使い、火→氷→風→土→雷→水→火を色付きの太い矢印で表示。光と闇は下段で相互の矢印にしました。ホームには新しい枠を足さず、部隊編成バナーに重ならないよう画面の高さに合わせます。倍率・属性相性のルールは変更していません。
- **設定画面を黒と金の専用素材で更新。** ヘッダーと各パネルを整え、名前の入力欄と保存ボタンの余白・幅を調整しました。
- **召喚画面に専用背景を追加。** モンスター召喚、装備召喚、専用装備契約、経験値パックを別々の絵で区別。祭壇の既存キャンペーンバナーと同じ絵を重ねて使う状態を解消し、特別召喚の説明パネル・曜日表にも対応する背景を入れました。価格・提供割合・開催曜日は維持しています。
- **記憶の間・戦闘の記憶・予言録を更新。** 3つの入口に異なる専用背景を用意。敵編成カードや消費魔晶石の表示を整え、予言録には章別の背景を追加しました。戻る矢印の崩れと読了数の折り返しも修正しています。

Build439の鍵交換、召喚回数・排出レベル、捕獲結晶育成、ランキング、役割おすすめからの編成変更は引き続き含まれます。4対4・奈落回廊のゲームルールと報酬は変更していません。
