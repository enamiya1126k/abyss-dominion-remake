## 初戦
初めての捕獲対象をSR「月喰狼ディアヴォルグ」（闇属性・Lv.1）へ変更。傷を負った狼として出会い、チュートリアルの戦闘時だけHP26、攻撃4、防御2へ調整します。通常個体や捕獲後の仲間の能力は変更しません。
敵HPを6倍にしていた処理を廃止。初戦専用の敵は防御や回復で引き延ばさず通常攻撃します。「通常攻撃→予見の一撃→捕獲」の3操作で終わる案内です。初回捕獲は成功率100%、捕獲結晶1個。倒し切っても初捕獲まではHP1で踏みとどまり、取り逃しを防ぎます。
既に保存されている旧チュートリアル戦も、再開時に残HPの割合と敵IDを保持して新しい敵へ変更します。初捕獲済みのプレイヤーへSRを再配布するパッチではありません。

## リオネル専用「予見の一撃」
Lv.1から習得。無属性・物理威力2.8倍、必中、防御25%無視、MP4、CT1。敵の動く先を読む預言者の技です。
リオネル本人の物語識別情報で判定し、普通のスライムには付与しません。新規開始では初期スキル枠に設定。既存のリオネルも習得し、設定済みの技に空きがあれば一度だけ追加します。全解除済み・4枠設定済みの場合は編成を維持し、スキル編集から選べます。プレイヤーが外した技を再設定する処理はありません。
