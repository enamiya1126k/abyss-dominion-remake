# ABYSS DOMINION Build526 / v3.1.205

「ぬし釣り大騒動」の魚影・奥行き・ヌシ争奪・視覚合図・AIを調整した差分。**Build525適用済みプロジェクト専用**です。単独の完全版ではありません。

## 変更点

- 魚影を楕円と三角形から、実際の魚の輪郭・ひれ・尾を持つ透過素材に変更。水中の色になじませ、尾を小さく動かします。ヌシも水面を覆う大きさを廃止し、最も手前でも横幅は画面の18.5％以下です。
- 既存の池の岸に沿った投げ入れ範囲を、対岸付近まで拡張。魚影・浮き・波紋は奥ほど小さくなり、取り込みで手前に近づくほど大きくなります。魚の本当のサイズと遠近感は別なので、奥の大物が手前の小魚より小さく見える場合があります。
- ヌシは**１試合に最大１匹**。出現抽選65％、出現時刻は開始42〜92秒の間でランダム。35％の回は出現しません。16秒間だけ狙え、先に掛けた人が挑戦します。釣り上げ・逃走・見逃し後の再出現はありません。
- 前版の「90秒で２つのヌシ魚影が出現し、６秒後に再び狙える」仕組みを廃止。同時入力はサーバーが受け取った投げ入れ順で処理し、巻く操作の通信が後から来ても順番を保ちます。AIの判断前に受信済みの人間の投げ入れを処理します。
- 巻く／緩めるの判断を水面へ移動。糸が張ると竿がしなり、糸が直線に近づいて震えます。予兆・暴れ時は橙色、限界では赤色と三角の警告。浮きのそばの外向きの印は「離す」、小さな巻く矢印は「巻く」を示します。色だけでなく形と動きも変えています。
- 浮きの周りに取り込み進行の弧を表示。下部の動的な説明とゲージを見続けなくても遊べます。２つの大きな操作ボタンは維持し、対応ボタンも控えめに強調します。
- 自分の釣果を手前へ引き上げ、中央で見せてから足元へ降ろす演出へ。通常2.1秒、ヌシ2.8秒。自分の釣果を最後に描くため、同時に釣れてもほかの魚に隠れにくくなります。
- AIを下方修正。反応の遅れ、次の一投や確保までの間、時々の操作ミスを追加。ヌシ発見後も最低2.6秒は待ち、即座に奪いません。人間と魚・得点・竿の性能は同じです。

魚種32種類、長靴からの連鎖、黄金魚、ルアー、エサ専用枠は維持しています。追加の実行用画像は17,252バイトの魚影１枚です。元の背景・釣果画像は再利用します。

## 適用

1. Build525適用済みの元プロジェクトへ、ZIPを相対パスのまま上書きします。
2. 本体の `src/`・`assets/`・`index.html`・Build526のオフラインファイルを反映します。
3. **online-server側も更新・再起動**します。サーバーが参照するプロジェクトの `src/fishing/`（新しいWater526.jsを含む）も必要です。
4. 参加者全員がページを再読み込みします。釣り通信は `fishingVersion524:3`。古いクライアントは更新が必要です。

対戦のないタイミングで適用してください。旧保存データでは、進行中の取り込みと得点は保持し、再利用可能なヌシ魚影を取り除きます。旧版で既に複数人が掛けていたヌシまで取り上げることはしないため、その旧試合だけは複数匹の取り込みが完了する場合があります。新規試合は最大１匹です。
