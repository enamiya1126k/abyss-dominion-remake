## 変更点

### 魔王のせまりくる壁

- 床全体に出ていた安全エリア、進路の矢印、すき間の補助表示を削除。壁が来る方向の予告は残しています。
- 足元の当たり判定の半径を約35％縮小し、壁の端にも余白を設けました。見た目が少しかする程度なら助かりやすくなります。壁の中心への接触や、ダッシュでのすり抜けは引き続き脱落です。
- 壁を赤黒い金属と大きなトゲに変更。接触時は衝撃、吹き飛び、破片、OUT表示、脱落バナーが出ます。画面の揺れは「視差効果を減らす」設定に対応しています。

### まわせ！魔王の回転寿司

- 箸が届く範囲を、自分の色の太い帯と両端の線で表示。届く皿を光らせ、範囲外は控えめに表示します。
- 下部の「のび〜る箸」ボタンと遠距離取得を廃止。AIも同じ範囲で皿を取ります。
- 注文３皿の完成ボーナスを **90点から180点へ**。普通の注文皿３枚なら、皿の得点60点と合わせて240点です。
- フィーバーでは皿の得点が２倍。完成ボーナス180点はそのままです。
- 寿司が並ぶ帯の縦横比、金皿の飾り、空いた皿のタップ処理を調整しました。

### 早押し！魔王のイス取り

- シャッフル時の効果音を削除。音楽はそのまま続き、停止の合図と区別できます。
- 音楽の音符を先に予約し、短く重ねることで、途中の無音を停止の合図と間違えにくくしました。
- 取れなかったときに別のイスへ再入力できるまでの待ち時間を短縮。押したときの反応も追加しました。
- キャラクターの移動描画とサイズ計測を見直し、空席・金席・「座れ」の表示を強調しました。
- 停止直前の金席へのフライングが、通信の処理順で無視される場合も修正しました。

### ぐつぐつ！溶岩ステップ

- 足場を背景透過の岩盤画像に差し替え。安全な岩は落ち着いた石肌、危険な岩は赤い溶岩のひびで区別できます。
- 足場番号、得点、危険／安全ラベルと選択の印を維持。小さい画面でも端の岩が切れないよう配置を調整しました。
- 選択の秘密、噴火の抽選、山分けなどのルールは従来通りです。

### 魔王のエレベーター

ゲーム選択一覧から外しました。大幅な再設計が必要と判断し、今回は好評だった４ゲームを優先しています。進行中の部屋を壊さないため、旧ゲームの処理・素材は残しています。ファイル削除の操作は不要です。
