Build509 (v3.1.188) からの差分パッチ

更新方法
1. 現在のゲームフォルダーとサーバー状態ファイルを退避する。
2. ZIPの中身をBuild509のゲームフォルダーへ上書きする。
3. 公開側の本体と、Nodeサーバー側の online-server/ および共通 src/ を更新する。
4. Nodeサーバーを再起動する。
5. 参加者全員が再読み込みする。表示バージョンは v3.1.189。
サイトへの公開・サーバーへの反映は行っていない。既存Build509一式に重ねる差分。

今回の変更
・「積んだぶんだけ、ぶっ飛ぶ。／発進前のパワー」の計算画面を削除。
・新しく作った部屋と再戦では計算画面の3秒待ちも省略。全8回で合計24秒短縮。
・通常のレース画面は、自分の前後1,000m（合計2,000m）を映す固定カメラ。
・自分は横方向の中央。全員を1画面へ押し込んだり、遠くのキャラを端に固定しない。
・1,000mより遠い相手は、小さな丸い魔物アイコンと矢印、実際の距離差で案内。
  例：5,000m先、1,500m後ろ。
・距離が縮まると相手が画面へ入り、自分の横を通り、離れると画面外へ出る。
・相手側の画面では、その逆方向の相対移動として表示される。
・通常の追い抜きは実際の距離差そのまま。極端に高速で瞬間的な通過には、短い残像を追加。
  残像は最大260msの視覚効果であり、実際の距離・順位を変更しない。
・背景・距離の線・数字を同じ世界座標で流す。背景の移動を6,000mで制限していた処理を廃止。
・500m間隔の目印を配置。線と数字は同じ要素として移動する。
・手前の景色は速く、遠景はゆっくり流れる。後退時は流れる向きも逆転する。
・走行・中継の間だけrequestAnimationFrameで連続描画。静止場面は従来どおり更新を抑制。
・画面が非表示になったとき、退出時、演出終了時は連続描画を停止する。

大きな距離でも正確に
自分と相手の差、カメラと目印の差を固定小数点の整数で計算してから画面座標へ変換。
累積距離が非常に大きくても、近くの相手の1m差を潰さない。
背景は座標を画像の繰り返し幅で余り計算して描くため、巨大な描画領域を作らない。
巨大な絶対距離の目印は末尾6桁を「…001500m」のように表示し、位置の違いを読めるようにする。
HUDと最終結果の大距離表示はBuild509を継続。

維持したもの
28種類のアイテム、継続装備20種類、抽選、性能、成長・重複、防御・反射、手札の非公開、
8ラウンド、距離計算、同順位、キャラクターと競技場の素材、共有される攻撃中継を維持。
Build507/508のレースは従来の表示・ルールを使用。
Build509の保存済みレースは元の時間割のまま再開できる。旧計算画面は新クライアントで表示しない。
新規部屋・再戦から計算の待ち時間もなくなる。
ゴリラなど他のミニゲームの配置・ルール・軽量化処理は変更しない。

確認範囲
iPhone Safariの実機表示・操作感・FPSは未確認。
この環境のブラウザーでは開発画面への接続がERR_BLOCKED_BY_CLIENTとなるため、実画面確認は行えていない。
今回のDOM検証と座標検証は、実機の見え方・滑らかさを保証するものではない。
不足している既存モジュールはテスト実行時のみメモリー上で補う。配布用の偽モジュールは追加していない。
