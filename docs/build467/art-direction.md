# Build467 素材設計

すべて組み込みの画像生成ツールで制作。以下は制作意図と組み込み方法の記録です。

| ファイル | デザイン | ゲームでの使用 |
| --- | --- | --- |
| assets/sugoroku467/world.png | 月の森、青い結晶洞窟、溶岩の要塞、紫の王城を結ぶ縦長の石畳。橋・階段・崖を織り込んだ暗いファンタジー世界 | 生成後の実際の石畳をトレースし、Adventure467.jsのROAD467へ。背景と80マスを同じ座標系で配置 |
| assets/sugoroku467/card-back.png | 黒曜石、紫の宝石、金細工、天球儀の文様。ABYSS DOMINIONのプレミアムカード裏面 | 相手のドロー・奪取候補を含む全裏面に共通使用。カードのランクや属性に応じて柄を変えない |
| assets/sugoroku467/card-frame.png | 金属の透かし彫り、宝石、王冠をあしらった縦長の額縁 | CSSで縁を抽出してカード表・詳細・公開演出に使用。文字と数値は画像に焼かず、ゲームの値を重ねる |
| assets/sugoroku467/dice.png | 象牙と金、紫の目を使った立体サイコロ。透過背景 | 自分でタップする入力と回転演出。確定した出目はサーバー値の目に切り替える |
| assets/sugoroku467/curse.png | 紫黒の霧、雷、暗い瞳が迫る呪いのフレーム | 公開された悪い速攻の発動時だけに使用。保持中の非公開カードには使わない |

カード固有のイラストは既存素材を引き続き使い、今回の装飾枠・ランクの面色・属性の外枠で統一しています。新たな画面演出は「動きを減らす」設定に対応し、強い反復点滅は使っていません。
