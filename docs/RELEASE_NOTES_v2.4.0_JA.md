# ABYSS DOMINION REMAKE v2.4.0 リリースノート

リリース日：2026年8月11日  
基準：`abyss-dominion-remake-main 130(1).zip`  
セーブスキーマ：`49`（旧セーブキーを維持）

## 概要

130版を基準に、引き継ぎ監査で確定した機能修正、追加キャラクター、画像再制作、UI修正を統合しました。既存セーブの最高到達階やクリア実績をGM出発権限で書き換えないこと、手動探索の従来挙動を維持すること、延期指定のオンライン機能へ着手しないことを守っています。

## 管理コード

- 既存8シリアルを維持し、新規9シリアルを追加。合計17種。
- 深淵鍵1,000、捕獲結晶50,000、深淵／十神の武器・防具・アクセ各1、ランダムLR／神話／深淵／十神、限定チャッピー報酬を追加。
- GM支援はEXP結晶10,000、魔晶石100,000、GOLD100,000,000、深淵鍵1,000、捕獲結晶50,000、深淵／十神装備各12、十神4体。
- GM出発権限は1〜9998階だけを解放し、最高到達階・現在階・9999階・10000階を変更しません。
- GM RESETは専用コード、文字列`RESET`、最終確認の三段階です。

## 探索・戦闘

- 自動探索の戦闘結果を約1秒で閉じ、同じ方針で自動再開。
- 自動探索メニューのちらつき・再表示を抑止。手動探索は従来どおり。
- ×1時の属性帯表示を1.5秒＋フェード0.5秒、スキル／状態表示を最低1秒、ダメージ表示の進行待ちを1秒へ統一。
- 敵は内部MPを持ち、特殊行動で消費し、MP不足時は通常攻撃へ切り替えます。敵MPバーは表示しません。
- 敵AIへ回復、蘇生、強化解除、状態異常、MP吸収、役割判断、集中攻撃、隊列、MP温存を追加。未来の行動予告は廃止しました。
- 裏街スロットは魔晶石100個、1倍なし。倍率帯と確率を確定値へ統一しました。

## 育成・チュートリアル

- なつき度を最大1000へ拡張し、100刻みで能力効果を解放。1000で「親友」表示。
- 通常勝利+2、ボス勝利+5、通常敗北-1。合成・限界突破・一括統合では素材を含む最高値を継承します。
- 1〜5階に探索、戦闘、回復・捕獲、属性、3種自動探索の段階チュートリアルを追加。
- 初回敗北で無料モンスター召喚1回と編成・装備・休息・スキル指南、2回目敗北で強化・合成・熟練度・保護・厳選・自動合成指南を表示します。

## 新規キャラクター・魔物

- 文房具系を各レア3体ずつ追加：N／R／SR／SSR、計12体。
- 指定名`コンパスカブト`を採用し、新規群に蜘蛛は含めていません。
- おちゅき、ベチー、きあら、ロキシー、ミリム、アイ、エリス、金色の闇を追加。
- おちゅきは777階以降の極低確率単独遭遇。防御中心で2〜4ラウンドに逃走し、撃破時は大EXP。
- 開発使魔チャッピーと未完成兵装《PATCH//404》はシリアル限定です。

## 画像素材

- 全248素材フォルダに`idle1`、`idle2`、`idle3`、`walk1`、`walk2`、`attack`、`damage`、`down`の8フレームを完備。
- 文房具系12体とチャッピーは128×128。
- おちゅき〜金色の闇の指定8体は512×512。
- 深淵7柱・十神10柱は旧小型素材の拡大利用を廃止し、新規高精細原画から全て512×512で再制作。
- 1,984画像を走査し、欠損0・透明画像0・画像端への不透明画素接触0を確認。

## UI修正

- 装備選択候補を実際の部位互換判定と一致させました。
- 紫色のヘルプ「？」を36×36へ固定し、巨大化を防止。
- モバイル装備画面の横幅、候補行、詳細パネルをレスポンシブ補正。

## 今回の対象外

ギルド、ログイン、オンライン機能は、引き継ぎ監査の延期指定どおり実装していません。
