# Build598 QA

旧Build597の同じ配置で、パックの直後に放置中の人、守備位置にAIを置くと、AIの判定は `defend`、発射指示なし。
Build598では `attack` となり、同じ配置から発射してパックを動かすことを確認。

ブラウザではなくNodeのゲームルールとサーバーコーディネーターを検証。46テスト中４接続の通信テストは実際のローカルWebSocketを使用。iPhoneでの指操作・振動・FPSを確認したという意味ではありません。

適用後の実機チェック：
1. 全員がBuild598に更新して同じ部屋へ参加する。
2. エアホッケーで手を離してもAIがパックを取りに来ることを確認。
3. ランナーズで虫の折り返し、氷の上に乗る・横から蹴る、被弾ののけぞり、天井の押し潰しを確認。
4. 各ゲームで部屋主が途中退出し、残った人がそのまま続行できることを確認。
5. 溶岩で宝を取って退避、爆弾で届く直前に盾、イス取りでSTOP直後の金席、壁で次の回に復帰を確認。
