# ABYSS DOMINION REMAKE v2.6.2 リリースノート

135版を土台に、戦闘画面のHP表示、ゲージ減少、被弾演出、キャラ詳細操作を修正した。セーブスキーマは`52`、セーブキーは従来どおり維持する。

## 修正内容

- HP数値の重なり順をゲージより上へ固定し、残量や色に左右されず読めるよう修正。
- ダメージ確定後、実HPゲージと数値を約0.5〜1.15秒かけて滑らかに減少。大ダメージほど余韻を長くした。
- 被弾対象へ強い横揺れ、白赤点滅、衝撃光を追加。戦場全体にも短い揺れとフラッシュを追加した。
- 演出時間を戦闘速度`×0.5／×1／×2／×4`へ追従させた。
- 戦闘中のキャラ詳細は、外側の背景を短くタップすると閉じる。詳細内の縦スクロールと右上の「×」は従来どおり使用できる。

## 互換性

- 旧セーブはそのまま利用できる。
- ゲーム進行、戦闘計算、ダメージ量、報酬には変更を加えていない。
