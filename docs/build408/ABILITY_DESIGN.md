# Build408 キャラ能力の設計・共通処理

Build407適用済み環境向け / v3.1.88 / セーブ形式84を維持

## 今回の到達点

現行70体・280固有スキル・24ペア48体、および十神10体のスキル・武器技を照合。ペア24組の強化方針、特殊能力5案の担当、数値、発動条件、回数、対策を確定した。コード正本は `src/data/ChapterTwoAbilityDesign408.js`。これは次の個別能力実装に渡す仕様であり、今回の適用だけでは新しい特殊能力やペア強化は発動しない。

実戦へ接続した変更は、従来の共鳴・反撃で使用する共通ラウンド回数管理と、新しい能力状態の保存・復元。既存の攻撃倍率、消費MP、キャラ基礎値、スキル習得条件は変更していない。新能力用の計算・判定処理は呼び出して検証できる状態まで実装した。

## 十神と違う欲しさを作る

十神はCT操作、蘇生、必中、処刑、全体修復などを単体で持つ。第二章は「2枠を使い、条件を成立させると得意分野で勝る」方向にする。低ランクを基礎ステータスの上昇だけで十神へ近づけない。相方を止める、状態を浄化する、標的を分けるといった対処が必ず残る。

現行のペアは状態異常への追撃、同ラウンドの後手強化、3回共鳴の蓄積などの土台がある。これを残し、ペアごとに条件付きの追加利益を1種類だけ持たせる。既存効果の置換と書いたものは加算しない。スキル4枠は維持し、特殊5体以外の基礎成長率は変更しない。

各ペアの現行追撃倍率・ヒット数・回復／障壁・ボーナス条件はコード正本の `current` と監査JSONに保存している。追加条件が不成立なら現行共鳴の性能。攻撃力の参照は常に実際の追撃者で、低ランクの攻撃を相方の高ステータスへ無条件に差し替えない。

追加効果の扱い：命中後に発動するものは実ダメージまたは正式な効果適用の成功が必要。複数ヒット・全体攻撃でも指定の1回のみ。最もHP割合が低い対象は同率ならパーティ順。最低HP対象の死亡を回復で蘇生しない。HP閾値の判定時点は共鳴開始時（対象HP条件だけは各ヒット直前）。二人で標的をそろえる条件は敵を対象とした自然な攻撃行動のみ。回復・ガード・追撃・反撃は標的の印を作らない。

共鳴中に片方が死ぬ、捕獲される、隔離される、行動不能になると残りの追撃・支援を止める。自然な行動の印はラウンド末に破棄。1回消費の軽減・MP割引は同じ名称の効果を加算せず更新し、回数を複製できない。星刻の速度25%は本人たちの18%を置換し、他の生存味方の18%は現行どおり。

## 特殊能力5案

個別倍率は「装備・レベルを含む、能力適用前の計算済みステータス」を基準にする。能力を適用済みの値に掛け直さない。5体は単独能力であり、24ペアへ追加で組み込まない。

### 灰燭の呪術師セネラ（SR）— 灰燭の道連れ

- 発動：敵の一次攻撃・敵由来DoTで本人の戦闘不能が確定した直後。
- 効果：倒した敵1人に道連れ。撃破者が死亡・不明なら生存敵の脅威値最大（同値はID順）。通常敵はHP0への終端攻撃。防御と通常障壁を無視し、無敵・踏みとどまり・自動蘇生は尊重。
- 例外：全ボス・レイド・PvP・オンライン・物語保護・即死無効には、開戦時魔法ATK×2.0の通常闇ダメージ。
- 回数：1回/R、1回/B。同種・同陣営で共有。
- 代償：HP×0.55、物理ATK×0.5、魔法ATK×0.5、DEF×0.55、魔法DEF×0.55、SPD×0.8。
- 制約：道連れによる死は別の道連れを誘発しない。同種複数でも陣営1回。蘇生で回数は戻らない。
- 対処：本人を無視、反射・味方の自傷では発動させない、無敵・踏みとどまり。

### 封書の小剣姫ルメア（N）— 裏返しの封書

- 発動：本人への敵由来の通常弱体が命中した直後・付与前。
- 効果：現行21種の通常弱体を自分への2ラウンドのバフへ置換。同種は加算せず最大値で更新。ステータス系は12%、再生は3%。回数制限なし。
- 例外：CT延長・MP吸収・強化解除・隔離・権能・コスト・味方や自分由来の弱体は反転しない。
- 回数：回数制限なし。各種バフは最大値で更新。
- 代償：HP×0.55、物理ATK×0.5、魔法ATK×0.5、DEF×0.6、魔法DEF×0.6、SPD×0.8。
- 制約：変換前の状態異常とstun補助効果は両方生成しない。入場前に付いていた異常は通常の浄化が必要。
- 対処：直接ダメージ・強化解除・MP吸収。本人だけが対象で、味方の異常は防げない。

### 霜鐘梟ノクティア（SSR）— 十夜の冬眠鐘

- 発動：本人の自然行動開始。最初の10回を見送り、11回目に解放。
- 効果：生存敵全体へHP1を下限とする終端攻撃。防御と通常障壁を無視。通常行動・スキル・ガードは10回とも行わない。被弾だけでは冬眠を解除しない。
- 例外：全ボス等の保護対象には開戦時魔法ATK（弱体化前）×4.0の通常氷ダメージ。無敵・ダメージ無効は尊重。
- 回数：1回/R、1回/B。同種・同陣営で共有。
- 代償：HP×0.4、物理ATK×0.25、魔法ATK×0.25、DEF×0.4、魔法DEF×0.4、SPD×0.5。
- 制約：倍速・追加行動・CT短縮では進まない。戦闘不能で中断、蘇生しても再開しない。解放後は弱い本体で通常行動に戻る。
- 対処：11回目までに倒す・隔離・麻痺等で自然行動のカウントを止める。

### 鎖翼竜ヴェルグ（UR）— 鎖翼の死喰い

- 発動：本人が生存中、開戦時から存在する他ユニットの最初の戦闘不能が確定。
- 効果：HP・物理ATK・魔法ATK・両DEFが死亡1件ごとに2倍、最大8倍。開戦時基準比25%→50%→100%→200%。速度は80%固定。
- 例外：同じ個体の蘇生後再死亡・召喚物・捕獲・離脱・本人の死は数えない。同時全滅時は吸収しない。
- 回数：3回/R、3回/B。同種・同陣営で共有。
- 代償：HP×0.25、物理ATK×0.25、魔法ATK×0.25、DEF×0.25、魔法DEF×0.25、SPD×0.8。
- 制約：最大HPが増えても現在HPは回復しない。恒久ステータスには加算しない。成長は陣営同種共有、最大3件を複製して増幅しない。
- 対処：成長前に本人へ集中攻撃。味方を犠牲にすると行動人数を失う。

### 夜灯の従騎フィオラ（N）— 百命の従騎盾

- 発動：開戦時と本人の自然行動開始時（本人が生存・行動可能）。
- 効果：本人を除く生存味方全員へ、各自の開戦時最大HP8%の専用障壁を2ラウンド付与。自分の最大HPは装備・強化を含め最終100固定。
- 例外：自身には全ての障壁を付与できない。HP増加・蘇生で最大HP100を超えない。
- 回数：1回/R、999回/B。同種・同陣営で共有。
- 代償：HP×1、物理ATK×0.5、魔法ATK×0.5、DEF×0.5、魔法DEF×0.5、SPD×0.8。最終最大HPは100固定。
- 制約：同種複数の盾は陣営で共有、加算せず8%まで更新。開戦時付与はラウンド1の枠を消費。既存「従騎の小さな盾」は同じ専用盾の8%更新へ置換。
- 対処：全体攻撃・継続ダメージ・本人狙い・行動不能。

セネラのボス向け2.0倍は弱体化後の開戦時魔法ATKを参照。ノクティアのボス向け4.0倍のみ、10回行動しない代価として弱体化前の開戦時魔法ATKを参照する。いずれも通常の属性・防御・障壁・無敵で軽減されるため固定ダメージではない。HP0／HP1の通常敵向け効果も、既存の無敵・踏みとどまり・自動蘇生を飛ばさない。

冬眠は専用状態で、通常の睡眠と別。浄化で10回の待機を飛ばせず、被弾でも解除されない。死亡した瞬間に中断を通知するため、途中で蘇生して次の行動開始時に生存していても再開しない。自身の冬眠状態を行動不能としてカウンター停止判定へ流さない。別の麻痺・凍結・隔離中は待機カウントを進めない。

死の吸収は、確定死のバッチ全体で生き残っているヴェルグだけが受け取る。最初の開戦時HPは25%を上限に切り詰める。成長で最大HPが増えても現在HPは増えないので回復役が必要。蘇生時も既存の成長値を参照し、回数を戻さない。戦闘終了で全補正を破棄する。

フィオラは開戦時に全快ならHP100、途中入場・再開で現在HPを勝手に100へ回復しない。自身への障壁を全経路で拒否する必要がある。専用盾と他キャラの別種障壁との合算は既存の全体障壁上限に従う。フィオラが複数いても専用盾は共有8%まで。開戦時に付いた盾は本人死亡で即消失せず、通常どおり消費か2ラウンド経過で消える。

### 弱体反転の対応表

|入力|変換後（2ラウンド、加算なし）|
|---|---|
|攻撃／防御／速度／命中／回避低下|それぞれの上昇12%|
|被ダメージ増加・蘇生封印・呪い・スタン|被ダメージ12%軽減|
|毒・炎上・出血・HP回復阻害・MP回復阻害|HP再生3%|
|睡眠・麻痺|速度12%上昇|
|凍結・感電|防御12%上昇|
|魅了・混乱|命中12%上昇|
|恐怖|攻撃12%上昇|

通常弱体21種を対象にする。敵由来の命中と付与確率が成立した後、耐性／無効化と通常付与の前に反転する。反転後に元の異常や行動スキップ用stunを別途付けない。CT延長、MPの直接減少、強化解除、権能による状態固定、隔離、コストは対象外。味方や自分による弱体でもバフを稼げない。

状態キーは `battle.chapterTwoAbilities408`。新規戦闘生成に追加し、mainの保存・再開で明示的に受け渡す。旧セーブで存在しない場合は空で開始。既存 `twinResonance385.used`／`counterUsed390` はそのまま使い、新状態への強制移行は行わない。バッチ内で予約だけ保存せず、実際のHP・付与効果と状態を同じチェックポイントへ保存する。

イベントIDは戦闘内で一意な actionId＋陣営＋対象ID＋hitIndex＋kind から作る。IDの長さは160文字以下。アニメーションを待つ前に同期的な戦闘結果を確定し、その結果から表示する。同種複数の処理順は初期パーティ順。回数上限に達して何も起きなかったイベントを次のラウンドに再利用しない。

共通状態は処理済みID4096件、能力枠512件、死亡256件、蓄積128件、冬眠32種まで。上限で履歴を捨てず、新規発動を止める。長期戦で到達する場合は上限自体を設計し直す。現在の共鳴の既存回数台帳はこの新規上限の対象外。

### 次段階で接続する順序

1. 自然行動の開始を確定。冬眠・開幕盾・一回限りの割引を判定する。
2. 通常の命中／弱体付与確率を確定。反転なら元の弱体付与を抑止する。
3. 通常ダメージ・無敵・障壁・踏みとどまり・自動蘇生を処理する。
4. 同時死亡の全対象が確定してから、死亡イベントと冬眠中断を登録する。敵DoTは殺害元も保持する。
5. 生存する吸収役にまとめて通知。道連れは一次敵攻撃または敵DoTによる本人の死だけを消費する。道連れの死から別の道連れを起動しない。
6. 二人の生存・行動可能を再判定し、共鳴・反撃の既存結果にペア追加効果を適用する。
7. HP・効果・能力状態をまとめて保存し、ログ／演出を表示する。

死亡の既存経路は敵ダメージ、味方への攻撃、味方DoT、反射、権能による直接HP変更に分かれている。`handleMagicCircleDeath` の1か所だけへ追加すると、自動蘇生より前の誤発動や敵側の通知漏れを生む。新5能力を有効にする前に各経路をこの契約へそろえる。

戦闘モードはアダプターで正規化する。boss / floorBossCatalogId / endgameBossId / 十神・深淵の敵・物語保護を `boss` などへ反映し、オンライン／レイド／PvPは `mode` を明示する。見た目が雑魚でもボス扱いの敵をHP0/1へ落とさない。味方・敵のHPフィールドは `currentHp` / `hp` を共通スナップショット `hp` へ変換する。

## 編成してみたくなる例と次の検証

- 薬毒＋双藤：毒を与えながら回復を封じ、自分たちは毒を薬にする。毒無効の相手には別編成へ。
- 返誓＋ノクティア＋回復役：盾と反撃で10回の冬眠を守り抜く。長い準備時間が勝ち筋になる。
- フィオラ＋ヴェルグ＋回復役＋攻撃役：薄い盾で開始をしのぎ、損耗後に竜へ回復を集中。味方死亡を意図的に作るだけでは行動数不足になる。
- 魔導姫＋十神2体：十神で準備時間を確保し、二人で溜めた必中解放を通す。CT短縮で共鳴回数自体は増えない。

検証基準：レベル1500／3000、装備なし／同予算6枠、魔法陣なし／同予算ありの各条件。汎用4枠、回復敵、弱体敵、障壁敵、短期火力、長期ボスで比較する。同ランクの単独2体・各ペア・十神2枠を比較し、4枠全体でも十神4体を参照する。オンライン／PvPの比較はサーバー側実装後。

同じ乱数列100本で勝率、勝利ラウンド中央値、MP消費、総与ダメージ、実回復量、実吸収した障壁量、発動回数を記録する。過剰回復・未消費盾は強さに加算しない。通常・4倍速・中断再開の結果が一致すること。得意な相手で目標を満たし、汎用戦で低ランクが高ランクを全面的に上回らないこと。今回の数値はこの比較の初期仕様であり、未実施のバランス実測を完了とは扱わない。

UI接続時は担当キャラに特性名、発動済み表示、冬眠の残り自然行動数、吸収段階0〜3、ペア条件の成否を表示する。効果のログを出してから派手な演出を追加し、何が起きたか読めるようにする。
