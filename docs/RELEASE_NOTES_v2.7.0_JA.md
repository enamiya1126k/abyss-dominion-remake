# ABYSS DOMINION REMAKE v2.7.0 リリースノート

136(2)版を土台に、敵の深層育成、探索AUTO、戦闘詳細、帰還、魔法陣、ミミックを統合更新した。セーブスキーマは`53`、セーブキーは従来どおり維持する。

## 敵編成・装備・魔法陣

- 50〜99Fの通常戦を2〜4体中心、100F以降を4体中心へ変更。100F以降の階層ボスも眷属込み4体編成とした。
- 50F以降の敵は96%以上の確率で右手・左手・胴・補助・首・指の6枠を装備する。全枠LR、装備Lvは階層×2、ソケットもLR相当として戦闘能力へ反映する。
- 50F未満は装備持ちと非装備を混在させ、階層上昇に応じて装備率と装備枠数が増える。
- 敵の魔法陣率を1Fから段階的に上げ、100Fで100%。LR・神話・深淵・十神は階層を問わず100%とした。

## ミミック

- 敵として出現するミミックのLvを階層適正へ変更し、HPを5へ固定。
- 通常攻撃、連撃、複数回攻撃、割合攻撃、反撃、状態異常、即死を含め、1ラウンド中に失うHPを合計1までに制限した。
- 敵専用の攻撃・魔法攻撃を大幅強化し、防御・回避・ガード・障壁・復活で対抗する危険敵へ変更。
- 最終捕獲率を常時1%へ固定。捕獲個体にはHP5、被ダメージ上限、敵専用火力を引き継がない。

## 完全AUTO探索

- ミミック警告、階層ボス確認、戦闘結果、取得通知、ボス選択報酬、秘密の入口、無料休憩を自動処理する。
- ボス選択報酬には魔晶石を常設し、AUTOでは必ず魔晶石を選択する。
- 秘密の裏街では全AUTO方針が無料休憩を利用して探索へ復帰する。
- 「回収優先」だけが相場の8%以下かつ異常特価のモンスター／装備を自動購入し、魔晶石が足りる場合は購入後所持GOLDの半分でカジノへ挑戦する。
- 「階層攻略」「経験値優先」は有料購入とカジノを実行しない。回復品も自動購入しない。
- 全滅、所持枠満杯、到達不能、10000F到達は理由を表示してAUTOを停止する。

## UI・データ整合性

- 戦闘中の味方詳細は、移動量10px以下の短いタップならカード内外を問わず閉じる。縦スライドによるスクロールは閉じない。
- 詳細へ属性ロゴ、なつき度と有効ボーナス、物理／魔法ATK、物理／魔法DEF、SPD、会心、回避、種族、役割、特性、EXP、装備、スキルを追加。
- プレイヤー魔法陣を1個1人制へ変更。使用中は装着者名を表示し、自動付け替えは行わない。旧重複データは出撃順を優先して1人だけ保持する。
- 帰還確定前に`inRun`を無効化し、予約済み遭遇・探索パス・戦闘チェックポイントを破棄して、帰還後に戦闘が始まる競合を解消。

## 互換性

- `schemaVersion 1〜52`は起動時に`53`へ自動移行する。
- セーブキー`abyss-dominion-remake-v001`は維持する。
- 既存の装備・仲間・階層・報酬・探索記録を保持する。
