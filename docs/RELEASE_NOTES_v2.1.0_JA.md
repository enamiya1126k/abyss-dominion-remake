# ABYSS DOMINION REMAKE v2.1.0 リリースノート

## 概要

現行の縦型レイアウトと「探索・育成・装備・帰還」の基本ゲームループを維持しながら、深淵・十神、奈落回廊、4 VS 4、召喚、装備、探索HUDを完成版仕様へ更新しました。

## 深淵・十神

- 深淵の正本ステータスを従来の10倍へ強化。
- 十神の正本ステータスを深淵の10倍（従来基準100倍）へ強化。
- 手動挑戦を次の4段階へ変更し、上から順に討伐して解禁する方式へ統一。

| 段階 | 推奨装備 | 欠片報酬 |
|---|---:|---:|
| 投影体 / 50% | Lv.999 通常装備 | 1個 |
| 投影体 / 100% | Lv.4,999 通常装備 | 3個 |
| 顕現体 / 50% | Lv.9,999 フル装備 | 5個 |
| 顕現体 / 100% | Lv.99,999 フル装備 | 10個 |

- 深淵・十神の全キャラクター／全段階で挑戦回数を共有し、日本時間0時更新の1日3戦に制限。
- 専用挑戦エンブレム、専用出現演出、専用プロシージャルSEを追加。

## 試練

- ホーム左上の重複した4 VS 4ボタンを撤去し、すべての試練を「試練」画面へ集約。
- 奈落回廊をボス階層型の歩行コンテンツへ刷新。
  - 法廷主へ歩いて接触すると戦闘開始。
  - 勝利後、出現する奈落孔へ歩いて次の法廷へ移動。
  - 戦闘前後に道具を使用可能。
  - 途中帰還可能。法廷進行を保存。
- 4 VS 4を全50試練へ再設計。敵能力・GOLD・魔晶石を指数成長させ、節目で装備レア度を保証。

## 召喚

- プレイヤーが支払う魔晶石必要数を従来の10倍へ統一。
- 3日ごとの召喚ローテーションを追加。
  1. 武器系
  2. 防具系
  3. アクセサリー
  4. GOLD
- GOLD召喚は100G〜99,999,999G。最高額99,999,999Gは0.02%。
- 7日間のうちランダムな1日（日本時間0:00〜24:00）だけ「深淵・十神 天変召喚」が出現。
- 天変召喚の提供割合は神話0.020%、深淵0.018%、十神0.016%。
- 深淵・十神獲得時は専用暗転、色調、粒子、振動、SEで明確に判別可能。
- 通常召喚の全レア度提供割合と10連最終枠の割合を画面内へ追加。
- 将来用のイベント装備シリーズ枠は、そのまま準備中として維持。

## モンスター・装備

- モンスターの生得★を1〜10へ拡張。同種族でも★が多いほど基礎能力が高くなります。
- ★は獲得時に個体ごとに抽選され、既存個体はセーブ移行時に安全な範囲へ正規化。
- 通常装備を18種から54種へ拡張。
  - 武器 30種
  - 防具 12種
  - アクセサリー 12種
- 装備名と種類に合わせたピクセルアトラスを追加。
- 深淵・十神の固有装備には、それぞれ専用ピクセルアトラスを追加。
- 闇市場は価格と性能を独立抽選する混沌相場へ変更。極端な高額品、異常特価、高Lv、高＋値、★10、深淵／十神が同じ階層でも出現可能。

## 探索・表示

- 50階ごとに炎、氷、毒などの属性環境を切り替え、その属性に合うモンスターを配置。
- 属性アイコンを押して相性と簡易説明を確認できるヘルプを追加。
- 探索HUDの小型「現在階層」表示を撤去し、空いた領域へ部隊戦力を大型表示。
- 戦力表示を高揚感のある桁へ拡張し、長大な値は`1.234e+12`形式で表示。
- 探索上部の4体カードへ簡易HPバー／MPバーを追加。既存の横並びレイアウトは維持。
- 魔晶石取得通知を、視界を遮らない小型通知へ変更。
- 捕獲結晶、GOLD、魔晶石、試練、属性などの表示を絵文字・記号から専用素材へ置換。

## セーブ・互換性

- アプリ版数：`2.1.0`
- セーブスキーマ：`45`
- セーブキー：`abyss-dominion-remake-v001`（変更なし）
- 旧セーブは起動時に自動移行。ブラウザのサイトデータを削除しない限り継続利用できます。

## 配置方法

完成版フォルダの中身を、現在公開している静的サイトの同じ場所へ上書きしてください。`index.html`、`src`、`assets`、`docs`、`tests`を含めて全体を置き換えます。

キャッシュ版数を`2.1.0-release`へ更新しているため、初回起動時に旧キャッシュを自動削除します。
