# ABYSS DOMINION REMAKE v2.2.1 起動修正

## 修正内容

- 探索中の骨・結晶・水場処理に混入していた余分な閉じ括弧を削除しました。
- `Unexpected token 'else'`または`unexpected keyword 'else'`で起動できない問題を修正しました。
- キャッシュ識別子を`2.2.1-hotfix`へ変更し、差し替え後に古いJavaScriptが残らないようにしました。
- セーブキーとセーブスキーマは変更していないため、既存セーブはそのまま引き継がれます。

## 配置方法

ZIPを展開し、`index.html`、`src`、`assets`を含む全ファイル・全フォルダを公開先へ上書きしてください。反映後はブラウザを一度再読み込みしてください。
