# ABYSS DOMINION v2.2.1 起動修正・検証レポート

## 原因

`src/main.js`の探索オブジェクト処理内で、骨の分岐を閉じる波括弧が1個余っていました。そのため、続く結晶の`else if`をブラウザが解釈できず、起動時に`Unexpected token 'else'`または`unexpected keyword 'else'`が発生していました。

従来の構文確認はJavaScriptファイルをCommonJS扱いで確認しており、ES Moduleとして読み込んだ場合の構文エラーを検出できていませんでした。

## 修正

- 余分な閉じ波括弧を削除。
- アプリ版を`2.2.1`へ更新。
- HTML、CSS、JavaScriptのキャッシュ識別子を`2.2.1-hotfix`へ更新。
- 全JavaScriptをES Moduleとして構文確認する回帰テストを追加。
- 実ブラウザ相当の起動試験でホーム画面表示とページエラー0件を確認。

## 検証結果

- ESM構文検査：PASS（76ファイル）
- GDD v1.0回帰試験：PASS
- v2.2.1リリース回帰試験：PASS
- モバイル表示条件でのブラウザ起動：PASS
- 起動時ページエラー：0件
- ZIP再展開後の同一試験：PASS

## セーブ互換

セーブキーとセーブスキーマ番号は変更していません。公開先を全上書きしても、ブラウザのサイトデータを削除しない限り既存セーブを引き継ぎます。
