# ABYSS DOMINION REMAKE v2.2.0 リリースノート

## 概要

現行の縦型レイアウトと「探索・育成・装備・帰還」のゲーム性を維持しながら、追加修正依頼を製品版へ統合しました。今回の中心は、戦力表示の再圧縮、深淵・十神の実戦強化、無限4 VS 4、奈落回廊、探索HUD、欠片祭壇、属性戦闘、専用BGM・戦闘背景です。

## 主な更新

- 実ステータスを弱体化せず、表示用戦力だけを非線形圧縮しました。旧セーブの歴代最高戦力も新尺度へ変換されます。
- 4 VS 4は第50試練で終了せず無限に継続します。第50試練以降は急激に難化し、深淵・十神と眷属が編成へ加わります。報酬も指数成長します。
- 深淵は通常個体基準の10倍、十神は100倍の基礎戦闘能力を持ちます。手動挑戦の主敵レベルは999／4,999／9,999／99,999を実戦へそのまま適用します。
- 手動挑戦は4段階の順次解禁、全深淵・十神共通で1日3戦、報酬は欠片1／3／5／10個です。
- 探索中の自然遭遇は選択画面を出さず、遭遇階層の顕現率を自動適用します。
- 深淵・十神勝利画面を専用演出へ更新し、欠片から人物を契約、または6部位の専用装備を顕現できる「欠片祭壇」を追加しました。
- 奈落回廊は、法廷内を歩いて法廷主へ接触し、戦闘後に奈落孔まで歩いて次の法廷へ進みます。戦闘前後の道具使用と途中帰還に対応します。
- 探索HUDの4体表示を2×2のステータスカードへ変更し、キャラクター名、現在HP／最大HP、現在MP／最大MPを常時確認できます。
- 取得・回復通知を画面端の小型表示へ変更しました。骨は使用済みとなり、ごく稀に深淵の鍵を発見します。水場は使用後に空の石枠素材へ変化します。
- 50階ごとの属性環境へ適性補正を追加しました。適性属性は戦闘中+22%、不適性属性は-16%。炎・溶岩・毒環境では不適性メンバーに探索中の微量ダメージも発生します。
- 味方と敵の双方へ属性共鳴を実装しました。同属性2／3／4体で段階強化され、4体一致時は戦闘開始演出が入ります。
- 戦闘カードへ属性ロゴを追加し、敵味方の前衛・後衛位置を固定しました。撃破後も残存敵は移動・拡大しません。
- 通常、被弾、スキル、会心、大ダメージ、回復、状態異常ごとに戦闘数字の色・大きさ・演出を分離しました。
- モンスターMPを役割、レベル、固有値、レア度、深淵・十神に応じて増加しました。十神固有技も通常のスキル設定画面で設定できます。
- モンスター所持上限を3,000体へ拡張し、指定レア度以下をまとめて同名合成できる一括合成を追加しました。
- 捕獲結晶の常設価格を1個10,000Gへ変更しました。
- 固有値は最大10。画面幅に余裕があれば星を並べ、狭い場所では「★6」のように表示します。固有値と、同名合成による「+」強化は別系統です。
- GOLD、魔晶石、捕獲結晶、深淵の鍵、戦闘アイテムの画像参照を修正しました。
- 提供された7曲を、拠点、探索、通常戦、強敵戦、ボス戦、深淵戦、十神戦へ割り当てました。
- 炎、氷、毒、ボス、深淵、十神の専用戦闘背景を追加しました。

## 配置方法

配布ZIPを展開し、公開中サイトのファイル一式へ上書きしてください。`index.html`だけでなく、`src`、`assets`、`docs`、`tests`を含めてフォルダ全体を置き換えます。

既存セーブを継続する場合は、ブラウザのサイトデータやローカルストレージを削除しないでください。起動時に旧セーブが自動移行されます。

## 配布物の使い分け

- 完成版ZIP：公開サイトへ上書きする本体です。
- 実装・検証レポート：変更内容と検証結果を確認する資料です。サイトへ置かなくてもゲームは動作します。
- SHA-256チェックサム：ダウンロードしたZIPが破損・改変していないか確認するための値です。サイトへ置く必要はありません。

## 起動

ES Modulesを使用するため、ローカル確認はHTTPサーバー経由で行います。

```bash
python3 -m http.server 8080
```

ブラウザで`http://localhost:8080/`を開きます。BGMはブラウザの自動再生制限に従い、最初のタップ後に開始します。
