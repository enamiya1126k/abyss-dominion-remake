# Build419 検証記録

## 基準と範囲

- 基準：Build418 / v3.1.97。対象：③ 戦闘表示・補正の確認。
- 実行対象：Build419 / v3.1.98。セーブ形式：schema 84を維持。
- 変更一覧とSHA-256：`runtime-manifest.json`。コード差分：`runtime.diff`。
- 画像素材、キャラ・ペア能力定義、戦闘ダメージ・倍率計算、報酬、オンライン通信処理は変更なし。

## 確認結果

`node --test tests/*.test.mjs`：253件成功、失敗0件。既存246件と追加7件。

追加確認は `tests/build419-display-hp.test.mjs` にあります。

1. 通常探索HP×28と宝物庫HP×42を、対象2ペアの部隊で確認。
2. 硝子・返誓連携の前後で最大HPは不変。回復・障壁は補正後HPを使用。
3. 戦闘準備の再実行・説明の再表示で倍率・HPが変わらないことを確認。
4. 対象外の十神、別戦闘の参照、戦闘終了後には適用中という説明を出さない。
5. フィオラのHP100固定を表示し、オンラインには部隊の備えの説明を出さない。
6. 同じ通常敵4体を第一章・第二章のBattleScreenへ渡し、敵カード全体のHTMLが同一であることを確認（描画ごとに変わるSVGクリップIDのみ正規化）。第二章ボスの名前・札、長い名前のエスケープも確認。
7. 変更モジュールの既存キャッシュ別名すべてとCSSリンクをBuild419へ更新したことを確認。

既存テストにはセーブ移行・復帰、報酬二重受取防止、手動／自動戦闘、①第一章の進行修正、②泉と編成の回帰、魔法陣の配置、オンライン境界が含まれます。

CSSは第二章だけの名前非表示・カード縮小・小さい札・縦折り返しを除去しました。HPカードとランク札は既存の第一章ルールを再利用。頭上名の横並びと省略表示を揃え、既存の画像位置計算は維持しています。
