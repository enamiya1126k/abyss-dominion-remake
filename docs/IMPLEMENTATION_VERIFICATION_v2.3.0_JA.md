## 追加修正の実装範囲

### 探索

- HP／MP数値、レア度色の名前、属性ロゴを持つ4体部隊HUD。
- 部隊HUD開閉と、閉じた領域ぶんの探索画面拡張。
- 階層攻略／アイテム回収／経験値の完全自動探索。
- 水場、骨、取得通知、装備ドロップLv、属性階層、環境装飾と適性補正。
- 同じ石枠を保持した使用済み水場画像。

### 戦闘

- 味方・敵の完全な名前表示、属性ロゴ、固定4スロット前衛／後衛。
- 撃破後の再配置・拡大を廃止。
- 高速スロット式ダメージ数字、クリティカル／スキル／通常攻撃の色分け。
- 通常敵・ボスの複数攻撃、属性技、状態異常、群体支援。
- 10階ボスの能力強化と、深層で最大4体のボス編成。

### 奈落回廊・深淵／十神

- 1画面に収まる歩行式ボス部屋、部隊HUD開閉、道具使用、途中帰還。
- 帰還・全滅時に連勝数と敵強度からまとめて精算し、次回は第1戦から開始。
- 欠片、希少武器の深度連動抽選。
- 持ち物内欠片一覧、欠片祭壇、人物契約、専用装備顕現。

### 音響・管理

- 場面ごとにBGMを一曲だけ再生し、自動ループ。
- `visibilitychange`、`pagehide`、`blur`で停止し、表示復帰時のみ再開。
- モンスター一括統合、属性絞り込み、3,000体所持枠、深淵ツリー復旧。
