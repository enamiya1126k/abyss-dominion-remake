- 公開した経路を別プレイヤーの画面で同じ時刻に評価すると位置と判定が一致する。正解・未来の問題・AIの内部計画は公開しない。
- 1,000回の抽選で20問の一意性、難易度の段階的上昇、直近30問の回避、全120問への到達を確認。
- 500試合を完走し、各遷移をJSON保存・復元して一致を確認。20問全員生存・全員脱落・脱落順の順位も検証。

- 混在バージョン拒否、Build513の進行中クイズのロビー移行、再戦の重複要求と古い部屋への入力を確認。

- 画面の動きを減らす設定、最大1本の有限RAF、非表示時の停止、移動連打の送信集約、静止状態の無駄なDOM変更0、入力イベントの終了時解放。

## 表示・負荷の扱い

問題欄と見出しは動かさない。演出は固定数の要素を使い、transform/opacity中心で更新する。背景の流れは繰り返し背景の1周期分で、毎フレーム画像を再生成しない。新しい常時タイマーは追加しない。

この環境では前回のローカルページへのブラウザーアクセスが `net::ERR_BLOCKED_BY_CLIENT` で拒否されており、今回は画面モデル・DOMテストダブル・画像のデコードによる検証を行った。実ブラウザーの描画スクリーンショット、iPhone SafariのFPS計測、実機のタップ感、実際の4端末同時接続は未確認。自動テストの成功はこれらの実機確認を意味しない。

部分ソースに欠けている `src/data/species.js`、`src/data/endgameCharacters.js`、`src/ui/MonsterVisual.js` は、テスト内でのみメモリー上の最小データを利用。本番用の偽ファイルは作成・同梱していない。

質問文120問の内容はBuild513のまま。出典・直接検算の記録は `docs/build513/question-sources.md`。本更新では問題の順序と難易度の選び方だけを変更した。
