## 結論

依頼された修正項目を、現行レイアウトと基本ゲームループを維持したまま実装しました。静的Web版として配布可能な構成にまとめ、構文・回帰・アセット・主要スマホ画面のスモーク検証を通過しています。

## 自動検証

実行コマンド：

```bash
find src -name '*.js' ! -name 'app.bundle.js' -print0 | xargs -0 -n1 node --check
node tests/gdd-v1-regression.mjs
node tests/v2.1-release-regression.mjs
```

検証内容：

- 全アクティブJavaScriptの構文。
- 起動モジュールと静的アセット参照。
- 旧セーブのschema 45への移行とセーブキー維持。
- 魔晶石費用10倍。
- ★1〜10の境界と能力差。
- 深淵×10／十神×100の戦闘倍率。
- 4段階挑戦、順次解禁、欠片1／3／5／10、共通1日3戦。
- 通常装備54種と装備アトラス。
- 50階属性帯。
- 4 VS 4第50試練の指数強化・報酬。

結果：すべてPASS。
