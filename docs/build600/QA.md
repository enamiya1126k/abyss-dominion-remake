# Build600 検証記録

## 結果

`node --test tools/build600/*.test.mjs`：102件成功、失敗０件。ログは `test-results.txt`。

| 検証 | 内容 |
| --- | --- |
| 空中の操舵 | 左右反転・ジャンプ解除・再ジャンプと、30〜110msの揺らぎを持つ状態配信を組み合わせる。60Hzの描画時刻で計算した位置に18ワールド単位以上の１フレーム移動がないことを確認。実画面のFPS測定ではない |
| 着地・復活 | 途中の描画時刻で未来の接地フラグを借りない。途中の死亡パケットを取り逃しても復活前の入力を消す。復活後の位置が上下しないことを確認 |
| 移動足場 | 上下する足場に６秒乗り続け、接地と空中が交互に発生しない。落下中の足場でも位置が一致し、再ジャンプできる |
| 箱・攻撃 | ６属性で規定回数当てた箱１個のみを破壊。高速弾・縁への接触。針山の貫通と普通の壁での停止を確認 |
| ８コースの配置 | 通常アイテム６個・全６属性・600単位以上の間隔。アイテムとチェックポイントの足元に実際の足場がある |
| 登り下り | 空中庭園と時計塔の新しい経路を、属性なしの通常ジャンプと左右操作で渡り切る。火柱等の危険を避けるプレイ難度の実機評価は含まない |
| 地下 | 実際の落下で隠し部屋の床へ着地し、追加ミスなく大バネで地上の高さへ戻れる |
| 大群・環境 | 群れの追加が３波・12体で止まる。火の棒の描画用座標と衝突座標が同じ。潮位で危険が変わる。転がる氷塊を砕いた周期には被弾しない |
| ボス | ３種類とも予告・攻撃・休息が進む。踏みつけと弾でHPが減り、撃破前はゲートが閉じ、撃破後に開く |
| 通信・既存機能 | 実WebSocket４接続、入力・属性・友軍への攻撃、切断と復帰、途中退出、部屋主交代、最後の退出、再戦。他のパーティーゲームの既存テストも継続 |

過去の70件をBuild600へ引き継ぎました。崩落の消失時刻は新仕様へ更新し、ゴールに直接配置する退出テストではボス撃破済みの前提を追加しています。プロトコル番号は10です。追加の不具合・機能テストは32件です。

## 描画

`scene-preview.png` は実際の `paint587` / `scenery600` をNodeのCanvasで描いた４場面です。各場面で60フレーム分の描画を実行し、画像読み込み後に描画エラーがないことを確認しました。背景・地形・属性アイコン・ボスにはゲーム内の素材を使っています。メインゲームのボス用素材24フレームを確認しました。

プレビューはブラウザUI、DOM上のプレイヤー、iPhone Safari実機の描画確認を代替するものではありません。ホーム復帰と端末の描画性能は実機確認が残っています。

## 配布

Build599の作業開始時点を基準に差分を作成します。変更JavaScriptの構文、相対import、全importmap別名のキャッシュ更新、新しいオフライン一覧、ZIP内容のSHA-256を確認します。メインゲームの既存ボス素材を参照しており、同じ素材の複製は追加していません。
