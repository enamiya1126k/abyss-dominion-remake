# ABYSS DOMINION REMAKE v2.0.0 リリースノート

## 深淵と十神、正式実装

深淵7柱と十神10柱を、新しいCharacter Bibleに合わせて全面更新しました。人物像、戦闘思想、固有技、属性相性、状態耐性、契約後の能力、固有装備がひとつの設定から動作します。

## 新コンテンツ

- 深淵7柱：暴食、憤怒、嫉妬、怠惰、強欲、色欲、傲慢。
- 十神10柱：時間、空間、生命、死、運命、混沌、支配、創造、終焉、神格。
- 固有スキル85種。
- 固有装備102種と2／4／6部位セット効果。
- 全22戦、無限周回型の「奈落回廊」。
- 17体の人物・権能・装備を確認できる挑戦門資料。
- 深淵／十神戦専用を含む本作オリジナルのプロシージャルBGM／SE。

## 進行ルール

- 深淵・十神、奈落回廊、4vs4は100階で解放。
- 緊急戦は3%、発生後10階のクールダウン。
- 勝利で5欠片、敗北時は10%で1欠片。
- 深淵は50欠片、十神は150欠片で確定契約。
- 奈落回廊は22戦突破ごとに周回し、敵能力が50%ずつ上昇。

## 互換性

既存セーブは初回起動時に`schemaVersion 44`へ自動移行します。旧深淵・十神の欠片、契約個体、装備、特殊戦進行も新しい17体へ引き継がれます。セーブキーは変更していません。

## 音響について

追加BGM／SEはWeb Audio APIでリアルタイム生成する本作専用音響です。外部楽曲や第三者サンプルは使用していません。ブラウザ仕様により、最初のタップ／クリック後に再生が始まります。

## 起動

静的Webサーバーへ配置するか、ローカルでは次のコマンドを実行してください。

```bash
python3 -m http.server 8080
```

その後、`http://localhost:8080/`を開きます。
