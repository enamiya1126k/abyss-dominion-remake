# ④ バランス調整 — Build415 / v3.1.94

② Build413の実装と、③ Build414の確定設計を基準にした差し替えパッチです。セーブ形式は84のままです。初期化は必要ありません。

## 適用方法

1. ②まで適用済みのゲームフォルダーに、ZIP内の `index.html` と `src` を同じ場所へ上書きしてください。③は設計資料だけなので、③の資料を置いた状態にも適用できます。
2. `docs/build415` は変更内容と検証結果、`tests` と `tools/build415` は再検証用です。ゲームの保存データではありません。
3. 更新後にページを読み込み直し、表示バージョンが **v3.1.94** になったことを確認してください。変更したモジュールの旧URLも、import mapで415へ向けています。

このZIPは完全版ではありません。既存の画像・音声・未変更ファイルと一緒に使用します。GitHubへの書き込みや公開サイトの更新は実施していません。

## 実装した内容

### ペアの発動条件と表示

- 「追加連携2/2→1/2→使用済み」と、相乗効果の状態を別に表示します。追加枠は次ラウンドに戻ります。相方不在・戦闘不能・行動不能・隔離を区別します。
- 相手が毒・火傷・凍結・睡眠・出血・速度低下・防御低下・回避低下を**明示的に無効化**した場合、対応するペアの準備技で「準備印」を作れます。
- 命中失敗、付与確率の失敗、通常の耐性、隔離、権能の代償では印を作りません。敵の免疫や行動不能耐性は維持します。
- 相方が次の共鳴で消費し、強化部分だけ半分を適用します。通常特効倍率をMとすると `1 + (M - 1) × 0.5` です。基礎威力まで半減したり、実異常と印を二重乗算したりしません。
- 印は陣営・ペア・対象・種類ごとに管理し、次ラウンド末まで有効です。硝子・星刻の2条件を、1種類の印だけで満たすことはできません。戦闘再開時にも復元します。
- 薬毒の追加回復は印なら4%、紅羽の阻害10%、氷晶の軽減5%、硝子のMP回復2%。月狐は印なら命中+20ポイントで、必中にはしません。双藤・星刻・夢境の完全な追加効果は実際の弱体成立時だけです。
- 同じ仕組みを敵のペアにも適用した状態で対戦しています。

### 支援AIと単体能力

- 通常キャラの支援判断を、有効な蘇生、複数人の行動不能解除、致死圏の回復・盾、ペアの準備、攻撃の順に改善しました。
- 満タンへの回復、無意味な盾の上書き、無効相手への準備技の無駄打ちを抑えます。支援役のおすすめスキルには全体回復や蘇生・解除を組み込みます。手動で保存済みのスキル構成は維持します。
- 主力回復を3回使えるMP量を確認できたため、MP量・スキル消費の一括変更は行っていません。
- セネラの保護対象への道連れ代替は係数4、防御30%無視、最終HP損失は相手最大HPの8%まで。戦闘中1回です。
- ノクティアは自然行動10回の冬眠後、保護対象へ係数10、防御50%無視、各対象最大HPの10%まで。通常の命中・属性耐性・盾・救命を通し、必中や即死にはしません。
- 反転・死の吸収・全体盾の既存上限は維持します。蘇生で一度限りの能力を再装填しません。フィオラの最大HPは100のままです。

### 戦闘中だけの「備え」

③の手動試練の開始係数だけでは、通常キャラの3編成で到達できない対象が残りました。実戦検証を受け、手動試練の係数を校正し、他モードにも役割編成を条件にした専用補正を追加しています。**手動試練以外への追加は、③からの実装上の拡張です。**

通常キャラが3体以上で、支援・回復・防御・妨害などの役と、それ以外の攻撃役を含むことが条件です。特定の名前・ペアは条件にしていません。条件は戦闘開始時の編成で決め、途中の死亡や敵の能力値によって倍率を動かしません。手動顕現試練は段階別補正を用います。

| 対象 | HP | 攻撃・魔力 | 防御・魔防 | 速度 |
|---|---:|---:|---:|---:|
| 通常探索・第一章・欠片・回廊1〜90 | 1〜3倍 | 1〜2倍 | 1〜1.5倍 | 1〜2倍 |
| 第二章・挑戦0の通常 | 28倍 | 12倍 | 8倍 | 16倍 |
| 王室・記憶 | 24倍 | 12倍 | 8倍 | 16倍 |
| 4対4・第1巡 | 12〜30倍 | 8〜20倍 | 6〜10倍 | 16〜28倍 |
| 回廊91以降 | 80倍 | 64倍 | 24倍 | 16倍 |
| 手動・投影50% | 96倍 | 54倍 | 48倍 | 9倍 |
| 手動・投影100% | 204倍 | 111倍 | 104倍 | 17倍 |
| 手動・顕現50% | 1,024倍 | 549倍 | 523倍 | 82倍 |
| 手動・顕現100% | 75,428倍 | 40,506倍 | 38,551倍 | 5,953倍 |

- 通常枠は現在の第一章階層1〜100で線形に増えます。4対4は40戦目まで表の下限、41〜90戦目に線形で上がります。
- 第二章は挑戦段階ごとにHP・攻撃・魔力・速度へ `1 + 0.3 × 段階` を乗算します。精鋭・覇者・極冠はさらに全対象能力へ1.5・2・2.5倍、宝物庫は1.5倍です。精鋭と宝物庫の係数を二重には掛けません。
- もとの手動最高顕現はLv99999・巨大な段階倍率を持つため、通常キャラのLv10000上限との差を戦闘側で吸収しています。最高試練の係数を通常探索へ流用しません。
- 装備込みの能力へ適用し、MP・命中・会心・異常耐性は増やしません。単体能力の低ステータス補正とHP100制限は維持します。
- 編成画面で適用条件、開戦時・戦闘詳細で実倍率を確認できます。終了時に破棄し、通常の所持キャラへ巨大なHPを保存しません。戦闘の途中保存には補正中HPを別に記録し、再開時の二重乗算を防ぎます。
- 深淵・十神の味方には補正を掛けません。深淵・十神の敵プロフィール、権能、耐性、スキル、成長値も変更していません。

## 検証条件と読み方

確定集計は `verification-summary.json`、各対象の3編成は `攻略編成.csv`、各100シードの結果は `合格編成100シード.jsonl` に収録します。合格は、100シード中70勝以上、勝利時40ラウンド以内、異なる3編成すべてに共通する必須キャラがいないことです。失敗した編成は合格CSVへ混ぜていません。

`編成スキル.csv` には各編成の4スロットを記載しています。既存の手動スキル構成は更新だけで変更されないため、攻略例を試す際は回復・蘇生・解除などの必要な技も合わせて設定してください。比較中に不合格だった構成の勝率も `編成比較一覧.csv` で確認できます。

- 第一章107配置、欠片試練の初回90、回廊初周112、4対4第1巡90、手動17体×4段階、第二章321条件、王室・記憶20条件の計808条件が対象です。
- 第一章の味方はその階までに遭遇できる通常キャラから選び、第二章キャラ・撃破前のボス契約を使いません。レベルは階層×30、最大3000です。これは今回の比較基準・攻略目安として設定した値です。
- ほかは生成された敵と同等のLvを基本とし、最高10000まで。王室・記憶は最低3000、手動は段階Lvを使い最高のみ10000です。対象ごとの実使用LvをCSVに記載しています。
- キャラはランク1・強化+0・親愛0。装備は市販系の武器2、防具2、アクセサリー2で、追加効果・シリーズ効果なし。同Lvを使用し、第一章は+0、それ以外は+10です。第一章の装備レア度はR→SR→SSR→UR→LRの段階制、それ以外はLRです。
- 魔法陣は利用開始以降、既存の `last_life / mana_reversal / aegis / opening_rite` を各Lv1で使用。ランダム即死・20R即死・レイド限定魔法陣には依存しません。消費アイテムは使っていません。
- 自動判断、命中、消費MP、状態異常、追撃、権能、盾、死亡、ラウンド進行は実モジュールとmain.jsの戦闘関数を実行しています。敵の生成も各モードの実関数を通しています。UI・音・待ち時間・保存呼び出し・通信は検証用に置き換えています。
- 乱数は1000〜1099で固定。敵装備なども各シードで再生成します。通常探索の無限の敵組み合わせ、無限周回、任意の対人編成への勝利を保証するものではありません。
- CSVの「MPが0」は文字どおり残MPが0になった記録です。「残MPはあるが大技の費用には足りない」ケースを網羅した指標ではありません。与回復量・盾吸収・初手戦闘不能・相乗発動も生データに残しています。

## オンライン・セーブ・既存機能

共闘3ボスと週替わりレイド15条件を、異なる所有者4人、通常キャラ3編成、各100シードでサーバー側の戦闘処理を実行して確認しています。結果は `coop-verification.jsonl` と `online-verification.jsonl` です。個人の4体ペアを、複数プレイヤーの共闘と混同していません。

今回のオフライン補正を対人・共闘・レイドの送信能力値へ持ち出さないようにしました。オンラインの第二章ペア・特殊能力は、現行サーバーが対応する従来仕様のままです。今回の代替効果をクライアントだけでオンライン有効化することはしていません。

深淵・十神17体×4育成条件の能力・MP・習得技を②の保存値と照合し、差がないことを確認しています。敵の権能・基礎データ・サーバーコードのハッシュも比較しています。セーブの通常HPと戦闘HPの分離、復元、フィオラのHP100、上限ダメージ、ペア24組、①の操作修正、②の表示処理を回帰テストで確認しています。

本番サーバーへの接続、実際のiPhone Safariでの表示・操作、実機負荷、報酬を受け取りながら全行程を進める通しプレイは未実施です。報酬・ドロップ・成長曲線は今回変更していません。育成に必要な実プレイ時間・入手運も、この戦闘シミュレーションだけで保証できるものではありません。

## 再検証

ゲームの完全フォルダーにパッチを重ねた場所で、Node.js 24系を使って実行できます。

```sh
node --test tests/build409-pair-series.test.mjs tests/build410-single-traits.test.mjs tests/build412-operations.test.mjs tests/build413-display.test.mjs tests/build415-balance.test.mjs tests/build415-boundaries.test.mjs tests/build415-server-compat.test.mjs
node --max-old-space-size=384 --expose-gc tools/build415/replay-selected.mjs
```

再実行は長時間かかります。`TARGET=campaign:100:ten_divinity` のように環境変数で対象を絞れます。検証前に戦闘ソースのSHA-256を照合するため、別ビルドへ上書きした後は同じ結果として実行できません。
