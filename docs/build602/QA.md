# Build602 検証記録

## 実行結果

- 自動テスト135件成功、失敗0件。124件の継続テストと11件の新規テストを実行した。
- 時計塔・遺跡地下出口・水晶洞地下出口を、属性なしの実際の物理計算で交互の壁キックにより登れることを確認した。
- 時計塔の縦穴を、右移動と通常ジャンプの長押しだけでは突破できないことを確認した。
- 遺跡と水晶洞の新しい地下ルートで、足場から次の足場へ単独で移れることを、ゲームの重力・当たり判定・ジャンプ計算で検証した。各区間の接続テストであり、全コース通しの人間によるプレイではない。
- 水晶洞の上段から下段の救済足場へ落ち、次の下段足場を経て出口側へ進めることを確認した。
- 水晶洞の出口バネで地上へ到達し、地上の一方向足場に着地できることを確認した。
- 時計塔の頂上の旗が固体の柱の上にあり、復活して足場に留まれることを確認した。
- 地下の追加スイッチで地上の対応する橋が開通し、必須の橋の総数が5のままであることを確認した。
- 既存の動く壁の上面・側面・下面、押し潰し、共通旗、協力スター、仲間ジャンプ、ボス連携、氷の蹴り出し、箱破壊、バネと空中操作の予測、復帰処理のテストが成功した。
- 4つの実WebSocketクライアントで、通信ルール12、移動、攻撃、再接続、共有進捗、退出を確認した。

## 画像と描画

- 新規WebP画像17点が正常にデコードできることを確認した。合計595,114バイト。
- スプライト16点は透過画像、地下背景1点は不透明画像。生成プロンプト、出力寸法、トリミングと縮小・変換情報をSOURCES.jsonに記録した。
- 橋とスイッチ、2人用封印、時計塔の壁キック、バネと加速石、遺跡地下、水晶洞地下の6場面を、本番のBoard587描画関数で各90フレーム描画した。描画例外なし。
- scene-preview.pngはネイティブCanvasによる描画確認。DOMで表示する本体のキャラクター画像を同じ座標に合成している。DOMのHUD・操作パネル・ブラウザーUIは含まない。
- 描画時間は検証環境のネイティブCanvasの値であり、iPhone Safariのフレームレートを示すものではない。
