# ミニゲームの引き継ぎ

えなみからの「次はのほほんと釣りをするミニゲーム」の希望は、2026-09-23に「ぬし釣り大騒動」を選択して具体化。Build524で新規実装しました。

のんびり魚影を狙う → 掛かったら巻く・緩める → 釣果を得点またはエサへ → 最後の30秒でぬしを狙う、という流れです。所持キャラと既存のパーティー機能を使い、４人・空席AI対応。

ブロック落としサバイバルはBuild522でユーザーが完成確認済み。Build523の魔獣ぶっとばし相撲を含め、既存ゲームの専用コードは今回変更していません。新しい依頼なしに変更しないこと。

Build524より後の新作は未指定です。公開先への適用・サーバー再起動は未実施。更新ZIPの適用前提はBuild523です。
