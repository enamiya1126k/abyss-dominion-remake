# ABYSS DOMINION GDD v1.0 改訂対応レポート

## 対応方針

- 現行のホーム、探索、戦闘、各メニューのレイアウトと基本操作を維持する。
- GDDで明示された差分を優先し、未確定値は新しく捏造しない。
- 本番用コードではテスト導線を無効化する。
- 既存セーブを破棄せず、`schemaVersion` による移行を行う。

## バージョン

- アプリ表示：`1.8.0`
- セーブスキーマ：`43`
- アセットキャッシュキー：`1.8.0-gdd-v1`

## 主な対応内容

### 探索

- 通常ダンジョン上限を10,000階として維持。
- 新規セーブのミニマップ初期値をOFFへ変更。既存セーブの設定値は維持。
- カメラドラッグ開始距離を画面上の10pxへ統一。端末のDPRに左右されない判定へ変更。
- ダブルタップによるカメラリセットは追加していない。既存の明示的な中央寄せ操作は維持。
- 石枠の水場を各階1～5か所、最大HP/MP各2%回復、生存中の出撃メンバーのみ、各水場につき遠征中1回として共通定義化。
- 使用済み水場は暗い空の水盤表示となり、戦闘・再読み込み後も状態を維持。
- 現在マップ、座標、カメラ位置・倍率、宝箱、水場、ドアイベント等を探索スナップショットとして保存。
- 再読み込みをマップ再抽選に利用できないよう、同じ遠征状態を復元。

### 戦闘

- 戦闘速度を `×0.5 / ×1 / ×2 / ×4` に統一。
- 待機時間とアニメーション時間の倍率二重適用を解消。
- 4vs4は味方4体編成時のみ開始可能。1～3体では開始不可。
- 戦闘画面でのスワイプ編成変更は追加していない。
- 持続型状態異常をモンスター個体データへ分離し、戦闘後・帰還・控え移動・再編成・再読み込み後も維持。
- 戦闘限定バフ、デバフ、CTは戦闘データ内だけで管理。
- 正式な治療アイテム、治療スキル、無料宿、ホーム休息で持続型状態異常を解除。
- 状態異常治療アイテムでは戦闘限定の能力低下・バフ等を巻き込んで解除しない。
- 敵の毒・火傷等を捕獲率へ加算し、画面表示と実際の抽選で同じ最終確率を使用。
- 戦闘終了・帰還でHP/MPを自動全回復しない。
- レベルアップは回復処理として扱わず、現在HP/MPを新しい最大値へクランプするだけに変更。
- 戦闘チェックポイントへ探索スナップショットと行動確定状態を保存し、再読み込み時の行動二重実行を抑止。

### 回復

- ホーム休息は所持中の全モンスターを完全回復・治療。
- ダンジョン内無料宿は現在の出撃パーティだけを完全回復・治療。
- 帰還処理とホーム休息処理を分離。

### 深淵・十神

- 関連機能の共通解放基準を100階へ変更。
- 1,000階未満という理由だけで十神を非表示・挑戦不可にしない。
- 階層別基準を500階40%、1,000階40%、3,000階60%、5,000階100%、10,000階100%へ統一。
- 緊急戦の基本発生率を3%、発生後クールダウンを10階へ変更。
- 緊急戦の発生結果・対象・開始前HP/MP/状態異常を保存し、再読み込みによる抽選引き直しを防止。
- 勝利時の欠片を5個、敗北時を10%で1個へ変更。
- 欠片結果と勝敗記録を戦闘ID単位で冪等化。
- 特殊戦のGOLD、チーム試練進行、欠片、契約結果を同じ戦闘IDの一括決済として保存し、結果復元時の二重付与を防止。
- 契約必要数を深淵50個、十神150個へ変更。必要欠片を消費して確定契約し、図鑑へ反映。
- 試練総数22戦と周回倍率 `1.0 + (周回数 - 1) × 0.5` を共通定義・保存形式へ追加。

### 本番・廃止仕様

- `CONTENT_TEST_MODE` をOFFに固定。
- 本番画面に一時的なTEST ACCESS表示を出さない。
- 魔魂、ホームのプレゼント入口、旧薬草屋を追加・復活していない。
- 参照されていない旧 `app.bundle.js` ではなく、`index.html` から読み込まれる `src/main.js` 系を正式実装として更新。

## セーブ移行

- 旧戦闘速度 `×1.5` 等は安全な `×1` へ正規化。
- 旧 `statuses` / `status` と旧戦闘中の毒・火傷を持続型状態異常へ移行。
- 既存セーブでミニマップ設定が欠けている場合は従来挙動のONを維持し、新規セーブだけOFF。
- 武器個体の種族別撃破数・異名進行データを正規化。
- 探索・戦闘スナップショットを検証して保存。
