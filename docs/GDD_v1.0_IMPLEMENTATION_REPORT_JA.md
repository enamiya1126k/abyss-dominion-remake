# ABYSS DOMINION GDD v1.0 改訂・Character Bible実装レポート

## 結論

提供された全22章の改訂GDDと「深淵、十神について」を、現行レイアウトと基本ゲームループを維持したままWeb版`v2.0.0`へ統合した。

| 検証指標 | 実装値 |
|---|---:|
| 深淵 | 7柱 |
| 十神 | 10柱 |
| 固有スキル | 85（各5） |
| 固有装備 | 102（各6部位） |
| セット効果 | 51段階（各2／4／6部位） |
| 奈落回廊 | 22戦 |
| BGMシーン | 7 |
| セーブスキーマ | 44 |

## 実装方針

- Character Bibleを表示、敵AI、契約個体、固有装備、回廊試練が参照する単一データへ統合。
- ホーム、探索、戦闘、管理画面のレイアウトと主要操作を維持。
- GDDの共通値は個別画面へ重複記述せず、共通ロジックから参照。
- 特殊戦の報酬と進行は戦闘ID単位で一度だけ決済。
- 旧セーブキーを変えず、新しいIDと保存形式へ自動移行。
- 未提供の音源は外部素材で補わず、本作専用のプロシージャル音響として実装。

## 深淵七柱・十神十柱

実装IDは次の17体に統一した。

| 区分 | 実装キャラクター |
|---|---|
| 深淵 | 暴食、憤怒、嫉妬、怠惰、強欲、色欲、傲慢 |
| 十神 | 時間、空間、生命、死、運命、混沌、支配、創造、終焉、神格 |

各キャラクターへ以下を実装した。

- 役割、称号、人物設定、遭遇台詞、勝利演出文。
- 戦闘AI方針、パッシブ、覚醒条件。
- 6属性の被ダメージ倍率、状態異常の無効／耐性／弱点。
- 固有基本技1＋権能4。契約後は同じ5技を習得候補として使用。
- 右手、左手、首、指、胴、補助の固有装備6部位。
- 各装備の固定能力文と固定数値、2／4／6部位セット効果。

旧IDは読み込み時だけ互換表を通し、新IDへ移行する。対象には旧「死滅」と旧属性神8体を含む。欠片、契約、キャラクター、装備、緊急戦、戦闘再開データを移行する。

## 戦闘・AI

- Character Bibleの4権能をボス固有行動へ接続。
- 攻撃、全体攻撃、吸収、割合ダメージ、防御無視、確定会心、回復、全体回復、蘇生、強化、弱体、状態異常、障壁を共通処理で実行。
- 属性倍率と状態耐性を、敵ボスと契約個体の双方へ適用。
- 睡眠、麻痺、凍結、魅了、混乱、恐怖は成功時に行動不能へ接続。
- 保存済み特殊戦を再開した場合もCharacter Bibleの属性・耐性・パッシブを補完。
- 通常探索・戦闘の隊列、AUTO、戦闘速度、捕獲、装備、育成の基本操作は維持。

## 奈落回廊

- 100階、4体編成で解放。
- 第1〜17戦は各キャラクターの単独審理。
- 第18〜22戦は複合回廊。
- 全22戦突破後は第1戦へ戻り、周回数を1増加。
- 敵補正は`1.0 + (周回数 - 1) × 0.5`。
- 戦闘開始時に味方を全回復し、終了後は挑戦前のHP／MP／状態へ復元。
- 敗北ペナルティなし。勝利時だけ次戦へ進行。

## 緊急戦・欠片・契約・固有装備

| 項目 | 実装値 |
|---|---:|
| 共通解放 | 100階 |
| 緊急戦率 | 3% |
| 発生後クールダウン | 10階 |
| 顕現 | 40%／60%／100% |
| 勝利欠片 | 5 |
| 敗北欠片 | 10%で1 |
| 深淵契約 | 50欠片 |
| 十神契約 | 150欠片 |

- 緊急戦の対象と発生階を保存し、再読み込みによる再抽選を防止。
- 欠片、GOLD、契約、回廊進行を戦闘ID単位で冪等化。
- 固有装備は6部位を順番に生成し、7個目以降は同じ順序で再生成。
- 装備は売却不可・自動素材化不可・初期ロックとして生成。

## 音響

- Web Audio APIでホーム、探索、通常戦、深淵戦、十神戦、勝利、敗北の7シーンを生成。
- 選択、攻撃、被弾、回復、ボス、勝利、敗北のSEを生成。
- 設定へ音響ON/OFF、BGM音量、SE音量を追加しセーブ。
- ブラウザの自動再生制限に対応し、最初のユーザー操作後に音響を開始。
- 外部音源、既存楽曲、第三者サンプルを使用していない。

## 改訂GDD共通対応

- ダンジョン上限10,000階、世界4領域を維持。
- 水場を各階1〜5か所、HP／MP各2%回復、遠征中1回へ統一。
- 戦闘速度を×0.5／×1／×2／×4へ統一。
- 4vs4は4体編成時だけ開始可能。
- 持続型状態異常を個体へ保存し、正式な治療だけで解除。
- 探索スナップショットと戦闘チェックポイントを保存し、再抽選・二重行動を抑止。
- 新規セーブのミニマップ初期値をOFF。既存設定は維持。
- 本番画面のテスト導線を無効化。
- 未参照の`src/app.bundle.js`は起動経路に使用せず、`src/main.js`を正本として維持。

## セーブ移行

- セーブキーは`abyss-dominion-remake-v001`を維持。
- `schemaVersion 1〜43`から`44`へ移行。
- 旧深淵・十神ID、状態異常、戦闘速度、契約個体、装備、特殊戦、探索／戦闘スナップショットを正規化。
- 新規音響設定と奈落回廊進行を欠損時だけ補完。
