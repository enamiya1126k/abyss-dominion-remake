# Build522 検証記録

## 原因調査で確認したコード上の問題

Build521では towerFrame517 が毎回 `serverNow - Date.now()` で時刻を補正し、自キャラの予測をスナップショットから再構成していました。表示時刻の巻き戻りや揺れが、そのまま予測時間に影響する経路がありました。自キャラ表示には別の追従処理がある一方、カメラは追従前の予測位置を使用していました。また他キャラの補間は受信から100msという固定間隔を前提としていました。

描画ループは毎フレームDOM検索、幅・高さ・属性・クラスの設定を繰り返し、左右ボタンのpointermoveではgetBoundingClientRectを毎回読み取っていました。同一サイズのResizeObserver通知でも背景キャッシュの再生成とカメラのリセットが発生する実装でした。

既存のタッチ抑止ヘルパーは単一タッチのbuttonを対象外としており、ボタンにはCSSの選択抑止があったものの、配下要素の明示指定とselectstart/contextmenu/dragstartの防止はありませんでした。今回、操作領域に限定して補強しました。ユーザー端末で実際に表示されたメニューやフレーム遅延の主因を実機で特定したものではありません。

**70項目成功、0失敗**。実行ログ: tests.txt。

今回の修正はクライアント表示・入力のみなので、100戦AIシミュレーションは修正後の検証対象から除外しました。物理、AI、閉鎖判定、20段／4段設定、サーバー側の各ファイルがBuild521からバイト単位で変更されていないことを別途確認しています。

新規検証:

- 不規則／まとめて届く通信でも表示時計・他キャラの補間位置が後退しない。
- 新ゲーム、サーバーによる開始時刻変更、長い中断からの復帰で時刻を再同期。
- サーバーの実際のスナップショット間隔で補間。死亡は直ちに確定状態を採用。
- 30/60/120Hzで位置追従の応答が一致。
- 同じHUD属性・クラス・スタイルを120回要求しても、書き込みは各1回。
- 選択／コンテキストメニュー／ドラッグ／ネイティブタッチの抑止が、このゲームの対象コントロールに限定される。
- 100回のpointermoveでもボタン矩形の読み取りは押し始めの2個分だけ。サイズ変更後は再取得。
- 同一サイズ通知でキャッシュとカメラを保持。画像デコードと実寸変更時は再構築。
- 縦長キャッシュの転送元領域がビューポート以内、描画DPR上限1.5を維持。
- 実際のView関数をDOM fixture上で動かし、フレーム中のDOM再検索が0、カメラが表示キャラと同じ位置を参照することを確認。
- 画面破棄でイベントを解除し、blurでも長押し移動を停止。
- 移動入力が確認済みでもスナップショットの速度が0なら長押し方向を失わず、指を離す入力は即時に送信・反映。

既存の物理、同時入力、キャンセル、再接続、閉鎖、超ジャンプ、固定全体表示、結果演出の回帰検証も成功しています。

## 見た目・範囲の確認

Build521/522のRendererを @napi-rs/canvas で同じ背景画像・盤面・DPR・サイズに設定し、逃げる側／全体表示のそれぞれで高さ0・8・16の計6場面を比較。全RGBA値が一致しました。結果: canvas-comparison.json。DOMキャラクター・ブラウザーCSSのスクリーンショット比較ではありません。

CSSの変更は既存操作領域とその配下の選択・コールアウト・ドラッグ抑止だけです。画像追加、レイアウト値・色・装飾変更はありません。ゲームルール、AI、カメラの寸法計算、フィナーレ、既存画像、online-server、〇×サバイバルは復元したBuild521作業ベースからバイト単位で変更していません。共通バージョン／キャッシュの変更は更新取得用です。

## 作業環境と制約

保存済みBuild468と差分群から復元し、Build521マニフェストの全掲載ファイルのSHA-256一致を確認しました。過去Build483のZIPは末尾不足のため展開できず、この作業コピーは完全な製品ソースではありません。従来同様、species.js、endgameCharacters.js、MonsterVisual.jsが不足し、既存テストのインメモリfixtureだけを使用しています。製品用の代用品は追加していません。

実ブラウザー、実iPhone、Safariのコンテキストメニュー、物理マルチタッチ、WebSocketの実回線往復は未検証。FPSや端末消費電力の測定は行っていません。処理回数の削減と通信揺れへの耐性をコード・シミュレーションで検証した修正です。

公開先への適用・サーバー再起動は実施していません。Build521本体／サーバーが適用済みの環境では、Build522は本体の更新とページ再読み込みだけで適用できます。
