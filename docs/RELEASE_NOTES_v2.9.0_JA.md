# ABYSS DOMINION REMAKE v2.9.0 リリースノート

## 戦闘AUTO

- 「自動 有効／無効」は指が触れた時点で切り替わるため、戦闘画面の再描画中でも1回のタップが届きやすくなりました。
- ボタンの実タップ領域を拡大し、現在状態を読み上げられるようにしました。
- 探索AUTOから入った戦闘でも、このボタンから現在の戦闘だけ手動へ切り替えられます。

## 戦闘カード

- 敵のMPは行動AI内部で引き続き消費・回復しますが、敵カードにはMPゲージを表示しません。
- 味方カードにも、敵と同じ位置へ装着中の魔法陣名とLvを表示します。

## 深層敵装備

- 旧「階層×2」より大幅に強い専用曲線へ変更しました。
- 300Fでは通常敵が約Lv.2000、ボスが約Lv.3100、高レア敵は約Lv.2700以上の装備を基準にします。
- 500F以降は階層とともに増加幅も大きくなります。50F以降の敵は従来どおり、ほぼ全員が6枠LR装備・全LRスロットです。
- この補正はダンジョン敵だけに適用され、捕獲後の仲間には持ち越しません。

## 魔法陣発動演出

- 味方と敵の双方で、発動者、魔法陣名・Lv、実際に発生した効果を専用バナーと戦闘ログへ表示します。
- 障壁吸収、蘇生、致死耐え、即死反射、死亡時継承、MP反転などは、発動した瞬間に数値を伴って表示します。
- 常時型はその戦闘で初めて効果が関係する行動時に、倍率や条件を表示します。
- 運命の三桁環は000〜999を3桁スロットで表示し、000なら行動休止、それ以外は0.5〜3倍をその行動へ反映します。敵側も同じ抽選を行います。

## 演出文字

- 通信不要の端末内蔵極太ゴシックを優先し、縁取り、発光、数字のスロット書体を組み合わせました。
- 小画面では自動縮小し、長い名称も戦闘情報を隠しすぎないサイズに抑えます。
- 「視差効果を減らす」が有効な端末では、回転や移動を省略して最終結果を即時表示します。

## 互換性

- アプリ／アセット版数：2.9.0
- セーブスキーマ：54（変更なし）
- セーブキーは変更していないため、既存セーブをそのまま利用できます。
