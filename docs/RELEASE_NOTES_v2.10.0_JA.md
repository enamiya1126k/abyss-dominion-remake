# ABYSS DOMINION REMAKE v2.10.0 リリースノート

## 魔法陣の読みやすさ

- 発動表示を通常スキルバナーと同等の長さへ延長しました。×0.5では、登場と退場を含めて約3秒表示します。
- 読み取り中の放射回転や強すぎる影を抑え、濃い背景、太いゴシック、明確な文字サイズ差へ変更しました。
- 表示順を「発動者／陣営」「魔法陣名・Lv」「実際の効果」「補足」の4段階へ統一しました。
- 味方の運命の三桁環で999が揃うと、現在選択している敵へ即死を適用し、専用の確定演出を表示します。敵側の999は3倍のままです。

## ミミック

- 味方1人につき、各ラウンド最初の攻撃だけ1ダメージを与えられます。同じ味方の連撃・追撃は、そのラウンド中は完全ガードされます。
- 1ラウンドの最大ダメージは4、HPは5のため、4人編成でも最低2ラウンド必要です。
- 敵ミミックの極端な攻撃力、捕獲率1%、捕獲後に敵専用補正を持ち越さない仕様は維持します。
- 全体攻撃になっていた特殊行動は、単体または2体だけを対象にします。

## 蘇生演出

- 味方は青＋金、敵は赤＋紫の光柱と足元魔法陣で陣営を判別できます。
- 暗転、タイトル、光柱、粒子、倒れ素材からの復帰、HPゲージ増加を一連の演出へまとめました。
- 複数体が同じ処理内で蘇生した場合は、1体ずつ待たずに全光柱を同時表示します。
- 複数体は「連鎖蘇生」、陣営全員なら「全軍復活」と表示します。

## お知らせ

- 「すべて／配布／イベント／更新／保守」の5タグで内容を実際に絞り込めます。
- 各タグに件数を表示し、選択状態を明確化しました。
- お知らせをタップすると詳細が展開し、その項目だけ既読になります。日付、NEW、既読、空表示にも対応します。
- 毎日配布は「配布」へ分類され、当日分の捕獲結晶×5・魔晶石×100を従来どおり手動で受け取れます。

## ホームと休息

- HPまたはMPが最大値の5%以下になった仲間は、ホームで倒れ素材を表示します。
- 瀕死中は足元魔法陣を暗くし、HP不足／MP不足／戦闘不能の理由を小さく表示します。
- 1体でも該当するとベッドが発光・脈動し、「休息できます」と対象人数を案内します。
- 回復してHP・MPがともに5%を超えると、通常素材へ戻ります。

## 敵の深層強化

- 敵部隊内で同じ魔法陣が重複しないよう、編成確定後に未使用種類へ再抽選します。
- 100F以降およびLR・神話・深淵・十神の敵は、魔法陣を必ず装着します。
- 300F通常敵は6枠すべてLv.6000級、LR敵はLv.8100級、ボスはLv.9300級を基準にしました。
- 500F通常敵はLv.15000級となり、それ以降も階層が深いほど伸び幅が増えます。

## 素材向きについて

- 252キャラクター×8枚を個別に判定・反転する作業は、誤反転を避けるため本版には含めていません。
- 今回は戦闘、レイアウト、演出、バランスの品質を優先しています。移動方向と対面方向の素材正規化は、専用の監査工程として次回へ分離できます。
