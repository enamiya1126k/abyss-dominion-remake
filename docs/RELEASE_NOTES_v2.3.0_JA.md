# ABYSS DOMINION REMAKE v2.3.0 リリースノート

## 更新概要

追加修正依頼を統合し、探索・戦闘・試練・奈落回廊・深淵／十神・音響・管理画面を仕上げた完成版です。既存の画面構成とゲーム性を土台にし、操作量、視認性、難易度、報酬の高揚感を重点的に調整しました。

## 主な更新

- 探索部隊HUDをHP／MP数値付き2×2カードへ更新し、開閉時は探索画面を自動拡張。
- 目的別の完全自動探索を追加。
- 水場使用後の素材を、使用前と同じ石枠・大きさで再制作。
- 通常敵を1〜4体、深層ボスを最大4体編成へ拡張。
- 10階ごとのボス能力を大幅強化。
- 敵の複数攻撃、火傷、凍結、毒、麻痺、出血、呪い、群体支援を実装。
- 戦闘中の名前、属性、TURN、前衛／後衛、撃破後の位置とサイズを整理。
- ダメージ表示へスロット確定演出と攻撃種別カラーを追加。
- 奈落回廊を歩行式ボス部屋と連勝精算ゲームへ再構築。
- 欠片祭壇、持ち物内欠片、契約／神装生成、モンスター一括統合、属性絞り込みを追加。
- BGMを場面ごとに正しく切り替え、非表示・離脱・画面ロック時に自動停止。

## 配置方法

ZIPを展開し、公開先の古いファイルへフォルダごと全上書きしてください。`index.html`だけでなく、`src`、`assets`、`tests`、`docs`も含めて差し替えます。

初回アクセス時にアセット版`2.3.0`を検知し、旧キャッシュと旧Service Workerを削除します。反映確認のため、配置後に一度だけページを再読み込みしてください。

既存セーブは同じセーブキーからスキーマ47へ自動移行します。ブラウザのサイトデータは削除しないでください。
