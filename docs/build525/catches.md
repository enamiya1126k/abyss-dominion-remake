## 抽選

通常の小さな魚影（tier 0・1）でエサを使わない場合、長靴10％、ルアー７％、エサ専用８％、通常の獲物75％。エサ専用はtier 0でザリガニ、tier 1でカメ。通常枠はそのtierの対象から等確率です。新規投げ入れのストックエサはtier 3未満を55％で１段上げ、取り込みを補助します。

連鎖では使った獲物のレシピを優先します。以下は継続時の抽選。

- 古びた長靴 → 宿借り大ヤドカリ 100％
- 宿借り大ヤドカリ → 宝箱ミミック 72％ ／ 鍵角ウナギ 28％
- 宝箱ミミック → 鍵角ウナギ 100％
- 鍵角ウナギ → 王冠ガニ 100％
- 王冠ガニ → 深淵の宝箱 100％
- アメリカザリガニ → 岩背ナマズ 65％ ／ 黒鎧チョウザメ 35％
- ミドリガメ → 黒鎧チョウザメ 70％ ／ 鍵角ウナギ 30％
- 岩背ナマズ → 黒鎧チョウザメ 100％
- 黒鎧チョウザメ → 王冠ガニ 100％
- 月冠キンギョ → 黄金アロワナ 60％ ／ 王冠ガニ 40％

ルアーからはtier 3の通常枠58％／tier 2の通常枠42％。ルアーの難易度係数は0.7（速度と張りに適用）。その他の連鎖は0.88。レシピのない連鎖中の獲物では通常枠のtierを１つ上げ、最大tier 3にします。最大６連鎖、終端の宝箱とヌシは継続不可。終盤のヌシは専用の魚影を狙います。
