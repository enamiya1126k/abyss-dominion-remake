# ABYSS DOMINION REMAKE v2.8.0 リリースノート

## スキル説明

戦闘コマンド、スキル設定、編成、戦闘詳細の説明を、実際のスキルデータから自動生成する方式へ変更しました。物理／魔法ATK倍率、Hit数と合計倍率、対象、属性、状態異常の成功率・持続・毎ターンダメージ、HP／MP回復率、蘇生量、吸収率、強化・弱体量、MP、CTを確認できます。

## 戦闘フィードバック

- 味方が通常攻撃や継続ダメージを受けた時も、対象の揺れ、点滅、戦場の衝撃、画面フラッシュが発生します。
- 味方・敵のHP回復は緑、MP回復は青の発光と粒子で表示します。
- 回復時は数値とゲージが直前値から滑らかに増えます。
- 敵のMP回復も読めるよう、敵カードへ小型MPゲージを追加しました。
- 端末の「視差効果を減らす」設定では、長い移動アニメーションを省略して最終値を即時表示します。

## 捕獲結晶

- ダンジョンの骨を調べた時、既存の鍵／GOLD抽選とは別に1%で捕獲結晶×1を獲得します。
- 取得は右上の簡易トーストだけで通知し、探索AUTOを停止しません。
- お知らせBOXに「本日のログイン支援物資」を追加しました。日本時間0時に当日分が更新され、捕獲結晶×5・魔晶石×100を受け取れます。
- 配布は受取ボタン式です。当日中に受け取らなかった分は翌日に持ち越さず、同日の二重受取もできません。
