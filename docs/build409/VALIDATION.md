# Build409 編成比較・検証

今回有効にしたのは24ペアの追加相乗効果。特殊能力5体はBuild408の設計状態のまま。通常戦闘のクライアント処理が対象。

## 100試行の主要比較

各欄は「勝率 / 勝利時ラウンド中央値」。レベル1500・装備なし・魔法陣なし、各編成・各敵で同じ初期乱数シード1〜100。敵の条件は編成間で固定。これは強さを比較するための制御されたテスト戦で、実際の地域の出現敵やPvPの勝率を表すものではない。

|編成|汎用|回復|弱体|障壁|短期火力|長期ボス|
|---|---|---|---|---|---|---|
|十神4体|100% / 2R|15% / 1R|3% / 2R|100% / 1R|34% / 1R|8% / 7R|
|薬毒＋双藤（R/SR）|100% / 5R|3% / 2R|0% / —|1% / 12R|0% / —|0% / —|
|返誓＋双鐘（SSR/UR）|100% / 5R|100% / 2R|4% / 5R|58% / 7R|89% / 2R|100% / 8R|
|魔導姫＋剣姫（LR/神話）|100% / 3R|100% / 1R|100% / 2R|100% / 2R|100% / 1R|100% / 5R|
|魔導姫＋時間・生命|100% / 5R|100% / 2R|73% / 3R|98% / 4R|71% / 3R|85% / 9R|
|上位単独4体（ペア不成立）|100% / 10R|92% / 4R|5% / 7R|0% / —|6% / 5.5R|0% / —|

## 読み取りと採用した調整

汎用戦では十神4体の速さを維持。上位ペア2組は弱体主体の敵・長期戦で強く、同じLR/神話の単独4体より勝ち筋が明確になった。低ランクの薬毒＋双藤は汎用戦に勝てるが、高ランクの攻撃・浄化・障壁を持つ相手へ全面的には勝てない。

追加相乗効果を無効にした比較も同じ条件で実施。上位ペアの優位は既存の連携倍率による部分も大きく、Build409だけで新たに生まれた差とは扱わない。たとえば弱体戦の魔導姫＋十神2体は71%→73%、短期火力戦の返誓＋双鐘は84%→89%。障壁戦の返誓＋双鐘は78%→58%となり、敵の返誓・竜姫側にも追加回復・障壁が働く影響が出ている。

基礎ステータス・既存追撃倍率は変更せず、Build408の条件付き数値を採用。重複した支援は加算せず最大値、二人の自然な攻撃対象が一致した時だけ双鏡+20%、剣姫の次ラウンド強化は最初の共鳴だけ+10%。返誓の5%回復は守られた本人へ、同種1回/R。多段・全体攻撃で回数を増やさず、死亡・捕獲・隔離・行動不能で後続効果を止める。

## 比較範囲

- 本番の `main.js` の関数宣言をVMへ読み込み、通常コマンド、敵AI、自然行動前の権能処理、行動順、CT、ラウンド終了、状態異常、回復・障壁を実行。描画、待ち時間、保存先への書き込み、勝利報酬処理のみ比較用に置換。
- 6編成 × 6敵条件 × 追加効果OFF/ON。主要条件は各100シードで7,200戦。
- レベル1500/3000 × 装備なし/あり × 魔法陣なし/ありの残り7条件は各20シード、10,080戦。合計17,280戦。
- 装備ありは全員同じLR・+0・キャラと同レベルの6枠（炎刃、星詠みの杖、魔布のローブ、守護者の外套、旅人の指輪、生命の首飾り）。本番の装備倍率で数値補正を合算。厳選・専用・シリーズ効果は除外。
- 魔法陣ありは並び順に不屈の残光・魔力反転陣・半月障壁陣・開戦共鳴陣、各Lv10。編成間で同じ予算・順序。敵側の魔法陣はなし。
- アイテム使用なし、30ラウンド打切り。味方の権能を使用。敵は既存のキャラ・固有スキルを使い、HPと攻撃性能をシナリオごとの一定係数で調整。
- 全24ペアを時間・生命と組ませた実戦処理も各3シード（72戦）で確認。
- 3編成×5シードの15組で、通常/4倍設定/ラウンド2のペア状態JSON復元後の結果を比較。HP・MP・発動数・勝敗が一致。待機時間を除いた処理の比較で、実機のアニメーションやアプリ全体の再起動試験ではない。

## 計測値と限界

CSV/JSONに勝敗、勝利ラウンド中央値、HP増減、MP消費・吸収、実際に吸収された共通障壁量、相乗効果の発動数を保存。HP増加は実際に増えた分だけで、過剰回復や未消費の盾を強さへ加算しない。HP増加には蘇生を含む。HP減少には自傷・継続ダメージも含む。MP減少は行動者自身の減少と他者による減少を区別。生の全試行は `samples.jsonl`。

全キャラ・全装備・全魔法陣の組合せを保証するものではない。専用6点装備の十神、深淵との混成、オンライン・レイド・PvP、iPhone実機の表示・フレームレートは今回の比較に含まない。比較表の絶対勝率より、同条件の編成差と前後差を評価する。

## 回帰確認

238テスト成功。24組×敵味方の発動、条件不成立・ミス・回数上限・同種複製・死亡・隔離・中断JSON、MP表示/使用判定/敵AI、実際のSaveServiceを通したチェックポイント保持を確認。古いテストの旧UI文字列・旧倍率期待値とVMの追加依存を新仕様へ更新し、テストの除外は行っていない。

演出は24配色・12紋章、二人同時登場、通常/充填/解放/終撃/反撃の5段階。既存キャラ画像を再利用し、操作入力を遮らず、OSの「動きを減らす」設定に対応。HTML構造・条件分岐・CSSは確認済み。ブラウザー実行環境を用意できなかったため、画面を描画した目視検証とiPhone実機確認は未実施。

## 再実行

Node.js 22以降。リポジトリのルートから実行：

```sh
node --test tests/build409-pair-series.test.mjs
node --expose-gc tools/build409/compare.mjs general primary
node --expose-gc tools/build409/compare.mjs general sensitivity
node --expose-gc tools/build409/extra-checks.mjs
```

敵条件名は general / healing / debuff / shield / burst / boss。primaryは100シード、sensitivityは残り7条件を20シードずつ。VMの抽出位置は同梱のBuild409 main.js専用で、SHA-256不一致なら停止する。
