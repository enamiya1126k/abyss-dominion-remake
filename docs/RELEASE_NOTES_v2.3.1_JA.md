# ABYSS DOMINION REMAKE v2.3.1 リリースノート

v2.3.1は、v2.3.0公開後に確認された表示崩れ・操作導線・試練回数・演出品質をまとめて修正した完成版です。セーブキーは維持され、旧データは起動時にschema 48へ自動移行します。

## 主な更新

- 探索上部の4体表示を、名前・属性・現在値付きHP／MPバーを持つ2×2カードへ統一。ワンタップで収納すると探索領域が拡張します。
- ミニマップと自動探索を小型化し、どちらもドラッグ移動に対応。自動探索は戦闘を挟んでも継続し、「自動停止」まで方針を保持します。
- 取得・回復・自動探索通知を小型化し、探索の視認性を改善しました。
- 編成候補の属性フィルターが実際の候補一覧へ反映されない問題を修正しました。
- 装備画像の旧フォールバック重ね描画を廃止し、各装備を正しい単一素材だけで表示します。
- 装備対象欄を、キャラクターと属性紋章を主体とした4枠の選択UIへ整理しました。
- 4 VS 4と奈落回廊をそれぞれ1日10回挑戦へ変更。敗北画面も専用の試練結果表示へ刷新しました。
- 奈落回廊の部屋・奈落孔を新規高品質ラスター素材へ置換。敵を中央、勝利後の奈落孔を部屋奥に固定しました。
- 戦闘ダメージを通常1.5秒、クリティカル1.8秒表示し、数字確定後の余韻を確保しました。
- 味方・敵の戦闘カードへ★／＋値と状態効果表示領域を追加しました。
- 深淵スキルツリー入口を1つの専用ゲートへ整理し、ツリー内の絵文字アイコンをゲーム内ピクセル素材へ置換しました。
- GOLD不足通知を簡潔な短文へ変更しました。

## 配置方法

ZIPを展開し、公開先にある旧ゲームフォルダの中身をすべて上書きしてください。ブラウザのサイトデータは削除しないでください。古い画面が残る場合は、Safariを完全終了してから再度開いてください。
