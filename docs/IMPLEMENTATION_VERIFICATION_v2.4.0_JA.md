## 6. 敵AI・内部MP

- 敵ごとに最大MP・現在MPを生成し、保存された異常値を内部最大値へクランプ。
- 通常攻撃、防御、溜め、強撃、狂暴化、MP吸収はMP0。回復、蘇生、群体回復、群体強化、解除、障壁、権能、属性特殊攻撃はMP消費。
- MP不足時は特殊行動を実行せず通常攻撃へ切替。
- 毎ラウンド最大MPの8%を内部回復。
- ヒーラー／支援役は戦闘不能者の蘇生、低HP味方の回復、相手強化の解除を優先。
- MP低下時は相手MPを見て吸収を選択。状態異常、集中攻撃、前後衛判断も既存戦闘ルールへ統合。
- 蘇生可能かつMP十分／MP0の両ケースを自動テストし、期待行動を確認。

## 7. なつき度

- 生成・移行時に0〜1000へクランプし、旧`bond`と同期。
- 100、200、300、400、500、600、700、800、900、1000の全境界で効果が変化することを自動検証。
- 通常勝利+2、ボス勝利+5、通常敗北-1、下限0・上限1000。
- 合成、限界突破、一括統合では、対象と素材のうち最高のなつき度を継承。
- 1000時の「親友」表示を実装。
