# Build604 検証記録

## 結果

`node --test tools/build604/*.test.mjs`：178件成功、0件失敗。

- 6属性すべてによる砲弾・落下氷・転がる氷・斧の一撃破壊を確認した。
- 砲身の追尾、発射前の狙い固定、弾の大きさ、高速弾の連続判定を確認した。
- 箱が氷を遮り、箱を壊さず、背後のプレイヤーを凍らせないことを確認した。
- プレイヤーの3秒凍結、移動・攻撃停止、味方の攻撃による救出、敵の攻撃による解凍、凍結中の死亡数非加算を確認した。
- 通常形態と雷形態の水場内速度がそれぞれ117.5、157.5であり、水場外の1/2になることを確認した。ジャンプ可能・水場の接触ダメージなしを確認した。
- 被弾1回につき死亡1回・700ms後の復帰・復帰直後の無敵・盾による防御時は非加算を確認した。死亡モーションの軌道と500ms後の消失を確認した。
- ボスの頭部が休止・気絶中のみ弱点になり、踏まれた後に跳び退くこと、500msの被弾間隔を確認した。
- 11コースすべてで、3番目の星だけを取った際にHUDの3枠目だけが点灯することを確認した。
- 6種の星ギミックの解放・共有取得、時間制限の再挑戦、壊した運搬用氷の復帰を確認した。
- 既存の壁キック、バネ、地下経路、移動足場、明滅足場、チェックポイント、箱の一撃破壊を再確認した。
- 4つの実WebSocketクライアントで進行、破壊、共有スター、砲弾・凍結・解凍、切断と再接続を確認した。

`scene-preview.png` は本体のCanvas描画関数で作成した6場面のプレビューである。HTMLで表示するプレイヤーだけを、同じ座標に既存ゲーム画像で合成した。スターのHUDは別途HTML出力テストで確認した。新素材3点と既存ボス画像を実際にデコードして描画した。

## 残る確認

iPhone Safari実機、端末間の実ネットワーク遅延、全コースの開始から終了までの通しプレイは未確認である。ローカルブラウザーの起動環境を用意できず、ブラウザー全体のスクリーンショット確認は実施できなかった。プレビューはSafariのスクリーンショットやFPS測定ではない。

変更JSの構文、相対import、キャッシュ更新、更新ZIPのCRCとSHA-256を検証した。公開サイトへの反映は行っていない。
