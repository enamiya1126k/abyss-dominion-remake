# Build545 — ４ゲームの操作・表示改善

v3.1.224。Build544適用済みプロジェクトへ上書きする差分パッチです。

## 適用

1. `ABYSS_DOMINION_Build545_patch.zip`を展開し、Build544のプロジェクト直下へ同名ファイルを上書き。
2. 本体をいつもの公開先へ反映し、`online-server`を再起動。
3. 参加者全員で画面を再読み込み。

本体とサーバーの両方の更新が必要です。公開サイトへの反映は、この作業では行っていません。
更新前の進行中カート戦・爆弾戦は準備画面に戻ります。古い参加者には更新を案内します。
セーブデータ、`online-server/data`、環境変数ファイルは含みません。

## 暴走ショッピングカート

- 滑る床を、新しく生成した磨き石の素材に変更。道路の遠近に合わせて描きます。
- コースをタップ、または下の方向バーで左右の角度を指定。方向を決めてから、従来どおり長押し→離して発進。
- 第３回は中央に搬入荷物があるコース。左右の壁に反射させて回り込みます。
- 白い予測線は、床・荷物・壁の反射を含めた道筋と停車位置。ほかのカートへの接触は予測に含みません。
- 接触した方向に応じて勢いを伝え、斜めの衝突では向きも揺れます。壁や荷物との重なりも解消します。
- 全４スタート位置から金枠まで届く反射ルートを検証しました。
- 全５回、最終回２倍、金枠＋50点、全車停止後に得点確定、場外０点は継続。

## 魔王城の爆弾リレー

- フィールドを押して指をスライドすると、その方向へ移動。指を離せば停止。小さいマスを正確に何度も押す必要を減らしました。
- 短い床タップで目的地へ移動する操作も残しています。
- 移動用の指を押したまま、もう１本の指で爆弾やキックを操作できます。
- 蹴れる範囲を1.2マスから1.55マスへ拡大。蹴る方向を矢印で表示し、先が塞がっている爆弾は「けり返す」を点灯させません。
- 通常撃破＋１点、蹴られた爆弾で撃破は最後に蹴った人へ＋２点。蹴り合っても導火線は延長しません。
- 黒紫の四角は「床が抜けた穴」でした。縁が崩れた穴の絵と「穴」の表示に変更。
- 爆風で床が崩れる前は「崩れる！」とひび割れを表示。予告を0.65秒から1.4秒へ延長。
- 盾アイテムは青い盾と光る台座、「盾」の表示で認識しやすく。拾うと１回だけ爆風を防ぎます。穴への落下は防げません。
- 矢印/WASDで移動、Spaceで爆弾、Kでキック。キーを離す・操作が中断する・通信が途切れる場合の停止も対応。

## 魔王のかくれんぼ

- 魔王の表示は、視界の境目で届く座標が出入りすると急に切り替わる状態でした。表示中の位置を補間し、見失った瞬間は最後に見えた位置から短く消えるようにしました。
- 見失った後の位置は予測しません。鬼へ渡す情報や視界のルールは変更していません。
- 仲間の名前を画面の安全な位置へ収め、重なった名前はずらします。小さい画面ではミニマップを避けて表示します。
- 地形とミニマップのキャッシュを維持し、固定の装飾の再生成・全体ソートを減らしました。表示範囲外の物体は補間・描画対象から外します。
- 横向きでフィールドが潰れていたため、横向き時だけ操作欄を横に配置。
- 変身、スタミナ、封印、攻撃回数などのルールはBuild544と同一です。

## 用水路防衛隊

- 巨大な連携通知の原因は、CSSの上端・下端の指定が重なり、通知が縦に引き伸ばされることでした。
- 通知を下端の高さ24px・１行に固定し、1.1秒で消します。タップを妨げません。
- 水車・水門・家の背景を新しいアセットURLで読み込みます。読み込み中はCSSの背景を使い、失敗時は既存の水路背景へ切り替えます。
- 制限時間、捕獲、FEVER、大網、家の体力などのルールは変更していません。

## 検証とスクリーンショット

自動テスト83項目を通過。テスト結果は `docs/build545/tests.txt`、実クライアントでのブラウザー確認は `docs/build545/browser-report.json` を参照してください。

- サーバーの正式な判定で角度・長押し・反射・衝突を確認。予測線と実際の単独走行の一致、衝突によるエネルギー増加がないことを検証。
- 方向移動と爆弾の同時入力、指を離した停止、キャンセル、キーを離した停止、キックの相手画面への反映を確認。
- 320×568、390×844、430×932、844×390で実際のRaceClient451とパーティー用CSSを読み込み、表示と操作欄を確認。
- かくれんぼは150回の描画計測で中央値0.2ms、95パーセンタイル0.4ms。地形・ミニマップ・装飾キャッシュの再利用を確認。
- 指定プレイヤーカラーを維持。他ゲームの専用ルール・画面は変更していません。
- スクリーンショットは実装の描画画面です。床・荷物・穴・盾・通知が見えるよう、一部に検証用の再現配置を使っています。

元プロジェクトの一部カタログと共通ポートレートがこの環境にはないため、ローカル検証でのみ `tools/build539/catalog-fixture.mjs` と既存の基本相棒画像を使用しています。検証用データは本番から読み込みません。
iPhone実機Safari・LINE内ブラウザーは未検証です。性能計測はローカルChromiumでの値で、実機性能の保証ではありません。
