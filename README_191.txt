ABYSS DOMINION REMAKE 191 差し替えパッチ

基準: 190完成版
バージョン: 2.11.74-build250

【191の修正内容】

1. 集会所の簡易チャット
- チャットボタンを押した時は、画面下部の入力欄・送信・閉じるだけを表示します。
- 左上へ出ていた履歴・見出し・談話板ボタンを非表示にしました。
- 入力中に新着チャットやエモートを受信しても入力欄を作り直さず、iPhoneのフォーカス・カーソル・キーボードを維持します。
- 送信した発言がプレイヤー頭上へ短時間表示される既存挙動は維持しています。
- 履歴を確認したい場合は、フィールド内の「募集・談話板」を利用できます。

2. 集会所のエモート
- 長押しの起点ボタンを固定したまま、6個の選択肢を等間隔に配置しました。
- 背景に残っていた用途不明の中央円を撤去しました。
- 長押し中の移動停止・指を離した位置の選択・iPhoneの誤スクロール防止は維持しています。

3. 「交流」ボタンを交流所へ変更
- 集会所に専用のドット絵建物「交流所」を追加しました。
- 右下へ浮いていた交流ボタンは集会所では表示しません。
- 交流所をタップすると建物まで歩き、近づいた時だけ「交流所へ入る」が表示されます。
- フレンド申請・招待・ギルド遠征のお知らせは、消さずに交流所の小さなバッジへ移しました。
- フレンド・ギルド・招待・交流パネルの中身は従来どおりです。

4. プレイヤー交換の操作性
- 集会所で他プレイヤーを押せる透明な範囲を上下左右へ拡大しました。
- 切断中のプレイヤーには透明な判定を付けず、床の移動タップを邪魔しません。
- 見た目の大きさ・立ち位置・交換申請の安全処理は変更していません。
- 交換品一覧が古いグリッド指定で潰れていた問題を解消しました。
- iPhoneでは検索欄と数量を1行に保ち、一覧を最低約3件分確保しました。
- 入力欄を16pxにして、選択時のSafari自動拡大を防止しました。

【適用方法】

このZIPの中身を、190完成版の公開フォルダ直下へそのまま上書きしてください。
ZIP内には191で変更・追加したファイルだけが入っています。

オンラインサーバー側の変更はありません。通常はサーバー再起動不要です。
既存のセーブデータ・部屋・交換履歴はそのまま利用できます。

【確認項目】

- 集会所のチャットボタンで下部入力バーだけが開く
- エモート6個が均等に並び、中央の謎の円が表示されない
- 集会所では浮遊交流ボタンが消え、交流所から交流パネルを開ける
- フレンド・招待・遠征通知が交流所のバッジへ表示される
- 入力中の新着チャット・エモートでもキーボードとカーソルが外れない
- 他プレイヤーの周囲を含めて交換を開始しやすい
- 切断中のプレイヤー周辺をタップしても床移動が阻害されない
- 交換一覧を3件以上見渡して縦スクロールできる
- 従来の交換確定・キャンセル・再接続保護が変わらない
