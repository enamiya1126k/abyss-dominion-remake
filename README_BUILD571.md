# Build571 / v3.1.250 — 運だけ大運動会・バフと新装備

育てた装備を掛け合わせて大きく飛ぶ楽しさを強める更新。アイテムを40種類から52種類へ追加した。

## 遊び方・表示

- 成長・太陽・コイル・命中チャージ・攻撃実績・走破などの倍率は、種類をまたいで掛け算。通常の「+m」は土台に足し、その合計に倍率を掛ける。端数処理は最後に一度だけ。
- 選択前の合計倍率・最終移動距離は表示しない。個々の効果は説明し、飛ぶ瞬間に倍率を順番に出す。実際にどこまで飛ぶかは演出と結果で分かる。
- 「装備の個数」と「蓄積したチャージ」を分ける。太陽3個は大技×27、コイル2個は×4。選択後に補充されるコイルも別記する。
- 毎回の4択には大技以外が必ず1枚以上。最終回には大技も必ず1枚以上。チャージを使わず育てる選択が残る。
- 出目のルーペを1個につき+2へ強化。6を超える補正も有効。ダイスの絵は1〜6の実際の目を見せ、補正後の値は別表示する。大砲は補正後6以上で当たり。
- 貯金箱の解放は貯金×8へ強化。マグネットは先頭の相手の累計距離の30%を奪う。コメットの追い上げは差の半分。どちらも従来のm上限を撤廃。
- 透明な青と金の結界素材、新しい12アイコンを追加。小さい画面の手札は縦スクロールに対応。

## 追加した12種類

| アイテム | 効果 |
|---|---|
| 狩人の蓄電コア | 効果を与えた相手1人ごとに命中チャージ+1/個。次の大技で1個×2、2個×4… |
| 連撃の勲章 | 次の回から前進×（1＋試合中の攻撃成功数）。複数装備の倍率も掛け算 |
| 千里の羅針盤 | 開始時の累計1,000mで×2、1万mで×3、10万mで×4… |
| 先陣の旗 | 前半のみ出現。装備した次の回から前進×3/個 |
| 開幕の流星靴 | 序盤1/4のみ出現。4,000m＋自分の累計距離×2を土台にする大技 |
| 双生の共鳴鏡 | 攻撃装備以外の装備数と蓄積バフを倍増。育った回数・距離の記録を引継ぐ。過去の攻撃成功数は倍増しない |
| 蓄熱タンク | 大技で使ったチャージを半分残す。2個で3/4、3個で7/8。端数切捨て |
| 再燃のフェニックス | 大技の前進が攻撃で0になったら消費分を返却。温存分との二重返却はしない。出目の外れは対象外 |
| 守りの発電ギア | 防御・反射した1発ごとにコイル+1/個 |
| 不屈の碇 | 甲羅・バナナ・ブレイカー・マグネットの距離損失を半減。2個で1/4 |
| 無傷の双羽 | 効果のある攻撃を受けなかった回に羽+1/個。次の回から前進×（1＋羽）。貯めた羽は失わない |
| 走破記録の金庫 | 装備時の距離500mで×2、5,000mで×3、5万mで×4…を固定し、以降の前進に掛ける |

距離連動の2装備は10倍ごとの節目で倍率が1段階育つ。装備の複製と累計距離を繰り返し直接掛ける試案は16回戦で数値が急増しすぎたため、この方式に調整した。累計距離そのものに上限は設けていない。

同種攻撃の重複は威力をまとめて1発。命中数は実際に効果を与えた相手の人数・攻撃種別で数える。防がれた攻撃や効果0は加算しない。反射が通った場合は反射した側の成功となる。奪った距離は攻防後に加算し、再度バフ倍率は掛けない。
