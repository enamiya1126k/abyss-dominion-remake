ABYSS DOMINION REMAKE v3.0.1 / build301
100階・区画ダンジョン完成／全体バランス調整パッチ

この差し替えパッチは build300 専用です。

【導入方法】
1. 念のため、現在のセーブデータとゲーム一式をバックアップしてください。
2. ZIPの中身を build300 のゲームルートへ、階層を保ったまま上書きしてください。
3. index.html、src、online-server、tests が元と同じ位置になるように展開します。
4. オンラインを使用する場合は、ブラウザ側と online-server 側を同時に差し替え、サーバーを再起動してください。
5. 更新後はブラウザを再読み込みしてください。古い表示が残る場合はキャッシュを消して再読み込みします。

【セーブ移行】
・旧セーブは初回起動時に Save schema 71 へ自動移行します。
・所持魔物、装備、通貨、図鑑、実績などの既存データは維持します。
・旧1000階進行は「旧10階＝新1階」で100階制へ換算します。
・座標互換のない旧探索途中データだけは安全のため入口から再開します。
・ボス討伐、鍵、戦利品箱、温泉、次階層出口の状態を保存し、再入場・退出・切断・再接続後も復元します。

【区画型ダンジョン】
・各階は4～6個の不規則な形の区画で構成されます。
・廊下で一枚の地図をつなぐ方式ではなく、区画端の暗い通路／ポータルを歩いて別区画へ移動します。
・区画配置と接続方向は階ごとに変化し、各区画には異なる属性が設定されます。
・床に落ちた鍵は各階3本。上を歩くだけで取得できます。
・鍵HUDを3枠表示に変更し、取得済み本数と残り本数を常に確認できます。
・階層ボスは公式の階層支配者を使用し、通常の雑魚を拡大した代用品は出現しません。

【ボス討伐後】
・ボスを倒すと、その階では雑魚敵の新規出現が停止します。
・討伐地点に、豪華な鍵付き戦利品箱、全回復の温泉、次階層へ進む出口が出現します。
・戦利品箱は紫金の専用演出と名称表示で、通常宝箱と明確に区別します。
・開封時は大きな「GET／MYTHIC GET」結果画面を表示し、装備画像、性能、欠片、所持数を確認できます。
・鍵は戦利品箱の追加解錠に使用します。途中まで開けたあと残りの鍵を拾って戻った場合も、未取得分だけ受け取れます。
・討伐済みの階へ入り直しても未クリアへ戻らず、戦利品箱・温泉・出口の状態を復元します。

【100階制】
・旧10階分を新1階として圧縮し、全100階へ統一しました。
・通常ボス、深淵、十神を100階の進行へ再配置しています。
・旧階層を参照する装備性能、敵強度、GOLDなどは内部で換算し、圧縮による報酬低下を防ぎます。

【全体バランス調整】
・4対4：最低クリスタル報酬を25個、初戦GOLD倍率を0.5倍へ増加しました。
・4対4：実戦難易度と報酬を同じ段階曲線へ統一し、50戦目の不自然な難易度急増と、深層報酬の桁あふれ級の暴騰を解消しました。
・4対4：10戦ごとの初回100魔晶石、捕獲結晶50個、確定装備は維持します。
・ガチャ：排出をシャッフル袋方式で平準化し、同じ結果への極端な偏りを抑制しました。
・ガチャ天井：有料通常召喚はUR以上50回、LR以上150回、神話300回以内を保証します。
・放置報酬：GOLDは5分単位、装備は2時間単位で別々に蓄積します。装備は最大12個です。
・放置上限：進行度に応じて4～24時間へ段階的に拡張しました。
・深淵スキルツリー：version 7へ再設計し、解放順、効果量、必要GOLDを長期育成向けに再調整しました。
・魔法陣：全系統でレベル効果を実戦へ反映し、Lv上げ費用と成長量を再調整しました。
・通常宝箱：装備部位の偏りを抑え、武器・防具・装飾品を均等に抽選します。
・装備売却：レア度に見合う売却価格へ引き上げました。
・追加効果再抽選：100階制の経済へ合わせて費用を再計算し、ロック数による負担も調整しました。
・ボス報酬：100階制の節目と育成速度へ合わせて報酬段階を再構成しました。
・隠し部屋：裏市場価格、超越個体価格、カジノBET上限を新100階制の経済深度へ統一しました。
・共闘／レイド：宝箱階級、個別ボーナス、週次レイドGOLD・魔晶石・EXPを旧10階＝新1階で正しく換算しました。
・敵装備：100階でも装備Lv・装備枠・魔法陣だけが浅層値へ戻らないよう、経済深度を戦闘開始まで保持します。

【最終決戦】
・100階の支配者撃破で最終決戦を解放します。撃破しただけでは真クリア扱いになりません。
・将軍戦で倒した勇者は魔王戦で復活せず、生き残った勇者は残HPを引き継ぎます。
・サイラーンの覇道・破壊・魔導・疾影・不落の5型は、実際の能力倍率と4枠スキル構成へ反映します。
・勝利時だけ真クリアとエンディングを記録します。敗北・撤退時は一時編成を消し、元の部隊を安全に復元します。

【オンライン状態永続化】
・ホスト階層を1～100階へ統一しました。
・ボス討伐、鍵、戦利品箱、温泉、次階層出口をルーム状態として保存します。
・退出、切断、再接続、同階への再入場後も討伐済み状態と討伐後オブジェクトを復元します。
・明示的に再挑戦を選んだ場合だけ、再戦用の状態を開始します。
・鍵取得、宝箱の各錠、温泉と全員のHP／MP、ボス討伐をサーバーで一括保存し、保存失敗時は全状態を巻き戻します。
・旧3択ボス報酬を廃止し、新しい3鍵戦利品箱へ一本化しました。旧受取記録を宝箱3錠開封済みとは扱いません。
・通常支配者は公式専用神話装備、深淵・十神は本人専用装備を初回3錠目に配布します。
・80／90／100階の複数ボスは、全ボスへ各々の欠片を配布します。再戦は欠片のみ再取得でき、初回専用装備は重複しません。
・schema 70以前の汚染済みオンライン進行は本編進行と分離して救済し、誤クリア・誤実績・旧保留報酬を除去します。
