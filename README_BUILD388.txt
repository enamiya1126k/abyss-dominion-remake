ABYSS DOMINION Build388 / v3.1.68

更新方法
このZIPはBuild387 / v3.1.67へ上書きする差分パッチです。
単体で起動するゲーム一式ではありません。Build386以前の場合は先にBuild387まで適用してください。
1. ZIPを展開し、中身を既存の abyss-dominion-remake フォルダーへコピー。
2. src・assetsなどを既存フォルダーへ統合し、同名ファイルを上書き。
   srcの中へさらにsrcを作らないでください。
3. GitHub Desktopで変更を確認し、コミット → Push origin。
4. 公開更新後に再読み込みし、v3.1.68を確認。
セーブ初期化は不要です。所持魔物・装備・物語・鍵・宝物庫報酬を維持します。
新部隊に会うには進行中の戦闘を終え、拠点から踏破済み地域の再探索へ入り直してください。

専用ペア共鳴：今回3組、合計12組
同じ陣営で2人とも生存中、通常攻撃・固有技・支援技のあとに相方が追撃します。
各キャラ1ラウンド1回、1組で最大2回。追加MPなし。追撃から再発動しません。
同じキャラの複数個体、同ラウンドの蘇生やセーブ再開では回数は増えません。
戦闘不能・捕獲・隔離・追加行動の封印で停止。敵も同じ連携を使用します。

■ 誓約・双剣の護陣（リリエット＋ロゼット）
相方が敵全体へ物理2.10倍。生存味方全体に最大HP18%の障壁と攻撃12%上昇（2ターン）。連撃をしのいで攻勢へ移る双子の護陣。障壁は加算されない。

■ 薔薇・黎闇の契り（ノクテル＋オーリアン）
相方が単体へ物理1.30倍×3連撃、防御25%無視。生存味方全体HP12%回復。発動時に姉妹のどちらかがHP40%以下なら「不滅の黎明」：1.65倍×3連撃＋全体HP20%回復。両方の生存が必要。

■ 双刻・星律の終奏（エイレーネ＋イリデル）
相方が敵全体へ2.40倍、防御20%無視。速度低下と防御低下の両方がある敵には3.84倍。高い方の攻撃・魔力を使用。生存味方全体にHP10%障壁と速度18%上昇（2ターン）。

新ペアの味方オートは、相方がHP32%以下なら、他の仲間への回復が余っても有効な全体回復を優先します。
星姫の敵AI・味方オートは、速度低下と防御低下をそろえてから強打へつなぎます。
弱体が消えると共鳴の強化条件も失われます。状態異常浄化・強化解除・回復阻害・片方への集中攻撃が対策です。

敵の装備と編成
各敵は役割に合う6枠の実装備と魔法陣を使用します。物理役と魔法役で武器を選び分けています。
誓姫の双子にはセネラ・グラント、薔薇姉妹にはラジル・セネラ、星姫にはイオネ・ネリクが同行。
天律の聖域「生命の聖壇」の星姫部隊はLv4,800の任意の再探索強敵です。
過去35体と既存9組のペアも再探索で入手でき、物語ボスや宝物庫の条件を維持しています。

捕獲・育成
今回の7体も第二章の再探索で通常の捕獲結晶を使って仲間にできます。所持枠の空きが必要です。
捕獲率上限はN65% / R55% / SR42% / SSR32% / UR24% / LR18% / 神話12%。
実際の成功率はHP・レベル差・状態異常・装備などに応じて変化します。
捕獲後も固有4技を使用し、手持ちの装備と魔法陣で育成できます。敵専用装備は持ち越しません。
第二章限定のため、第一章の通常遭遇・通常召喚には混ざりません。
