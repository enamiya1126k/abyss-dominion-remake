# ABYSS DOMINION Build417 / v3.1.96

① 第一章の進行不具合 修正版

## 適用方法

前回の統合版 Build416（v3.1.95）を適用したゲームフォルダーへ、このZIPの中身を上書きする。ZIPに含まれない既存ファイルは残す。

更新後、ゲームを再読み込みし、ホームのバージョンが v3.1.96 になったことを確認する。セーブの初期化は不要である。オンラインサーバーの更新は不要である。

## 修正内容

- 敗北後に残った区画表示の更新予約が、終了済みの戦闘画面を再表示する問題を修正した。
- 敗北結果を表示している間にアプリを切り替えるなどしても、終了した戦闘を再び途中セーブしないようにした。
- 終了済みの探索に通常戦闘だけが残っている旧セーブを読み込んだ場合、その戦闘と探索画面の残存データを除去する。GOLD・HP・MP・最高到達階・討伐記録は維持し、敗北処理を二重に実行しない。
- 探索が終了している状態で、古い探索画面から遭遇演出を開始しないようにした。
- 遭遇演出が中断された場合、移動停止が残らないようにした。新しく開始した遭遇や、別のダイアログの停止状態は解除しない。
- 古い戦闘の開始演出・行動準備が、終了後や次の戦闘に干渉しないようにした。

HP1・MP0は、通常戦闘で敗北した際の既存の救出仕様である。1階表示はチェックポイントが1階の場合の帰還先であり、最高到達階の消失とは異なる。今回は、その結果画面が隠れて「100階の戦闘や探索が続いている」ように見える経路を修正した。救出された仲間は拠点の寝台で回復できる。

## 確認

自動テスト237件を通過した。報告にある敵4体（深淵海姫セイレーネ・妖精・影爪猫ノワールフェレス・トゲツボミ）と、瀕死・MP0・毒を持つ味方で、10通りの乱数条件を追加確認した。敵の判断と戦闘処理はゲーム本体の関数を使用した。

第一章・第二章・特殊戦闘のセーブ復帰、報酬の二重取得防止、手動スキルと自動戦闘への影響も回帰テストに含む。キャラ能力、ペア倍率、戦闘補正、敵の強さは変更していない。

iPhone Safari実機での画面操作と、本番オンライン通信は未確認である。今回の調査はスクリーンショットとBuild416のソースを基に行ったものであり、利用者の実セーブや端末ログを直接調べたものではない。

今回のZIPは①の修正である。温泉・編成画面は②、第二章の敵表示・HP補正の確認は③で扱う。
