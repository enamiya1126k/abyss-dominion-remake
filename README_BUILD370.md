## 修正内容

- ロゴをタップして属性相性を開く操作を維持。空き枠に属性ロゴは追加しません。
- 予言枠の案内を「勇者情報を見る ›」に変更。スマホで案内を隠していた指定を上書きし、下端の余白に表示。
- 階層枠の「戦力・記録」を「戦力・ランキングを見る ›」に変更。既存の文字行を使い、案内が増えてもカードが縦に伸びない構成。
- ホームのカード位置・サイズ、キャラ配置、戦力計算、勇者情報・ランキングへの遷移処理は維持。
