# ABYSS DOMINION Build565 / v3.1.244

2対2「人間エアホッケー！」の見た目・ルール・得点演出を更新した。
GitHub main の Build563（`72c63563787f2ab5b2e519e86551065da7830ff4`）と、前回のBuild564を基にした累積差分である。Build563／564のどちらにも適用できる。

## 変更内容

- ゴールを上下の壁へ埋め込んだ。得点ラインも台の端へ移し、ゴール内へパック全体が抜けると得点する。
- 台、金属製ストライカー、丸いパック、埋め込みゴールの専用画像を4点制作した。WebPの合計は約215KBである。
- 見出し・得点・操作欄を小さくし、390×740画面のコート高を475.5pxから600pxへ拡大した（約26％増）。
- 引いて離す操作、発射の力、勢いの持ち越し、1.25秒の再発射間隔を維持した。プレイヤーのコマは自陣の半分から出られない。
- **味方へのパス1回につき、パックの弾速倍率が＋0.05。上限はない。** 20回で2倍、40回で3倍となる。相手の打ち返しや壁・プロペラへの衝突では強化を失わない。
- 体が接触し続けるだけではパスにならない。別の味方への移動を伴う接触で加算する。新しいパックの出現時に強化をリセットする。
- 得点時にチーム名と「+1／+2」、光の衝撃、短い画面振動、衝撃音とファンファーレを出す。コマを一時停止し、**2秒後**に失点したチーム側へ新しいパックを送る。試合時間は進む。
- オウンゴールも相手の得点となる。育てたパックを打ち返されて自爆する展開に対応する。
- 準備画面で部屋主が「プロペラなし／あり」「弾速通常／×2」を選べる。標準はプロペラなし・通常弾速。×2モードはパス強化後の倍率にも掛かる。設定変更時は全員の準備OKを取り直し、再戦時には設定を引き継ぐ。
- 90秒／150秒、最後の15秒の2点、空席・切断時のAI補充、チーム選択を維持した。
- 動きを減らす端末設定では、画面振動と強い点滅・粒子演出を抑える。

## 更新手順

1. 差分ZIPをBuild563または564へ、階層を保って上書きする。GitHubではPR #2にまとまっている。
2. **本体とオンラインサーバーの両方を更新する。** サーバーの `online-server/src` と、それが参照するルートの `src` を反映して再起動する。

通信ルールはバージョン9である。旧ルールの部屋は準備画面へ戻る。古い本体との混在開始は拒否する。セーブ削除は不要である。
