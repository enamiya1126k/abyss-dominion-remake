ABYSS DOMINION Build507 / v3.1.186
適用元：Build506（v3.1.185）

追加：運だけ大運動会
パーティーのミニゲーム一覧の先頭に追加。
1〜4人＋空席AI、参加無料。魔物の能力・レベル・選択の速さに有利不利はない。

遊び方
・全8ラウンド。3つの同じ見た目の箱から1つを選ぶ。
・選んだ箱は変更不可。全員が決めたら一斉に開封。
・選択は最大12秒。時間切れ・切断中は自動選択。
・おさんぽ、ダッシュ、ばねジャンプ、ロケット、バナナ、落とし穴、流星ロケットの7種類。
・ロケット系は先頭との差に応じて飛距離が伸び、最下位からの逆転も可能。
・最終ラウンド後、累計距離が最大の人が優勝。同距離は同順位・同時優勝。
・通常約1〜2分、全ラウンド時間切れの場合は約2分36秒。
・所持魔物、パーティー、設定済みプレイヤーカラーを引き継ぐ。
・キーボードは1〜3でも箱を選択可能。

ビジュアル
・専用の夕焼けの競技場、装飾付き宝箱、アイテム7種、優勝トロフィー。
・箱の一斉開封、ジャンプ、空中飛行、バナナで回転、落とし穴の沈み込み。
・プレイヤーカラーを上部枠、足元、名前、開封カード、結果に反映。
・開始カウント、ラウンド進行、優勝画面、全ラウンド振り返り。
・背景は静止画像、移動演出は4人の要素を中心に更新。待機中は同じ画面を書き換えない。
・非表示時は更新を停止。動きを減らす設定に対応。

導入
1. 念のため、現在のBuild506本体とサーバー保存データをバックアップ。
2. ZIP内のファイルを、Build506のゲームフォルダーへ同じ階層で上書き。
   ZIP内に外側のgameフォルダーはない。index.htmlは既存index.htmlと同じ位置。
3. サーバー配置にも online-server/src と共有 src の更新分を反映。
   このゲームはサーバーが ../../src/luck/Rules507.js を参照する。
4. Node.jsオンラインサーバーを再起動。
5. 全員がゲームを再読み込み。v3.1.186を確認し、パーティーから「運だけ大運動会」を選ぶ。

本体だけの更新では遊べない。サーバー更新が必要な場合は画面に案内が出る。
既存の本編セーブ・所持品・通貨・既存ミニゲームのルールを変更しない。
公開サイトへのデプロイは行っていない。
