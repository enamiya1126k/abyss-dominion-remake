## 今回の変更

- ミニゲーム一覧の「ブロック落としサバイバル」「〇×サバイバル」のサムネを描き直し。深緑・金属装飾の世界観で、登る／落ちるキャラクターがいる絵へ変更。
- ブロック落としの背景を彫刻入りの城壁・鎖・金属柱へ変更。ブロックも縁金・発光する魔石・落下の軌跡で重さを表現。
- 逃げ道の完全封鎖をサーバーが判定し、時間切れを待たず落とす側の勝利にする。最後の１人で、全手札の配置が不可、かつジャンプでも到達できない場合も終了。
- 逃げる側の勝利は、脱出した相棒が上へ飛び出し、落とす側を蹴り飛ばし、その場所へ着地。「天空、奪還！」を表示。
- 落とす側の勝利は、巨大な封印で閉鎖し、相棒が上で勝利。「完全制圧！」を表示。
- 決着から5.4秒は演出を見せてから結果へ。通信が遅れたり、途中で画面へ戻った場合もサーバーの決着時刻を基準とし、最初から繰り返さない。
- 逃げる側のスティックの遊びを調整。ジャンプ／ダッシュボタンを拡大し、ダッシュ再使用までの時間を表示。素早い複数ボタン入力と指を離した瞬間の停止を改善。
- 落とす側は、左親指に左右ペア、その隣に回転、右側に大きな落下ボタン。候補や回転は指を置いた瞬間に反応。左右長押しと、盤面をなぞる位置指定に対応。
- 終盤の速度上限を12→24ブロック/秒へ。序盤は3.5のまま、後半ほど加速。着地後待機は450→180ms、自動落下までの操作時間は2200→1100ms。
- 上部の情報をコンパクトにし、遊ぶ領域を広げる。サムネの長いゲーム名が末尾１文字だけ折り返す問題を緩和。

## 詰み判定の考え方

積まれたブロックを取り除くルールはないため、生存者全員のいる空間が出口から切り離されたら、その時点で脱出不能です。
小さな点が自由に飛べるという、実際より有利な条件で出口との接続を調べます。この条件でも外へ出られない場合だけ「完全封鎖」とします。
仲間の頭から連続して跳ぶ可能性、今後ブロックが足場になる可能性が残る場合は終了しません。AIが動かないことや、高い壁があることだけでは負けにしません。
生存者が最後の１人で、全４枠・全回転・全位置にも配置できない場合は、上向きの勢いと２段ジャンプ、既存の足場への到達も確認します。
これは確実に不可能と証明できる状態を終了させる保守的な判定です。あらゆる協力ジャンプの操作列を網羅探索しているわけではありません。
