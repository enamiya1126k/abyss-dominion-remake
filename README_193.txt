ABYSS DOMINION REMAKE 193 差し替えパッチ

基準: 192完成版
バージョン: 2.11.76-build252

【193の追加内容】

1. 集会所の「遊戯広場」
- 集会所の上側中央へ、複数人で遊べる遊戯広場を追加しました。
- 施設へ歩いて近づくと「遊びに行く」が表示されます。
- 下部ナビや独立したオンラインモードは増やさず、集会所の同じ部屋・同じメンバーのまま遊べます。
- 参加しない人は観戦でき、途中で部屋へ入った人も現在の試合を見られます。

2. 爆弾ミミック回し
- 2〜4人で遊ぶ、5ラウンド制のホットポテトです。
- 爆弾ミミックを持っている人が、仲間のカードをタップして渡します。
- 爆発時刻は毎ラウンド変わり、正確な残り時間はサーバーだけが保持します。
- 爆発しても脱落せず全員が最終ラウンドまで参加できます。
- 5ラウンド後、被爆回数が最も少ない参加者が優勝です。同数なら同率優勝になります。
- 同じ操作の再送・高速連打・所持者以外からのパスはサーバー側で無効化します。

3. 魔物レース
- 2〜4人で参加し、自分のオンライン編成から1体を選んで走らせます。
- 走者の魔物・進行・着順はサーバーが確定し、全端末へ同じ結果を同期します。
- 育てた魔物の速さは少し反映しつつ、大きなレベル差でも勝敗が固定されない補正を入れています。
- レース中は応援できます。応援の回数や通信速度が着順を変えることはありません。
- 結果画面で順位とルーム内の勝利数を確認し、そのまま再戦できます。

4. 安全なオンライン同期
- 2つのゲームは同時に起動せず、進行中は共同探索・レイド・自由チーム戦・交換との重複開始を防ぎます。
- 切断・再接続後も、同じ試合の状態へ復帰します。
- 参加者が不足した場合は固まらず、安全に中断または結果へ進みます。
- 古いオンラインサーバーへ接続した場合は、画面を壊さず193サーバーへの更新案内を表示します。
- GOLD・宝石・アイテム・セーブデータは増減しません。何度遊んでも経済や進行へ影響しない交流用ゲームです。

【適用方法】

このZIPの中身を、192完成版の公開フォルダ直下へそのまま上書きしてください。
ZIP内には193で変更・追加したファイルだけが入っています。

193はオンラインサーバー側も変更します。
公開ファイルの上書き後、online-server を必ず完全停止してから再起動してください。
サーバーを再起動しない場合、遊戯広場には「サーバー更新が必要」と表示されます。

既存のセーブデータ・オンライン部屋・交換履歴・レイド進行には変更を加えません。

【確認項目】

- 集会所の遊戯広場へ歩いて近づき、入口を開ける
- 爆弾ミミック回しへ2〜4人で参加し、5ラウンドを最後まで遊べる
- 爆弾の所持者だけが仲間へパスでき、同じパスが二重反映されない
- 魔物レースで各自のオンライン編成から1体を選べる
- レースの進行と最終順位が全端末で一致する
- 観戦者・途中参加者にも現在のゲームが表示される
- 切断後に同じ部屋へ再接続してゲーム状態へ復帰できる
- ゲーム進行中に共同探索・レイド・チーム戦・交換を重複開始できない
- iPhone幅で横にはみ出さず、各ボタンを押しやすい
- GOLD・宝石・所持品・通常探索進行が変化しない
