# Build581 / v3.1.260

## 追加ゲーム：まわせ！魔王の回転寿司

- ４人対戦、75秒。ひとりでも空席をAIが担当します。
- 自分の前を通る光る皿をタップ。普通の皿10点、注文ならさらに10点。
- 注文の３皿をそろえると90点ボーナス。金皿40点はどの注文にも使えます。
- 「のび〜る箸」で遠くの注文皿を先取り。14秒で復活します。
- 激辛わさびは40点ロスト（０点未満にはなりません）、1.5秒お休み。
- ときどき逆回転。最後の15秒は金皿が増えます。同点は同順位。
- PCでは皿ボタンを選んでEnter/Space、ゲーム画面にフォーカスした状態のSキーで箸。

## 適用

1. 今のプロジェクトをバックアップします。
2. ZIPを展開し、`index.html`と同じ階層へ、中身のフォルダー構成を保って上書きします。
3. 本体の公開ファイルとオンラインサーバーを更新します。サーバーは隣の`src/`にある共通ルールを読み込むため、`online-server/`だけでなく今回含む`src/`も配置してください。
4. オンラインサーバーを再起動します。新しい依存パッケージの追加はありません。
5. 参加者全員がページを再読み込みし、Build581になってからゲームを選んでください。

前回のゲーム・修正・画像はBuild580をそのまま使います。このZIPには再同梱しません。既存のセーブデータ、サーバー設定、環境変数ファイルを上書きするファイルはありません。公開・サーバー更新はこのZIPの適用後に行ってください。
