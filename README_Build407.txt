ABYSS DOMINION — Build407 / v3.1.87
⑤ ホームの環境モーション

【適用方法】
Build406まで適用したゲームに、ZIP内の index.html と src フォルダのファイルを
同じ場所へ追加・上書きしてください。src フォルダ自体の削除・置き換えは不要です。
このZIPは差分です。ゲーム全体・既存背景素材一式は含みません。
反映後はページを再読み込みし、ホームのバージョンが v3.1.87 になったことを確認してください。

【5種類のモーション】
境界の森：水流、広く揺れる木漏れ日、蛍の軌道、木々の揺れ。
黒根の侵食域：元画像の篝火部分を動かす炎、火の明かり、大きく吹き上がる火の粉。
深淵の回廊：前後に流れる霧、紫の光の強弱、星の軌跡。
天律の聖域：流れる雲海、旗の揺れ、横切る光。
理の中枢：外側12秒／内側8秒で逆回転する光輪、中心の鼓動、柱を巡る光。

【見やすさ・負荷】
・背景画像とサムネイルは既存10ファイルを変更せず使用。
・演出はキャラ・戦力表示・操作ボタンの背面。装飾はタップを受け取りません。
・キャラのいる手前の背景に静かな陰影を付け、戦力表示の暗い下地を維持。
・動くグループは最大23個。幅600px以下の画面では最大17個まで細部を減らします。
・省データ設定／少ないCPUコア・メモリの端末でも細部を減らします。
・別タブ、ページ非表示、画面外のプレビュー、ホーム上のモーダル表示中は停止。
・画面を切り替えたら監視を解除し、戻ったときに重複して増えないようにしました。
・環境モーションOFF、端末の「視差効果を減らす」では追加演出を消して静止背景を表示。
・常時動くJavaScriptのフレームループ、タイマー、追加音声はありません。

【引き継ぎ】
ホームの風景選択とON/OFFは以前と同じ設定を利用します。
解禁条件、所持通貨、仲間、育成、装備、第二章の進行、Build406のペア名は維持します。
第一章の通常ホームは既存の環境モーションを引き続き使用します。

自動テスト30件成功。5種類の切り替えとセーブ再読込、保存失敗時の復元、
ON/OFF、非表示時停止、画面切替時の解除、演出数、操作ボタンと部隊データの保持を確認。
既存の背景5枚・サムネイル5枚のファイルハッシュが一致することを確認。
