N 巻鍵の工姫ティクタ
境界の森「西の封印樹」：ネリク／グラント／コロル／ティクタ。
巻鍵の槍を持つ自動人形。防御低下→貫き、速度低下、自己障壁・回避で味方を助けます。

R 翠薬の魔女ミレア ＆ SR 毒花の魔女ヴィオラ
黒根の侵食域「吸命の荒野」：ミレア／ヴィオラ／シェルザ。
ミレアは全体回復・浄化・障壁、ヴィオラは全体毒・毒への強打・回復阻害。
二人は黒根の毒花を薬にも毒にも変える工房の相棒です。
ヴィオラが先に毒を広げ、ミレアの追撃とシェルザの毒追討につなげます。

SSR 紅月の巫狐カグラ ＆ UR 蒼月の巫狐サヨ
天律の聖域「天秤の回廊」：カグラ／サヨ／ノクティア。
紅の太刀を持つ姉と蒼の双扇を持つ妹。狐火の火傷に連撃を重ねます。
サヨは命中・速度支援、回復、浄化も担当。二人とも物理攻撃を使います。

LR 星糸の織姫セレス ＆ 神話 星刃の舞姫ルミナ
理の中枢「輪廻の歯車」：セレス／ルミナ／ミメリア／ネリク。
同じ星核から生まれた姉妹機。セレスは回避低下・全体障壁・強化解除、
ルミナは攻撃支援・回避低下への強打・防御貫通で終演につなげます。
Lv.4,900の任意の追加強敵です。二人目の行動前に片方を倒す／捕獲するのが対策です。

ペア共鳴：同じ部隊に二人をそろえると発動
通常攻撃・固有スキルのあとに相方が追撃します。回復・浄化・支援技からも発動。
両方が同じ陣営で生存していることが条件です。
各キャラ1ラウンド1回、1組で最大2回。追加MPなし。追撃から再発動しません。
同じキャラの複数個体や、同ラウンドの蘇生・セーブ再開で回数は増えません。
戦闘不能・捕獲・隔離・追加行動の封印で停止します。
敵も同じ専用技を使うため、浄化と集中攻撃を考えた編成が有効です。
編成・戦闘画面に相方の条件、発動状況、残り回数が表示されます。

■ 薬毒・豊穣輪舞（ミレア＋ヴィオラ）
相方が敵全体へ魔法2.00倍。毒状態の敵には3.00倍。
生存味方全体のHP15%回復。敵ごとに毒の有無を判定します。

■ 霊狐・焔月神楽（カグラ＋サヨ）
相方が敵単体へ物理1.15倍×3連撃、防御20%無視。
火傷中の対象には各打撃1.45倍。生存味方全体の命中18%上昇（2ターン）。
倒した場合は別の生存敵へ追撃し、火傷の有無を打撃ごとに判定します。
同じ共鳴の命中上昇は無限に重なりません。

■ 星糸のデュエット → 星幕・終演のアリア（セレス＋ルミナ）
1回目：敵全体1.60倍＋生存味方全体に最大HP8%の障壁。
同じラウンドにもう一人も共鳴すると「星幕・終演のアリア」へ変化！
敵全体4.20倍、防御45%無視、全体に最大HP22%の障壁。
相方の攻撃・魔力の高い方を使います。どちらから始めても発動します。
ラウンドが変わると1回目へ戻り、同じキャラを並べても終演の条件は満たせません。

共鳴にも実際の能力値、装備、魔法陣、命中、防御、属性、障壁が適用されます。
回復阻害は共鳴回復にも有効で、回復だけでは戦闘不能者は復活しません。
障壁は残量と比較して大きい方へ更新します。
オートはペアがそろうと毒・火傷・回避低下の準備と追撃を優先します。
倒し切れる攻撃、緊急回復・浄化、MPの温存には引き続き配慮します。
対象は通常の手持ち部隊で行う戦闘（第一章・第二章・王室等）。
サーバーで処理するオンライン戦闘へのペア共鳴は本弾には含みません。

捕獲・育成
全7体を通常の捕獲で仲間にできます。捕獲結晶と空き枠が必要です。
捕獲率上限：N65% / R55% / SR42% / SSR32% / UR24% / LR18% / 神話12%。
実際の成功率はHP・レベル差・状態異常・装備などで変化します。
捕獲後は固有4技を使い、手持ちの装備・魔法陣で育成できます。
敵は役割に合う6枠の装備種類・レベル・魔法陣を持ちます。捕獲時に敵専用装備は付いてきません。
第一章の通常遭遇・通常召喚には混ぜていません。既存21体の捕獲経路も維持しています。
