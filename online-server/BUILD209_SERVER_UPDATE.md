# build209 オンラインサーバー更新

build209ではサーバープロトコルを `1.11.1` へ更新しました。ゲーム側と `online-server` を同時に差し替え、サーバーを停止後に再起動してください。

## 更新された同期処理

- 階層帯と出発時人数から共闘宝箱4段階を確定
- 途中切断後もAI代理を含む開始人数と報酬品質を保持
- 共鳴宝箱の3×3範囲と成立人数をサーバー判定
- 複数の近接対象から最寄り1件だけを安定選択
- 共鳴／豪華／異界宝箱の固定品質ラベルと共有報酬
- 異界商人のプレイヤー別受取状態と正確な支援内容

`node --test tests/*.test.js` で40件すべて合格しています。
