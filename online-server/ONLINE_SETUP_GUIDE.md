# ABYSS DOMINION オンライン — 自宅PCサーバー手順

このフォルダは、最大4人で遊ぶオンライン専用サーバーです。オンラインは「ホーム・通常探索・レイドボス・自由チーム戦・共鳴迷宮・チャット」の6画面に分かれ、選択中の画面だけが表示されます。サーバーが止まっていても、通常ゲームとセーブには影響しません。

## 最初の1回だけ

1. [Node.js公式サイト](https://nodejs.org/en/download)から **LTS版** をインストールします。
2. [Cloudflare公式](https://developers.cloudflare.com/tunnel/downloads/)からWindows版cloudflaredをインストールします。
3. `01_FIRST_SETUP.bat` をダブルクリックします。`[完了]` と表示されたら準備完了です。

## URLを毎回同じにする（推奨・無料）

Cloudflare Quick TunnelのURLは仕様上、起動のたびに変わります。独自ドメインを持っていない場合は、無料ngrokアカウントへ割り当てられる固定dev domainを使います。

1. [ngrok](https://dashboard.ngrok.com/signup)で無料アカウントを作成します。
2. [Windows版ngrok](https://ngrok.com/download/windows)をインストールし、`ngrok`へPATHを通します。
3. `05_SETUP_FIXED_URL.bat` をダブルクリックします。
4. 自動で開くAuthtoken画面からトークンをコピーして、黒い画面へ貼り付けます。
5. 自動で開くDomains画面から、割り当てられた `xxxxx.ngrok-free.app` をコピーします。
6. 固定URLを黒い画面へ貼り付けます。`https://`や末尾の`/`が付いていても自動で整えます。

設定後は `fixed-tunnel-domain.txt` が作られ、`04_START_ONLINE.bat` と `03_OPEN_TUNNEL.bat` が自動的にngrok固定URLを使います。Authtokenはngrok自身のPC設定へ保存され、ゲームフォルダや差分ZIPには入りません。

固定URLを変更する場合は `05_SETUP_FIXED_URL.bat` をもう一度実行します。Cloudflare Quick Tunnelへ戻す場合は、オンライン停止中に `fixed-tunnel-domain.txt` だけを削除します。

## 友達と遊ぶ日

1. `04_START_ONLINE.bat` をダブルクリックします。
2. サーバー用とトンネル用の黒い画面が開きます。遊んでいる間は両方とも閉じません。
3. 固定設定済みなら、トンネル画面には毎回同じ `https://xxxxx.ngrok-free.app` が表示されます。
4. 初回だけゲームの「パーティ」→「オンライン」へ進み、固定URLを貼り付けて接続します。以後はゲームがURLを記憶します。
5. 部屋を作成して、表示された6文字のルームIDまたは招待リンクを友達へ送ります。
6. 同じ部屋に入ったら、下の6タブから遊ぶ内容を選びます。

友達側にNode.jsやcloudflaredは不要です。ホストだけがPCサーバーを起動します。

## 6つのオンライン画面

- **ホーム**：参加者、使用キャラクター、ルームID、招待リンクを確認します。
- **通常探索**：同じダンジョンを最大4人で歩き、宝箱・イベント・戦闘を共有します。マップの床をタップするか、方向パッド／WASD／矢印キーで移動できます。
- **レイドボス**：通常探索と同じ戦闘UIで巨大ボスへ挑みます。敗北時は残りHPを保存し、次回へ引き継ぎます。
- **自由チーム戦**：紅組と蒼組へ自由に分かれ、1vs1・1vs2・1vs3・2vs2で対戦します。報酬のないフレンド模擬戦です。
- **共鳴迷宮**：2〜4人で別々の手掛かりを共有し、音板の同時起動・防衛・救助・宝箱選択を進める協力迷宮です。
- **チャット**：80文字までの会話、定型文、絵文字を送れます。直近50件を保持し、再接続後も復元します。

通常探索・レイド・チーム戦では、攻撃・ガード・スキル・応急薬を各自が入力します。制限時間までに入力しない場合や一時切断中はサーバーが自動行動を選びます。戦闘の乱数と結果はサーバーが決め、全員へ同じ状態を配信します。

## 更新・切断・再接続

- ゲーム画面を更新しても、更新前にいた通常ゲーム画面を復元します。ホームから勝手にオンラインへ移動しません。
- オンライン接続中にページを更新した場合は、保存済みのサーバーURLと再接続情報を使って同じ部屋への復帰を試みます。
- 通信が切れても5分間は席を保持します。戦闘中は復帰するまで自動行動になります。
- 受渡し開始後の交換と未受取報酬は `data/settlements.json` へ保存されます。サーバー再起動後も元の端末から接続すると、未受取報酬は24時間、未確認の交換受取は7日間を上限に復旧します。
- `退出` を押した場合は席を手放し、自動再接続もしません。

## ミュートとブロック

- 交流パネルの「安全設定」から、ミュート中・ブロック中の相手を確認して解除できます。
- ミュートは相手の部屋／探索／ギルドチャット、吹き出し、スタンプ、探索ピンだけを自分の画面で非表示にします。戦闘、HP、救助、宝箱などの進行情報は表示されます。
- ブロックはフレンド、申請、招待、新しい交換を停止し、公開掲示板、おまかせ参加、ルームID、招待、ギルド募集のどの経路でも同じ部屋へ再参加できないようにします。
- 進行中の探索や戦闘は安全操作だけで強制終了しません。帰還後から再合流を防ぎます。受渡し開始済みの交換は資産を壊さないため完了・復旧を優先します。
- ブロックしても既存ギルドの所属、役職、ポイント、予定、参加表明は削除しません。今回は共通の運営窓口が必要な通報や管理者BANを追加していません。
- 安全設定は `data/friends.json` version 2へ保存します。version 1は既存関係を維持したまま自動移行します。

## 更新とバックアップ

1. オンラインサーバーを停止します。
2. `online-server/data` フォルダ全体を別の場所へコピーします。
3. 差分ZIPの中身を同じ階層へ上書きします。`data` フォルダや既存JSONは削除しません。
4. オンラインサーバーを起動し、`http://127.0.0.1:8787/health` が `"ok":true` になることを確認します。

通常は `data/settlements.json` をそのまま使用してください。保存先を変更する運用では、`SETTLEMENT_STATE_FILE` に書き込み可能なファイルパスを指定します。このファイルには未確認の受取情報が入るため、稼働中に編集しないでください。

## `04_START_ONLINE.bat` を押しても何も起きない場合

1. ファイルを右クリックして **プロパティ** を開きます。
2. 「このファイルは他のコンピューターから取得したものです」と表示される場合だけ、**許可する** にチェックして「適用」→「OK」を押します。
3. もう一度 `04_START_ONLINE.bat` をダブルクリックします。

それでも開かない場合は、`online-server` フォルダの空白部分を右クリックして「ターミナルで開く」を選び、次の2つを別々のターミナルで実行します。

```bat
npm start
```

```bat
cloudflared tunnel --url http://127.0.0.1:8787
```

固定URL設定済みの場合、2つ目のターミナルでは `fixed-tunnel-domain.txt` に保存したドメインを使います。

```bat
ngrok http 8787 --url https://xxxxx.ngrok-free.app
```

文字化けした命令が大量に出る場合は、古いバッチではなく、このZIP内のバッチを使ってください。Smart App Control自体を無効にする必要はありません。

## 安全性と注意

- サーバーは `127.0.0.1:8787` のみに待ち受けます。ルーターのポート開放は不要です。
- 固定設定済みならngrokの暗号化URL、未設定ならCloudflare Quick Tunnelの暗号化URLを使います。
- サーバーはゲームの全セーブを受け取りません。オンライン用プロフィール、ルーム進行、未受領報酬だけを扱います。未受領報酬と受渡し開始後の交換は、再起動復旧のため上限付きで保存します。
- チーム戦に報酬はありません。探索とレイドの報酬はIDで二重受取を防止します。
- PCまたはサーバーを終了すると部屋は消えます。未確認の交換受取と報酬だけは `data/settlements.json` から復旧します。
- ngrok無料版には通信量・接続数などの月間上限があります。少人数テストを超えて常時運営する場合は、独自ドメイン付きCloudflare Tunnelまたは常設サーバーへの移行を検討してください。
- Cloudflare Quick Tunnelへ戻すとURLは起動ごとに変わります。
- WindowsファイアウォールがNode.jsの通信許可を尋ねた場合、家庭内PCでは「プライベートネットワーク」のみを選ぶ運用が安全です。

## 困ったとき

- `node が見つかりません`：Node.jsを入れた後、黒い画面をすべて閉じて再実行します。
- `ngrok が見つかりません`：Windows版ngrokのインストール後に黒い画面をすべて閉じ、もう一度 `05_SETUP_FIXED_URL.bat` を実行します。
- `cloudflared が見つかりません`：固定URLを使わない場合は、インストール後にWindowsを再起動するか、cloudflared.exeへPATHを通します。
- 接続できない：`http://127.0.0.1:8787/health` をPCで開き、`"ok":true` が出るか確認します。
- `"ok":false` または `persistence.settlements:false`：`online-server/data` に書き込めることと、隔離された `settlements.json.corrupt-*` がないかを確認します。壊れたファイルは戻さず、バックアップから復元してください。
- URLが違う：固定設定済みなら `https://...ngrok-free.app`、未設定なら `https://...trycloudflare.com` を入力します。
- 04だけ動かない：`02_START_SERVER.bat` と `03_OPEN_TUNNEL.bat` を順番に個別起動して、表示されたエラーを確認します。
