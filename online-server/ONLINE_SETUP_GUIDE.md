# ABYSS DOMINION オンライン広場 — 自宅PCサーバー手順

このフォルダは、既存ゲームから独立した「オンライン広場」専用サーバーです。サーバーが停止していても、ダンジョン・戦闘・装備・セーブなど従来機能は通常どおり動きます。

## 最初の1回だけ

1. [Node.js公式サイト](https://nodejs.org/en/download)から **LTS版** をインストールします。インストーラーは基本的に初期設定のままで構いません。
2. [Cloudflare公式のcloudflaredダウンロード](https://developers.cloudflare.com/tunnel/downloads/)からWindows版をインストールします。
3. `01_FIRST_SETUP.bat` をダブルクリックします。`[完了]` と表示されたら準備完了です。

## 友達と遊ぶ日

1. `04_START_ONLINE.bat` をダブルクリックします。
2. サーバー用とトンネル用、2つの黒い画面が開きます。どちらも遊んでいる間は閉じません。
3. トンネル画面に表示された `https://xxxxx.trycloudflare.com` をコピーします。
4. GitHub Pages上のゲームを開き、ホームの **パーティ → オンライン広場** へ進みます。
5. サーバーURLに貼り付けて「サーバーへ接続」を押します。
6. 「部屋を作成」を押し、ルームIDまたは招待リンクを友達へ送ります。
7. 友達は招待リンクを開き、「サーバーへ接続」を押します。友達側のインストールはありません。

## できること（第1段階）

- 1部屋最大4人
- 選択キャラクター・魔法陣・表示名・移動方向の同期
- 画面タップ、方向ボタン、PCのWASD／矢印キーで移動
- スタンプと定型クイックチャット
- 相手タップで戦力・装備・魔法陣を確認
- リーダーマーク、ほかのプレイヤーへの自動追従
- 約15秒以内の通信切断なら同じ部屋へ自動復帰

## 安全性と注意

- サーバーは `127.0.0.1:8787` のみに待ち受けます。ルーターのポート開放は不要です。
- 外部公開はCloudflare Quick Tunnelの暗号化されたURLを使います。
- サーバーはゲームのセーブデータを受け取りません。広場用の公開プロフィールと座標だけを一時的にメモリへ保持します。
- 部屋データはPCまたはサーバーを終了すると消えます。
- Quick Tunnelは試験運用向けです。URLは起動ごとに変わります。常設運用へ移る場合は、後から通常のCloudflare Tunnel等へ差し替えられます。
- WindowsファイアウォールがNode.jsの通信許可を尋ねた場合、家庭内PCでは「プライベートネットワーク」のみを選ぶ運用が安全です。外部の友達はCloudflare経由で接続します。

## 困ったとき

- `node が見つかりません`：Node.jsを入れた後、一度すべての黒い画面を閉じて再実行します。
- `cloudflared が見つかりません`：インストール後にWindowsを再起動するか、cloudflared.exeへPATHを通します。
- 接続できない：サーバー画面に `Local: http://127.0.0.1:8787` が出ているか確認します。ブラウザで `http://127.0.0.1:8787/health` を開き、`"ok":true` が出ればサーバーは正常です。
- URLが違う：ゲームへ入れるのはローカルURLではなく、トンネル画面の `https://...trycloudflare.com` です。
