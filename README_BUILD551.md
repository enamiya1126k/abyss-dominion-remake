# ABYSS DOMINION Build551 · v3.1.230

Build550への上書きパッチです。ポンコツ改造GPを中心に、人間ピンボールも連続進行へ更新します。

## 入れ方

1. 使用中のBuild550一式へ、ZIPの中身を同じ階層で上書きしてください。
2. **本体と `online-server` の両方を更新し、サーバーを再起動**してください。
3. 各参加者のブラウザーを再読み込みしてください。v3.1.230が目印です。

ゲーム内の既存「パーティー」メニューから入れます。新しい外部サイトへの登録は不要です。保存データや所持キャラクターを上書きするファイルは含めていません。更新前に進行中だった旧ルールの２ゲームは、混在を防ぐため一度だけ準備画面へ戻ります。Build551で開始したゲームは、全ラウンド同じ位置・速度を引き継ぎます。

## 遊び方の変更

- **８ラウンドを１本のコースで続けて走ります。** 16回設定も同様です。各回18秒で、８回なら２分24秒。ラウンド開始時に位置・速度を戻しません。
- 中間の結果画面とカウントダウンを廃止しました。最終結果だけ、最後に表示します。
- 装備はコースを見ながら３枚のカードから１枚。選んだ人から、その場で引いて発射できます。他の人を待ちません。選択８秒・発射12.5秒の時間切れはAIが代行します。
- 動いている間も改造できます。発射は各回１回。押された勢いも、自分が残した勢いも、新しい発射へ足し合わせます。
- GPはスタートからの**最長到達距離**で勝負します。同じ距離を回ごとに重複加算しません。後退しても到達記録は残ります。
- GPの後続には追い風が働きます。移動は物理演算の加速で、ワープはしません。最初の発射前の待機車は風で勝手に走りません。
- GPは2.3秒以内に衝突を重ねると連鎖し、３連鎖ごとに追加加速。加速ローラーは踏んだ車だけ加速し、同じローラーは各車１回までです。
- コース上の充電カプセルは早い者勝ちで充電＋18。次の発射へ放出します。既存の仕返し電池は、さらに衝突からも充電できます。
- 道路・障害物・ローラーは距離で固定され、遠くへ進むと先の区間が生成されます。ラウンドが変わっても障害物の位置は変わりません。
- ピンボールも位置・速度・壁倍率・装備・充電を持ち越します。毎回、金ピンと宝箱のチャンスが更新されます。
- タップだけ／元の位置へ戻す／操作中断はキャンセルです。停止位置の予告・着地点の丸・予測軌道は表示しません。

## ビジュアル

生成した画像素材７種を組み込みました。装備24種の絵、エメラルドと真鍮のカード枠、工房の街道、新しい車体、ローラー／バンパー／カプセル／ポッド、ピンボール台です。装備一覧にも同じ絵を使い、改造は車体の見た目にも反映します。生成用プロンプトと元データの扱いは `docs/build551/asset-prompts.json` に記録しています。

４人分のHUDを小さくまとめ、縦画面のコース表示を広げました。横画面では装備カードを右側へ移します。キャラクターはコース内のレイヤーに閉じ込め、最終結果画面へはみ出しません。ラウンド更新・他の人の装備選択だけではキャンバスを作り直さず、進行中の引っ張りを保ちます。
