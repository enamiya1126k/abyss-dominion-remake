今回は全員美少女！
N / R / SR / SSR / UR / LR / 神話を各1体、合計7体追加しました。
単独の剣魔1人と、メイド・キョンシー・天使の双子3組です。

7体それぞれに固有4技、待機3・歩行2・攻撃・被撃・戦闘不能の8モーションを用意しています。
姿は正面〜左向き、ドット絵風。ゲームでは各ポーズを256px枠に収めて描画します。

適用先と更新手順
Build381 / 382 / 383 / 384へ上書きする累積パッチです。

2. src・assetsなどは既存フォルダーへ統合し、同名ファイルを上書きします。
   srcの中にもう一つsrcを作らないようにしてください。
3. GitHub Desktopで変更を確認し、コミット → Push origin。
4. いつもの公開更新が完了したら再読み込みし、v3.1.65を確認してください。
セーブ初期化は不要。所持魔物・装備・踏破・鍵・宝物庫報酬を維持します。
戦闘途中の敵編成は保存されているため、新しい敵に会うにはその戦闘を終え、再探索へ入り直してください。

N 煤紫の剣魔リリカ
境界の森「倒木の小径」：リリカ／コロル／バルク。
紫のフードと魔剣を持つ単独の剣士。回避低下から追撃、防御貫通、自己障壁。

R 湖鏡の侍女リュネ ＆ SR 紅鏡の侍女ロゼ
境界の森「東の封印樹」：リュネ／ロゼ／バルク。
青いリボンの姉は剣盾と障壁・浄化。紅いリボンの妹は斧と攻撃支援。
姉の防御低下に妹の強打を合わせられる、最初にそろえやすい双子です。

SSR 幽符の姉シオン ＆ UR 霊鈴の妹スイレン
深淵の回廊「王権の裁定」：シオン／スイレン／ヴェルグ。
紅の扇と蒼の鈴を持つキョンシー姉妹。回復阻害と魔法追撃、蘇生・回復・浄化。
妹の蘇生技はMP36、再使用待ち5ターン、HP30%復活。蘇生封印中は復活できません。
蘇生後のMPは残量を維持し、足りない場合だけ最大MPの5%まで補充します。

LR 暁翼の祈姫アウレ ＆ 神話 宵翼の詠姫ノエル
天律の聖域「因果の聖壇」：アウレ／ノエル。
桜髪の姉は太陽剣、銀髪の妹は月の杖。剣と聖歌が合わさる上位の双子です。
Lv.4,300の任意の追加強敵。攻略時は片方へ攻撃を集めて連携を止めましょう。

双子共鳴：2人を一緒に編成すると専用連携！
両方が同じ陣営で生存していると、通常攻撃・固有スキルのあとに相方が追撃します。
回復・浄化・障壁・蘇生などの支援スキルからも発動します。
各姉妹につき1ラウンド1回、1組で最大2回。追撃の追加MP消費はありません。
追撃自体から次の追撃が連鎖することはありません。同じ姉妹の複数個体でも回数は増えません。
戦闘不能・捕獲・隔離・追加行動を封じる領域で停止。蘇生で2人そろうと再開します。
同ラウンドで使用済みの回数は、蘇生やセーブ再開で戻りません。
残り回数と相方の条件は、戦闘画面・編成画面で確認できます。

■ 双鏡狂奏（リュネ＋ロゼ）
相方が敵単体へ物理1.10倍×3連撃。防御30%無視。
倒した場合は残りの打撃が別の生存敵へ向かいます。
双子2人に最大HP12%の障壁。2人とも行動すれば最大6回の追加打撃です。

■ 双符百鬼夜行（シオン＋スイレン）
相方が敵全体へ2.20倍の魔法追撃。
ダメージが通った生存敵にHP回復35%低下（2ターン）。生存味方全体のHP12%回復。

■ 天穹・双翼聖歌（アウレ＋ノエル）
相方が敵全体へ3.00倍の追撃。実際の攻撃・魔力の高い方を使います。
生存味方全体のHP20%回復＋最大HP20%の障壁。

共鳴の攻撃には装備・魔法陣・能力値・命中・防御・属性・敵の障壁等が適用されます。
回復阻害は共鳴の回復にも有効。共鳴回復だけでは戦闘不能者は蘇生しません。
障壁は同じ枠の残量と比較して大きい方へ更新し、無限加算はしません。
敵の双子にも同じ発動回数と専用技があります。片方を倒す／捕獲することが対策です。
対象は通常の手持ち部隊で行う戦闘（第一章・第二章・王室等）です。
サーバーで処理するオンライン戦闘への双子連携は本弾には含みません。

捕獲と育成
7体とも通常の捕獲で仲間になります。捕獲結晶と空き枠が必要です。
捕獲率上限は N65% / R55% / SR42% / SSR32% / UR24% / LR18% / 神話12%。
HP・レベル差・状態異常・装備などによって実際の成功率は変わります。
捕獲後は固有4技を初期装備し、手持ちの装備・魔法陣で育成できます。
敵の6枠の装備種類・装備レベル・魔法陣は敵専用で、捕獲時には持ち越しません。
第一章の通常遭遇・通常召喚には混ぜていません。
過去14体の捕獲場所も残しています。オルディアは理の中枢「修復の中枢」、ルクシオンは「記録の中枢」です。
