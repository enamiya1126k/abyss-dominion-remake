ABYSS DOMINION Build331
常時オンライン導線・冒険者酒場アップデート

【適用元】
Build330

【主な変更】
・オンラインを開くと固定サーバーへ自動接続し、前回の部屋へ自動復帰します。
・前回の部屋がない場合は、非公開の個人用集会所を自動作成します。
・オンライン画面を離れても接続と部屋在席を維持し、戻ると同じ場所へ復帰します。
・サーバーURL入力、手動接続、入口の募集フォームを撤去しました。
・フレンドID、表示名、出撃優先スロットは「旅人手帳」へ移しました。
・遊戯広場を撤去し、専用画像付きの「冒険者酒場」へ置き換えました。
・公開募集、部屋検索、合言葉参加、招待を冒険者酒場へ一本化しました。
・談話板から重複していた募集操作を取り除きました。
・オンライン報酬と通常ゲーム進行の分離、最大4人、100階制を維持しています。
・旧セーブ互換のため SAVE_SCHEMA_VERSION は 84 のままです。

【バージョン】
アプリ: 3.1.12
アセット: build331
オンラインプロトコル: 1.17.0

【適用方法】
1. Build330 のプロジェクトへ、このZIPの内容を同じ階層で上書きしてください。
2. Web側を再配置し、ブラウザキャッシュを更新してください。
3. online-server/server.js と online-server/src 以下の同梱ファイルもサーバーへ上書きしてください。
4. online-server で npm install 済みであることを確認し、サーバーを再起動してください。
