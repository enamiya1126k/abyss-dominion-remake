ABYSS DOMINION Build476 / v3.1.155
Build475からの差し替えパッチ

【適用】
1. Build475適用済みのゲーム本体とサーバーをバックアップする。
2. ZIPの中身を、index.htmlのあるゲームフォルダーへ同じ構成で上書きする。
3. 稼働中のオンラインサーバーにも online-server/src/PartyCoordinator462.js を反映する。
   本体とサーバーが別々の配置先なら、両方に更新する必要がある。
4. オンラインサーバーを再起動し、ゲームのブラウザーを再読み込みする。
5. パーティーを開き直すと、現在のSLOT1情報が送信される。

変更・追加ファイルのみ。未変更の元ファイルと素材は引き続き必要となる。
ゲームのセーブ形式と通信ルール番号14は継続する。
サーバー未更新の場合、ほかの参加者のSLOT1は表示できない。
このZIPの作成では、公開サイト・稼働サーバーへの反映は行っていない。

【変更内容】
■ゲーム選択画面
背景画像を上段、タイトル・説明・開始ボタンを下段に分けた。
画像に重なる暗い説明パネルを取り除き、絵が見える面積を確保した。

■ロビーの4つの◇
入室したプレイヤーごとに、本編のSLOT1の魔物と名前を表示する。
ミニゲーム用に選んだコマとは別の情報として扱う。
空席は◇と「募集中」、SLOT1が空なら「SLOT1未設定」と表示する。
接続切れでは席を保持して「再接続待ち」、退出では席を空ける。
本編でSLOT1を変更してパーティーへ戻ると更新する。
ほかの参加者に送る魔物情報は表示用の種族IDのみとする。
SLOT1が所持リストの501番目以降の場合も送信対象に含める。

■基本カード116種類
宝石型のレア度表示、絵柄枠、名前帯、効果欄、属性表示を共通化した。
N / R / SR / SSR / UR / LR / 神話 / 深淵 / 十神の9段階で色と装飾量を変更した。
手札・カード一覧・詳細・獲得や使用の演出に共通の表面を使用する。
元の写真・カード番号・効果・ルールは維持する。

■闇カード
呪い、悪い速攻、闇の絵柄を対象とする。
黒紫・紅色の枠、角のある髑髏の印、暗い効果欄で区別する。
闇の4枚セットを束ねた表示も配色を合わせた。

■特殊カード16種類
金の二重枠、青緑の配色、星の印、明るい効果欄を採用した。
一覧・詳細・覚醒演出の表面を統一した。

【確認できたこと】
対象コードを使った自動検証7項目を通過した。
・入室、再接続、退出、パーティー保存後のSLOT1情報
・選択コマとSLOT1の分離、不正・消失・空のIDの扱い
・クライアント送信内容、所持リスト501番目以降のSLOT1
・基本116種類＋特殊16種類の表面生成、番号、効果文、分類
・一覧の検索、切替、詳細への移動がゲーム操作を送信しないこと
・プレイヤー名のHTMLエスケープ、空席と接続切れの表示生成
・本番のビュー関数による手札、カード詳細、特殊カードのHTML生成
変更したJavaScriptの構文と、追加ファイルの参照・キャッシュ更新も確認した。
