# ABYSS DOMINION — Build512

v3.1.191 / Build511 に重ねる差分更新です。

## 距離で世界が変わる

各プレイヤーの累積距離に合わせて、本人の画面の景色が変わります。

| 累積距離 | 景色 |
|---|---|
| 0m〜 | 王立競技場 |
| 1万m〜 | 大森林と滝 |
| 10万m〜 | 砂漠の古代遺跡 |
| 100万m〜 | 天空都市 |
| 1000万m〜 | 成層圏・地球のふち |
| 1億m〜 | 宇宙・惑星 |
| 10億m〜 | 銀河の彼方 |

6種類の新しい背景を追加しました。背景・手前・遠景がそれぞれ流れ、宇宙でも距離線や追い抜きが続きます。大ジャンプで複数の境界を一気に越えると、途中の景色も短く通り抜けます。既存の4.8秒の走行中に収め、演出用の待ち時間は追加しません。結果画面は優勝者が到達した世界になります。

自分を中心に前後1000mを表示するカメラ、画面外の相手アイコン、すれ違い・追い越し、サイコロ、40種類のアイテム、バフの計算、8ラウンドのルールは継続しています。

## 軽さへの対応

- 背景は最大2つの世界を重ねて切り替えます。7世界を同時描画しません。
- 同時に読み込む新背景は最大2枚。基本画像の準備が済んでから先読みします。
- 新背景の読み込みを出走条件にしません。読み込み中・失敗時もその世界の配色とレーンを表示してゲームを続行します。
- 独立したアニメーションループは追加していません。既存の走行更新を使い、終了・非表示・退出時は停止／解除します。
- 動きを減らす設定では背景の連続切り替えを省き、到達した世界を直接表示します。

## 更新方法

1. Build511 のプロジェクト直下へ、ZIP内のファイルを同じ構成で上書きしてください。
2. フロントエンドの更新後、画面を再読み込みしてください。
3. バージョンが v3.1.191 になっていることを確認してください。

この更新は画面側のみです。オンラインサーバーがBuild511なら、サーバー側の変更・再起動は不要です。Build511形式の進行中レースにも距離連動背景が適用されます。旧Build509/510形式の進行中レースは旧表示のままです。このZIPは差分であり単体では起動しません。公開サイトへの反映作業は行っていません。

## 確認

自動テスト274件が通過。境界距離・巨大数・逆走・途中参加・読み込み失敗・描画更新の停止と、従来のゲーム機能を確認しました。実ブラウザーへの接続は前回から制限されており、今回の実機iPhone/Safariの見た目・FPSは未確認です。詳細は `docs/build512/verification.md`、全テスト結果は `docs/build512/tests.tap`。

新背景は `assets/luck512/`。生成画像を無加工で収録し、サイズ・SHA-256・プロンプトは `docs/build512/generated-assets.json` に記録しています。
