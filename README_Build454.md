# Build454 / v3.1.133 — 魔物レースのスクロール修正

Build453までを含む累積上書きZIPです。既存ゲームの同名ファイルへ上書きしてください。
Build453のサーバー更新が済んでいれば、今回はゲーム側の更新だけで対応できます。
サーバー処理、賞金、配当、育成計算、セーブ形式は変更していません。

## 修正

アプリ本体の #app は画面の高さに固定され、overflow:hidden になっていました。
レース中のみ #app を縦スクロール領域にし、ホーム等へ戻ると設定を解除します。
魔物一覧の独立スクロールは維持し、一覧の端では外側のスクロールへつなげます。
画面下部の余白とセーフエリア対応は既存設定を維持します。

## 検証

実際の全スタイル、レースクライアント、ローカル認証サーバーで確認。
修正なしでは指のスワイプで外側が動かない症状を再現し、修正後は幅320/393/709で
指の入力だけで開始ボタンまで移動できることを確認しました。
開始ボタンは自動スクロール付きのテスト操作を使わず、表示された座標をタップします。
魔物一覧の内部スクロール・末尾からの外側への移行・退出時の解除も検証します。
物理iPhone Safariでの実機検証は行っていません。
検証結果は docs/build454/scroll-results.json に収録します。
