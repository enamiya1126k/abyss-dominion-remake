# Build455 / v3.1.134 — 魔物レース：予想新聞・連戦疲労・AI重複防止

Build454までを含む累積上書きZIP。既存ゲームの同名ファイルへ上書きする。
今回はゲームとオンラインサーバーの両方を更新し、サーバーを再起動する。
サーバーの保存データは削除しない。ZIPに保存データ・node_modulesは含まない。

## 更新後の遊び方

新ルールは更新後に新しく作成する部屋から有効。
更新時に残っている旧部屋は、購入済み馬券・着順・賞金を含め旧ルールを維持する。
旧部屋で「もう1レース」を選んでも旧ルールが続くため、一度退室して新しく部屋を作る。
古いクライアントは新ルールの部屋へ入れず、更新を案内する。

## 変更点

- プレイヤー同士の同種選択は許可。システム4匹とAIの出走魔物は、プレイヤーと重ならず、互いにも重複しない。
- 全員の選択確定後・馬券受付前に重複を解消。選択期限による自動決定にも対応。
- AIとシステムの候補を既存の334種類へ拡張。既存の魔物素材を使用する。
- パレードに人気順の「予想新聞」を追加。脚質、コース適性、調子、疲労、評価、勝率目安、単勝倍率を比較できる。
- 馬券選択カードにも人気と単勝倍率を表示。表示する勝率・配当とサーバー抽選は同じ計算を共有する。
- 新レースの予想締切は最大120秒。全員が準備すると、既存のパレード最低時間経過後に開始する。
- 連戦疲労はプレイヤーごと・魔物の種類ごとに保存。1回完走で1段階、最大3段階。評価は1段階あたり−6。
- 休ませた種類は、そのプレイヤーが別の魔物で1回完走すると1段階回復。同じ種類の別個体へ替えても疲労は共通。部屋変更・再接続・サーバー再起動では消えない。
- AI・システムの疲労は同じ部屋の連続レースで引き継ぐ。プレイヤーの疲労とは別管理。
- 疲労はレース専用。通常戦闘、レベル、装備、なつき度による走力差は追加しない。
- Build454の画面全体スクロール修正を維持。出走賞金・EXP・なつき度の報酬は変更しない。

## 勝ちやすさと払戻

コース別の基礎値＋調子＋適性−疲労から勝ちやすさを計算し、条件差を従来より強く反映する。
同条件なら8匹均等。極端な好条件でも1匹の勝率は最大80％。
人気は今回の勝ちやすさ順であり、プレイヤーの購入数による人気ではない。同率は同順位。
1番人気が必ず勝つことはなく、混戦では1番人気の勝率も低くなる。
倍率は購入時固定、払戻は購入額を含む。各馬券の理論払戻率は90％以下（丸め・上限の影響あり）。

再現可能な2,000種類の条件群・計200,000レースの試算では、1番人気の平均勝率は
旧計算15.20％、新計算の理論40.31％、実測40.47％。
これは試算条件全体の平均であり、個々のレースで40％を保証するものではない。
