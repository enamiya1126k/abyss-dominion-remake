# ③ ペア効果・攻略バランス設計 完成版

基準は①Build412＋②Build413適用済みのゲーム。以前の③をこの資料で置き換える。

**ゲームへの上書き操作は不要。** ③は調査・設計であり、能力・UIの実装は予定どおり④で行う。ゲームはv3.1.93、セーブ形式84のまま。

最初に `docs/build414/DESIGN.md` を読む。全攻略対象の照合表は `targets.csv`、キャラとスキルは `characters.json`。

今回追加した重点事項：
- 第一章・回廊・手動試練・王室・オンラインを含む正本調査。
- ペアの追加連携残数と相乗効果の表示を分離。
- 状態異常だけでなく、能力低下無効への代替連携。
- 深淵・十神を変更せず、手動顕現試練で通常キャラの育成上限差を埋める試練内補正。
- ④で異なる3編成以上を使う検証基準、⑤へ渡す統合確認事項。

調査に用いた生成処理は実コード。ダメージを伴う全ボス攻略・勝率検証は④、実機・負荷・稼働サーバーの確認は⑤。数字の一覧が全勝の証拠という意味ではない。

再現：同じGitHubコミットに①②を適用し、このZIPのtoolsを配置して `node tools/build414/catalogue.mjs`、`node tools/build414/pair-audit.mjs`、`node tools/build414/countermeasures.mjs` を実行する。ゲームのsrcやサーバーコードはこのZIPに含めない。
