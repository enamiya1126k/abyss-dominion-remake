ABYSS DOMINION REMAKE 194
Version: 2.11.77-build253

【194で追加した内容】

・ホームの「戦力・記録」に「自分の記録」「全体ランキング」の2タブを追加
・サーバーが再計算した最新戦力で、直近30日以内の上位100人を表示
・100位圏外でも自分の順位をランキング下部へ固定表示
・ランキングアイコンは、公開パーティーのスロット1魔物を使用
・順位、プレイヤー名、最新戦力、最高到達階、更新時刻を表示
・ランキング行を押すと、最大4体の公開パーティーを閲覧可能
・公開詳細に魔物画像、名前、Lv、ランク、個別戦力、装備、魔法陣を表示
・起動時、編成／装備変更後30秒以内、5分ごと、画面復帰時に同期
・通常画面とオンライン画面で同じOnlinePartyControllerと接続を共有
・旧サーバーではランキング通信を行わず、自分の戦力記録を安全に利用可能
・iPhone Safari向けに44px以上の操作領域、固定タブ、慣性スクロールを調整

【安全仕様】

・クライアントが申告した合計戦力は順位判定に使用しない
・サーバーが公開battleStatsから各魔物の戦力を再計算する
・公開パーティーは最大4体、装備は各6枠まで
・HP残量、MP残量、所持通貨、所持品、セーブデータは公開しない
・ランキング通信は powerRankingsV1 対応サーバーでのみ有効

【反映方法】

193完成版へ、この差し替えZIPの中身を同じ階層のまま上書きする。
online-serverも更新されるため、反映後はサーバーを完全停止して再起動する。
