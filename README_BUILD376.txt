Build376 / v3.1.56 — 第二章・序章「境界の森」

【適用】
Build375のゲームフォルダーへZIPの中身を上書きし、GitHub Pagesへ配信。
配信後はゲームを再読み込み。オンラインサーバーの再起動は不要。
セーブの初期化は不要。バックアップを手元に残してから上書きしてください。

【今回遊べる範囲】
第二章の入口、序章16会話、境界の森6区画、4つの敵編成、封印樹2か所、宝箱、回復の泉、踏破後9会話、再探索。
次のエリア・第二章用高難度レイド・勇者の恒常加入は今回含みません。
森は今の移動キャラクター・カメラ・経路探索・戦闘・スキルを利用し、第一章の階層生成とは別に構成しています。

【解放と入口】
100階到達／突破の記録と、勇者一行への勝利記録の両方を確認します。
最高100階だけ、最終戦敗北だけでは解放しません。
クリア済みのホームの「輪廻を選ぶ」を「第二章へ」に変更。玉座の同じ導線も変更。
転生の実行ボタンは廃止。過去データを壊さないため、旧転生データの読み取り互換は維持しています。
未クリアのホーム・1〜100階・勇者戦・スキル・既存報酬を変更するバランス調整はありません。

【遊び方】
ホーム「第二章へ」→序章を読む→森へ出発。
床をタップして移動、ドラッグで視点移動、2本指で拡大。PCは矢印キーも対応。
下部の方角ボタンは、その出口まで部隊を歩かせます。
西と東の封印樹の守護者を倒すと、最深部への道が開きます。
途中で魔王城へ帰還しても、部屋・位置・討伐・宝箱・物語の進行は第二章専用データに保存されます。
「新しく再探索する」で、その回の森の進行だけをリセットできます。
仲間・装備・Lv・所持品・第一章の最高階層・勇者記録はリセットしません。
通常の獣／護衛は既存の捕獲を利用できます。守護者本体とエリアボス本体は捕獲不可。
戦闘敗北／撤退時はその戦闘前のHP・MPへ戻り、報酬なし。使用した消耗品は消費されます。

【報酬】
小径の敵：各員EXP 30,000／45,000G。
西・東の守護者：それぞれ各員EXP 50,000／70,000G。
最深部：各員EXP 120,000／180,000G。
最初の踏破のみ、さらに各員EXP 180,000と魔晶石300を付与。
水辺の宝箱：80,000G（探索1回につき1回）。
再探索では通常の戦闘報酬と宝箱を再取得可能。初回踏破ボーナスは再付与しません。
