今回の中心実装 — LINK ARTS:
1. 2人以上の共同探索に、行動の組み合わせで共用ゲージをためる連携技を追加
2. ゲージ最大値は6。同一ラウンドでは1種類だけを決定的に選択
3. 5種類のLINK ARTSを実装
   - 共鳴連撃: 同じ敵へ2人以上で攻撃／敵の被ダメージ+35%
   - 護刃結界: 攻撃＋防御／生存者全員へ最大HP10%の障壁
   - 戦脈鼓舞: 攻撃＋支援／生存者全員の攻撃・魔力+10%
   - 命脈唱和: 支援＋支援／生存者全員のHP10%・MP6%回復
   - 三位深淵陣: 攻撃＋防御＋支援／敵弱体・味方障壁・攻撃魔力強化
4. 参加者全員の発動FX、技名・効果バナー、ゲージ、直近連携、レシピ表示を追加
5. 390×667相当の小画面、共闘ボスHUDとの左右共存、動き軽減設定、ARIA進捗へ対応

安全性とオンライン境界:
- 1人オンラインではLINK ARTSの状態・表示・効果・乱数消費を一切発生させません。
- 一時切断中は既存AI代理が連携へ参加し、再接続後も同じ発動を再生・再適用しません。
- 正式退出または切断猶予切れで戦闘が1人になった場合は、LINK ARTS表示と判定を終了します。
- 共闘ボス課題と効果が完全に重複する場合は、ゲージを消費せず満タンで保持します。
- LINK ARTSは追加報酬、貢献度水増し、階層解放、通常ボス撃破、ホスト世界進行を発生させません。
- 従来のcoopBreakデータを維持しつつ、coopTechnique別名を追加。旧クライアント向けの主要フィールドも維持しています。

起動上の注意:

- 既存セーブ形式と通信プロトコルは変更していないため、168のセーブをそのまま使用できます。
