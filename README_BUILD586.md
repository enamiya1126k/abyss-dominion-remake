# Build586 — せまりくる壁・操作と駆け引きの改良

Build585へ上書きする差分。アプリバージョン3.1.265。

## 操作

- スティックを倒したまま移動し続ける。浅く倒すとゆっくり移動し、指を離すと停止する。
- 右のボタンで、表示された矢印の方向へ約0.2秒の短距離ダッシュ。再使用は４秒後。スティックとダッシュは２本指で同時に操作できる。
- ダッシュ中も壁に当たれば脱落する。壁を通り抜ける無敵時間はない。
- 床タップによる目的地移動も利用可能。PCは矢印／WASDで移動、Space／Shiftでダッシュ。
- 通信が途切れた操作入力は300msで停止する。切断・離席をサーバーが検知した後はAIへ引き継ぐ。

## 内容

通常の壁に加えて、２つのすき間から逃げ道を選ぶ「二択ゲート」、すき間がずれた２枚が迫る「連続ウォール」、縦横から来る「クロスウォール」を追加した。どの壁も出現前に方向とすき間を予告する。AIも同じ移動速度、当たり判定、ダッシュの再使用間隔で動く。

点数なし、１回当たったらその試合では脱落。最後まで生き残った人が勝つ。復活はなく、同時脱落は同順位となる。

## 見た目

遊ぶ床を拡大。自分の頭上に色付きマーカーを表示し、足元の当たり判定の輪を明確化した。金属のブロック・鋲・トゲ・影を描き直し、ダッシュの残光、破片、連続壁の「２枚目」予告、脱落と一騎打ちの通知を追加した。

## 適用

1. 試合終了後、ZIPの内容を同じ場所へ上書きする。
2. 本体、online-server/src、およびサーバーから参照する兄弟ディレクトリsrcを更新する。
3. オンラインサーバーを再起動し、参加者全員が画面を再読み込みする。

旧ルールで保存された部屋はロビーへ戻す。参加者全員の更新が完了するまで新ルールの対戦は開始できない。既存画像は再配布していないため、必ずBuild585適用済み環境へ重ねる。

## 検証

ルール、継続操作、精密移動、ダッシュ、当たり判定、４本のWebSocket、旧版の拒否と移行、キャッシュ、既存ゲームの回帰を計42テストで確認した。実画面モジュールと全291スタイルシートを読み込み、Chromiumで320×568／390×844／844×390のタッチ操作、２本指の同時入力、観戦、切断表示、再戦を確認した。

AI同士60試合の決着は39.55〜65.475秒、中央値49.55秒。人間のプレイ時間を保証する数値ではない。iPhone実機Safari、実回線の遅延、公開環境へのデプロイは未検証。
