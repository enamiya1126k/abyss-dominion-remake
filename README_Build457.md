# Build457 / v3.1.136 — コンパクトな予想画面・自由に叩けるレース

Build456までの変更を含む累積上書きZIPです。既存ゲームとオンラインサーバーの同名ファイルへ上書きし、サーバーを再起動してください。保存データは削除しません。ZIPに保存データ・node_modulesは含みません。

## 予想画面

「観察」「出走表」「馬券」を切り替える形式へ変更しました。

- **観察**：魔物の姿、調子、脚質、コース適性、人気、予測勝率、単勝倍率、疲労、3種類の能力をまとめて表示します。魔物競走新聞の全文と、特技・評価の内訳はその場で開けます。どちらかを開くと自動紹介が止まり、落ち着いて読めます。
- **出走表**：全8匹を人気順で比較できます。行を押すとその魔物の観察へ移動します。予想・疲労・払戻の説明も残しています。
- **馬券**：7種類の賭け方と8匹の選択カードをコンパクトに配置しました。切り替えても選択した魔物、順番、購入金額は保持します。

表示していない情報は別のタブや開閉欄へ移したもので、従来の情報は残しています。プレイヤーの準備状況と締切も確認できます。画面全体のスクロールは従来どおり可能です。

## レースの見た目

- 上部に全8匹の現在順位、自分の魔物の順位、先頭の残り距離を表示します。
- 芝・砂の競技場、金・黒・紫の装飾、追い込みや加速の光を調整しました。既存の魔物画像はそのまま使用します。
- 「全体」と「先頭を追う」を切り替えられます。追尾表示では先頭周辺を拡大し、全員の順位は上部で確認できます。カメラ操作は走りや着順に影響しません。
- 自分の操作欄と、全員の馬券をコンパクトに表示します。

## ケツを叩く！

**新しい部屋では、2.2秒の待ち時間を撤廃しました。**

| 操作 | 効果 |
| --- | --- |
| 1回 | 1.4秒間＋18％、スタミナ−10 |
| 効果中に追加 | 加速率を上乗せ。各回はそれぞれ1.4秒で終了 |
| 5回を一気に使用 | 最大＋90％、スタミナ合計−50 |
| 小分けに使用 | 加速する区間を分散できる |
| 終盤まで温存 | ゴール前の短い加速へまとめて使える |

合計5回までです。スタミナ20未満では徐々に減速し、10未満では叩けません。連打しても同じ操作を二重計上しません。AIも同じ5回・同じ消費で、種類ごとに序盤寄り・分散・終盤寄りの使い方をします。

手元の残り回数とボタン演出はタップ直後に更新し、次のタップのために通信の返事を待ちません。通信自体の遅れがなくなるわけではなく、実際の走行はサーバーが受け付けた時点で反映します。切断中やゴール後は追加操作できません。

## 更新時の注意

**ゲームとサーバーの両方を更新・再起動し、新しい部屋を作ってください。**
更新前に作った部屋は購入済み馬券・走行中の記録を守るため旧ルールを続けます。Build456の部屋では2.2秒の操作間隔も残ります。「もう1レース」だけでは旧ルールのままなので、一度退室して新規作成してください。

通常戦闘、育成、魔法陣、出走賞金・経験値・なつき度、連戦疲労は変更していません。予測倍率は新ルールで再計算し、購入時に固定します。既存部屋の購入済み倍率・結果は変更しません。
