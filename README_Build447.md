# Build447 / v3.1.126 — 勇者4人の表示戦力補正

Build446までを含む累積上書きZIPです。既存のゲームフォルダへ、フォルダ構成を維持して上書きしてください。新規インストール用のリポジトリ全体ではありません。

## 変更

「りおん」「より」「えなみ」「ひで」の個人戦力に、表示用の0.65倍補正を加えます。四捨五入し、正の戦力の最小値は1です。種族IDで判定するため、名前の変更や見た目の変更では補正対象が変わりません。

4人は基礎能力値が高く、従来の戦力計算はその能力値を集計する一方、単独時の与ダメージ補正などの条件付き能力を評価していませんでした。今回は表示用の調整係数を追加します。実戦結果を厳密に予測する指標へ変更するものではありません。

- 十神・深淵・ほかの魔物の計算値は維持します。
- 各キャラの育成・装備による増減は引き続き反映します。レベルや装備に関係なく、必ず十神より低く固定する方式ではありません。
- HP、攻撃力、ダメージ計算、スキル、勇者4人の共鳴・連携は変更しません。
- ホーム、編成、装備、探索、戦力記録、ランキングへ同じ補正を反映します。総戦力は補正後の個人戦力の合計です。
- Build446の低戦力側の調整と、ホームの「戦力／数字」の上下配置・自動文字サイズ調整も維持します。

ランキングは保存済みの各メンバーの種族IDと従来の検証済み戦力から換算して並べ直します。未ログインのプレイヤーも対象です。サーバーの保存値と戦闘用プロフィールは従来基準を維持し、以前のクライアントからの送信や再送との互換性を保持します。

各メンバーの内訳がない過去の自己ベストは正確に再計算できないため、「更新前の戦力記録」へ保存し、新基準の記録は現在の編成から開始します。さらに古い記録も保持します。

## 反映手順

1. ZIPを展開して、既存のゲームフォルダへ同じ構成で上書きする。
2. 本体とオンラインサーバーの両方を更新する。サーバーを別フォルダへ置く場合は、参照先の `src/core/PowerScale445.js`・`PowerScale446.js`・`PowerScale447.js` を同じ相対位置へ配置する。
3. オンラインサーバーを再起動し、本体を公開する。
4. ゲームを再読み込みして `v3.1.126` を確認する。

セーブやサーバー保存データの削除は不要です。今回のZIP作成では公開先への反映は行っていません。
