# ABYSS DOMINION Build471 — 手札と、1マスずつの移動

Build470（v3.1.149）適用済みのゲームへ重ねる、Build471（v3.1.150）の差し替え専用ZIPです。
変更・追加した実行用13ファイルと、この説明書だけを収録しています。新規起動用のフルセットではありません。

## 適用手順

1. 対戦が終わってから、Build470適用済みのゲームに、ZIP内のファイルを同じ階層で上書きしてください。既存フォルダー全体の削除・置換は不要です。
2. オンラインサーバーにも `online-server/src/` の2ファイルと、変更された共有コード `src/sugoroku/` を反映し、サーバーを再起動してください。特に `Engine463.js` と `Pacing465.js` はサーバーでも使用します。
3. フロント側を更新し、参加者全員が再読み込みしてください。表示バージョンは **3.1.150**。更新後の新しい対戦から使ってください。

1マスごとの移動時間と手番表示を全員で合わせるため、通信バージョンは12です。旧画面からの操作は新サーバーで拒否し、新画面から旧サーバーへのゲーム開始も更新案内を表示します。

## 今回の変更

- **手札の見切れを修正。** マップに固定の最低高さを取る方式をやめ、手札の下端とカードの状態表示を確保しました。スマホの実際の表示領域、画面上端の余白、安全領域に対応します。「広げる」と4枚完成シリーズも対象です。
- **自分の手番で手札を開き、他の人の手番で閉じます。** 途中で手動開閉も可能です。次の手番で自動設定へ戻ります。追加の自分の手番でも開きます。表示中の演出が終わる前に、次の手番の情報だけで開閉しないようにしました。
- **現在の手番のコマが柔らかく発光。** 輪郭と足元の楕円がゆっくり明滅します。「動きを減らす」設定では、明滅せず一定の光で示します。
- **コマを囲む四角い枠を削除。** 攻撃対象の強調は上部のプレイヤー欄に残しています。
- **通常の移動を1マスずつ、短いジャンプと着地で表示。** 前進・後退・分岐ルートに対応。通常は約0.21秒間隔で進み、長距離では少し速めます。スタートへ戻す特殊な効果は従来どおり直接移動します。
- **小さな「ピッ」という移動音。** 1マスにつき1回。既存の音声設定・ミュート設定に従います。画面の再描画で同じマスの音を重複させません。
- **小さい画面でも操作と演出を読めるよう調整。** マップの高さが少ない時はサイコロ・山札と操作案内を横並びにします。カード獲得や覚醒などの演出中だけ、手札の上まで広い表示を重ね、終了後はそのままの手札へ戻ります。全員表示のカメラも手札の開閉後に収まる範囲へ再調整します。

## 確認した範囲

本番のすごろく描画・エンジンを用いたChromiumの確認環境で、以下を検証しました。

- 320×568、375×620、393×694、393×740のスマホ相当表示で、通常カードとシリーズカードの下端・状態表示が見切れないこと。
- 手札の拡大、表示領域のリサイズ、画面上部に余白がある場合、サイコロ操作の位置。
- 自分／相手／追加手番の開閉、途中の手動開閉、演出待ち中の手番切替、手札を閉じたままでの防御選択。
- 手番のコマだけが発光し、コマに四角い対象枠が付かないこと。
- 前進・後退・分岐で全マスを順番に通過し、音が1マスにつき1回であること。移動中の再描画と動きを減らす設定。
- 小さいマップでのドロー・特殊カード・覚醒・サイコロ演出と、演出後の手札への復帰。重ねた演出の裏側へタップが通らないこと。
- 手札を開閉した後も、全員表示のカメラが再調整されること。デスクトップ1280×900での表示。
- 2つのローカルWebSocketクライアントと本番のすごろくサーバー処理で、旧版拒否・演出中の操作制御・状態復元を確認。
- 20試合の自動対戦が終了し、カードの枚数・所在と優勝者1人を確認。

実機のiPhone Safariと公開先での検証は未実施です。確認画面のキャラは既存アートによる代替表示を使用しています。既存の人物写真・モンスター素材・ゲームの勝利条件は変更していません。
