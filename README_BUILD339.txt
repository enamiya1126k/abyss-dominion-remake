ABYSS DOMINION Build339 / v3.1.20
Build338 適用済みのゲームへの差し替え用です。

適用方法
ZIPを展開し、index.html と src フォルダをゲームの同じ場所へ上書きしてください。
更新後のホーム右下が v3.1.20 になれば読み込み完了です。

修正内容
・仲間の階層ボスは、ホームの配置枠を元の大きさに戻し、キャラの絵だけを2倍表示。
・拡大の基準を足元に固定し、右下への位置ずれと戦力枠からの離脱を修正。
・探索でも仲間の階層ボスの絵を2倍表示。隊列・通行判定・移動経路は変更なし。
・戦闘の仲間階層ボスは絵だけを拡大し、レア度と名前を拡大後の画像より上に配置。
・通常の仲間、敵、魔法陣、戦力・HP枠のサイズは変更なし。
・セーブ形式や所持品、サーバー処理の変更はありません。

確認内容
・JavaScript構文チェック。
・対象テスト9件合格。探索4スロット、カメラ倍率、移動・戦闘不能時の足元固定など。
・Chromiumの表示用ページで320/390/430/768px幅を検証。
  ホームと戦闘で、絵の倍率2倍、配置枠・魔法陣・カードの位置維持、名前の重なり回避を確認。
・表示用ページは手元で取得できたCSSと代替の既存キャラ素材を使用しています。
  過去の差し替えZIPに含まれないCSS・階層ボス画像があるため、現在公開中の画面全体の完全再現、
  全階層ボス素材、Safari実機での最終表示は未確認です。
