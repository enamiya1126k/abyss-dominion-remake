ABYSS DOMINION Build490 / v3.1.169
Build489 適用済み環境への差分更新

【今回の変更】
・同じキャベツを刻むほど山が低くなり、横に最大約18%広がります。
  素材ごとの透明な余白を除いた共通サイズで表示し、素材の切替で大きく戻る見え方を修正。
  最終素材になっても、1回切るごとの縮小が続きます。
・まな板→テーブル全壊の後、床も破壊できます。
  合計27打目から床のひび割れ・陥没・深淵の8段階、その後も穴が少しずつ広がります。
  傷は次の合図・通信復帰・結果画面まで保持。新しい試合でリセットします。
  1回の「切るな！」につき−80点という採点は変更していません。
・結果を閉じず一覧だけ表示していた経路を修正。
  部屋主の「ミニゲーム一覧へ戻る」は終了済みゲームを閉じ、同じパーティーを保持。
  「もう一度」は同じミニゲームの新しい準備画面へ移動します。
  通信エラーを結果画面にも表示し、応答待ちのまま操作不能にならないようにしました。
  再送された古い操作で次のゲームを消さないよう、ゲームIDと操作済み記録を確認します。
・魔物レース／カードすごろく／限界キャベツ千切り／用水路防衛隊の結果操作を共通化。
  「もう一度」「ミニゲーム一覧へ戻る」の2ボタン。「ホームへ戻る」は結果から削除。
  部屋主以外は自分の結果を閉じて一覧へ戻れます。再戦・ゲーム選択は部屋主が行います。
・優勝者のキャベツの山は従来どおり最終ポイントと連動します。

【適用】
1. Build489 適用済みのゲームフォルダーへ、ZIP内のファイルを同じ相対パスで上書き。
2. online-server/src/PartyCoordinator462.js と RaceCoordinator451.js も更新し、
   既存のオンラインサーバーを再起動してください。保存データは削除しないでください。
3. ページを再読み込みし v3.1.169 を確認。既存の終了済みゲームにも今回の操作を使えます。
   サーバーが旧版の場合、結果操作時にBuild490更新・再起動の案内が表示されます。
4. これは差分ZIPです。Build489までの既存ファイル・素材が必要です。
   本ZIPを作成した時点では、本番サイトへの公開・デプロイは実施していません。

【検証】
既存156件＋今回16件＝172件の自動テスト通過。
・全素材の切替をまたぐ連続縮小、床破壊の各段階、次の合図・保存・結果での傷の保持。
・実際のクリック振り分けからサーバー処理まで通した、結果閉鎖・再戦・全ゲーム選択。
・ゲスト操作、古い操作の再送、永続データからの再起動、通信失敗・待機解除、報酬保持。
・4種類の実際の結果テンプレートの2ボタンと「ホームへ戻る」の非表示。
・高速タップ、二本指入力、ズーム抑止、カードすごろく、用水路防衛隊の既存検証。
この作業環境は差分ファイル中心のため、テスト内だけ未同梱の本編カタログ／魔物描画に
fixtureを使用しています。本番用の置き換えはしていません。
実ブラウザーでの表示・実機iPhone/Safariでの操作確認は未実施です。
