## 変更
- 針の側面は壁。上面への接触だけミスになります。
- 敵・針・蒸気・天井への接触はミス1回として点滅し、その場から続行。落下のみチェックポイントへ戻ります。残機制限なし。
- ゴールした人はミス数の少なさ、同数なら時間で順位決定。未完走者は到達距離、ミス数の順です。制限時間は継続します。
- 火・風・氷・雷・岩・水の6属性。弾数制限なし、連射間隔あり。火は貫通と箱破壊、風は空中追加ジャンプ（1飛行につき1回）、氷は敵凍結、雷は近くの敵に連鎖、岩は箱破壊と自動回復する防御、水は蒸気を一時停止。
- 箱は1個ずつ独立して壊れます。火2発、岩1発。
- 足場の説明文字とカウントゲージを撤去。揺れ→落下→復帰のアニメーションへ変更。
- 各コースに横幅約5マスの蒸気区間、上下する天井と避難用の凹みを追加。該当区間を迂回する上の足場を除去。
- 地上の虫は地形に沿って前進。上の足場にも敵を配置。
- 背景化・通信切断からの復帰では位置と属性を保持。全員が離席中はゲーム内時間も停止。他の参加者がいる場合、その人たちは続行します。部屋自体の期限切れ・削除後の復元は対象外です。
- 人間のみ1～4人、AI補充なし。蒸気・ゲートのアニメーションは継続。
