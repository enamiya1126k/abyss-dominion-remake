# ABYSS DOMINION Build602

Build601に重ねる差分更新。アプリバージョンは3.1.281、魔界ランナーズの通信ルールは12。

## 更新方法

1. ZIPを展開し、Build601の同名ファイルに上書きする。
2. 本体とonline-serverの両方を更新し、サーバーを再起動する。
3. 参加者全員がゲームを再読み込みし、冒険を開始する。

コース配置の変更を伴うため、更新前の冒険は準備画面へ戻る。本更新は公開サイトへの反映を実行していない。

## 画像素材による描画

17点の画像素材を新規生成し、既存の背景・地形・キャラクター・属性ロゴと組み合わせて使う。

- 橋は木板・石材・金属金具のある吊り橋に変更。未開通時は両岸の鎖だけを見せ、通れる橋と区別する。
- スイッチは押し込み式の装飾台に変更。未作動は琥珀色、作動済みはエメラルド色の画像に切り替える。
- バネは金属製のスプリング画像を圧縮して動かす。加速石は細長い緑の結晶に変更する。
- 壁キック用の柱、旗、スター、凍結の殻、鎖、風の流れ、水面、光の粒も画像で描く。
- 操作ボタンと情報パネルに生成した装飾画像を使用する。数値やボタン名は読みやすい文字として維持する。
- 右上の橋・ゴール表示をアイコンと数値にまとめ、横にはみ出していた長い表示を縮める。
- 画像は一度読み込んで再利用する。WebP画像17点の合計は595,114バイト。新素材の準備が済むまで操作を開始しない。

新素材の生成プロンプト・寸法・変換記録は `assets/runners602/SOURCES.json` に含む。図形で描いていた仕掛けやエフェクトの代わりに、画像の切り替え・移動・拡縮で動きを付ける。

## 壁キックで登るルート

時計塔の2区画目に、左右の柱を交互に蹴って登る縦穴を追加する。通常ジャンプだけでは登れず、単独・属性なしでも壁キックで突破できる。頂上には共通の旗があり、その先は段階的に下山する。

遺跡と水晶洞の地下から地上へ戻る道にも縦穴を追加する。水晶洞の出口には上向きのバネも置く。柱は見た目と同じ位置で壁・足場として判定する。

## 大きな隠し寄り道

つながるスイッチ遺跡と蛍あかりの水晶洞の小さな隠し部屋を、幅約2,000の地下ルートに作り直す。

- 遺跡は深い地下背景、段差、崩れる足場、横移動する足場、敵、奥のスターを組み合わせる。
- 地下の追加スイッチから地上の橋も開けられる。寄り道を進んだ人が仲間の道をつなげられる。
- 水晶洞は上段に登るスターの道と、落下を受け止める下段の足場を設ける。途中で落ちても低い道から出口へ進める。
- 出口から本ルートへ復帰できる。元の地上ルートと旗も維持する。
- 入口の光るアーチと宝石の誘導列は撤去。崖の縁の下に小さな欠けた石だけを残し、注意して探す入口にする。
- 遺跡・水晶洞の制限時間は7分に延長する。他の6コースは6分のままとする。

全8コース・各3スター、仲間ジャンプ、2人用の封印、共通の復活旗、人間プレイヤーだけの参加条件は維持する。
