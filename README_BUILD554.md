# Build554 — スクラップターボと暴発ギア / v3.1.233

Build553 適用済みの本体・online-server に重ねる差分パッチです。
ポンコツ改造GPを、走りながら育てる工房レースへ更新します。

## 遊びの変更

- 接触と新しく進んだ距離で「スクラップターボ」を充填。
  通常発射の後、満タンになったら走行中のマシンを引き直して再噴射できます。
  今の速度に発射の力を加算。満タンに戻れば同じラウンドでも再使用できます。
- 噴射後2.6秒は減速を軽減。噴射中は接触・前進による再充填を休止しますが、
  加速ローラー・燃料カプセル・ゲートからは充填できます。最終回の充填は1.5倍。
  ターボと、次の通常発射を強める従来の「仕返し電池」の充電は別です。
- コース上の２つのゲートは、左右を交互に入れ替えて登場。
  安定側は加速とターボ25%充填。暴発側はサーバーが１〜６を等確率で抽選します。
  １〜２は小加速、３〜５は強加速、６は大加速＋ターボ満タン。
  各ゲートは１人につき１回。往復・再接続で引き直しはできません。
- ゲートは実際の速度に力を加えます。距離を直接加点したり、位置を飛ばしたりしません。
  得点は引き続き１本のコースでの最長到達距離。速度上限95と高速時の衝突判定を維持します。
- 引く方向・強さ・タイミングでゲートを狙えます。タップ、引いた位置を戻す、
  Esc、画面外キャンセルではターボを消費しません。キーボード操作も対応します。
- AIも残量を見てゲートを選び、満タンになったターボを再噴射します。
  最後まで装備の組み合わせが効くよう、重ね取りと組み合わせの説明をカードに表示します。

８／16ラウンドを通して位置・速度・装備・充電・ターボ残量・ゲート通過履歴を継続。
途中の結果画面、スタート位置へのリセットはありません。
まだ発射していない相手にも当たり判定があり、押された勢いのまま発射できます。
着地点や未来の軌道は表示しません。

## ビジュアル

- 専用の工房コース、真鍮の配管、炉の光、金属床を画像素材で制作。
- 車体にロケット、エンジン、装甲、車輪、蓄電装置を重ね、取得した改造を見える形に。
  選んだ相棒は座席に表示します。
- 加速ゲート、ローラー、バンパー、燃料カプセルを専用素材へ変更。
- 装備３択を画面下の固定トレイへ。選んでいる間もコースと移動が見えます。
  アイコンと飾り枠は既存の生成素材を活用します。
- 速度計、次のゲート、マシンの改造レベル、ターボ残量を表示。
  噴射炎、金色の発光、衝突火花、金属音、実際の順位上昇通知を追加。
  大きな加速には短い画面振動。動きを減らす設定では振動・軌跡・点滅を抑えます。
- メニュー・準備・最終結果には専用のレースイラストを使用します。

## 適用

1. Build553 をバックアップし、ZIP の中身を同じ階層へ上書き。
2. 本体の index.html / src / assets / offline 関連と online-server の両方を更新。
3. online-server を再起動し、参加者全員が本体を再読み込み。

本体 v3.1.233、通信 `ricochetVersion550:5`、保存ルール `rules550:5`。
旧バージョンとの混在は拒否します。旧ルールで進行中の保存対戦は準備画面へ戻るため、
更新前に現在の対戦を終えてください。ターボ消費とゲート通過・出目は即時保存します。
公開サイトの更新・サーバー再起動は、このパッチの作成には含まれません。
人間ピンボールのBuild553の限界突破・王冠抽選は維持しています。
