Build488向け差分 — 新パーティーゲーム「用水路防衛隊」

【適用】
1. Build488適用済みのゲーム一式へ、ZIP内のファイルを同じ階層で上書きしてください。
2. 今回は本体とオンラインサーバー両方の更新です。
   online-server/srcだけでなく、サーバーが参照する共通src/canal・src/partyも同じリリースへ更新してください。
3. 通常の方法でNode.jsオンラインサーバーを再起動してください。
4. 参加者全員がゲーム画面を再読み込みし、「パーティー」→「用水路防衛隊」を選んでください。
保存データの削除は不要。この差分ZIP単体では起動しません。公開サイトへのデプロイは行っていません。

【遊び方】
4人協力、1試合60秒。全員が所持魔物から相棒を選び、「準備OK」後に部屋主が開始します。
足りない席にはAIが入るので、ひとりから遊べます。魔物の強さによる性能差はありません。
北・東・南・西の担当が1人ずつ割り当てられます。
方向ボタンをタップで網を1回、長押しで連続捕獲。自分と左右の隣の水路を守れます。
向かい側の担当は仲間に任せ、暇な方向の隊員は隣を援護してください。
「大網」は選択中の水路をまとめて捕獲。硬い相手にも3回分の捕獲ダメージ。再使用まで12秒。
PCでは矢印キー/WASDで方向の網、Spaceで大網。スマホでは両親指の切替に対応しています。
網は水路を少し進んだ相手に届きます。最も集落へ近い相手から捕獲します。

集落の耐久は全員共通100。生物が中央へ到達すると減少します。0になると全員で失敗。
60秒を耐え切れば全員で成功。結果は耐久75%以上S、50%以上A、それ未満B。
開始50秒で全4水門を開放、最後の10秒は流れが速くなり、4方向へ同時に生物が現れます。
結果画面は全隊員で並び、合計捕獲・残り耐久・援護・個別貢献を表示します。
参加無料。本編の通貨や能力値への加算・支払いはありません。

【登場する生物】
アメリカザリガニ44%、ミドリガメ27%、ブラックバス24%。
残り5%は架空の「コーンザリ将軍」。登場割合は出現ごとの抽選値です。
生物の行動、強さ、捕獲演出はコミカルなゲーム表現です。
ザリガニは網1回、ミドリガメ3回、ブラックバス2回、コーンザリ将軍4回で捕獲。
生物・用水路・カバーの新規生成素材、網、水しぶき、援護表示、警報音を追加しました。

【通信・操作】
既存の認証済みパーティー通信を使用。判定はサーバーで行います。
相手の水路を勝手に担当できる範囲は隣まで。向かい側の操作、重複入力、古い試合の入力を拒否します。
サーバーの250ms更新に合わせて入力をまとめ、長押しでも1打ごとの保存・全員送信はしません。
長押し信号が途切れると1.1秒で停止。切断またはホームへ戻った隊員の担当はAIが引き継ぎます。
接続復帰後は同じ魔物・同じ記録で戻ります。観戦参加者は次の試合から参加できます。
再戦、別ゲームへの切替、ロビー/結果での部屋主による退場操作を既存パーティーへ接続しています。
ゲーム中だけ拡大操作を抑止し、他画面へ戻ると元に戻します。
通常更新で操作ボタンを作り直さず、生物の移動と捕獲をCanvasで更新します。
音ON/OFF、演出を減らす設定に対応。メインのパーティー配置は変更していません。
