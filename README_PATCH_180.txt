release180 差分パッチ

対象: release179 適用済みのゲームフォルダ
内容: release179 から変更・追加されたファイルだけ
削除対象: なし

ZIPを展開し、中の`abyss-dominion-remake-main`フォルダの「中身」を、release179の同名フォルダへ階層を保ったまま上書きしてください。
ゲーム全体の再配置は不要です。

更新前に確認すること:
- release179が適用済みであること
- 進行中のオンラインプレイと交換を終え、オンラインサーバーを停止する
- `online-server/data`フォルダ全体を別の場所へバックアップする
- `online-server/data`フォルダと既存JSONを削除しない
- 上書き後にオンラインサーバーを再起動する
- ブラウザを再読み込みする

この差分ZIPには、画像・音声などのゲーム素材、利用中のオンライン保存データ、`online-server/node_modules`、実行時生成物、一時ファイル、旧差分マニフェスト、ZIPファイルを含めません。

build239では、ミュートとブロックをオンライン全体へ接続します。ミュートは相手のチャット、吹き出し、スタンプ、探索ピンだけを自分の画面で非表示にし、ゲーム進行、フレンド、招待、交換、同室参加は変えません。ブロックはフレンド、申請、招待、新しい交換を止め、公開掲示板、おまかせ参加、直接ルームID、招待、ギルド募集の各経路から同じ部屋へ入ることを防ぎます。安全設定から両方の一覧確認と解除ができます。

進行中の探索、レイド、チーム戦、共鳴迷宮は、安全操作だけでは強制終了しません。受渡し開始前の未確定交換は安全に取り消し、最終確認後の確定交換は巻き戻さず、release179で追加した受取保全を継続します。

`online-server/data/friends.json`はversion 1からversion 2へ自動移行します。既存アカウント、フレンド、申請、ブロックを維持し、ミュート一覧を追加します。更新時に`data`フォルダや既存JSONを削除しないでください。

オンライン通信はprotocol 1.16.0、通常セーブはschema 58を維持します。今回は通報、管理者BAN、IP／端末BAN、自動NGワード判定を追加しません。

詳しい変更は README_180.txt と BUILD239_PUBLIC_ONLINE_SAFETY_UPDATE.md を確認してください。
