# Build582 / v3.1.261

Build581に上書きする差分です。「まわせ！魔王の回転寿司」を作り込みました。

## 遊びの追加

- 注文の皿を５枚連続で取ると、６秒間フィーバー。発動後に取る皿の得点と注文一致の10点が２倍になります。金皿も対象です。注文完成の90点ボーナスは２倍になりません。
- 注文外の皿は、発動前の連続数をリセットします。取れなかったタップで連続数は切れません。フィーバー中に注文外の皿を取ってもフィーバーは継続します。
- 激辛わさびは40点ロストと1.5秒休み。連続数をリセットし、フィーバーも終了します。
- フィーバー中は次の連続数を貯められません。終了後、また０から狙えます。
- 逆回転を３秒前から予告。自分の順位・首位までの差・箸の回復ゲージが見えるようになりました。

## 見た目・操作

- 箸が伸び、お寿司が弧を描いて手元へ飛ぶ演出を前面に表示。
- キャラクターのもぐもぐ動作、激辛リアクション、注文完成の紙吹雪、金皿のきらめき、食べた皿の山を追加。
- フィーバー中は金色の画面、残り時間ゲージ、皿の２倍表示でチャンスをお知らせします。
- 相手の注文完成の大きな通知を抑え、画面を覆いにくくしました。
- 皿の移動をCSS transformへ変更。レーンの動きと表示予測をそろえました。
- 音OFF・視差効果を減らす設定・縦横画面・キーボード操作に対応します。

## 適用方法

1. Build581導入済みのプロジェクトへ、フォルダー構成を保って上書きします。
2. 本体とオンラインサーバーを両方更新します。サーバーから読み込む隣の`src/`内の共通ルールも今回の版へ更新してください。
3. サーバーを再起動し、参加者全員がページを再読み込みします。依存パッケージの追加は不要です。

今回、寿司のルール版を更新しています。適用時に残っている旧版の寿司の部屋は準備画面へ戻るため、対戦が終わってから更新してください。ゲームのセーブデータやサーバー設定を上書きするファイルは含みません。

前回の画像素材はそのまま使います。このZIPには再同梱していません。
