# Build612 — 旗を越えるボスと、上下に戦える広場

Build611適用済み本体へ重ねる更新パッチ。アプリ3.1.291、ランナーズ通信ルール22。

## 変更

- 全7ボスの戦闘範囲を拡張。旗より手前の床まで追跡でき、旗の左側で立ち止まって撃つだけの安全地帯を解消。
- 閉じたゴールでプレイヤーを左へ強制移動する処理を撤去。戦闘中もゲートの左右へ移動できる。ボス撃破などの既存クリア条件は維持。
- 各ボス広場の床を左右に延長し、コース右端まで連続した安全な床を配置。右端では通常の共通移動処理で止まり、ゲート由来の押し戻し・落下を起こさない。
- 各広場に4枚の足場を追加。地面→下段→上段の経路を2組用意し、通常ジャンプだけで上り下りできる。
- ボスの技を、突進・高所も狙う扇状射撃・3列の落下弾・跳躍からの左右衝撃波へ拡充。ボスの系統ごとに技順を変更し、上段に居続けても狙われる。
- 攻撃予兆は最低750ms。射撃の狙い、落下弾の列、跳躍の着地点を表示。予告後に射撃の狙いを変更しない。攻撃後の反撃時間を確保。
- 跳躍の座標計算をサーバー・描画・予測で共有。空中で連携攻撃によりひるんだ場合は床へ落下して復帰する。
- 最終魔王の2人連携によるダメージ条件、既存の頭部ガード、船の独立した自動運行・連続コース・船に依存しないゴール、中止／退出機能を維持。

## 適用

1. Build611適用済み本体へ、このZIP内のファイルを同じ位置に上書きする。
2. `online-server/src`と、サーバーが参照する共有`src`も更新し、サーバーを再起動する。
3. 参加者全員が画面を再読み込みする。本体とサーバーの通信ルールが異なる場合は更新案内を表示する。

GitHub・公開サイト・本番サーバーには反映していない。
