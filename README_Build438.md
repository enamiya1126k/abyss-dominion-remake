# ABYSS DOMINION — Build438 / v3.1.117

Build437までの更新を含む、累積の上書き用ZIPです。

## 入れ方

1. 今のゲームフォルダーとセーブをバックアップします。
2. ZIPの中身を、いつものゲームフォルダーへ上書きします。元の素材やセーブ、サーバーの `data/` と設定を残してください。
3. **今回はレイドサーバーも更新します。** `online-server/` と同階層の `src/` を含めて上書きし、いつもの方法でサーバーを再起動してください。戦闘速度の拡張にはサーバー側の更新が必要です。
4. 公開先を更新してゲームを再読み込みします。表示バージョンは **3.1.117** です。

このZIPは公開中のゲームへ自動反映されません。

## 今回の変更

- ホームの「共闘レイド」は、過去の戦闘結果ではなくレイドの受付を開きます。進行中の挑戦は再開でき、その場で終えた戦闘の結果は通常どおり表示します。
- 装備画面の大枠を保ち、上部に「【ランク】名前」、左に大きなキャラクター、右に魔法陣設定を配置しました。第二章キャラは待機モーションの全身が枠内に収まります。下の属性・戦力・ステータスの位置を保っています。
- 装備の整理・一括操作・選択・並べ替えを黒と金の素材へ統一しました。売却は赤系で区別します。
- スキル選択の「設定中」を横向きのバッジに修正しました。別枠のスキルは暗く表示し、「SLOT 2に設定中」のように使用先を表示します。別枠で使っている間は選べません。移す場合は使用中の枠から外して設定します。
- スキル一覧のカテゴリ絞り込みも、非表示指定が装飾CSSに打ち消されないよう修正しました。
- 魔物一覧、記憶の間、放置帰還報酬、お知らせ、戦力記録、レイド受付・ランキング・交換所に、画像生成で制作したフレーム・黒曜石のボタン・古書庫・地下祭殿の素材を組み込みました。
- 戦力ランキングの上位3名は、元のメダル枠の中央に順位数字を配置し、金・銀・銅の質感で区別しました。
- レイド戦のHP・MP表示をさらに小さくし、画面幅に応じて全桁が収まるよう調整しました。
- 共闘レイドの速度ボタンは **×0.5 → ×1 → ×2 → ×4 → ×16 → ×32** を循環します。オンラインと保存したオフライン挑戦の進行・演出に適用します。通信・端末性能で実際の所要時間は変わります。

キャラ・装備・スキルの性能、戦闘計算、報酬、挑戦回数を保っています。今回指定の装備枠内部以外は、既存の配置を維持しています。

Build437の99ラウンド上限・活躍表も同梱しています。更新前に発行済みの旧形式のオフライン挑戦券は、元の10ラウンドのルールで再現します。
