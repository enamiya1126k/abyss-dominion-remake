# ABYSS Build465 — 冒険マップ・読み取れる演出・AI対戦のやり直し

Build464への累積更新。APP_VERSION 3.1.144 / Save schema 84（維持）。

## 今回の変更

### AI対戦をやり直す・終了する

プレイ画面右上の「メニュー」から、次の操作を選べます。

- **最初からやり直す**：確認後、同じ部屋・同じ選択魔物で新しい対戦を開始。手札・位置・特殊カード・得点・演出を初期化します。
- **ゲームを終了してパーティーへ**：確認後、対戦を終了してゲーム一覧へ。同じパーティーと合言葉を維持します。

自分＋AIだけの進行中の対戦で使えます。AIの手番、サイコロ・カード演出中、分岐・防御などの選択待ちでも利用できます。選択画面が開いている時は「閉じる」からメニューを開いてください。

他の人間プレイヤーがいる場合は利用できません。切断中の人や観戦参加者も含め、サーバー側で確認します。古いゲームIDや同じ要求の再送で再度リセットされません。メインゲームの育成データ・所持GOLD・レースの精算には触れません。

### 盤面と手札の配置

- スマートフォンではヘッダー・プレイヤー情報・操作欄を圧縮。ログは「履歴」に移し、盤面と手札の間は1行の操作欄にしました。
- 393×694の検証画面で、通常時の盤面は約380px（画面高の約55%）。「マップ拡大」で手札を畳み、盤面をさらに広げられます。
- 手札はコンパクトなカードトレイ。タップで詳細、「広げる」で大きく表示。「整理」でフィルターと並び替えを表示します。
- 生成した新しい冒険背景を使用。樹海→結晶洞窟→火山→王城へ続く階段や橋、石のマス、進行方向と効果ラベルを表示します。
- 分岐は風景付きの2つの道から選択。寄り道が4マス長いことと、途中の効果を表示します。
- 捨て札・防御札などはカード型で選択し、選択中の札を強調。「このカードを捨てる」などで確定します。複数枚を捨てる効果は従来どおり1枚ずつ確認します。

### 演出と進行速度

- カード消失の原因だった、空の非表示オーバーレイの高さ0によるカード縮小を修正。見えている盤面の高さから計算し、カード自体にも最小サイズを指定しました。
- 基本カードは使用者のキャラと名前、裏面→表面、カード効果を4.8秒かけて表示します。
- サイコロは使用者・実際の出目・補正後の合計を3秒表示。移動は通過したマスを1つずつ進みます。
- 効果は「使用者のキャラ → 対象のキャラ」「効果名」「何が起こるか」を表示。悪いマスと自分への効果はそれぞれに合わせて表示します。
- 演出を順番に再生し、途中で次の操作やAI処理に進まないようサーバーでも待ち時間を設けました。選択の75秒は演出完了後から確保します。
- 再描画でカードが消えたり演出が最初から再開したりしないよう維持。接続し直した場合は古い演出を大量再生しません。
- 「動きを減らす」設定では回転・浮遊を抑制し、内容を読む時間は維持します。

カード116種類／山札335枚、マスの効果と接続、得点計算、秘密の手札、パーティー共有、魔物レースのルールは維持しています。マップの座標は表示用のみ変更しています。

## 適用

1. **既存ゲーム一式へ、このZIPの中身を上書き**します。以前の累積更新と同じ形式で、過去のベースにだけある未変更ファイルは含みません。単独では起動できません。
2. **フロントエンドとオンラインサーバーの両方を更新してサーバーを再起動**してください。サーバーにも `src/sugoroku/Pacing465.js` を含む共有コードが必要です。
3. ブラウザを再読み込みし、Build465 / 3.1.144を確認してください。オフラインキャッシュの名前も更新しています。

本番サイトへのデプロイは行っていません。
