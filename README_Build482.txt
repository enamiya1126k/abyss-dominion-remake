【防御画面】
・巨大な代替アイコンを、現在の特殊カードの絵柄・装飾に置き換え。
・ツンデレと通常の防御札を、同じ縦横比のカードで並べて選択。
・受ける略奪・半減・全喪失の💎数と、適用前後の持ち金を上部に表示。
・長い攻撃説明とカード効果は「詳細」「効果を確認」から展開。
・防御が1種類だけなら選択済みで開く。確定ボタンを押すまでは発動しません。
・防御が複数ある場合はカードを選んでから確定。
・防御／受けるボタンを画面下に固定。使用時のカード消費も表示。
・送信中・切断中の選択と二重送信を抑止。

【💎略奪】
・相手1人の対戦用の持ち金を全額奪います。
・「参加費の20％まで」の略奪額制限を撤廃。
・略奪で受け取る分には「参加費の4倍」の保有制限も適用しません。
・防御・反射は引き続き可能。反射が通れば、攻撃者の対戦用💎を全額奪います。
・各💎マスは従来どおり1人1回です。メインゲームで保有する💎を直接奪うことはありません。
・略奪はプレイヤー間で移転するため、ゲーム全体の💎総量は増えません。
・実プレイヤーへの追加供給は、参加費合計の20％までを維持。固定の1人100個上限はありません。
・AIから奪った分を含め、本編への受取合計が「実プレイヤーの参加費合計＋20％」を超える場合は従来どおり比例調整します。
・泉・2倍・神殿など、共有宝庫からの補充分には従来の参加費4倍までの制限が残ります。
  略奪でその額を超えた後に補充マスへ止まっても、超過分を減らしません。
・Build480以降の循環ルールで開始した対戦に適用。開始済みでも再接続後の略奪から有効です。
  Build479以前に開始した旧精算ルールの対戦は従来の処理を維持します。
