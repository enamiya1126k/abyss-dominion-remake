# Build458 / v3.1.137 — 魔物レースの操作・画面をまとめて改善

Build457までの変更をすべて含む累積上書きZIPです。既存ゲームとオンラインサーバーの同名ファイルへ上書きし、サーバーを再起動してください。保存データと既存画像は残してください。ZIPに保存データ・node_modulesは含みません。

**ゲームとサーバーの両方を更新して、新しい部屋を作ってください。** MAX BETは新しい部屋で有効です。更新前の部屋は購入済み馬券・走行記録を守るため、旧上限100万Gを継続します。「もう1レース」では部屋のルールは更新されません。

## 出走準備

- 芝・砂のコースを背景付きのカードで選べます。4人の参加状況はコンパクトに表示します。
- 魔物を画像付きの小さなカードから選択できます。名前検索・脚質の絞り込み・所持順／コース適性／疲労の並べ替えに対応します。
- 選択中の魔物と出走準備ボタンを画面下に固定しました。一覧の一番下まで移動する必要はありません。能力・特技などの詳しい情報も開けます。
- 一覧は画面全体でスクロールします。システム出走の魔物も確認できます。

## 観察・予想

- パレードの魔物を左右にスワイプすると前後へ切り替わります。縦方向はそのまま画面スクロールになります。左右ボタンと8匹の画像付きナビも使えます。
- 調子・人気・予測勝率・倍率・疲労・能力・新聞記事・特技・評価の内訳を維持しています。記事や詳細を読む間は自動紹介が止まります。
- 「この魔物を馬券候補に」から、観察している魔物を選択に引き継げます。
- ボタン操作、通信による表示更新、タブの切り替えで画面が先頭に戻る問題を修正しました。各タブのスクロール位置と馬券の入力を保持します。新しいレース段階と発表演出の再生では先頭から表示します。

## 馬券・MAX BET

- 7種類の賭け方を維持し、順番を指定する枠・魔物カード・購入内容を整理しました。指定枠を押して魔物を選び直せます。すでに別枠にいる魔物なら位置を入れ替えます。
- 金額は直接入力、100G／1,000G／10,000G、半分、MAXから設定できます。
- **MAXは所持GOLDを金額欄へ入力するボタンです。購入ボタンを押すまではGOLDを使いません。** 購入予定・倍率・的中払戻・購入後の残高を確認してから購入できます。
- 通常の所持金では全額を指定できます。計算精度を保つ技術上の上限は9,007,199,254,732Gです。倍率の上限は従来どおり1,000倍です。
- 購入ボタンを画面下に固定しました。購入後は画像付きの馬券と、出走を待つ状態を表示します。
- GOLDが0でも購入せずに参加し、出走賞金・育成報酬を受け取れます。💎での賭けは今回導入していません。

## レース・結果

- 黒・紫・金と既存の競技場背景で統一し、自分の魔物と馬券で選んだ魔物を別の印で示します。加速・妨害などの状態も表示します。
- 「ケツを叩く！」を画面下に固定し、残り5回をダイヤ形の目盛りで表示します。連打・小分け・温存はBuild457のまま使えます。走行ルールやスタミナ消費は変更していません。
- 全員の馬券は小さく一覧表示し、押すと詳しい内容を確認できます。
- 結果は表彰台、自分の収支、育成報酬、全員の収支を整理しました。購入・払戻・賞金の内訳や全8匹の着順は開いて確認できます。
- 「もう1レース」「退出」を下に固定し、押した直後に処理中表示を出します。発表演出の再生ボタンも固定欄に隠れないようにしました。
- 切断中でも退出からホームへ戻れます。再接続したときに同じ部屋から退出します。購入・払戻の記録は保持します。

通常戦闘、育成、魔法陣、出走賞金、経験値、なつき度、連戦疲労、レース予測・走行の計算は変更していません。払戻は整数計算で大きな金額にも対応しました。

## 確認したこと

- レース関連の自動テスト70件が成功。MAXの予約・購入・返金・精算、旧部屋の100万G制限、二重受取防止、0G参加を含みます。
- 実際のWebSocketで4人接続し、購入からレース、結果、次のレース、退出まで通して確認しました。
- 55,838,554GのMAX購入、レース途中のサーバー再起動、参加者の切断・再接続後の一度だけの精算を確認しました。
- タッチによる左右スワイプ、縦スクロール、5回連打、タブごとの位置保持、金額の保持を確認しました。
- 幅320・393・709・1280pxで横にはみ出さず、購入・次レース・退出の固定ボタンへ到達できることを確認しました。
- キャッシュ対象615パスと更新モジュール9件を確認し、凍結された過去のレイド実行コードは同一のままです。

検証はChromiumのモバイル・タッチ環境です。実機iPhone Safariは未確認です。この環境には既存の魔物画像と日本語フォントが揃っていないため、それらの描画を含む最終的な見た目は実機での確認が必要です。既存画像への参照は維持しています。
