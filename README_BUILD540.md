バージョン：3.1.219。**Build539適用済みの本体へ上書きする差分ZIP**です。本体・online-serverの両方を更新してください。公開サイトへの反映は行っていません。

## 反映手順

1. 本体フォルダーと `online-server/data` をバックアップする。
2. ZIPの中身を本体フォルダーへ上書きする。`src`、`assets`、`index.html`、`online-server`、キャッシュ更新をすべて反映する。
3. online-serverを再起動する。参加者全員が本体を再読み込みし、3.1.219へ揃える。
4. 更新前から進行中のかくれんぼ・テトラポットは、ルールが変わるためロビーへ戻る。メンバーと相棒は維持され、準備OKを押し直す。

セーブファイル・所持キャラデータはZIPに含めていません。空のフォルダーでは起動できません。`docs`・`tests`・`tools` は説明・検証用です。

## ぬし釣り大騒動

- 毎秒10回の通信から、増え続ける釣果履歴などを除外。参加・再接続・結果では完全な記録を送る。

- 画面表示は最大60fps、文字やゲージなどの更新を間引く。巻いていない間の入力連打も削減。

ゲスト側の負荷につながる処理を軽減しました。実機iPhoneで報告されたカクつきそのものの再現・改善率測定は未実施です。

## ゴリラ大王の胸毛抜き

下部のネタバレ文を削除しました。隠し操作の判定と、実際に操作した後のリアクションは維持しています。

## 運だけ大運動会

- 保存先がWindows/OneDrive等に一時ロックされた場合、完成した保存データを固有名で確保し、非同期に再試行する。再起動時も最新の完全な保存データから復旧する。
- 保存先を削除してから置き換える処理は行わない。ディスク容量不足など、本当に保存できない失敗は従来どおり操作を失敗扱いにする。パス付きの生エラーは画面へ表示しない。
- 落とし穴・狙撃で前進停止した後、磁石などの後続効果で前進が復活する不具合を修正。
- 巨大倍率は意図した重ねがけだったため維持。例：R1とR8で得た倍々クリスタルはR16で 2^(15+8) = **8,388,608倍**。距離はBigIntによる正確な計算を維持。
- 太陽・貯金・倍々・余韻などの説明を短くし、重ねた際の増分や掛け算を明記。レイアウトは変更していない。

## 魔王のかくれんぼ

- 小地図の2,112マスを毎フレーム描き直す処理を、地形画像の再利用へ変更。全体状態の再受信でも同じ地形画像を再利用する。
- 静的装飾を再利用し、高密度画面の描画解像度・最大fpsを制限。
- 移動先を保持したまま、別の指で攻撃できる。攻撃範囲を145から235ワールド単位へ拡大。
- 逃げる側は開始後も下の2択から自由に変身できる。移動・スタミナをリセットしない。
- 最大3回／10秒ごとに1回補充、逃走側のスタミナ、鬼の狭い視界、仲間だけの位置共有は維持。

## 因縁の決戦！テトラポット渡り

- 画面のどこかを押し、飛びたい方向と逆へ引く。引いた長さで距離を決め、離すとジャンプ。長押し時間で距離は変わらない。
- 指を開始位置へ戻して離すとキャンセル。着地点予測を表示し、先端近くは小さな着地補助が働く。予測とサーバーは同じ計算。
- 下部の操作ボタンを撤去。390×844の確認画面では、フィールドを721px確保。
- 横1500・縦6500のコースに、約110個の足場を縦横ランダム配置。固定の安全ルートはない。途中4つの中継を順に通ってゴールへ。
- テトラポットは回転・傾斜運動をしない。低い足場は約17秒周期で水没。苔の足場は先端以外が滑る。
- 通常波は12秒ごと。水面に出た先端と中継以外は流される。低い足場は先端も水没する。
- 大波は36秒ごと。**中継だけが安全**で、先端やジャンプ中でも流される。約6.5秒前に警告。
- 他プレイヤーとの接触を判定。先客がいる着地点へのジャンプは落水し、復帰時も重ならない場所へ配置する。
- AIも同じジャンプ・着地・波のルールを使用。落水時は直前の中継から復帰し、よりの「イージー！」は継続。
- PCはSpaceを押して照準、左右キーで向き、上下キーで距離、Spaceを離して跳ぶ。Escapeでキャンセル。

新しい足場4種は画像生成で制作した透明アトラスです。既存の海面・ロビー画像を継続使用。波・軌道・水しぶきはCanvas描画で、プレイ中の画像生成通信はありません。
