# ABYSS DOMINION Build548 / v3.1.227

暴走ショッピングカートの表示と引っ張り演出を改修した差分パッチ。
Build547適用済みの本体へ、ZIP内のファイルを同じ場所に上書きして使用する。

## 適用方法

1. ゲームを準備画面へ戻す。
2. 本体のBuild547へZIPの中身を上書きし、公開先に反映する。
3. 参加者全員がゲーム画面を再読み込みする。

今回は本体のみの更新。Build547のサーバーを継続して使用する。
セーブデータやサーバー保存データは含めていない。

## 変更内容

- 床の「P P P P」、4台分の区画線、黄色い塗りつぶしを削除。木目が見える金属の縁取りへ変更した。
- 停車予測の輪、予測軌道の点線、「海まで飛ぶ！」「金枠ねらい！」「停車の目安」を削除。描画側から予測計算の呼び出しも外した。
- 海の警告文・警告テープ・床上の補助線・説明札を整理。金枠の「＋50」は残した。
- 画面中央の丸い操作部と点線を削除。カートにつながる縫い目入りベルト、革のグリップ、金属の留め具を描画する。
- 矢印はカート付近の短い表示に限定。金属の縁・プレイヤーカラーの内側・反射光を加え、方向と引き加減だけを伝える。
- 発射時の反動、車輪からの砂ぼこり、細い走行の残光を追加した。
- パワーの数値表示を外し、引き加減のメーターへ変更。数値は支援技術用のメーター属性に保持した。
- スコア欄・ラウンド表示・下部操作欄の色と装飾を揃えた。
- 横画面ではカートの表示位置を少し奥に寄せ、グリップを画面内に収めた。海側の境界位置は維持した。

引く長さ・発射方向・8.5秒の制限時間・キャンセル方法・得点・衝突・AI・通信方式はBuild547のまま。
引っ張り中の表示は止まる位置を示さない。行き先は床と力加減から自分の感覚で狙う。
新しい大容量画像や外部通信は追加していない。

## 確認範囲

- 引っ張り入力の既存テスト9件を通過。
- 実際のView / Controls / RendererとCartCoordinatorを使うローカル接続で、2つのブラウザー間の発射強度一致を確認。
- タップ・元へ戻す操作・タッチ中断・2本指・画面切り替え・回転・ラウンド変更・領域外での指離し・キーボードを確認。
- 320×690、390×844、430×932、844×390で表示を確認。横はみ出し・フッターの見切れ・タイマーの隠れはない。
- 全5コースで予測を計算せず描画できること、引っ張り中に背景を再生成しないこと、動きを減らす設定を確認。
- ブラウザー実行エラー・不足アセットは0件。
- 新モジュール・追加CSS・インポートマップ・オフラインキャッシュの参照整合を確認。

ブラウザー確認用の環境はカート専用。別ゲームのウォレットUIだけを未使用の代替モジュールとしている。
