ABYSS DOMINION REMAKE — Build 303
ダンジョン全面改善パッチ（Build 302 からの差し替え用）

適用方法
1. Build 302 のゲーム一式を用意します。
2. このZIPの中身をゲームのルートへすべて上書きします。
3. ブラウザを再読み込みします。Build 303 初回起動時に旧キャッシュは自動更新されます。

主な変更
- 各階の4〜6ダンジョン区画を平均約1.65倍へ拡大。
- 接続のない方向へ延びる空通路を廃止し、実際の接続口だけを生成。
- 価値のない区画には既存の魔晶石採取物を保証。
- 区画接続を暗闇へ溶ける通路として描画。
- 属性名を日本語化し、既存属性ロゴ・属性別ダンジョンスキンを反映。
- 通常戦・支配者戦の背景を現在区画の属性へ連動。
- ミニマップを実際のダンジョン形状・接続・現在地・発見物の表示へ刷新。
- 支配者討伐後の解放演出を専用アイコンへ統一。
- 通常宝箱にも「獲得！」演出、資源・装備の明細表示を追加。
- 通常宝箱の二重取得を防ぎ、報酬と開封状態を一度の保存で確定。

セーブ互換
- アプリ版: 3.0.3
- セーブスキーマ: 73
- 所持品・育成・階層クリア・支配者報酬などの永続データは引き継ぎます。
- ダンジョン形状変更のため、Build 302以前で途中保存された現在区画だけは安全に再生成します。
- online-server/data はこのパッチに含めません。

検証
- 4〜6区画の接続性、実ポータル、最大258マスの保存範囲を確認。
- 2,400生成階で、討伐後の次階層出口が通路を分断しないことを確認。
- 属性表示、属性スキン、戦闘背景、実形状ミニマップ、報酬演出を回帰テスト。
- Build 302の進行保存、鍵付き戦利品、カジノ終了、自動攻略も再検証。
