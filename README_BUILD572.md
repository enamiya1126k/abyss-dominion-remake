# ABYSS DOMINION Build572 / v3.1.251

運だけ大運動会の銀河の先に3種類の背景を追加しました。

| 距離 | 背景 |
| --- | --- |
| 1000億m | 事象の地平線：ブラックホールと星屑の海 |
| 1京m | 時空の外側：反転した宮殿と金の時空環 |
| 1秭m | 混沌の果て：提供された顔写真をもとにした顔の天体と崩れた宇宙 |

自分の累計距離で切り替わります。距離を失った場合は対応する背景へ戻ります。最後の背景の一覧や次の到達条件をプレイ中に予告せず、到達後に世界名と距離を表示します。到達難度は今後の実プレイで調整可能です。

新背景は3:2の比率を保ち、顔を複数の視差レイヤーで分断しません。WebP3枚、合計約1.38MB。既存の同時2ダウンロード、2画面クロスフェード、低モーション対応を利用します。既存7背景、距離計算、所持アイテム、サーバールールは変更しません。

Build571以前を含む累積パッチです。既存プロジェクトのルートへ上書きして利用してください。サーバーの保存データは含みません。Build571導入済みなら今回の背景追加によるサーバー再起動は不要。本体更新後に全員が再読み込みしてください。Build570以前からの更新はBuild571のルール変更を含むため、本体・サーバー両方の更新とサーバー再起動が必要です。
