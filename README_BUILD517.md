# ABYSS DOMINION Build517 / v3.1.196

「パーティー」のミニゲーム一覧に「ブロック落としサバイバル」を追加した。
Build516適用済みの完全なプロジェクトへ重ねる差分ZIPであり、単独では起動しない。

## 追加内容

- 1人が落とす側、3人が逃げる側。人数不足時はAIを補充する。
- 開始前に役割の希望を選択する。部屋主は希望者から抽選・全員ランダム・特定プレイヤー指定・AI指定を設定できる。
- 所持魔物の選択とパーティーの色・準備OK・再戦・一覧復帰に対応する。
- 7種類のテトロミノ。4択のうち使用した枠だけをランダム補充し、他の3枠は保持する。
- 選択、90度回転、左右位置、落下。位置はボタンのほか箱のタップ・ドラッグでも指定できる。落下後のブロックの操作はできない。
- 左下に半透明の移動スティック、右下にジャンプとダッシュを配置する。移動しながら別の指でジャンプ・ダッシュを操作できる。
- ジャンプは高さ2ブロックの段差に乗れる。空中二段ジャンプではない。他プレイヤーの頭に乗って再び跳べる。
- 頭から跳んだとき、下のプレイヤーが空中なら下向きに押す。地面では踏ん張れる。
- 落下中のブロックと床・固定ブロックに挟まれて空間がなくなると即脱落する。側面に触れただけでは脱落しない。
- 箱は横10・高さ16ブロック、制限時間150秒。誰か1人が上端へ到達すると逃げる側3人の勝利となる。
- 全員脱落または時間切れで落とす側の勝利となる。
- 落下速度は3.5から12ブロック/秒へ時間とともに上昇する。
- 着地後0.45秒の待機後、最長2.2秒で自動落下する。満杯の場所を避けて有効な形・回転・位置を探す。手持ちのすべてが置けない間も、逃げる側の移動と制限時間は進む。
- 落下予告、積み上がる足場、着地の振動と粒子、脱落の光、ダッシュの残像、合成効果音を追加した。
- ホーム滞在・切断中はAIが代行し、復帰すると本人が操作を再開する。
- PCでは左右キー/A・Dで移動、上/空白でジャンプ、Shiftでダッシュ。落とす側は上/Rで回転、空白/下で落下する。

## 適用方法

1. 現在のプロジェクトとサーバー保存データをバックアップする。
2. **Build516適用済みのプロジェクト**へZIPの内容を同じ階層で上書きする。
3. 本体を更新する。**online-server側も更新して再起動する。** 新しいサーバー処理は本体側の `src/tower/Rules517.js` と `src/party/GameColors501.js` も参照するため、従来と同じフォルダ構成を保つ。
4. 参加者全員が本体を再読み込みし、バージョン3.1.196を確認する。
5. ホーム下部「パーティー」から新作を選択する。

既存7作品の個別ルール・素材・進行は変更していない。共通パーティーと通信の接続箇所、バージョン・キャッシュ登録だけを更新した。セーブ形式のバージョンは変更していない。
