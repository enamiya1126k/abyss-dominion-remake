ABYSS DOMINION REMAKE — Release 201差し替えパッチ build263
============================================================

バージョン: 2.11.87-build263
セーブスキーマ: 62
適用元: Release 201完成版（build262）

今回の変更は、依頼された次の3件だけです。
「予言の十日間」と、100階層・複数部屋型への再設計は含みません。

1. iPhone Safari：「ボス・深淵・十神 挑戦門」の縦スクロール
------------------------------------------------------------
- モーダル内部の高さの受け渡しを修正しました。
- ボス一覧部分だけを縦スクロール可能にし、下部の「閉じる」は常に残ります。
- 階層帯フィルターは横スクロールのまま、縦スワイプを妨げません。
- iPhoneのsafe area、dvh、慣性スクロールに対応しました。

2. 4対4：勝利報酬と挑戦回数
------------------------------------------------------------
- 勝利GOLD倍率の最低値: ×0.05 → ×0.5
- 通常勝利の魔晶石: 最低10個。試練進行に合わせて増加します。
- 初回勝利: 現在階層に対応した経験値パックを配布します。
- 10試練ごとの初回突破報酬:
  魔晶石 +100個 / 捕獲結晶 +50個 / 経験値パック追加
- 初回装備確定:
  第10試練 SR / 第25試練 SSR / 第40試練 UR / 第50試練以降 LR
- 経験値パック倍率は10試練進むごとに上昇します。
- 敗北時は、その挑戦で消費した当日分の回数だけを返却します。
- 初回報酬・10試練報酬・確定装備は再受取できません。
- 日付変更、切断、再開、結果画面の再表示でも二重配布しないようにしました。
- 所持上限付近でも通貨がオーバーフローしないようにしました。

3. ガチャ：排出偏りの監査と修正
------------------------------------------------------------
- 画面表示と実抽選を同一の確率テーブルへ統一しました。
- 通常枠の実確率:
  神話 0.12% / LR 0.18% / UR 0.80% / SSR 4.00%
  SR 13.00% / R 32.00% / N 49.90%
- SR以上保証枠の実確率:
  神話 0.20% / LR 1.80% / UR 6.00% / SSR 22.00% / SR 70.00%
- 通常ガチャの同レア度内モンスターを均等抽選にしました。
- 通常装備は「武器・防具・装飾を各1/3」→「選ばれた部位内で均等抽選」です。
- 有料の常設混合は魔物50%・装備50%。1日1回無料は従来どおり魔物30%・装備70%です。
- 新着、未所持、配列順、装備カテゴリ固有の隠れた重みを通常ガチャから撤去しました。
- 宝箱限定ミミック、シリアル限定キャラ、深淵、十神などを通常排出対象外にしました。
- 同じ対象が3回連続する極端な偏りを防止しました。
- 専用装備の未所持部位優先など、仕様として残す補正は提供説明へ明記しました。

検証
------------------------------------------------------------
- build263専用回帰テスト: 10/10 合格
- 通常枠100万回 + SR以上保証枠100万回の抽選シミュレーションを実施
- 同一プール70万回の均等性検証: 最大/最小 1.0046、3連続なし
- クライアント全体: 386件中301件合格、85件失敗
  Release 201完成版も376件中291件合格、85件失敗のため、新規失敗は0件です。
- JavaScript構文検査とZIP展開一致検査を実施済みです。

適用方法
------------------------------------------------------------
1. Release 201完成版（build262）のルートへ、このZIPの中身を上書きします。
2. 配信先へ反映後、iPhone Safariを再読み込みしてください。
   古い表示が残る場合は、タブを閉じて開き直してください。
3. サーバー側ファイルの更新・再起動は不要です。
