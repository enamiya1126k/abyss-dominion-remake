# ABYSS DOMINION — Build519 / v3.1.198

Build518適用済みの完全なプロジェクトに重ねる差分ZIPです。
単独の完全版ではありません。公開先への反映・サーバー再起動は実施していません。

## 変更

### ブロック落としサバイバル：AI強化

- 逃げるAIは、約1.1秒先まで実際の移動・ジャンプ・落下判定を試算し、足場と危険を比較して操作を選ぶ。
- 高い足場への連続ジャンプ、壁際からの早めの回避、横に長いブロックからのダッシュ、仲間の頭を使った登りを改善。
- 頭を使う際は跳ぶタイミングをずらす。踏み台になる側も高い壁の近くでジャンプし、２人同時に跳ね続ける動きを減らす。
- 落とすAIは４枠・全回転・全横位置を比較。相手の位置と移動方向、逃げられる横幅、出口封鎖、相手に足場を与える危険を評価する。
- 位置を見せる短い待機を挟んで落下する。隠された人間の入力や未来の手札は参照しない。
- キャラの速度、ジャンプ力、ダッシュ性能、当たり判定、制限時間は変更していない。AIも押し潰されれば脱落する。

### 〇×サバイバル：AI弱体化

- AIごとに２〜４問に１回、正解を参照せず〇×を50％ずつ選ぶ。
- 最初のランダム回答は２〜４問目。その後も２〜４問間隔。各AIで発生問題を別々に抽選する。
- 迷った後に移動する演出も、ランダム回答を正解へ修正しない。
- 20問分の回答予定は開始時にサーバーで確定し、人間の移動に合わせて変更しない。
- 18万件の予定回答サンプル：初級79.07％、中級71.20％、上級63.50％。これは予定回答の正答率であり、実プレイの勝率ではない。
- 進行中の〇×対戦は保存済みの回答予定を継続し、新規対戦から新AIを使う。600問の問題集・抽選・難易度構成は変更していない。

### ブロック落としサバイバル：キャラ選択のスクロール

キャラ選択の再描画前に、ページ全体・ゲーム領域・親のスクロール領域・キャラ一覧内の位置を記録する。
同じ準備画面の描画直後と次のフレームで位置を復元する。別のゲーム・対戦開始後・画面を閉じた後には復元しない。

## 適用

1. 動作中のBuild518プロジェクトへZIP内のファイルを同じ場所に上書きする。
2. 公開するフロントエンドと、サーバー配置の共有ソースを両方更新する。
3. `online-server` を通常の手順で再起動する。
4. ページを再読み込みし、v3.1.198を確認する。

今回のサーバーロジックは `src/tower/Rules517.js`・`src/tower/AI519.js` と `src/quiz/Rules513.js`・`src/quiz/AI519.js` にある。
`online-server` がこれらを相対パスで読み込む構成のため、フロントエンドの公開ファイルだけ更新してもAIは変わらない。サーバーが参照するプロジェクト側の `src` も更新する。
通信の互換値と保存スキーマ84は据え置き。新画像・音声は追加していない。
