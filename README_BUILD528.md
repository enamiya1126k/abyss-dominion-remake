# Build528 — すごろく・胸毛抜き・大運動会

Build527 適用済みの本体に重ねる差分です。バージョンは 3.1.207。

## 適用方法

1. 現在の本体と online-server の状態ファイルをバックアップ。
2. ZIPを展開し、同じ階層のファイルを上書き。本体の `index.html`、`src`、オフライン用2ファイルを更新。
3. `online-server/src` も更新し、オンラインサーバーを再起動。
4. 参加者全員がゲーム画面を再読み込み。進行中の対戦を終えてから更新するのがおすすめです。

セーブ形式は変更していません。新しい3ゲームの開始には、全員のBuild528対応を確認します。サーバー更新前は案内を表示します。

## カードすごろく

- 初回だけ強制停止する神殿に赤い **初回 STOP** を追加。通過済みは緑の **通過 OK**。
- 盤面上に、次の停止地点までのマス数と「残りの移動は繰り越さない」を表示。
- 移動カード詳細にも、強欲を反映した移動量と実際の停止地点を使用ボタンの前に表示。分岐がある場合は距離の幅を表示。
- 強欲は、自分の出目・移動・追加サイコロ・出目補正・カードの増減枚数を2倍に。+10マス→20マス、サイコロ+1個→+2個。
- バランスとして **行動できる自分の2手番** で終了。後退・手札喪失・休みも2倍。サイコロは最大5個、休みは既存上限の2回。
- 💎、支払コスト、枚数を固定する効果などは対象外。カード説明に範囲を明記。
- 出目補正や分岐後の残り移動が重複して4倍になる処理を防止。特殊カードの交換・奪取でも残り手番数を保持。

## ゴリラ大王の胸毛抜き

- 乳首をつまむ操作を、怒りの表情だけでなく激怒・吹き飛ばし・敗北へ接続。
- 初期の即激怒率25%、怒り12以上で55%、24以上で80%。同じ手番の2回目はさらに+15ポイント（最大95%）。3回目は必ず激怒。
- 助かった場合も80%の確率で激おこ寸前まで怒りが上がる。弱い反応でも通常の毛抜きより大きい怒りを加算。
- 抽選はサーバーが行い、演出が終わるまで結果を公開しない。連打・再送で再抽選しない。
- 普通の毛抜きのハズレ・お慈悲抽選は従来どおり。

## 運だけ大運動会

- 準備画面で部屋主が **8 / 16ラウンド** を選択。変更すると全員の準備OKを解除し、選び直しを共有。
- 最終大技の保証・終幕のクラウン・AIの残り手数判断・進行表示・結果を選択した長さに連動。
- 同じゲームを再戦すると選んだラウンド数を引き継ぐ。既存の8ラウンド対戦も対応。
- 上のプレイヤーカード全面を押すと、直接その人の装備・現在の蓄積を表示。二重のプレイヤー選択を撤去。
- プレイヤー欄の下から画面下まで詳細画面を広げ、全装備と効果説明を縦スクロール。コイル・太陽・貯金・結界・成長倍率なども確認可能。
- 更新時のスクロール位置を保持。上の別プレイヤーを押して切り替え。閉じるボタン・Escapeで復帰。
- ゲームのタッチ制御に、装備一覧だけ指でスクロールできる設定を追加。他ゲームの既定の入力制御は従来どおり。

## 検証

- 新規20ケース、既存回帰37ケースが成功。
- 8/16ラウンドを4人・AI混在の両方で最後まで実行。
- 既存回帰では500試合、1,600アイテム組合せ、サーバー保存・復帰、二重送信、カード防御、タッチ制御も確認。
- Chromiumのスマホ幅320/375/390/430pxで実際の画面モジュールを表示し、タッチスワイプ、最後の装備、直接切替、更新時のスクロール復元を確認。
- 変更したJavaScriptの構文・読み込みバージョン・オフライン一覧を検証。
- 前回の相撲、釣り、ブロック落としの専用コード・相撲画像は変更なし。
