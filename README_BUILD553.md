# Build553 — 限界突破と王冠抽選 / v3.1.232

Build552 適用済みの本体・online-server に重ねる差分パッチです。

## 遊びの変更

- 接触で「限界突破」ゲージを充填。通常発射後、満タンなら各回１回、引き直して追い撃ち。
  発射の力は通常の1.6倍（発射バネも適用）。現在の速度に加算し、全体の上限95を守ります。
  通常発射と同じ操作で、移動中の選手から引けます。タップ・元の位置へ戻す操作では消費しません。
- 限界突破から4.2秒間、獲得点２倍。フィーバー・連鎖・壁・友情などの倍率と重なります。
  未使用ゲージ、使用後に再び溜めたゲージ、残っている強化時間は次の回へ持ち越し。
  「仕返し電池」の充電は別枠で、次の通常発射に使います。
- ３色を集めて王冠に接触すると、約0.96秒の抽選を経て×1（60%）・×3（32%）・×7（8%）。
  王冠に当たった時点の得点倍率を固定し、サーバーで一度だけ抽選・加点します。
  最終回の王冠はさらに２倍。終了直前の当選は集計前に確定し、投資の利息にも含めます。
- 抽選中も物理・入力を続行。通常当選の表示は小さく1.3秒、大当たりは1.9秒、７倍は2.5秒。
  大きな得点で順位が上がった場合は、実際の「４位 → １位」のような変化を表示。
- 新しい画像素材による限界突破の紋章・王冠、充填メーター、金色のオーラ、強弱のある効果音。
  大技だけ短い画面振動。軽減設定では振動・点滅・移動軌跡を抑えます。
- MAX通常発射の勢い41、弱め（40%）の約３倍は維持。
  通常ピンの自動加速を抑え、連鎖による加速は12連鎖まで。得点倍率は従来どおり最大２倍。
  ラウンドで表示なく床の摩擦や宝箱倍率が切り替わっていた処理を除き、同じ盤面の手触りを統一。

8／16回を通して、位置・速度・能力・宝石・壁倍率を持ち越します。
途中のラウンド結果画面やスタート位置へのリセットはありません。
未発射の相手も衝突し、押されながら引いた発射もその時点の勢いを上乗せします。
未来の軌道や着地点の予測は表示しません。ポンコツ改造GPの走行ルールは維持します。

## 適用

1. Build552 をバックアップし、ZIP の中身を同じ階層へ上書き。
2. 本体の index.html / src / assets / offline 関連と online-server の両方を更新。
3. online-server を再起動し、参加者全員が本体を再読み込み。

本体 v3.1.232、通信 `ricochetVersion550:4`、保存ルール `rules550:4`。
旧バージョンとの混在を拒否します。旧ルールで進行中の保存対戦は準備画面へ戻るため、
更新前に現在の対戦を終えてください。新ルールの追い撃ち消費・抽選開始・当選は即時保存し、
再接続やサーバーの復元で倍率の引き直しや二重加点が起きないようにしています。
公開サイトの更新・サーバー再起動はこの差分パッチの作成には含まれません。

## 確認したこと

```sh
node --test tests/build553-*.test.mjs tests/build547-cart-sling.test.mjs tests/build549-cart-physics.test.mjs
python3 tools/build553/static-check.py --baseline /path/to/build552
```

- 自動テスト84件：物理、勢いの加算、MAXすり抜け、追い撃ち条件・重複拒否、倍率抽選の境界、
  抽選結果の非公開・復元・一度だけの加点、最終利息、８／16回の連続進行、部屋・旧カートなど。
- ４つのローカルWebSocketブラウザを、実際の対象View/Input/Renderer、メイン受信処理、
  RicochetCoordinator・PartyCoordinatorに接続。タッチで移動中の追い撃ち、抽選中の再接続、
  全員の得点一致、ラウンドでcanvasが再生成されないことを確認。
- 320×690、390×664、430×932、844×390で両ゲームの選択・対戦・結果を確認。
- ８つの固定シードのAI対戦では、平均接触数は１人786.6→485.0回、平均フィーバーは12.75→8.25回。
  各AIは８回の追加発射を獲得。通常時と大技の強弱を検討するための数値で、面白さの証明ではありません。
- 掲載スクリーンショットは、１人分を自動入力＋３AIで実際に８回遊んだ記録。
  得点・位置・宝石・演出の画像用注入はしていません。７倍が必ず出るような処理もありません。

部分構成の作業環境のため、対象外の依存はテスト用アダプターです。
アプリ全体・実機iPhone/Safari・公開ネットワークは未検証。
詳しい結果は docs/build553、検証スクリプトは tools/build553 に収録しています。
