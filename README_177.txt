ABYSS DOMINION REMAKE release177 / build236

これは release176 に上書きする「差し替え部分だけ」の更新です。
ゲーム全体は含まれていません。

主な更新:
- ギルドで将来の共闘日時を共有する「遠征予定」
- 目的、遊び方、1F〜10000F、48文字メモを設定
- 「参加予定」「未定」の表明と取消
- ギルド全体で最大8件、作成者1人につき最大2件
- サーバー時刻の10分後〜14日後まで作成可能
- 開催から2時間後の自動整理
- guilds.jsonへの保存と再起動後の復元
- 旧guilds.json version 1・2からversion 3への自動移行
- ギルド外への予定・参加者情報の非公開
- 切断・再接続時の交流パネル操作可否と再描画を修正
- 週間ポイント上限後の成立活動もpoints=0で記録し、再送時の重複を防止

適用方法:
1. 更新前の `online-server/data/guilds.json` を別の場所へバックアップします。
2. ZIPを展開し、中の `abyss-dominion-remake-main` フォルダを開きます。
3. その「中身」を、release176適用済みの `abyss-dominion-remake-main` フォルダへ同じ階層で上書きします。
4. `online-server/data` フォルダと既存のJSON保存ファイルは削除しません。
5. オンラインサーバーを再起動します。
6. ブラウザを再読み込みします。

注意:
- ZIP内の階層を崩さずに上書きしてください。
- 差分ZIPには画像・音声などのゲーム素材、`online-server/node_modules`、実際の`online-server/data/*.json`は含まれていません。
- 遠征予定は日時を共有する予定表です。予定時刻の自動部屋作成・自動入室は行いません。
- 実際に遊ぶときは従来のオンライン部屋とギルド共闘募集を利用してください。
- 遠征予定と参加表明は所属ギルドのメンバー全員に公開されます。
- 予定の作成・表明・取消から、アイテム、GOLD、魔晶石、週間共闘Ptなどの報酬は発生しません。
- 通常探索、所持品、通常セーブ、セーブスキーマ58は変更しません。
- build236の起動後、`guilds.json`はversion 3になります。release176へ戻す場合は、適用前にバックアップしたversion 2の`guilds.json`も一緒に戻してください。version 3の保存データ自体はZIPに含まれていません。

詳しい仕様は BUILD236_GUILD_PLANS_UPDATE.md を確認してください。
