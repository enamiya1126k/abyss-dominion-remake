# Build374 / v3.1.54 — 階層ボスの背景のぼかし除去

Build373適用済みのフォルダーへ上書き・Web配信後、ゲームを再読み込みしてください。サーバー再起動は不要です。

階層ボスのside-unit-sprite全体（名前札・画像・魔法陣を含む）に適用されていた白色13px／紫色22px等のdrop-shadowを取り除きました。旧スタイル側に残っていた同じボス用の発光指定も除去しています。
階層ボスと名前札の周囲に広がるぼかしがなくなります。戦闘ロジック・能力・キャラ素材・背景画像は変更していません。MISS文字など独立した戦闘通知の演出は今回の対象外です。
通常戦闘・オンライン共闘で共通の階層ボス用CSSに適用します。

確認：階層ボスに適用される2箇所の広域drop-shadow削除、CSS参照の更新、差分内のJavaScript構文チェック。iPhone実機での見た目は未確認です。CSSだけの変更のため戦闘テストの追加は行っていません。
