# Build420 / v3.1.99 — ①〜③ 統合版

① 第一章の進行不具合、② 探索・編成画面、③ 戦闘表示・補正確認をまとめた差し替えZIPです。

## 上書きする元

**Build416（v3.1.95）〜Build419（v3.1.98）のいずれにも、このZIPを1回上書きします。** ①〜③のZIPを順番に入れる必要はありません。既に③まで適用済みの場合も、そのまま上書きできます。

これはゲーム全体の新規インストール用ではなく、既存ゲームへ適用する統合差分です。画像・音楽など既存のassetsはそのまま必要です。

## 適用方法

1. 現在のゲームフォルダーをコピーしてバックアップします。
2. ZIPを展開し、中身をゲームの `index.html` がある場所へ同じフォルダー構成で上書きします。既存フォルダーを削除せず、同名ファイルを置き換えます。
3. 更新後にページを再読み込みし、ホームに **v3.1.99** が表示されることを確認します。

セーブの初期化は不要です。保存キー・セーブ形式（schema 84）は変更していません。オンラインサーバーの差し替えは含みません。
