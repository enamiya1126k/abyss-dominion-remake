## 今回の改善

### コマの足元

マスの中心から5px上を足元の基準にしました。キャラが円に少し重なり、立っているマスを追いやすくなります。
通常表示・全員表示・移動中で同じ計算を使います。名前は頭上へ移し、足元とマスのアイコンを覆いにくくしました。同じマスの複数人は横にずらします。

### 専用山札 → 表面 → 覚醒

特殊カードを山札から獲得する時は、専用の金・青白・深緑の山札から1枚が出て、表になり、続けてそのカードを中心に覚醒します。
山札から表面まで3.4秒、覚醒2.2秒。覚醒後に装備欄へ反映します。
すでに特殊カードを持っている時も候補を先に見せ、その後で残す1枚を選びます。元のカードを残した場合は、獲得していない能力の覚醒演出を出しません。交換・奪取では、山札から引いたような演出を加えません。

### 全員の特殊カードを常設

画面上部の各プレイヤー欄に、絵柄・能力名・短い効果を持つ小さなカードを常設しました。
手札を閉じている時も見えます。タップするとその人の能力の全文を確認できます。未所持なら「未覚醒・神殿で獲得」を表示します。
自分の手動能力が使える時は詳細からも使用できます。手番1回の使用制限を引き続き適用します。
強欲の短い説明には「強制破棄も2倍」、限界社畜には「4〜6は1に」も表示します。

### 上面で読むサイコロ

確定した出目が立方体の上面になるよう変更。カメラも上から見下ろす角度にしました。
上面にわずかな光を添え、合計と計算式も表示。待機・回転・停止まで既存の金縁・象牙色の素材を共通使用します。

### ドローの読み取りやすさ

人が引くカードは1枚あたり3.4秒に延長。表になってから手元へ移るまで約2.2秒、効果を確認できます。
カードの横に役割のアイコン、短い効果、使用タイミング、「詳しく読む」を表示します。アイコンだけに依存せず、文字も併記します。
AIの非公開ドローは1.65秒。相手のカードは飛んでいる間も裏面を維持し、名前・画像・効果を公開しません。
自分の獲得後、手札欄の「直近の獲得」から最大8枚を読み返せます。この画面を開いてからの記録で、手札から離れたカードも含みます。対戦終了後やページ再読み込みをまたぐ永続履歴ではありません。

先着ゴール・1手番1枚・防御別枠・写真カード・4枚完成シリーズのルールはBuild469のままです。
