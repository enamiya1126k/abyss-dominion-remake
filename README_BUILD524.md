# ABYSS Build524 / v3.1.203

**Build523適用済みのプロジェクトへ重ねる差分ZIPです。単独の完全版ではありません。**

ホーム下部「パーティー」の一覧に、新作「ぬし釣り大騒動」を追加しました。

## 遊び方

- ４人で釣果の合計得点を競います。１〜４人で参加、空席はAI。所持キャラの見た目を使い、持ち込みレベルによる能力差はありません。
- 水面の魚影の近くをタップして投げます。「近くへ投げる」ボタンからも投げられます。大きい影ほど大物です。
- 掛かったら「巻く」を長押し。離すと糸を緩めます。「緩める」を押している間は、巻く操作より優先して休みます。
- 魚が暴れる前には予兆。糸が限界になると切れ、長く逃がし続けても逃げられます。疲れたタイミングは取り込みのチャンス。
- 釣るたびに竿の経験が増え、２匹ごとにレベルアップ（最大Lv.6）。強化は巻く力と糸の耐えやすさに反映されます。
- 釣った魚を「得点として確保」か「エサにする」か選びます。５秒選ばなければ得点へ自動確保。ぬしは自動で得点になります。
- エサは最大３個。次の投げ入れで１個使うと、大物が掛かりやすくなり、取り込みも楽になります。「使う／温存」を切り替えできます。満タン時に魚を無駄にエサへ変えることはできません。
- 90秒経過でぬしの魚影が出現。120秒で新しい投げ入れを終了し、すでに掛かっている魚は最大10秒の取り込み時間が残ります。
- 合計得点が最も高い人の勝利。同点は同率。最後は各人の最大の確保魚と、勝者の大物を約5.2秒お披露目して結果へ。
- 切断／ホーム滞在中はAIが引き継ぎ、戻ると操作を再開。途中で部屋に入った人は観戦し、次の対戦から参加します。
- キーボードはスペースで巻く、Shiftで緩める。投げ入れは水面またはボタンを選択します。

魚・エサ・竿レベル・得点は対戦内だけのものです。本体の通貨・所持品は増減させません。

## 見た目と操作

池・表紙・５種類の魚に生成素材を使用。背景は描画サイズに合わせてキャッシュし、水面のきらめき、魚影、浮き、しなる竿、糸、魚のジャンプ・飛沫は動かして表示します。キャラは実際の所持キャラを桟橋に配置し、魚の力で引っ張られたり、巻いて踏ん張ったりします。

操作ボタンは大きな四角形。二本指で巻く／緩める、キャンセルや画面離脱時の解除に対応。ネイティブの長押し選択・コピー・ドラッグを操作領域内で抑止。キャラ選択でスクロール位置を保持し、釣り中はメーター出現によって画面の高さが変わらないようにしています。

## 適用手順

1. Build523まで適用済みの完全なプロジェクトに、ZIP内のファイルを同じパスで上書きします。
2. **online-server側も更新します。** server.js、online-server/srcと、その相対パスから参照される共有src/fishing/Rules524.js等を同じ構成で配置してください。
3. online-serverを再起動し、本体を公開先へ反映します。
4. 参加者全員が再読み込みし、v3.1.203で「パーティー」から「ぬし釣り大騒動」を選びます。

釣りの通信仕様はfishingVersion524:1。旧サーバーでは案内付きで開始を止めます。相撲の仕様1、タワーの仕様4は維持。
