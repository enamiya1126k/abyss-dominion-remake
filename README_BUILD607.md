# ABYSS DOMINION Build607

Build606へ重ねる差分更新。アプリ3.1.286、魔界ランナーズ通信ルール17。

## 変更

- 光の輪を画像生成した金・エメラルドの専用素材へ変更した。次に通る輪を明るくし、順番を表示する。元画像の透明部分を保ち、ゲーム用WebPを追加した。生成ツールとプロンプトはassets/runners607/SOURCES.jsonに記録する。
- 炎棒の根元を幅28の片側足場にした。上から着地でき、乗っている間はその炎棒からダメージを受けない。炎の先端、空中の接触、別の罠は危険なままである。
- 属性アイテムは6種類を100msごとに切り替える。表示と取得は共通のゲーム内時刻に従う。取得時の属性を装備する。
- 死亡時は属性・火の連射予約を解除し、アイテムを拾い直せるようにした。盾の防御や凍結解除だけでは属性を失わない。
- 無属性の攻撃は前方のごく近距離だけを殴る。連続入力の間隔は350ms。弾は飛ばない。敵・箱・敵弾・的に既存の攻撃判定を適用し、凍った仲間も救助できる。ボタンは属性マークを消し、中央に「殴る」「近距離」を表示する。
- 11コースの星ギミックに4段の上空ルートを追加した。幅48の足場、切り返し、移動・崩落を組み合わせ、報酬を起点から318上へ移動した。通常ルートとチェックポイントは維持する。森林・海岸・氷・城の低い寄り道の星も3段の高所ルートへ変更した。
- 時間制限の星は起動時に足場と星が現れる。単独の猶予は3.2秒。仲間が起点を踏み続けると維持できる。取得後は開いたままとなる。
- 射的は6秒、番兵は6.5秒以内に異なる高さの3か所を攻略する。失敗時は再挑戦できる。上空に追加の属性アイテムを配置した。旧来の2人スイッチがある森林・リレーは2人で解除する仕様を維持した。

## 更新手順

1. Build606にZIPの中身を同じ構成で上書きし、新規ファイルを追加する。
2. 本体とonline-serverを両方更新し、サーバーを再起動する。
3. 全員が再読み込みする。旧版の進行中の魔界ランナーズは準備画面へ戻る。

公開サイトへの反映は行っていない。セーブのキー・スキーマは変更していない。

11コースの上空ルートおよび4つの低所スターの代替ルートを通常ジャンプの物理で検証した。時間制限ルートの最短の自動操作は約2.5秒であり、制限3.2秒以内であった。この値は最適操作によるもので、実プレイの難易度を保証するものではない。協力維持と目標のタイムアウトも確認した。
