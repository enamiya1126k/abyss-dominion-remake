# Build568 — エアホッケーの自陣を下へ統一・操作調整

本体 v3.1.247。Build563〜567に適用できる累積パッチである。お宝クレーンとキャベツの縦スライド操作を含む。

## 変更内容

- サファイア・ルビーのどちらでも、本人の画面では自チームの2人と自ゴールが下、相手ゴールが上に表示される。ルビー視点では盤面座標を180度回転する。名前・得点・説明は正立させ、キャラクター色とチーム色を維持する。
- タッチ、マウス、キーボード、発射矢印を同じ視点へ合わせる。下へ引けば上へ発射し、左右も画面どおりに動く。通信・得点・衝突は共通の世界座標を使う。
- 引いて狙っている間はキャラが減速する。前の速度を次の発射へ引き継ぐ割合を100%から25%へ下げ、狙いとのズレを小さくする。矢印には残った速度も反映する。
- 弱い引きで小さく動けるよう調整する。最大の発射力35、再発射間隔1.25秒、最高速度46は維持する。指の10px以内の動きでは発射しない。
- キャラの壁・中央線での反発係数を0.90から0.12へ下げ、自陣へ勢いよく跳ね戻る動きを抑える。パックの反発係数0.90は維持する。
- AIがパックの反対側へ戻る際、正面から押し込まず横へ回り込む。AIにも同じ発射・減速・反発ルールを適用する。

味方パスごとの弾速＋5%・上限なし、通常／2倍速、プロペラ、90秒／150秒、ゴール後2秒、ラスト15秒2点を維持する。自ゴールを越えたパックは引き続き相手の得点になる。

## 検証

- 86テスト成功、失敗0。視点変換、入力・連番、狙い中の減速、壁反射、AIの回り込み、メニューの更新判定、4本の実WebSocket接続、クレーン・キャベツ・カート等の回帰を確認した。
- Chromiumで4席×3画面サイズの12条件を確認した。両チームのネイティブタッチ、上下左右キー、キャンセル・微小ドラッグ・2本指・切断・結果画面を確認した。
- 同じ12シードのAI試合を各ルール設定で旧版と比較した。通常速度・プロペラなしでは、オウンゴールが28/56得点（50.0%）から12/32得点（37.5%）となった。対人の改善率を示すものではない。
- iPhone/Safari実機は未確認である。

## 更新手順

ZIPの階層を保って既存プロジェクトへ上書きし、**本体とオンラインサーバーを一緒に更新して、サーバーを再起動する。** 参加者全員が再読み込みし、v3.1.247を確認する。

ホッケーの通信ルールは `ricochetVersion550:10` である。旧版と混在した開始は拒否する。旧ルールのホッケールームは準備画面へ戻る。セーブ・アカウントの初期化は不要である。更新ZIPに `online-server/data/` は含めない。
