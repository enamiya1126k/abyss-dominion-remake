## 適用

1. このZIPを展開し、元プロジェクトの同じ相対パスへ上書きする。フォルダ構成を保持する。
2. 本体側の `index.html`、`src/`、`assets/sumo527/`、`world-raid-offline527-sw.js`、`world-raid-offline527-assets.json` を反映する。
3. `online-server/src/` の３ファイルも反映し、サーバーを再起動する。サーバーから参照するプロジェクト直下の `src/sumo/Rules523.js` も必ず同時に更新する。
4. 全員がゲーム画面を再読み込みする。表示バージョンは v3.1.206 となる。

本体だけの更新では新ルールを開始できない。対戦が終わってから更新する。旧対戦が保存されていた場合には、開始時刻・進行段階・位置の割合・成長値を一度だけ移行する。RPGのセーブ形式は変更しない。

## 操作・変更

- 地面をタップすると、その位置まで移動する。押したまま指を動かすと移動先を変更する。
- 下中央のボタンを長押しし、離すと体当たりする。別の指で地面を触れば溜めながら狙いを変えられる。矢印の先が突進距離の目安となる。
- PCでは方向キー／WASDで移動、スペースで溜め・離して体当たりを行う。
- 中断・画面非表示・指のキャンセル時は誤って突進しない。２本指操作中のブラウザ拡大も抑制する。
- 最大150秒。40／75／105／130秒に外周が崩壊する。最後の１人になれば即決着する。時間切れは中央に近い人の勝ち、全員同時場外は引き分けとなる。
- ６秒前から落下する床に発光する亀裂・振動する小石・内向きの目印を表示する。危険予告に文字を使わない。中央の模様は縮小せず、外側の石板だけが分離して落下する。
- 磁石の魔道具は初回14秒、その後約22〜28秒間隔で出現を試みる。場に１個まで、16秒で消滅する。取得すると８秒間、半径3.3の結晶を吸引する。再取得は残り時間を８秒に更新する。
- 成長上限は結晶48相当／Lv.13。体格は最大1.5倍となり、押す力・重さ・オーラも成長する。上限後も拾った結晶数は結果に記録する。
- 相手の攻撃で場外へ押し出された際、１試合に１度だけ縁で踏ん張る。歩いて自分から落ちた場合や、床が崩れた瞬間には発動しない。
- 深淵の専用背景・石床、金属調の中央ボタン、コンパクトな上部表示を追加する。自分を緩く追尾し、崩壊前後は全体が見えるように引く。画面外の相手は色付きマーカーで示す。
- 強い衝突時のみ短いヒットストップ・画面揺れを表示する。残像・砂煙・成長・吸引・踏ん張りの演出を追加する。
