ABYSS DOMINION REMAKE - Release 201
Version: 2.11.86 / build262

今回の内容
- 全魔物図鑑を追加（全353種）
- 通常魔物240体・限定魔物6体・階層ボス90体・深淵7体・十神10体を収録
- 本体を獲得した魔物だけ、名前・姿・入手方法を開示
- 一度獲得した本体は、合成・交換・解放後も図鑑の獲得記録を維持
- 図鑑10種達成ごとに豪華報酬を「お知らせ」へ配布
- 50種ごとの大口報酬で神話装備・深淵の鍵などを追加
- 探索・戦闘・捕獲・収集・ボス・契約・オンライン・育成の実績35種を追加
- 旧セーブの到達階層・討伐・捕獲・装備・オンライン記録から実績を遡及判定
- お知らせに達成報酬・ランキング報酬の受取箱と一括受取を追加
- 未受取プレゼントは件数上限で削除せず、受取済み履歴だけを整理
- 全体戦力ランキングを毎週月曜0:00（JST）に確定し、TOP 100へ週間報酬を配布
- ランキング報酬はサーバー保存・再送・受取ACKに対応し、切断中も消失せず二重受取を防止
- ランキングのアイコンはスロット1の魔物を維持し、タップで公開パーティーを確認可能

適用方法
1. Release 200 のフォルダへ、このZIPの内容を上書きしてください。
2. オンラインサーバーを再起動してください。
3. ブラウザを再読み込みしてください。build262への更新時に旧キャッシュは自動破棄されます。

補足
- 保存データ互換を維持し、既に所持している魔物も図鑑進捗へ反映します。
- 既達成の図鑑報酬・実績報酬は初回起動時にまとめてお知らせへ届きます。
- 週間報酬の対象は、対象週に戦力情報を送信したプレイヤーです。
