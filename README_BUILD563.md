# ABYSS DOMINION Build563 / v3.1.242

４つのミニゲームを、目的と操作がプレイ画面から分かる形に改修しました。４つともゲーム一覧に残しています。

**Build560・561・562へ上書きする累積差分ZIPです。本体とオンラインサーバーを更新し、サーバーを再起動してください。** Build561の音声復旧とBuild562の「運だけ大運動会」のアイテム修正を含みます。

## 何が変わったか

### 人間ピンボール大運動会

「宝石を自分の色のゴールへ入れる」争奪戦に作り直しました。引いて離すと発射、1.25秒で再発射できます。動いている勢いに発射の力が加わり、発射前の相手にも当たります。

得点は最後に触った人ではなく、入ったゴールの持ち主に１点。自分の色と番号をゴールにも表示し、最後の15秒は２点になります。宝石を横取りしたり、相手を押してシュートを邪魔したりできます。90秒／150秒の連続試合で、得点後もプレイヤーの位置はそのままです。

中央の棒は衝突の力で回転し、その回転速度も跳ね返りに反映します。画面幅を使う盤面、光る宝石、ゴール、軌跡、得点演出を再構成しました。装備選択・３色収集・ジャックポットは新ルールでは使いません。

### 魔王城の爆弾リレー！

「爆弾が来たら、渡す相手をタップ」に操作を一本化しました。自分が手前、相手３人が周囲に並び、現在の持ち主と残り時間が見えます。

渡しても導火線は戻りません。受け取ってから0.65秒は渡せず、受け渡しには0.16秒かかります。０秒で持っていた人が脱落、生き残った人に１点。３人が脱落すると次の回へ進み、全３回の合計点で勝負します。連打、古い爆弾への入力、他人の爆弾を操作する要求をサーバー側でも防いでいます。

### テトラポット渡り

光る足場をタップすると、その足場へジャンプします。今までの引っ張り操作も残し、距離を自分で調整できます。足場の表示と着地点計算は同じルールを使用します。

最初の海域は安定した広めの足場にし、先端への着地を補助。落ちたら直前の安全な足場へすぐ戻ります（水没・混雑時は中継地点）。ジャンプの着地判定より先に波で失敗扱いになる問題と、AIが中継手前で進めなくなる問題も修正しました。次の旗への方向と失敗理由を表示します。

### 魔王のかくれんぼ

逃げる側の画面は「封印３つ→出口」に整理し、「封印へ」「出口へ」で移動と道案内を始められます。別の封印・出口も選択可能です。変身などの追加操作は必要なときに開けます。

鬼は怪しい家具をタップすると、近づいて１回調査します。距離・視界・調査の残数はサーバーが確認し、対象が見えなくなった場合や別の移動指示を出した場合は予約を取り消します。見えていない逃走者を自動追跡する機能にはしていません。

勝敗は５つの封印から３つを解除し、東西どちらかの門から１人脱出すれば逃走チームの勝ち。180秒で脱出できない、または３人全員捕まると鬼の勝ちです。

## 更新手順

1. 既存のBuild560・561・562のプロジェクトに、ZIPの階層を保って上書きします。
2. **オンラインサーバーにも同じ更新済みソースを反映し、再起動します。** `online-server/src` と、そのサーバーが参照するルート側の `src` の両方が必要です。
3. 本体を通常の方法で公開し、参加者全員が再読み込みして **v3.1.242** を確認します。
4. 対象ゲームを選び直し、準備完了にして開始します。旧ルールで進行中の対象４ゲームは待機室に戻ります。旧版クライアントとの混在開始は防止します。

セーブやサーバー保存データを削除する必要はありません。ZIPにはアカウント、サーバー保存データ、秘密情報を含めていません。公開サイトへの反映はこのZIPを適用してからです。

暴走ショッピングカート・ゴリラ・運だけ大運動会のゲーム本体はBuild562から変更していません。以前削除したポンコツ改造GPは復活させていません。
