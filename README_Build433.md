# ABYSS DOMINION — Build433 / v3.1.112

共闘レイドのBuild432までの更新と、第二章「十神の母」の今回の修正をまとめた、上書き用の統合ZIPです。

## 上書き手順

1. ゲームのセーブと、オンラインサーバーの既存 `data/` をバックアップします。起動中のサーバーは停止します。
2. ZIPを解凍し、中身をすべて、**`index.html` がある既存ゲームのフォルダーへ上書き**します。既存フォルダーを丸ごと削除しないでください。
3. いつものGitHub Desktopで変更をコミットしてPushし、公開先を更新します。
4. サーバーを別の場所で動かしている場合は、同梱 `online-server/` と、その隣の `src/` も同じ更新内容にそろえ、いつもの設定で再起動します。追加パッケージは不要です。
5. ゲームを再読み込みし、**v3.1.112** を確認します。

**既存の `data/`、環境設定、セーブを保持してください。** このZIPには利用者の保存データや環境設定を含めていません。ルートの `world-raid-offline433-sw.js` と `world-raid-offline433-assets.json` もまとめて上書きします。

Build424以降へ適用できる累積更新版です。過去の更新を順番に入れ直す必要はありません。元のゲーム一式・既存画像は必要です。今回の作業では公開先の更新は行っていません。

## 今回の修正

- 母の円盤を、透過画像の余白ではなく実際の体の中心へ配置。回転中も中心を移動させず、敵側の表示範囲に収めます。
- 母の表示枠を固定し、子分が増えても極端に縮まないよう調整。HP・HP障壁の文字も枠内に表示します。
- 戦闘下部の長い母専用説明を削除。既存の戦闘・ステータス表示を使用し、短い画面では縦にスクロールできます。
- 召喚は、被ダメージ後の母のHPが**50%未満**の時に発生。50%ちょうどでは発生せず、50%以上まで回復した間は停止します。
- 召喚候補を固定8種から**332候補**へ拡張。ノーマル〜神話の既存魔物と、深淵・十神それぞれの本来のキャラを候補単位で等確率に抽選します。母自身とSECRET枠は除外します。
- 円盤は回転・減速・数字の停止を順に見せ、選ばれた数字を強調。その後、通常のスキル演出で実際の技名と「十神Ⅳ 死より発動」などの出所を表示します。
- 聖胎では母の**体・名前をタップして挑戦／再戦**できます。クリア後の歩行による接触にも対応。ドラッグ・ピンチ操作は挑戦と区別します。
- 母の確認画面は既存の黒金の枠で「挑戦する／再戦する」「やめる」に整理。祭壇は第二章の結末の回想へつながります。
- 再戦勝利後は母のいる聖胎へ戻り、初回報酬を再取得したり、結末を毎回強制表示したりしません。

母のふんばり・復活、召喚数上限、次ラウンドからの子分の行動、召喚敵の捕獲不可・ドロップなし、既存の初回報酬保護を維持しています。円盤の技・威力・ラウンドごとの順序も既存設定を使用します。戦闘再開時に召喚敵や装備を再抽選しません。

## 同梱する共闘レイド更新

Build432の既存素材を使うレイド画面、ボス残HP・ランキング・残り回数・交換所への導線、探索と共通の戦闘・活躍表・報酬、スクロール対応を含みます。敵は対応するボスとLv100の子分2体、専用魔法陣はレイドボスだけに適用する構成です。
