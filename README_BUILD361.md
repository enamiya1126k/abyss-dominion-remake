## 王室への移動
100階の扉から王室へ移った直後に、旧ダンジョンの描画が出口を参照していた問題を修正しました。移動前の描画ループを継続しません。出口のないフィールドへの参照も保護しています。

## 勇者と最終決戦
勇者4人の基礎特性として「勇者のふんばり」を追加しました。各人、1戦につき1回だけ致死ダメージをHP1で耐えます。スキル・魔法陣の枠は使いません。単独戦、最終戦、リベンジ、味方としての勇者にも適用します。
回復・蘇生・再読み込みで使用回数は復活しません。連撃の次の一撃では倒れます。致死耐久の魔法陣とは重複せず、別の蘇生効果は従来の条件に従います。道中で撃退済みの勇者を最終戦へ復活させるものではありません。
最終決戦では、残る勇者の人数に応じてHPを調整しました。道中の負傷割合・撃退成果は維持し、プレイヤーの現在能力に合わせた隠れた自動調整は行いません。
最終戦のHP係数：1人3.5倍、2人3倍、3人2.4倍、4人2倍。攻撃・魔法攻撃は1.1倍、速度は据え置きです（Build360の専用装備適用後の値を基準）。
決着後の会話、勝利の音、四体を並べたクリア表示と余韻を追加しました。

## クリア後の勇者リベンジ
玉座へ戻ると、全快した勇者4人の「決戦の記憶」に何度でも挑めます。王室にも4人の姿を表示します。
勝つたびに次の段階へ進み、敗北・撤退では同じ段階に再挑戦します。本編の結末・勇者の傷の記録は変更しません。今周回の撃破数と歴代最高を表示します。
第1次を基準に、次の段階ごとにHP×1.18、攻撃・魔法攻撃×1.08、防御・魔法防御×1.06。速度は固定です。段階自体にゲーム上の終点は設けず、計算値には数値破綻を防ぐ上限があります。
勝利すると出撃した各員に120,000EXPから始まる経験値を付与し、段階ごとに×1.15となります。勝敗を問わず戦闘消耗品とGOLDは挑戦開始時へ戻り、獲得経験値は残ります。撤退も物資を返却します。結果は保存と一体で処理し、同じ決着による二重取得を防ぎます。

## 輪廻転生
実行直前の確認画面で、リセット内容、保持内容、現在GOLD→転生後GOLDを明示します。「キャンセル」や閉じる操作では転生しません。「この内容で輪廻転生する」を押し、保存に成功したときだけ確定します。

| 項目 | 転生後 |
| --- | --- |
| 所持する全ての仲間 | 個体とレアリティを保持。Lv1・経験値0へ |
| 限界突破・なつき度・習得スキル | 保持 |
| 装備・魔法陣・強化成果 | 保持。下記の能力制限を適用 |
| GOLD | 10,000G |
| 💎・捕獲石・鍵・消耗品 | 保持 |
| 今周回の階層・物語・勇者の状態 | 1階から |
| リベンジ段階 | 第1次から。歴代最高は保持 |
| 図鑑・称号・結末・歴代最高階層 | 保持 |
| シリアルコード・初回限定報酬の受領履歴 | 保持。重複取得不可 |

装備の数値能力は「今周回の最高到達階層÷100」を有効率とします。1階で1%、50階で50%、100階で100%です。元の装備レベル・強化値を消す処理ではありません。装備画面に有効値と本来の値を表示します。装備から得る数値ボーナスも制限し、習得済み技などの内容は保持します。
魔法陣は今周回の到達階層に応じて有効レベル上限をLv1〜99で解放します。元の投資レベルは保持し、装備画面で本来のレベルと区別します。
今周回と歴代最高階層を分離し、物語は今周回の進行に従います。既得戦利品の履歴が、今周回のボス撃破や最終戦解放に誤変換される問題も修正しました。
すでに旧版で輪廻済みのデータへ、レベルとGOLDのリセットを後付けでは行いません。新しいリセット内容は、次に確認画面で転生を確定した時から適用します。物語判定・装備の有効能力制限は更新後から適用します。
