## 更新方法

1. Build510のプロジェクト直下へ、ZIP内のファイルを同じ構成で上書きしてください。
2. **本体とオンラインサーバーの両方**を更新してください。サーバーが参照する共通の `src/` も含みます。
3. オンラインサーバーを再起動し、参加者全員が画面を再読み込みしてください。新しいレースは全員がBuild511対応後に開始できます。

進行中の旧バージョンのレースは旧ルールのまま続行します。次に作成するレースから新ルールです。このZIPは差分であり、単体では起動しません。
