## 今回の修正

- 空中で左右を切り替えたとき、向きだけでカメラの基準点を大きく変えないようにしました。描画側が次の物理ステップの着地判定を先取りする処理も修正しました。
- リスポーンの前後で入力履歴と位置補正を区切りました。死亡前のジャンプを復活後に再生せず、カメラは復活後の最初の描画からチェックポイントへ戻ります。
- 上下に動く足場に乗っているとき、足場と一緒に移動した後の位置で着地判定を行います。接地と空中を細かく行き来する状態を防ぎます。
- 木箱は全属性で１個ずつ破壊できます。火は２発（土は１発）、風・氷・雷・水は４発。火は１タップの３連弾で破壊できます。高速の弾や絵の端がかする場合も判定します。針山を弾が貫通する仕様は維持しています。
- 属性アイテムは通常ルートに各コース６個。通常アイテム同士は600ワールド単位以上離しています。遺跡・水晶洞の隠し部屋にだけ１個ずつ追加し、最大７個です。取得済みの属性はミスしても保持します。
- 崩落足場は1.1秒揺れた後、2.6秒かけてゆっくり落下します。落下中も乗れて、そこからジャンプできます。発動から6.2秒で復帰します。
