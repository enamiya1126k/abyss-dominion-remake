Build377 / v3.1.57 — 第二章の導入・会話・探索画面を第一章と統一

【適用方法】
Build376（v3.1.56）のゲームフォルダーに、このZIPの中身を上書きしてください。
index.html と src フォルダーを既存の同じ位置に重ねて、GitHub Pagesへ配信します。
配信後にゲームを再読み込みし、v3.1.57の表示を確認してください。
セーブの初期化とオンラインサーバーの更新・再起動は不要です。
このZIPは差分です。単独でゲーム全体を起動するものではありません。

【第二章への流れ】
100階の記録と勇者一行への勝利の両方があるプレイヤーが対象です。
序章が未読なら、ホームで中央の「〜 第二章 〜」を表示し、そのまま会話へ進みます。
会話は第一章の舞台・吹き出しを利用。リオネル、サイラーン、勇者一行の6人が並びます。
最後まで読むとホームへ戻り、下部の「ダンジョン」が光り、「新たな行き先」を案内します。
行き先は「1〜100階層 → 魔王城王室 → 第二章・境界の森」の順に表示します。
旧版のホーム右上の「第二章へ」と、別形式の第二章ハブは、この導線へ統合しました。
すでに序章を読み終えている人は既読記録を引き継ぎます。行き先画面から読み返せます。

【森の探索】
第一章の探索画面、移動・カメラ操作、ミニマップ、通路演出、キャラクター描画を共用。
既存の森林テクスチャを使い、水辺は青緑、奥地は暗い紫を加えた背景にしています。
6区画の形状は第一章の地形生成を使い、小径・分岐・水辺・封印樹・最深部ごとに変化します。
画面上部に現在の目的、現在区画、発見した区画数を表示します。
初回入場時に遊び方を表示。目的表示をタップするといつでも読み直せます。
ミニマップか「マップ」を押すと全体図と凡例が開きます。
訪問済みの場所と隣の未探索区画を表示し、場所を選ぶとその方向の入口へ歩きます。
東西の封印樹の守護者を倒す（0/2 → 1/2 → 2/2）→ 東の封印樹から北へ → 最深部ボス。
封印を解くたびに次の目的が更新されます。自動移動も封印・ボスを順番に目指します。
地面をタップで移動、ドラッグで視点移動、2本指で拡大。PCの矢印キーも対応します。

【引き継ぎと変更範囲】
第一章の未クリア時のホーム、1〜100階、勇者戦のバランスは維持しています。
既存の仲間、装備、Lv、所持品、第一章の進行記録を引き継ぎます。
第二章の既読、討伐、封印、宝箱、踏破数、途中の戦闘も引き継ぎます。
地形変更のため、旧版で探索中だった部隊の位置は同じ区画内の新しい開始位置に移します。
戦闘報酬・初回踏破ボーナス・敵編成・6区画の内容はBuild376と同じです。
新しいエリア、第二章のレイド、勇者の恒常加入は今回追加していません。
「境界の森を最初から再探索」では、その回の敵・宝箱・封印だけを再配置します。
