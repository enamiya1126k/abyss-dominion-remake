# ABYSS DOMINION Build603

Build602に重ねる差分更新。アプリ3.1.282、魔界ランナーズの通信ルール13。

## 更新方法

1. ZIPを展開し、Build602の同名ファイルに上書きする。
2. 本体とonline-serverを両方更新し、サーバーを再起動する。
3. 参加者全員がページを再読み込みする。

通信ルールの更新により、旧バージョンの冒険は準備画面へ戻る。通常のバックグラウンド復帰・再接続時には進行を維持する。本ZIPの作成時点では公開サイトへの反映は行っていない。

## 序盤の負荷と木箱

- 地形画像をコース全体ぶん一括で加工する処理を廃止。画面サイズ確定後に最初の範囲だけ準備し、タイル間で処理を譲る。その先は進行方向を先読みし、1タイルずつ空き時間に準備する。
- ボス画像はアリーナ付近で読み込む。既存のメインゲームの8フレームを1枚のWebPにまとめ、ゲーム開始時の8枚読み込みと透明部分のピクセル走査をなくす。見た目とアニメーションの各フレームは維持する。
- 初期の地形・敵素材と背景の準備が済むまで操作を開始しない。画面を退出した場合は残った先読み処理を止める。
- 木箱は6属性のどの攻撃でも1発で壊れる。積まれた箱は1個ずつ独立して壊れ、弾は命中した箱で消える。針山を攻撃が通過する仕様も維持する。

森林コースの地形・ボス準備経路を同条件で比較すると、初期Canvas生成は39枚から3枚、生成したCanvasの画素領域は5,709,760バイトから621,360バイト、画像要求は17件から5件、透明部分の走査は8回から0回になった。これは全アプリの通信量や使用メモリ、SafariのFPSを測った値ではない。
