ABYSS DOMINION Build491 / v3.1.170
Build490 適用済み環境への差分更新

【今回の変更】
・開始合図を、キャベツの葉・交差した包丁・真鍮の時計風メダリオンに変更。
  「3 → 2 → 1 → 開店！」を文字と合図音で表示します。
  数字と日本語は画像に焼き込まず、画面サイズに合わせた文字で重ねています。
・緑の「切れ！」、琥珀色の停止予告、赤の「切るな！」、終了合図の
  4種類の新しいプレート素材を追加。色・文字・装飾で区別します。
  動きを減らす設定では数字のアニメーションを抑えます。
・「切るな！」の間は、有効なタップ1回につき必ず−80pt。
  同じ手で続けて押した場合も毎回減点。停止開始直後の免除と、
  1回の停止合図につき1回だけという減点制限を廃止しました。
  停止前の700msの予告は引き続き表示します。
・0点で打ち止めにせず、マイナスのまま加減算・表示・保存・順位付けを続けます。
  例：100ptから禁止中に3回タップすると、20 → −60 → −140pt。
  その後、通常の千切りが成功すれば10ptずつ戻せます（コンボ加点も継続）。
・AIも同じ採点ルールを使用。誤って停止中に切ったAIは、その後は手を止めます。
・実際の1タップと通信再送を区別し、再送では追加減点しません。
  両手入力・高速交互タップの反応、ゲーム中の拡大抑止も維持。
・まな板→テーブル→床の破壊は引き続き毎タップ進行し、最後まで傷が残ります。
・全員マイナスでも正しく優勝者・同点順位を表示します。
  得点は負のまま表示し、収穫量の描画だけ0を下限とします。
  結果の「もう一度」「ミニゲーム一覧へ戻る」はBuild490の共通操作を継続。

【適用】
1. Build490 適用済みのゲームフォルダーへ、ZIP内のファイルを同じ相対パスで上書き。
2. online-server/src/ 内の同梱ファイルも更新し、オンラインサーバーを再起動。
   保存データは削除しないでください。
3. 全プレイヤーがページを再読み込みし v3.1.170 を確認。
   旧版サーバー／旧版クライアントが混在すると、更新案内を出して開始を止めます。
4. 更新前から進行中の試合のみ旧採点を維持し、次の試合から毎タップ減点に切り替え。
   準備画面の試合は全員更新後に新ルールで開始します。
5. 本ZIPは差分です。Build490までの既存ファイル・素材が必要です。
   本番サイトへの公開・デプロイは実施していません。
