# Build448 / v3.1.127 — 種族差を抑え、育成で伸びる戦力表示

Build447までを含む累積上書きZIPです。既存のゲームフォルダへ、フォルダ構成を維持して上書きしてください。新規インストール用のリポジトリ全体ではありません。

## 表示用の計算式を整理

同じレベル帯のN・SSR・神話に数十倍の差が付いていたため、種族ごとの元の能力値を、その種族自身の無装備基準で調整する方式へ変更しました。

以前の「低戦力側をさらに二乗する補正」と「勇者4人だけ0.65倍にする補正」は、通常のキャラの表示計算では使いません。新しい計算式へ置き換えています。旧クライアントの検証に必要な旧式のコードは保持します。

新戦力は「ランク係数 ×（レベルによる戦力 ＋ 能力値の成長による戦力）」です。

| ランク | 係数 |
|---|---:|
| N | 1.0 |
| R | 1.2 |
| SR | 1.5 |
| SSR | 1.8 |
| UR | 2.1 |
| LR | 2.5 |
| 神話 | 3.0 |
| 深淵 | 4.0 |
| 十神 | 5.5 |

種族ごとの基準は、無装備・未強化・ランク1のLv1とLv1000で固定します。レベルアップのたびに分母が大きくなって戦力が下がる問題を避けています。装備・強化・育成で実際の能力値が増えた分は、成長分へ反映します。到達階層そのものを倍率には使いません。

| SSR・氷界女帝グラシエラ | 9 | 762 |

同レベル付近での種族差を抑えつつ、りおんのLv7→Lv6800では約426倍の成長差を維持します。装備や強化によって値は変わり、下位ランクでも十分に育成すれば上位個体を超えられます。戦力は育成状態の比較指標であり、相性・連携・固有スキルを含む勝敗の保証ではありません。

## 維持するもの

- 実際のHP、攻撃力、防御力、ダメージ、スキル、勇者の共鳴・連携は変更しません。
- ホームの「戦力／数字」の上下配置・7桁表示・文字サイズの自動調整を維持します。
- 総戦力は新しい個人戦力の合計です。ホーム・編成・装備・探索・戦力記録・ランキングに同じ式を使います。
- ランキングの保存値と戦闘用プロフィールは従来基準で保持し、種族・レベル・ランク・検証済み能力値に基づく保存戦力から新しい値を計算して並べ直します。未ログインのプレイヤーも対象です。
- 古い版からの送信・再送を受け付け、再起動後も同じ要求を重複処理しません。
- 各キャラの内訳がない過去の自己ベストは正確に再計算できないため、「更新前の戦力記録」へ保存し、新基準の記録を現在の編成から始めます。さらに古い記録も残します。
- 未知の種族IDを含む古いデータは、情報不足のまま新式へ推測換算せず、以前の方式を保ちます。

## 反映手順

1. ZIPを展開し、既存のゲームフォルダへ同じ構成で上書きする。
2. 本体とオンラインサーバーの両方を更新する。
3. サーバーを別フォルダで動かしている場合は、ゲーム側の `src/` フォルダ全体を `online-server/` と同じ親フォルダへ同期する。今回の式は種族データ・能力値計算も参照するため、PowerScaleのファイルだけのコピーでは不足する。
4. オンラインサーバーを再起動し、本体を公開する。
5. ゲームを再読み込みして `v3.1.127` を確認する。

セーブ・サーバー保存データの削除は不要です。公開先への反映は行っていません。

## 計算の詳細

- `L`：キャラのレベル
- `P`：以前から保存・検証に使用している能力値ベースの戦力
- `P1 / P1000`：同じ種族・ランク種別の無装備基準個体のLv1 / Lv1000での上記戦力
- レベル分：`100 × (1 + (L−1) ÷ 10)^1.1`
- 能力成長分：`10000 × max(0, P²−P1²) ÷ max(1, P1000²−P1²)`
- 表示戦力：`四捨五入(ランク係数 × (レベル分＋能力成長分))`

正の戦力の最小値は1、安全な整数の最大値を上限にします。基準計算の結果は件数上限のあるキャッシュで再利用します。
