# ABYSS DOMINION Build605

Build604に重ねる差分更新。アプリ3.1.284、魔界ランナーズ通信ルール15。

## 更新方法

1. Build604へ、このZIPの中身を同じフォルダー構成で上書きする。新規ファイルも追加する。
2. 本体とonline-serverの両方を更新し、サーバーを再起動する。
3. 参加者全員がページを再読み込みする。

旧版で開始した魔界ランナーズは準備画面へ戻る。セーブのキー・スキーマは変更しない。公開サイトへの反映は行っていない。

## 修正内容

- 大砲の砲弾を上から踏むと、一撃で壊して軽く跳ねる。続けてジャンプできる。横・下からの接触は引き続き危険であり、攻撃での破壊も可能である。砲弾の動きを含めた交差判定を使い、サーバーと操作側の予測にも同じ判定を適用した。
- 穴への落下は上へバウンドせず、そのまま画面外まで落ちる。落下をカメラが延々と追う動作を止め、地上では床面より420下まで落ちてから死亡とする。地下の通路には地下床に合わせたカメラと判定を維持した。死亡数は1回だけ増え、旗から復帰する。
- 操作4ボタンの上端と高さを統一した。縦画面の高さは96px、幅350px以下では88px。攻撃ボタンは幅390pxの画面で60×66pxから90.5×96pxへ拡大した。全ボタンの長方形の範囲をタッチ可能にし、四隅も反応する。
- 「攻撃」を常時表示し、その下に属性名を添えた。左右の指スライド、移動とジャンプの同時押し、攻撃へのスライド切り替えを維持した。ボタン間の境目付近で意図せず別の操作へ切り替わる範囲を狭めた。
- 振動非対応端末では、操作パネル上の空き行を取り除いた。既存の深緑と金属装飾の見た目を維持した。
