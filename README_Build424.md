# ABYSS DOMINION Build424 / v3.1.103

Build423 適用済みのゲームへ上書きする差し替え版です。ZIP 内の index.html、src、assets をゲームの同じ場所へコピーしてください。旧ファイルを削除する必要はありません。画面を再読み込みし、バージョン 3.1.103 を確認してください。

## 今回の変更

- 原初の聖胎の丸い装飾を、母のキャラ画像の実際の描画位置と拡大率に合わせました。
- 魔法陣を I〜X のローマ数字付きドット絵表現に変更しました。
- 母の戦闘画像を HP 情報枠の上へ配置し、画像が隠れる重なりを修正しました。
- 会話画面は7人の足元と名前欄を揃え、母だけ浮く配置を修正しました。
- 母に専用ギミック「十律輪」を追加しました。毎ラウンドの開始時、輪が回転して数字を指し、対応する十神の技を追加発動します。輪の演出は攻撃前に閉じ、倍速に同期します。
- 最終エピソードを読み終えると「第二章 完結」画面を表示します。物語は一区切りとし、今後の追加章につながる余地を残しています。
- 初回撃破限定のホームスキン「原初の聖胎・明けゆく世界」を追加しました。完結画面の設定ボタン、または設定の「ホームの風景」で選べます。

## 十律輪と難易度

母の通常行動に加えて、ラウンドごとに1回、十神の技を再演します。MP・再使用待ち・行動不能によって輪の発動は止まりません。発動後の命中・耐性・防御・障壁・反撃は既存の戦闘処理を使います。

巡る順は VIII → I → IV → V → III → VI → X → II → VII → IX。10ラウンドで一巡し、再戦も同じ順です。次の数字・技を表示するため、解除・浄化・回復阻害・障壁などで準備できます。挑戦画面に全10技の説明を追加しています。

再演は母専用の威力です。十神本人の元技の威力係数を20%で再演し、回復12%、障壁6%、再生3%、軽減18%、攻防・速度強化20%を専用値として設定。数値だけを膨らませず、通常行動との組み合わせで難しくしています。母の HP は1,600,000、攻撃・魔力14,000、速度8,000です。所持キャラの深淵・十神のデータやペアの共通ルールは変更していません。

## セーブと報酬

- すでに母を倒しているセーブでも、限定ホームスキンを選択できます。再撃破は不要です。
- 旧クリア済みセーブでは、原初の聖胎へ入り直すと完結画面を表示します。
- ホームスキンはボタンで選択したときに設定します。勝手には切り替わりません。
- 初回の通貨報酬は従来どおり一度だけです。完結画面・回想・スキン選択で通貨を再配布しません。
- 輪の発動済みラウンドを戦闘チェックポイントに記録し、記録済みの技を再開時に二重発動させません。
- 更新前から途中保存されている母戦は従来の内容を維持します。新しい十律輪は新規の挑戦・再戦から適用されます。

## 確認結果と範囲

300件の自動テストを実施。手動スキル操作、倍速演出の待ち時間、輪の二重起動防止、チェックポイント再開、セーブ失敗時の復元、報酬重複防止、ホーム設定、従来の階層・探索・オンライン互換の回帰を確認しました。差し替えZIPをBuild423へ展開した状態でも同じテストを実行しています。

母戦はゲーム本体の戦闘処理を使い、9編成 × 3育成段階 × 3乱数条件の81戦を検証。25勝・56敗、全戦23ラウンド以内に決着しました。通常キャラの異なる4編成が Lv.6,000 で3条件すべて勝利しています。強く噛み合う Lv.8,000 編成には3ラウンドで勝つ例もあり、すべての編成で接戦になる調整ではありません。

検証装備は共通のLR装備6枠、装備LvはキャラLvと同じ、装備+10、キャラ+0、魔法陣Lv.1です。スクリーンショットの実セーブ・専用装備を完全再現した結果ではありません。戦闘検証では描画と待ち時間を置き換えています。

この環境ではブラウザーがローカルページを開けず、iPhone実機の見た目・タッチ操作・実時間の描画負荷は未確認です。表示は描画座標・可視領域計算と構造を検証しています。オンライン実接続試験やサイトへの公開は行っていません。
