ABYSS DOMINION Build393 / v3.1.73
第二章・精鋭再探索

5地域に15部隊、3段階の任意挑戦を追加。既存60体で24組すべてのペアを編成。
第二章の総数は70体・各ランク10体・280固有技・560ポーズ・24ペア。
各部隊は6枠の実装備・装備Lv/＋値・4種類の魔法陣を持ち、支援・状態異常・追撃を組み合わせる。
精鋭のAIは部隊の狙いに応じて支援役、負傷者、ペア、強化中の相手を優先。固有技の特効対象を優先する仕組みも維持。
通常の再探索と全70体の捕獲経路を維持し、精鋭でも捕獲可能。敵の装備は仲間に持ち越さない。

導入
Build392 / v3.1.72に上書きする差分ZIP。Build391以前なら先にBuild392まで適用。
展開した中身のsrc・tests・artifacts等を既存 abyss-dominion-remake フォルダーへ統合し、同名ファイルを上書き。
GitHub Desktopで変更を確認 → コミット → Push origin。公開更新後に再読み込みし、v3.1.73を確認。
セーブ初期化は不要。戦闘中の場合は戦闘を終えてから新しい探索へ。

遊び方
1. 探索開始 → 第二章 → 踏破済み地域を選ぶ。
2. 「精鋭再探索」を開き、相手の編成・装備・魔法陣・攻略ヒントを確認。
3. 「1・精鋭」を選び、地域内の3部屋を討伐する。
4. 3部隊討伐で装備報酬と次の段階が解放。段階は地域ごとに独立。
途中帰還後は同じパネルの「再開」で討伐済み部隊・段階・訪問を引き継ぐ。
段階ボタンを押すと3部隊を再配置する。メインの「通常探索へ出発する」は通常の部隊に戻す。
開始・再開・敗北でHP/MPを戻さない。回復が必要なら泉や拠点を使う。
その地域を最初からやり直している途中は、再び踏破してから精鋭に挑戦できる。
進行中の戦闘がある間は、別の地域・段階・通常探索への変更を受け付けない。

強さと報酬
段階1「精鋭」：基準Lv×1.15、HP×1.35、攻撃/魔力×1.15、防御×1.10、速度×1.05。
段階2「覇者」：基準Lv×1.35、HP×1.75、攻撃/魔力×1.35、防御×1.20、速度×1.10。
段階3「極冠」：基準Lv×1.60、HP×2.25、攻撃/魔力×1.60、防御×1.35、速度×1.15。
HP等の倍率は役割と実装備を反映した能力に適用。魔法陣の既存の能力補正・固有效果もその後に適用する。
強さは地域と段階で固定。味方のレベルや戦闘力に合わせて上昇しない。
GOLD・経験値は通常部隊の基準報酬に対して1.5倍/2倍/2.5倍。経験値パック（超）も入手。
3部隊の討伐報酬：段階1はLR装備＋12、段階2は神話装備＋18、段階3は神話装備＋24。
報酬装備Lvは地域の目安Lv×1.15/1.35/1.60。地域ごとの種類は武器/防具/装飾/武器/防具。
同じ段階を再挑戦して装備を集められる。1回の訪問につき装備報酬は1回。
敗北・重複クリック・セーブ再開で報酬を増やさない。保存失敗時は報酬と段階解放を戻し、再試行可能。
物語初回報酬・鍵・宝物庫の取得済み状態は維持する。
