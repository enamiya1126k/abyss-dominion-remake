# ABYSS DOMINION Build580（v3.1.259）

Build578 / Build579 に重ねる差し替え版です。エレベーターの本編実装、新作もう１本、用水路の難易度アップ、Build579のアイテム透過修正をまとめています。

## 入れ方

1. ZIPを解凍し、中身をプロジェクトのルート（index.html がある場所）へ、同じフォルダー構成のまま上書きしてください。フォルダーごと削除して入れ直す必要はありません。
2. フロント側のファイルを公開先へ反映してください。
3. **online-server と、その隣の src の両方をサーバー設置先へ反映し、Nodeサーバーを再起動してください。** 新作の判定と用水路の変更があるため、今回は再起動が必要です。依存パッケージの追加はありません。
4. 参加者全員がゲーム画面を再読み込みしてください。バージョンは **3.1.259** です。

セーブデータ、サーバーの保存データ、環境変数はZIPに入っていません。既存の保存データを削除する必要はありません。GitHubの公開中mainへは自動反映していません。

## 魔王のエレベーター

- ４人対戦、空席と離席はAI。相棒とカラーはパーティーから引き継ぎます。
- 左右になぞる、タップ、スライダーで移動。金貨25点・宝石60点・金塊100点を取り合います。
- 拾うほどカゴが重くなり、きしみが増加。「降りて確保」でその便の得点を保存します。
- 10階まで残ると＋200点。カゴが壊れたら、その便の未確保分が０点になります。以前の便の得点は残ります。
- 爆弾はカゴを揺らし、近くの人の持ち分を最大40点減らします。脱出ジャンプ、揺れ、得点表示、落下演出、効果音切替つき。
- １便最大30秒、３便の合計点で順位決定。同点は同順位。矢印キーで移動、Spaceで確保できます。

## ぐつぐつ！溶岩ステップ

- ４人対戦、全８回。５つの足場からタップで選び、締切まで変更できます。
- 赤い「危険」２つのうち１つが噴火します。安全な足場100点、危険な足場で生還180点、お宝の足場はさらに＋100点。
- 同じ足場に着いた人で得点を山分け。最後の２回は得点２倍です。
- 選んだ足場は締切まで本人だけに配信。AIも噴火の正解や他人の選択を参照しません。
- 落下・未選択はその回０点。次の回で復帰するため全員が最後まで参加できます。数字キー１～５でも選べます。
