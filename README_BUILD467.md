# ABYSS DOMINION Build467

バージョン3.1.146／セーブスキーマ84。Build466の全ファイルを含む累積更新ZIPです。既存プロジェクトに上書きする更新であり、未収録の従来依存ファイルも必要です。

## 今回の変更

- サイコロ画像そのものをタップして振ります。移動前に使えるカードがなくても、人間の手番はタップを待ちます。AI・通信切断時の代行・既存の制限時間処理は維持しています。
- 専用の冒険マップを生成し、描かれた石畳の中心線を座標化。80個の本線マスを道に沿って配置し、3か所・計12マスの寄り道は石橋でつなぎます。森、結晶の洞窟、火山、王城を進みます。マスの接続と効果は変更していません。
- 巨大な八角形マスを、小さな紋章入りの石へ変更。効果は短いラベルで読み、タップで詳しく確認できます。
- カード表の金属装飾枠、共通裏面、サイコロ、冒険マップ、闇の演出背景の5素材を画像生成で制作し、実際の表示に組み込みました。表面色はランク、外枠色は属性を維持します。裏面は全カード共通です。
- 悪い速攻が発動すると、紫黒の闇、強制発動表示、短い衝撃、カードの反転で知らせます。通常札・手札に保持した呪い・発動しなかった速攻は従来の非公開範囲を守ります。
- 「マップ拡大」を手札境界の「手札カードを閉じる ▼／開く ▲」へ変更。閉じるとマップを広く使え、倍率と見ていた中心位置を保ちます。
- 「森のより（手札を5枚にそろえる）」のデッキ内枚数を3枚から1枚へ減らしました。全体は335枚から333枚、通常の初期デッキ中の割合は約0.90%から約0.30%です。実際の抽選は残り山札や安全ドロー等で変わります。他のカード効果・点数は維持します。
- 捨てるカードを複数まとめて選択し、必要枚数を確認して一度に確定できます。枚数違い・重複・古い選択はサーバーで拒否します。
- Build466までの複数ドロー演出、相手のカード非公開、奪取、特殊カード覚醒、手札の長押し並び替え、カメラ維持、AI戦やり直し・終了を引き継ぎます。

## 適用

1. 現在のプロジェクトをバックアップする。
2. ZIP内のファイルを既存プロジェクトの同じ場所に上書きする。
3. フロントエンドとオンラインサーバーが参照する共有 `src/sugoroku` を両方更新し、サーバーを再起動する。複数捨て札のコマンド形式が増えているため、片方だけの更新は避けてください。
4. 参加者全員がページを更新する。表示が古ければタブを閉じて開き直す。

公開サイトには自動反映していません。メインRPG・育成・GOLD・レースルール・セーブスキーマは変更していません。同じ対戦では全員が同じ更新版を利用してください。
