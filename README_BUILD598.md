## 修正・追加
- 人間エアホッケー：動いていない人を攻撃役に選び続け、AIが守備位置で止まる状態を修正。操作中の人との役割分担は残し、止まったパックをAIが取りに行きます。
- 途中退出：ゲーム中でも、左上の戻る→パーティーから退出が可能。残った人は続行。部屋主は引き継がれ、最後の人が退出したら部屋を終了します。ランナーズの退出者はAI化せず、ゴール待ち・順位から除外します。
- ランナーズの虫：長い移動範囲の端で反転・往復。端から端へのワープを撤去。
- 属性マーク：メインゲームの属性アトラスを、拾う紋章と攻撃ボタンの両方で使用。
- 氷：凍った敵を透ける氷塊で表示。上に乗れて、横から触れると滑り出します。滑る氷塊は敵を倒し、ほかのプレイヤーに接触ミスを与え、壁にぶつかると砕けます。蹴った直後の本人は保護。凍結は約6.5秒です。
- 被弾：普通の接触は短く後ろにのけぞり、点滅してその場から続行。落下・押し潰しはチェックポイントへ戻ります。押し潰しは点滅中や土の盾でも防げません。
- 無限復活・弾数無制限・人間だけのランナーズ・背景化からの位置保持は継続。
