ABYSS DOMINION Build355 / v3.1.35
Build354適用済みゲーム用・勇者4人の単独戦強化差分

【反映】
ZIP内を、既存ゲームのindex.html・srcと同じ階層で上書きする。
index.htmlも必ず反映し、再読み込み後のバージョンv3.1.35を確認する。
オンラインサーバーを運用している場合は、online-server/src/HeroAllianceAdapter.jsと
共有srcもサーバー側へ反映し、サーバーを再起動する。
セーブ削除は不要。すでに撃退した勇者の記録や蓄積した傷は保持する。
保存中の旧勇者戦はHP・MPの残存比率を保って6枠装備の能力へ移行する。

【4人共通】
勇者Lv.1000に装備条件を満たす専用装備6点（Lv.2000・+100）を装着。
右手・左手・胴・補助・首・指の装備、セット効果を通常の能力計算へ通す。
敵専用の隠しHP倍率は使用しない。同じレベル・装備なら入手後も同じ能力。
Lv.1000・上記装備での最大HP：
えなみ 291,908 / より 268,780 / りおん 292,350 / ひで 299,409

生存する勇者が自分1人の場合、勇者本人の被ダメージを30%軽減。
一般の魔物が一緒にいても有効。勇者が2人以上なら既存の人数別共鳴へ切替。
単独時の初手は攻撃と自己シールドを兼ねる技を優先する。
えなみ：メンタル！！（最大HP18%） / より：開けんかいコラァ！（15%）
りおん：いこうぜ！（15%） / ひで：フォー！！！！（18%）
シールドは加算で無限に積まず、既存値と新しい付与値の大きい方を使用。
りおん・ひでは、負傷時は回復を優先。復活対象のいない蘇生は選ばない。
単独AIは瀕死の敵、技の追加効果が有効な敵、高火力・高速の敵を優先。
手動の攻撃対象指定は尊重する。
よりはシールドを抜ける被弾で攻撃20%上昇・3ターン。再被弾は残りターンの更新のみ。
これらの技・軽減・AIは敵味方の共有処理に実装。
4人共鳴の連携上限・緊急行動・一度限りの踏みとどまりは維持する。

【表記】
guaranteedCriticalを「確定会心」、guaranteedHitを「必中」へ。
会心率上昇・蘇生封印も日本語化。未知の効果IDをそのまま表示しない。
単独勇者には「勇者の胆力・軽減30%」を表示。

【検証】
22テスト成功。通常・会心・3連撃・90%防御無視を物理/魔法で4人分検証。
防御計算後の入力65,611を5回続けて与える試験では、シールドなしで4人とも生存。
これは固定入力の耐久試験であり、スクリーンショットのセーブ・装備の完全再現ではない。
全16技の敵味方一致、2～4人の連携上限、オンラインの共通処理、
旧バージョン戦闘の再開・HP比率保持、日本語表示関数も検証。
iPhone/Safari実機での描画・操作は未確認。
