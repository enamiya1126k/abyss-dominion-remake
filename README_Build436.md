# ABYSS DOMINION — Build436 / v3.1.115

Build435までの更新を含む、累積の上書き用ZIPです。

## 入れ方

1. 今のゲームフォルダーとセーブをバックアップします。
2. ZIPを解凍し、中身をいつものゲームフォルダーへ上書きします。
3. 古いゲームフォルダーを丸ごと削除しないでください。元の画像素材、セーブ、サーバーの `data/`、設定を残します。
4. いつもの方法で公開先へ更新し、ゲームを再読み込みします。表示バージョンは **3.1.115** です。

このZIP自体は公開中のゲームへ自動反映されません。

## 今回の変更

- 第二章の召喚はペア紹介を短くまとめ、肩書きと名前を分離しました。ペア共鳴の説明は開いて読めます。
- 召喚回数のボタンに新しい生成素材を追加。回数を大きくし、必要魔晶石を下段に揃えました。通常・曜日・専用装備の回数選択にも適用しています。
- 母戦の敵名・HP・HP障壁・レベル表示を小さくしました。数値は省略していません。
- 母戦の敵スキルに実際の効果を追記しました。最低3秒、長い説明は最大6秒表示します。倍速切替や自動戦闘切替による画面更新でも表示を維持します。
- 編成画面へ「役割から仲間を探す」を追加しました。既存の4体配置と操作はそのままです。
- 回復量低下、強化解除、蘇生封印、耐久、回復、蘇生、浄化、行動順、火力の9項目から所持キャラを探せます。
- スキル設定中・習得済み未設定・未習得を区別。名前検索、習得済みの絞り込み、候補の詳細、育成ステータスの目安を表示します。
- ガイドは所持キャラ自身のスキルと現在の装備で得ているスキルを対象とします。ペア共鳴・魔法陣・未所持装備の総合的な自動編成診断は含みません。
- 検索や閲覧ではセーブを書き換えず、編成・装備・スキルを自動変更しません。探索中も閲覧できますが、編集画面への移動は帰還後です。

召喚価格・提供割合・保証、キャラ性能、戦闘計算、報酬、再戦レベル進行は従来どおりです。転生システムは追加していません。
