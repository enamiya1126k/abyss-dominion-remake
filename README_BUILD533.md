# ABYSS DOMINION — Build533 / 3.1.212

Build532へ重ねる差分更新です。**実在魚を32種類追加し、獲物は全120種類**になりました。

## 今回の追加

- 食卓の魚：マダイ、クロマグロ、カツオ、サワラ、マダラ、ホッケ、キンメダイ、タチウオ、マコガレイ、キチジ、アカムツ（ノドグロ）、カンパチ、スズキ、ニシン、シシャモ、ニホンウナギ。
- 磯・堤防などの魚：クロダイ、メジナ、カワハギ、カサゴ、クロメバル、アイナメ、シロギス、マゴチ、ボラ、サヨリ、ホウボウ、ヒメジ、ハタハタ、シラウオ。
- 不思議な実在魚：デメニギス、ラブカ。
- 新しい32種類すべてに専用画像、個体ごとに変わるゲーム重量・得点、釣果カードの豆知識、図鑑の出典リンクを追加。
- 図鑑に「今回追加」「深海」の分類を追加。従来の食卓・実在などの分類にも反映しました。
- 試合ごとの出現傾向に「磯と堤防」「深海の気配」を追加し、計６パターンへ。直近の同じ魚が連続しにくい仕組みは継続。特定テーマでしか出ない魚はありません。
- 通常の魚の抽選では実在の生き物が約92〜94％（各テーマ３万回・各階級同数の抽選試験）。実際の試合では距離・餌・狙う魚影でも割合が変わります。
- ヌシ級６種類、ルアー６種類、固定の餌連鎖は維持。竿強化、手動投げ先指定、食いつく前の回収、ヌシ再挑戦も維持しました。

## 適用方法

1. 現在のBuild532一式をバックアップしてください。
2. ZIPの中身を、既存のゲームルートへ同じ相対パスで追加・上書きしてください。
3. **本体とonline-serverの両方を更新し、サーバーを再起動してください。** 釣りの通信互換番号は７です。旧本体は更新案内で止まります。
4. 全員が画面を再読み込みして入り直してください。準備画面の図鑑で「120種類」「今回追加32種類」を確認できます。

## 現実の魚について

図鑑の実在生物項目は計64種類。獲物数はゲーム内の項目数であり、生物学的な種数とは異なります。名前と短い豆知識は水族館・研究機関・公的機関などの情報をもとに記述し、出典を各項目に添えました。

重さ・得点・難易度・距離ごとの出現・餌連鎖はゲーム設定です。連鎖による巨大化や、海水魚と淡水魚が同じ湖に現れることもゲームの演出です。画像は生成したイメージで、現実の同定や食用判断には使えません。従来の毒・トゲの注意表示も残しています。
