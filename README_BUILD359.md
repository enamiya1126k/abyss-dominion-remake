# ABYSS DOMINION Build359 / v3.1.39

Build358に上書きする差分。勇者一行の最終決戦を、十神2体・深淵2体と専用装備を基準に調整した。

## 新GMコード

```text
AD-GM-2G2A-9R6K
```

設定画面の「GMコード」へ入力する。前の `AD-GM-100F-LR4-7K9P` と旧GM支援コードを使用済みでも受取可能。各セーブにつき1回。完全初期化後は再度使用可能。

| 配布対象 | 内容 |
| --- | --- |
| 十神 | 時間・生命の2体。各Lv.1500・+10 |
| 深淵 | 暴食・憤怒の2体。各Lv.1500・+10 |
| 専用装備 | 各キャラ6部位、合計24点。各Lv.3000・+10 |
| GOLD | 100,000,000G |
| 魔晶石 | 30,000個 |
| 捕獲結晶 | 1,000個 |

4体は控え、装備は通常所持品へ追加する。階層・討伐記録・現在の編成は変更しない。受取には仲間4枠と通常装備24枠の空きが必要。満杯の場合は何も配布せず、コードも未使用のままとする。

### 配布後の準備

1. 配布された「時間・生命・暴食・憤怒」を4枠に編成する。
2. 装備画面で「全員を自動装備」を押す。専用装備が優先される。既に同じ専用装備の上位品を所持していれば、そちらが選ばれる場合がある。
3. HP・MPを全回復して挑む。魔法陣は手持ちに合わせて選択する。

控えへの装備は自動解除される既存仕様のため、「装着済みの控え」としては配布しない。魔法陣の新規配布や術式の解禁も行わない。

| キャラ | 配布時に選択済みの4技 |
| --- | --- |
| 時間 | 永劫・無限秒針／時間加速・先刻／時間逆行・生環／終刻宣告 |
| 生命 | 世界樹・万葉障壁／再誕・分命の芽／命の祝福・万命帰樹／万命再誕 |
| 暴食 | 万象終喰／飢餓咆哮／魔喰／万象捕食 |
| 憤怒 | 憤怒解放・紅蓮葬／瀕怒撃／理性焼却／不死狂戦 |

各キャラの新しい切り札は選択済み。他の固有技と専用武器技は、スキル編集で入れ替え可能。

## 勇者の調整

基準は単独勇者ではなく、えなみ・より・りおん・ひでが全員生存している最終決戦とした。

従来の4人連携は、今回の基準編成でも行動前に全滅する結果だった。Lv.1000と専用装備6点・Lv.2000は維持し、複数人で連携中の与ダメージを調整した。連携の行動数、個々の技、追撃のMP無料、回復・支援の役割は維持する。

| 生存勇者数 | ラウンド内の最大行動数 | 1回の与ダメージ係数 | 共鳴による被ダメージ軽減 |
| ---: | ---: | ---: | ---: |
| 1人 | 1回 | 従来通り：えなみ35%・より25%・りおん50%・ひで35% | 胆力30% |
| 2人 | 4回 | 12% | 15% |
| 3人 | 9回 | 6% | 30% |
| 4人 | 16回 | 4% | 50%（従来60%） |

与ダメージ係数は、専用装備・会心・弱体特効などを含むダメージ計算に適用する。共鳴追撃には従来の技威力70%も適用する。複数の全体攻撃と連携が重なるため、単発の係数とパーティー全体の実際の火力は異なる。

敵で出現する勇者、入手後の勇者、通信戦はいずれも同じ共通処理を使用する。相手がGM配布キャラかどうかによる特別補正はない。生存人数に応じてその場で切り替わる。単独勇者の能力と、過去に与えた傷・撃退記録は変更しない。

## 比較結果と確認範囲

全員HP・MP満タン、勇者に事前の傷なし、アイテム・魔法陣・恒久ツリー補正なし。実際の配布生成・能力計算と、通信戦の行動解決・ラウンド終了処理を使った固定乱数の比較。

| 条件 | 基準編成側の結果 |
| --- | --- |
| 調整前の勇者4人 | 試行した12戦すべて1ラウンド目に敗北 |
| 調整後の勇者4人・スキル判断あり | 40戦中16勝、平均約6.4ラウンド、1ラウンド目の全滅なし |
| 調整後の勇者4人・通常攻撃のみ | 40戦中0勝 |
| 調整後の勇者4人・従来のLR4体パック | 20戦中0勝 |
| 調整後の単独勇者 | 4人それぞれ40戦中40勝、平均約2〜2.4ラウンド |

これは条件を揃えた比較値であり、個々のセーブや手動操作、オフライン画面を完全再現した実測勝率ではない。組み合わせや魔法陣、技の選択、事前の傷によって結果は変わる。

重点テスト77件を実施。今回のコード認証、旧コードとの独立性、満杯時の無変更、重複受取防止、実際の保存・再読込、控えでの保持、編成後の自動装備、敵味方の共通補正に加え、Build358のアイテム・新技・十神補正などを確認した。

iPhone／Safari実機での操作・描画確認は未実施。
