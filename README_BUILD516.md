# ABYSS DOMINION Build516 — 〇×サバイバル 600問

Build515適用済みのプロジェクトに、このZIPの中身を同じ階層へ上書きしてください。バージョンは3.1.195です。

## 変更内容

- 問題ストックを120問から600問へ。24分野に各20問を追加し、既存分野と合わせて30ジャンルになりました。
- 新たに文学、美術、世界史、神話、建築、世界遺産、発明、交通、言語、暦・時間、数学、物理、化学、地学、植物、海洋、単位、情報を追加。既存の宇宙・動物・食べ物・地理・歴史・音楽も増量。
- １〜６問は初級、７〜13問は中級、14〜17問は上級、18〜20問は96問の特別難問候補から出題。
- １回のゲームでジャンルが偏らない抽選。最近出た120問を優先的に避け、候補不足時は有限回で安全に選択します。
- 新規問題はすべて短い解説付き。知識問題に出典を付け、計算問題は計算・定義で検証しています。問題と出典の対応表は `docs/build516/question-sources.md`。

## 適用

1. Build515の上へ、このZIPを上書きしてください。
2. 本体の静的ファイルを通常の手順で更新し、**online-server側の追加・変更ファイルも反映してサーバーを再起動**してください。本体だけの更新では600問になりません。
3. 本体を再読み込みし、新しいクイズを開始してください。進行中のゲームに保存されている20問は、そのまま最後まで使用します。次の新規ゲームから新しい問題集で抽選します。

問題データは `online-server/src/quiz/QuestionData516.js` と `Questions516.js` に置きます。ブラウザーのimport map・オフラインキャッシュには含めません。スマホに送るのは現在の１問と、判定後の解説です。

20問制、制限時間、AIの動き、床の移動、壁の閉鎖、マグマや上昇の演出は変更していません。画像・音声ファイルも追加していません。
