# Build444 / v3.1.123 — 新しい魔法陣の回転を修正

Build443までの変更を含む累積上書きZIPです。既存のゲームフォルダへ、フォルダ構成を維持して展開してください。リポジトリ全体や新規インストール用の一式ではありません。

## 今回の修正

- 新しい第二章の魔法陣8種など、1枚絵の魔法陣が回転しない問題を修正。
- 1枚絵の点滅防止が回転も止めていたため、点滅を抑えたまま画像だけを28秒で1周させます。
- ホーム・通常戦闘・オンライン戦闘・装着中プレビューに適用。位置合わせ用の外側要素は回転させません。
- オンライン戦闘の1枚絵にも同じ設定を適用し、3コマ用の切り替え処理で消える問題を防止。
- 既存の複数コマの演出は継続。端末で動きを減らす設定を使用している場合は静止表示になります。

## 反映

1. ZIPを既存のプロジェクトに上書きし、普段の手順で公開先を更新。
2. ゲームを再読み込みし、バージョンが `v3.1.123` になったことを確認。
3. 魔法陣を装着したキャラクターのホーム画面・戦闘画面で回転を確認。

Build444単体の変更は表示とキャッシュ更新のみです。セーブの初期化や削除は不要です。
Build443の魔法陣バランス調整をまだ反映していない場合は、同梱のサーバー側更新も反映して再起動してください。Build443適用済みの場合、今回の修正だけでサーバーの変更はありません。
