# Build529 — 魔物レース・ブロック落としサバイバル

**Build528適用済みの本体へ重ねる差分ZIPです。バージョン：3.1.208。**

## 適用方法

1. 対戦を終え、本体とオンラインサーバーの状態ファイルをバックアップ。
2. ZIPを展開して、同じ階層へ上書き。本体の `index.html`・`src`・オフライン用2ファイルを更新。
3. `online-server/src` も上書きして、オンラインサーバーを再起動。
4. 参加者全員がゲームを再読み込み。

セーブ形式・所持品・通貨は変更していません。ブロック落としは新旧の移動判定が混ざらないよう、Build529対応端末で開始します。前回のすごろく・胸毛抜き・大運動会と、相撲・釣りの実装を保持しています。

## 魔物レース

- 33msの固定タイマー描画を、画面の描画タイミングに合わせる `requestAnimationFrame` に変更。
- ワールド表示で、旧レーンの位置指定とワールド座標の指定を毎回重ねていた処理を解消。走者は `translate3d` で動かします。
- DOM参照と表示サイズを保持し、サイズ変更時は `ResizeObserver` で更新。毎フレームのサイズ読み出しを除去しました。
- 数字・効果・操作表示を必要な頻度で更新。通信で届く位置の補正を滑らかにし、通常走行中の後戻りを防ぎます。
- 走行中の通信を、そのレースの参加者・観戦者に限定したコンパクトな状態に変更。全アカウント・予想データ・別ゲームの情報を毎回再送しません。
- サーバーの表示更新は約250ms、進行の定期保存は2秒間隔。叩く操作の受付・順位確定・報酬処理は即時に保存します。
- ゲームの速度計算・抽選・得点・着順の決め方は維持。結果・再接続時の全状態の送信と、旧クライアント向け通信も残しています。
- 全体／追尾カメラ、拡大表示、ゴール前スロー、叩く操作を維持。

## ブロック落としサバイバル

- AIは、登れる足場・脱出口・接近中の落下ブロックがない安全な場所で待機。不要なジャンプと、平地での頭の踏み合いを減らしました。
- 段差を登るジャンプ、必要な頭ジャンプ、落下からの回避、最後の超ジャンプは維持。
- 超ジャンプの再使用を **10秒** に変更。説明・ボタンの読み上げ・チャージ表示も統一。
- 落下ブロックとの重なりが **体の幅の半分未満** なら、近い側の端へ滑り出します。軽い軌跡も表示。
- **半分以上は救済しません。** 下へ押されても空間があれば生存し、床や足場と挟まれた時点で脱落します。
- 押し出し先や通り道に壁・別のブロックがあれば即脱落。反対側へ飛び越えて救済することはありません。
- 複数セルの重なりは合算して判定。セルの境目を利用したすり抜けを防ぎます。

## 確認結果

- **120項目の自動テストに合格。** 新判定、境界値、10秒の再使用、AIの回避・登攀・協力、通信対象、重複操作、再起動、着順、報酬、Build528の変更を確認。
- Chromium 153で **320×568・390×700・430×800** のタッチ画面を確認。カメラ切替、8体の表示、叩く操作、接続断時の操作抑止、押し出し、超ジャンプ、画面回転、画面を閉じた後の描画停止を確認。
- 同条件の比較：2部屋・各4人・待機中の購読者1人・10秒。送信JSONは **4,019,712 → 1,090,924バイト（約73％減）**、状態ストアの更新は **40 → 10回**。関係ない待機者への走行中の配信は40回から0回。
- 安全な平地で3体を30秒観察した比較：ジャンプ関連イベント **110 → 0回**。

これらはローカル比較の結果で、端末・通信環境によって体感は変わります。iPhone実機のSafariおよび公開サーバーでの負荷試験は未実施です。復元した差分資料に含まれない本編のカタログ・魔物描画・EXPモジュールは、検証時だけフィクスチャで補っています。画面画像の魔物は検証用表示で、実ゲームの魔物画像には変更を加えていません。

## 同梱資料

- `docs/build529/`：検証記録、比較値、画面確認画像。
- `tests/build529-*.test.mjs`：追加したロジック検証。
- `tools/build529/`：再現用のローカル検証スクリプト。
- `BUILD529_MANIFEST.json`：差分ファイルのSHA-256。

Node.js 24で `node tools/build529/regression.mjs` を実行できます。検証用の過去テストは、意図して変更したプロトコル番号・待ち時間だけを実行時に読み替えます。ブラウザー確認はPlaywright・Chromiumのパスを環境変数で指定する方式です。
