# ABYSS DOMINION Build 530

Version 3.1.209 / Fishing interaction update

## ぬし釣り大騒動

- すべての投擲を水面タップによる手動指定に統一しました。
- 「エサにして続ける」選択後も自動投擲せず、好きな場所を改めて狙えます。
- 選んだ魚・長靴・ルアーは投擲の軌道上だけ表示し、着水後は隠します。
- 食いつく前から「巻く」を長押しして浮きを手前へ移動できます。
- 巻きを離すと現在位置で待機し、岸まで戻すと失敗扱いなしで回収・再投擲できます。
- 未使用の通常エサは完全回収時に返却され、連鎖エサも付けたまま再投擲できます。
- 近距離は短く、遠距離は長い取り込み時間になるよう糸の距離を反映しました。
- 狙われた魚影を消さず、予約状態として水面に残すよう変更しました。
- 魚に「驚いていったん離れる」「そのまま寄ってくる」の2行動を追加しました。
- 食いつき直前は魚影が浮きをつつき、水紋を出してから食いつく演出にしました。
- 釣り通信プロトコルを version 4 に更新しました。
