ABYSS DOMINION REMAKE release180 / build239

これは release179 に上書きする「差し替え部分だけ」の更新です。
ゲーム全体は含まれていません。

主な更新:
- 同室メンバー、フレンド、届いた申請、ギルドメンバーからミュート／ブロック
- 交流パネルの安全設定から、ミュート中・ブロック中の一覧確認と解除
- ミュート相手のチャット、吹き出し、スタンプ、探索ピンを自分の画面と未読件数から除外
- 戦闘、HP、救助、宝箱など進行に必要な情報はミュートしても表示
- ブロック相手とのフレンド、申請、招待、新しい交換を停止
- 公開掲示板、おまかせ参加、直接ルームID、招待、ギルド募集の全入室経路で再参加を防止
- ブロック一覧へオンライン状態・現在の部屋・最終接続時刻を出さないプライバシー保護
- 旧friends.json version 1を、既存関係を維持したままversion 2へ自動移行

ミュートとブロック:
- ミュートは、相手のチャットやリアクションだけを自分の画面で非表示にします。フレンド、招待、交換、同室参加には影響しません。
- ブロックは、相手とのオンライン交流と今後の同室参加を止めます。解除しても以前のフレンド関係や招待は自動では戻りません。
- どちらの操作も相手へ通知しません。

適用方法:
1. 進行中のオンラインプレイと交換を終え、オンラインサーバーを停止します。
2. 更新前の `online-server/data` フォルダを別の場所へバックアップします。
3. ZIPを展開し、中の `abyss-dominion-remake-main` フォルダを開きます。
4. その「中身」を、release179適用済みの `abyss-dominion-remake-main` フォルダへ同じ階層で上書きします。
5. `online-server/data` フォルダと既存のJSON保存ファイルは削除しません。
6. オンラインサーバーを再起動します。
7. ブラウザを再読み込みします。

注意:
- ZIP内の階層を崩さずに上書きしてください。
- 差分ZIPには画像・音声などのゲーム素材、`online-server/node_modules`、実際の`online-server/data/*.json`は含めません。
- `friends.json`はversion 1からversion 2へ自動移行します。既存のフレンド、申請、ブロックは維持されます。
- 進行中の探索、レイド、チーム戦、共鳴迷宮は、安全操作だけで強制終了しません。現在の進行を終えた後から今後の同室参加を防ぎます。
- 受渡し開始前の未確定交換は取り消せます。最終確認後の確定交換は巻き戻さず、release179の受取保全で未受取側だけを復旧します。
- 今回は通報、管理者BAN、IP／端末BAN、自動NGワード判定を追加していません。
- オンライン通信はprotocol 1.16.0、通常セーブはschema 58のままです。
- 報酬内容、交換品目、所持品、GOLD、魔晶石、週間共闘Ptの計算は変更していません。

詳しい仕様は BUILD239_PUBLIC_ONLINE_SAFETY_UPDATE.md を確認してください。
