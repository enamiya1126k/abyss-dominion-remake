1. 強化した8種類（記載値はLv.1 → Lv.99）
魔力反転陣：与ダメージ ×1.30 → ×1.55。
  MP回復に伴うHP代償は従来どおり。回復したMPに比例し、HP1は残します。
深神封殺陣：深淵・十神からの会心無効を維持。対象からの被ダメージ15% → 30%軽減。
弱撃必殺陣：従来の弱攻撃会心補正を維持。与ダメージ常時+15% → +25%を追加。
  すでに会心率が高い仲間にも火力面の利点があります。
等価滅殺陣：発動後、生存味方へ最大HP25% → 50%の障壁。
  味方1体と敵1体への即死判定という代償は維持。強い既存障壁は上書きで減らしません。
黄金換力陣：所持GOLDによる与ダメージ上限+30% → +50%。
  対数による逓減、所持GOLD0なら倍率1、行動消費最大10万Gは維持。
万象抽選陣：抽選された攻撃スキルの与ダメージ+20% → +45%。
  通常戦闘は所持仲間の習得技から、共闘は共通の抽選候補から選ぶ既存仕様です。
  未習得の全スキルを自由に使える陣ではありません。画面説明を実装に合わせました。
断末吸魔陣：倒れた時の敵MP65% → 90%減少を維持。
  生存味方のMP20% → 35%回復を追加。1戦1回。死亡中の仲間は回復しません。
  魔力反転装着者へのMP回復は、その陣のHP代償も発生します。
即死返鏡陣：開戦時、自身へ最大HP25% → 45%の障壁を追加。
  最初の即死の反射、レベルに応じた反射後のHP回復は維持します。

入手ルートや既存の再転生に伴う有効レベル制限も維持します。

3. 新しい3種類（各Lv.1 → Lv.99）
異彩協奏陣：生存味方の属性が2種類以上なら、1種類増すごとに装着者の直接与ダメージ+10% → +15%。
  4種類で最大+30% → +45%。無属性は数えません。戦闘不能者の属性も数えません。
  同じ属性をそろえる編成に対して、属性を分ける編成の選択肢です。
百禍織刻陣：敵に残る状態異常1種類ごとに直接与ダメージ+12% → +18%。
  最大3種類で+36% → +54%。同じ異常の重複は1種類、期限切れや単なる能力低下は対象外。
  対象は毒・火傷・出血・睡眠・凍結・麻痺・感電・呪い・魅了・混乱・恐怖・気絶。
  状態異常を重ねる補助役と、陣を付けた攻撃役を組み合わせます。
澄明蓄魔陣：命中直前のMPが最大値の80%以上なら、直接与ダメージ+30% → +50%。
  スキルで消費した後のMPで判定。低消費技、通常攻撃、MP支援を活かす陣です。

新陣の直接攻撃補正は、毒などの継続ダメージ・割合ダメージ・HP転写・即死を増幅しません。
通常戦闘では通常攻撃・攻撃スキル・反撃・ペア攻撃・勇者攻撃が共通の条件判定を通ります。
新陣の属性・状態異常・MP条件は、各攻撃が当たる直前に判定します。
新陣は従来の通常敵ランダム魔法陣抽選に加えません。第一章の抽選結果は維持します。
3種類には専用の透過SVG魔法陣を同梱。大きなぼかし発光は使っていません。

4. 受け取り方・表示
第二章解放後、仲間の魔法陣画面を開き、上部「第二章・新術式の研究」の受取ボタンを押してください。
各1個、Lv.1で受け取れます。消費はありません。既に第二章を解放しているセーブでも受け取れます。
条件は第二章ガチャと同じ「100階到達条件＋勇者一行勝利」です。
戦闘中・探索中は受け取れません。受取はセーブごとに1回。自動で装着はしません。
その後は既存の魔法陣画面で装着・GOLD強化ができます。
二重操作や保存失敗で重複付与せず、受取済み情報はセーブ移行後も保持します。
魔法陣一覧には現在レベルの効果量、未所持ならLv.1の効果、入手先を表示します。
装着中の見出しには実際の有効レベルの効果を表示します。
