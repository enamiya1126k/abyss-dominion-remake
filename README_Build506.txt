ABYSS DOMINION Build506 / v3.1.185
Build505に上書きする、ゴリラ大王の胸毛抜きの動作改善パッチです。
本体側だけの更新です。オンラインサーバーはBuild505のままで使用できます。

【修正した負荷】
・選択中・交代待ちでも約33msごとに全画面を描き直していた処理を修正。
  状態の変わらない60秒間では、約1,800回の全描画が最初の1回になります。
  最後の10秒表示、プレイヤーの魔物、入力、サーバー同期は引き続き動作します。
・引き抜き中は背景、静止した毛、固定カメラ時のゴリラと影を再利用。
  各フレームの動く毛とピンセットは従来と同じ描画処理です。
・同じフレームに重複して届いた描画要求を1回にまとめます。
・ボタン位置、表示・非表示、色、魔物位置などを、実際に変化した時だけ書き換えます。
・順番や演出の更新のたびにCanvasと魔物を含む画面全体を作り直す処理を抑制。
  受け取ったゲーム状態は、既存の画面に直ちに反映します。
・バックグラウンド中は描画を止め、作業用画像を解放します。
  復帰時、画面サイズ変更時、Canvas復元時は必要な場面を描き直します。
・ゲームを離れる際にフレーム予約と作業用画像を解放します。

【維持した内容】
画像素材、レイアウトCSS、毛の配置と本数、当たり判定、カメラ移動、
表情、ピンセット、プレイヤーカラー、隠し操作、抽選、時間、交代、結果画面。
解像度や演出の速度を下げる変更はありません。
ゲームルールとサーバー処理は変更していません。

【適用】
1. 現在のBuild505をバックアップします。
2. ZIPを展開し、中身を既存ゲームフォルダーへ同じパスで上書きします。
   既存ファイル・画像素材は残してください。このZIP単体では起動できません。
3. 本体の公開ファイルを更新します。
4. 各プレイヤーが再読み込みし、v3.1.185を確認してください。
   サーバーの再起動は不要です。進行中の505の試合にも同じルールで復帰できます。

バックグラウンド復帰、Canvas復元、退出時の解放、旧ルール互換を確認。
素材・CSS・ルール・サーバーなど299ファイルのSHA-256が505と同一。
