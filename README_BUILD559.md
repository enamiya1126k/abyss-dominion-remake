# Build559 · 魔王のかくれんぼ「封印とふたつの門」

Build558 に重ねる更新パッチ。アプリ v3.1.238、かくれんぼ通信ルール 6。

## 遊びの変更

- 館内５か所の封印から、好きな３つを解除。ひとつを守られても別の部屋へ回れる。
- 解除は１人８秒、２人以上で６秒。３人でも６秒が最短。
- 累計３秒の解除作業で、その**部屋**に音が響く。鬼に変身中の正体・座標・進捗は送らない。
- 作業をやめると未完了の進捗が１秒につき作業0.3秒分ずつ戻る（８秒分を失うまで約26.7秒）。解除済みは戻らない。音は最後の作業から６秒余韻が残るので、陽動も可能。
- ３つ解除すると薔薇の西門と噴水の東門が同時に開く。どちらかに仲間１人が到達すれば３人チームの勝利。
- 180秒以内に脱出できなければ、生存者がいても鬼の勝利。全員捕獲でも鬼の勝利。
- 鬼は館の中央寄りから捜索開始。歩行速度は230→260（約13%増）。隠れる側は230のまま。
- 鬼AIは音のした部屋へ向かい、見えている置き物を調査。隠れたプレイヤーの正体を直接参照して狙わない。逃げるAIは見えた鬼の記憶から、別の封印や門へ回る。
- 身代わり、攻撃チャージ、気配、スタミナ、仲間の１度限りの救出は継続。

## 画面と操作

既存の封印・門の画像素材を用い、５つの封印の状態をボタンで表示。タップでその部屋へ移動。解除中は進捗と音の警告を表示し、開門後は２つの出口ボタンに切り替わる。地図にも両方の門を表示。結果画面では脱出者と援護した仲間、脱出できなかった生存者を区別する。

## 更新手順

1. Build558 適用済みのプロジェクトをバックアップ。
2. ZIP 内を同じ相対パスへ上書き。`src/hide/` はクライアント・サーバー共通なので全変更ファイルを反映。
3. **オンラインサーバーも更新して再起動**する。サーバー３ファイルと共通ルールの更新が必要。
4. クライアントを公開し、再読込で v3.1.238 を確認。全参加者が更新してから準備OK。

旧ルールの進行中のかくれんぼは、パーティーメンバーを残してロビーに戻る。旧クライアントとの混在開始は拒否する。既存のゲームデータは削除しない。カートの絨毯・得点・コース、ピンボールのコードと通信ルールは変更なし。

## 検証と範囲

`tests/build559-hide.test.mjs` は解除時間、３か所到達、時間切れ、両方の出口、音の秘匿、別ルート選択、救出と途中状態の復元を検証。`tests/build559-wire.test.mjs` は実際のメイン・パーティー・かくれんぼサーバーの経路で４人分の秘匿配信、入力の所有者、旧版拒否、移行、再接続を検証。

AI同士26シードの調整試走は鬼11勝・隠れる側15勝。人間の勝率を保証する数値ではない。スクリーンショットとブラウザ確認はローカル Chromium。iPhone Safari 実機と公開サーバーの対戦は未確認、公開作業は未実施。

関連しないゲームの依存ファイルがない部分チェックアウトのため、QAではそのアダプターだけを置き換えている。かくれんぼのルール・描画・通信・パーティー処理は本番ファイルを使用。QAの強制配置・時間送りは検証用サーバーのみで、本番アプリには存在しない。
