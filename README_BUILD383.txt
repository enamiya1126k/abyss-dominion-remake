新しい魔物に出会うには
各地の通常戦と、地域踏破後の再探索に登場します。
すでに第二章を終えた場合も、拠点から行き先を選び直して入場すれば残党が再出現します。
倒した後、再度会いたい場合は一度拠点へ帰って入り直してください。
進行を消す操作は必要ありません。

オルディアの守衛隊はLv.4,900の追加強敵です。
ヴェルグ・ノクティア・アステラとの4体編成。任意の再探索戦です。
通常の物語ボス・封印・鍵の条件は維持しています。

捕獲
新7体はいずれも通常の「捕獲」で仲間になります。
捕獲結晶を使い、空き枠が必要です。戦闘中の成功率表示を確認してください。
成功率の上限：N65% / R55% / SR42% / SSR32% / UR24% / LR18% / 神話12%。
実際の率はHP・レベル差・状態異常・装備により変わり、上限を超えません。
通常召喚・闇市場・第一章の野良遭遇には混ぜていません。
敵専用の高レベル装備や魔法陣は捕獲時に持ち越しません。
捕獲した魔物には、手持ちの装備・魔法陣を組み合わせてください。
固有4技はすべてLv.1から使用可能です。

戦い方の例
・コロルで毒を仕込み、シェルザが毒の敵を狙う。
・バルクの障壁で支援役を守り、アステラの回復までつなぐ。
・ノクティアの速度低下から氷羽で追撃。
・ヴェルグが強化を剥がして脆弱を付与、オルディアが裁定で追撃。
敵も状態・残りHP・MP・再使用待ちを見て同じ固有技を使います。
弱体の浄化、強化解除、回復役への集中攻撃が対策になります。
装備6枠と魔法陣は各編成の役割に合わせています。
