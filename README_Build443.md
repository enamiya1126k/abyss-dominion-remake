# Build443 / v3.1.122 — 魔法陣の強さを入手難度順に調整

Build442までの内容を含む累積上書きZIP。公開サイトへの反映は行っていない。

## 変更内容

- 深淵ツリー序盤〜中盤11種を基礎〜中上位、終盤6種と第二章8種を上位、レイド産3種を最上位に調整。
- 第二章は連撃、睡眠、ペア、ガード・反撃、瀕死敵、属性編成、状態異常、MP維持の条件に見合う効果へ強化。睡眠・反撃などの効果が旧上限で切り捨てられないよう修正。
- レイド産3種に常時の与ダメージ増加を追加。輪廻はHP・MP蘇生率を引き上げ、零界凍結は全体障壁を強化、天雷轟界は被弾1回・3回で追加連撃を得る。
- 障壁はパーティーの並び順に関係なく最高の効果を採用し、同種を複数装着しても加算しない。
- 魔法陣画面に入手元に応じた格付けを表示。同レベルの自動選択では格付けが高い魔法陣を優先。
- 取得済み魔法陣のID、レベル、装着、強化履歴、GOLDを維持。セーブ形式84、魔法陣状態バージョン4は継続。
- 入手する魔法陣の調整であり、共闘レイドのボス本体の障壁・蘇生・攻撃倍率は維持する。

## レイド産の性能

| 魔法陣 | Lv.1 | Lv.99 |
|---|---|---|
| 輪廻 | 常時与ダメ+60%、1戦1回HP85%・MP75%で蘇生 | 常時与ダメ+85%、HP100%・MP100%で蘇生 |
| 零界凍結 | 味方全体に最大HP150%の開戦障壁、装着者の与ダメ+60% | 障壁200%、装着者の与ダメ+85% |
| 天雷轟界 | 常時与ダメ+75%、被弾ごと+15%（被弾分は最大+150%） | 常時与ダメ+100%、被弾ごと+20%（被弾分は最大+200%） |

天雷轟界は被弾1回で追加連撃1回、3回で2回。常時分と被弾分は加算する。条件付きの即死・孤王・反射などは特殊用途を維持するため、全状況で単一の順位になるものではない。
全28種の詳細は `docs/build443/balance-table.md` に収録。

## 適用方法

1. ZIPを展開し、既存リポジトリの同じ場所へ上書きする。
2. 通常の公開手順で本体を反映し、**オンラインサーバーも更新・再起動する**。
3. 同じブラウザで再読み込みし、v3.1.122を確認する。Safariのサイトデータやセーブデータは削除しない。

新規オフライン挑戦権は今回の性能を保存するルール4。取得済みのルール1〜3は以前の性能で最後まで再現・精算する。古い挑戦権の履歴を書き換えず、回数・報酬の重複反映も防ぐ。進行中の戦闘を再開した場合、消費済みの障壁や使用済み蘇生は再配布しない。
