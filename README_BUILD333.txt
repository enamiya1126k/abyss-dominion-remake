ABYSS DOMINION REMAKE — Build333
共同探索の一人用探索準拠・攻略情報の可読性・レイド表示修正

適用元
  Build332

適用方法
  1. Build332 のゲーム本体フォルダをバックアップします。
  2. このZIPをゲーム本体フォルダの直下へ展開します。
  3. 同名ファイルはすべて上書きします。
  4. オンラインサーバーを再起動します。
  5. ブラウザを再読み込みします。表示が古い場合はキャッシュを消して再読み込みしてください。

主な変更
  ・共同探索のマップ生成を、一人用探索と同じ共通生成処理へ統合しました。
  ・共同探索へ一人用探索と同じ区画、属性、通路、ポータル、形状履歴を反映します。
  ・共同探索の下部操作を「編成・装備・持ち物・現在地・帰還」に統一しました。
  ・共同探索画面の「長押し」ボタンを削除しました。
  ・オンラインの「接続済み」表示を固定解除し、旅人手帳を開いている間は隠します。
  ・勇者一行の攻略情報を日本語化し、画像・特性・対策・使用スキルを読みやすいカードへ整理しました。
  ・レイドボスを神話級として扱い、未定義レベルや壊れた巨大画像表示を防止しました。
  ・レイド交換所の「魔晶石」を廃止し、各ボス固有の魔法陣へ置き換えました。
  ・零界凍結陣、天雷轟界陣の専用画像素材を追加しました。

確認
  ・Build333追加検証 10件 合格
  ・関連回帰検証 22件 合格
  ・変更JavaScript 13ファイルの構文検査 合格

注意
  オンラインサーバー側の処理を変更しているため、ファイルの上書きだけでなくサーバー再起動が必要です。
