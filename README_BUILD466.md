# ABYSS DOMINION Build466

バージョン3.1.145／セーブスキーマ84。Build465の全ファイルを含む累積更新ZIPです。既存のゲーム本体に上書きする更新であり、新規起動用の全依存ファイルをそろえた単独配布ではありません。

## 今回の変更

- マップ・カード詳細の開閉で初期縮尺から再ズームする問題を修正。カメラの倍率と位置を保持します。
- 小さい手札に短い効果説明と補足を追加。詳しい説明も引き続き開けます。
- カードランクは N → R → SR → SSR → UR → LR → 神話 → 深淵 → 十神。表面色がランク、枠色が属性です。既存116種類の効果・影響範囲に基づく分類で、効果量や点数を一律に増幅してはいません。発動条件・コストも維持しています。
- 約0.42秒の長押しからドラッグして手札を並べ替え。普通のタップは詳細、すぐ横へ動かすとスクロールです。並び順は自分の端末だけに保存され、新しい札は末尾へ追加されます。
- 「1枚引く」「サイコロ」「手番終了」は中央の小さな操作パネルへ。引く→カード→移動→マス効果→終了を細い帯で表示します。
- 通常ドロー、カード・マスによる複数ドロー、奪取・交換・回収を1枚ずつ演出。手札・枚数・位置の表示を演出の進行とそろえます。
- 通常札、所持型の呪い、セット絵柄、ハッカーが保持した速攻は本人だけに表を表示。他の画面へは同じ裏面を送り、ランク・属性・カードIDも漏らしません。
- 実際に使用したカードと発動する速攻は全員に公開。「速攻を引いた→強制発動」「無効化」を区別します。
- 奪取画面は相手キャラと扇状の裏向きカード。残り枚数を示し、1枚ずつ獲得演出を挟みます。
- 特殊カードの確定獲得は約5.8秒の覚醒演出。魔法陣、光柱、粒子、キャラ、能力名を表示。進行を待機し、獲得後は能力バッジを残します。古い能力を残す選択では新能力の覚醒を出しません。
- サイコロ・通常の効果ではマップを隠さず、小さな説明とキャラ、対象矢印、マスの発光を表示。大きな演出はカード公開と覚醒に使います。
- Build465のAI戦やり直し・終了、分岐・捨て札選択、パーティー維持、従来の魔物レース改修を保持しています。

## 適用

1. 現在のプロジェクトをバックアップする。
2. ZIP内のファイルを既存プロジェクトの同じ場所に上書きする。
3. フロントエンドとオンラインサーバーが参照する共有 `src/sugoroku` を両方更新し、サーバーを再起動する。イベントデータも変わるため片方だけでは新演出がそろいません。
4. 参加者全員がページを更新する。表示が古い場合はタブを閉じて開き直す。

公開サイトへの自動反映はしていません。メインRPG・育成・GOLD・レースルール・セーブスキーマは変更していません。同じ対戦の参加者は同じ更新版を利用してください。
