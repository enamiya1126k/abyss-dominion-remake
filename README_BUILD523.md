# ABYSS Build523 / v3.1.202

Build522適用済みのプロジェクトに重ねる差分ZIPです。単独の完全版ではありません。

ホーム下部「パーティー」の一覧に、新作「魔獣ぶっとばし相撲」を追加しました。

## 遊び方

- ４人の乱戦。１〜４人で参加でき、空席はAIが参加。所持キャラを選択できます。
- 左の大きな四角い８方向パッドで移動・方向指定。右ボタンを長押しで溜め、離すと体当たり。２本指で同時操作できます。キーボードは矢印／WASDとスペースです。
- 土俵の結晶を取るほどキャラが大きくなり、攻撃と踏ん張りが強化。24ポイントで成長上限。所持キャラのレベルによる能力差はありません。
- 溜めは最大1.4秒。溜め中は移動が遅くなります。突進終了後は0.85秒の回復時間があります。
- 横・背後からの体当たりは強力。大きく育った相手にも逆転が可能。空振りして勢いで場外に出ると、自分も脱落します。
- 最後に残った１人が勝利。45／60／75／85秒に外周が崩れ、残り５秒は中央まで縮小。最長90秒。同時全滅は引き分け。時間切れで複数生存の場合は中央に近い人が勝ち、同距離は同率です。
- 結晶収集・巨大化、狙いの矢印、溜めの発光、突進の残像、衝撃波、踏ん張る跡、場外への吹き飛び、外周落下を表示します。勝者が中央へ進み、約4.6秒の決着演出後に結果・再戦へ移ります。
- 切断／ホーム滞在時はAIが引き継ぎ、戻ると操作を再開。AIは結晶集め、間合い、溜め時間、外周からの退避を判断します。

## 適用

1. Build522まで適用済みの本体へ、ZIP内を同じパスで上書きします。
2. **online-server側も更新してください。** online-server/server.js、online-server/srcの更新と、共有するsrc/sumo/Rules523.js等がサーバー側の配置にも必要です。サーバーだけ別フォルダへ配置する場合も、既存の相対パス構成を維持してください。
3. online-serverを再起動し、本体の公開先へ更新を反映します。
4. 参加者全員がページを再読み込みし、v3.1.202で「パーティー」から選びます。

相撲の通信仕様はsumoVersion523:1です。旧サーバーでは新作の開始を案内付きで止めます。タワーの通信仕様は4のままです。

**この成果物は実装とZIP作成・保存までです。公開先への適用、サーバー再起動は行っていません。**
