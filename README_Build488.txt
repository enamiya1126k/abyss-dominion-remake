【まな板 → テーブル → 床】
「切るな！」中の有効な誤打を、試合中累計で数えます。
1〜7打：まな板の亀裂・分離・大破・全壊。8打目からテーブルに到達します。
8〜14打：テーブルの亀裂→裂け目→穴→大きな崩落→残骸。各打で素材が切り替わります。
15〜26打：残った木片が1打ごとに崩れ落ち、26打でテーブルが完全になくなります。
以降は床で千切りを続けられます。キャベツと包丁・料理人も床側へ下がります。
合図の切り替わり、再接続、結果画面でも破壊状態は残り、新しい試合でだけ元に戻ります。
減点は従来どおり「切るな！」1回につき−80点、下限0点。同じ合図中の追加破壊は追加減点なし。

【見た目】
背景に焼き込まれていたテーブルを除き、床背景・壊れるテーブル・まな板を別々に描画します。
テーブルの穴からは床が見えます。まな板の残骸を長方形に切り取る処理を廃止しました。
包丁を、金属刃・木の柄・真鍮の金具がある生成素材へ差し替えました。
連打で振り上げだけが繰り返されないよう、タップ直後に刃が当たる姿から反動へつなぎます。
左右ボタンは押せる範囲を保ち、立体的な縁・質感・次の手の発光・85msの押し込み反応を追加しました。
スマホでは不要なA/Dキー案内を「交互にタップ」へ変更。「切るな！」では「手を止めて！」を表示します。
木片は角のある形で飛散。素材ラベル、警告札、スコア枠、時間バーも調整しました。
演出を減らす設定では、追加の反動・飛散アニメーションを抑制します。
結果の王冠は絵文字置換されない形へ変更。魔物の足元を標準56/64の基準に合わせて山頂へ補正しました。
結果には、まな板の全壊・テーブルへの誤打・テーブル全壊も表示します。
