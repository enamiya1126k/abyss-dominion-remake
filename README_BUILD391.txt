第二章限定魔物・第九弾

第二章限定は合計63体（N/R/SR/SSR/UR/LR/神話を各9体）、固有252技、504ポーズ、専用ペア21組。

今回は短剣、黒羽の細剣、紅羽の双剣、鐘槌と聖鐘、月輪と日輪の杖で個性を分けた。

更新方法
このZIPはBuild390 / v3.1.70への上書き差分パッチ。
Build389以前なら、先にBuild390まで適用してください。
1. ZIPを展開し、中身を既存の abyss-dominion-remake フォルダーへコピー。
2. src・assetsなどを既存フォルダーに統合し、同名ファイルを上書き。
   srcの中へさらにsrcを作らないようにしてください。
3. GitHub Desktopで変更を確認し、コミット → Push origin。
4. 公開更新後にページを再読み込みし、v3.1.71を確認。
セーブ初期化は不要。戦闘中に更新した場合は、その戦闘を終えてから再探索へ入り直してください。

新しい出現方法：再訪で部隊交代
魔物が63体になったため、下記3部屋は従来の部隊と新部隊が再訪ごとに交代する。
地域を踏破後、拠点へ戻り、同じ地域の再探索に入り直すと交代する。
旧キャラと旧ペアにも次の再訪で会える。新部隊がいなければ、もう一度入り直そう。
戦闘の敗北・再挑戦・セーブ再開では、その訪問の部隊は変わらない。
進行中の戦闘は旧部隊のまま再開でき、1部屋で新旧両方の報酬を重複取得することはない。
1地域の再探索3部屋を倒したときのLR装備報酬は継続。

・境界の森「倒木の小径」／Lv1,050
  黒羽の細剣姫ニゼル／紅羽の双剣姫シャルネ／根灯の短剣姫リティア／ch2_lilica
・深淵の回廊「眠りの裁定」／Lv2,000
  宵鐘の護姫フェルネ／暁鐘の聖姫クラリス／ch2_noctelle／ch2_auriane
・理の中枢「修復の中枢」／Lv5,400
  月冥の翼姫ルナリア／日輪の翼姫ソラリア／ch2_meliora／ch2_elyselle
その他の12部屋は従来どおり。新旧合わせて全63体の捕獲経路を維持している。
物語ボス・宝物庫・拾った鍵・物語の初回報酬を再取得する変更はない。
敵は役割に合う6枠の実装備と魔法陣を使い、物理役と魔法役で武器を選び分ける。

今回の魔物・固有技（MPは基本消費量）

N 根灯の短剣姫リティア
境界の森・再探索「倒木の小径」（再訪で交代）
倒木の内側に残った灯りから生まれた案内役。根灯を掲げ、迷い込んだ黒羽と紅羽の双子に帰り道を示す。
・根灯・絡み根の短剣／MP9／再使用待ち2ターン：風属性1.00倍。速度15%低下（2ターン）。
・帰路を照らす灯り／MP13／再使用待ち3ターン：生存味方全体のHP14%回復。
・根灯の祓火／MP12／再使用待ち3ターン：生存味方全体の状態異常と弱体を浄化。
・木漏れ日の抜け道／MP12／再使用待ち3ターン：味方全体に最大HP10%の障壁、回避15%上昇（2ターン）。
攻略：低燃費の回復役。足止めと回避で双子を支えるが、全体攻撃や命中強化で崩せる。

R 黒羽の細剣姫ニゼル
境界の森・再探索「倒木の小径」（再訪で交代）
封樹に奪われた紅い羽を探す双子の姉。黒羽の細剣で浅い傷を刻み、妹だけが読める軌跡を残す。
・黒羽・紅糸の刻傷／MP14／再使用待ち2ターン：闇属性1.00倍。80%で出血（3ターン、最大HP2.5%）。
・羽根縫いの細剣／MP15／再使用待ち2ターン：闇属性1.10倍。回避18%低下（2ターン）。
・紅糸を辿る刺突／MP14／再使用待ち1ターン：闇属性1.25倍。出血中には威力1.50倍。
・黒羽の身替わり／MP15／再使用待ち3ターン：自身に最大HP15%の障壁、回避20%上昇（2ターン）。
攻略：出血が双剣連撃の起点。出血を治すか、速い姉を先に止めると妹の追撃が弱まる。

SR 紅羽の双剣姫シャルネ
境界の森・再探索「倒木の小径」（再訪で交代）
姉が刻んだ紅糸を追う双剣の妹。失われた羽を取り戻すため、二本の剣を重ねて封樹の呪いを切り開く。
・紅羽・双刃追葬／MP18／再使用待ち1ターン：火属性1.55倍、防御20%無視。出血中には威力1.60倍。
・癒えぬ紅の剣痕／MP17／再使用待ち2ターン：火属性1.10倍。HP回復35%低下（2ターン）。
・散華・紅羽の剣雨／MP20／再使用待ち2ターン：敵全体に火属性0.95倍、防御15%無視。
・帰り道の約束／MP17／再使用待ち3ターン：自身に最大HP16%の障壁、攻撃20%上昇（2ターン）。
攻略：出血相手への連撃が強烈。出血耐性・浄化・物理軽減を用意し、姉妹の片方を集中して倒す。

SSR 宵鐘の護姫フェルネ
深淵の回廊・再探索「眠りの裁定」（再訪で交代）
眠りの裁定を告げる古い鐘から生まれた姉妹機の姉。槌を鳴らして呪いを引き受け、妹の澄んだ鐘へ受け渡す。
・宵鐘・鎮めの槌／MP21／再使用待ち2ターン：闇属性1.25倍。攻撃20%低下（2ターン）。
・黒鐘楼の守り／MP25／再使用待ち3ターン：味方全体に最大HP20%の障壁、防御20%上昇（2ターン）。
・静寂を破る返響／MP22／再使用待ち1ターン：闇属性1.50倍。攻撃低下中には威力1.45倍。
・宵の弔鐘／MP23／再使用待ち3ターン：生存味方全体のHP18%回復。
攻略：姉妹がそろうと攻撃後に全体浄化。弱体を重ねるだけでは押し切れないため、片方の足止めや集中攻撃が有効。

UR 暁鐘の聖姫クラリス
深淵の回廊・再探索「眠りの裁定」（再訪で交代）
裁定の夜を明かす青い水晶鐘の妹。姉が引き受けた呪いをほどき、二つの音を重ねて閉ざされた回廊を照らす。
・暁鐘・偽りの加護崩し／MP24／再使用待ち2ターン：光属性1.15倍の魔法攻撃。敵の強化を1つ解除。
・澄鐘の赦し／MP25／再使用待ち3ターン：生存味方全体の状態異常と弱体を浄化。
・夜明けの祝鐘／MP27／再使用待ち3ターン：生存味方全体のHP22%回復。
・青晶の審鐘／MP25／再使用待ち1ターン：光属性1.55倍の魔法攻撃。攻撃低下中には威力1.45倍。
攻略：浄化・回復・強化解除を兼ねる支援役。高い単体火力で姉妹を分断し、連携を止める。

LR 月冥の翼姫ルナリア
理の中枢・再探索「修復の中枢」（再訪で交代）
修復機構の夜側を護る月翼の姉。欠けた記憶を月輪へ集め、妹の太陽へ渡すことで失われた魔力を巡らせる。
・月冥・欠けゆく夜／MP28／再使用待ち2ターン：闇属性1.20倍の魔法攻撃。防御22%低下（2ターン）。
・欠月の追輪／MP30／再使用待ち1ターン：闇属性1.65倍の魔法攻撃。防御低下中には威力1.50倍。
・月蝕の魔力封じ／MP31／再使用待ち3ターン：敵全体に闇属性0.85倍の魔法攻撃。MP回復45%低下（2ターン）。
・黒月の羽衣／MP29／再使用待ち3ターン：味方全体に最大HP18%の障壁、命中18%上昇（2ターン）。
攻略：防御低下から月輪で追討し、姉妹連携で魔力を回収。MP回復阻害や片方の撃破で長期戦の循環を断つ。

神話 日輪の翼姫ソラリア
理の中枢・再探索「修復の中枢」（再訪で交代）
修復機構の昼側を護る日翼の妹。月が集めた記憶を日輪で再び灯し、永い夜の先へ姉の手を引いて進む。
・日輪・朝焼けの裁き／MP30／再使用待ち2ターン：光属性1.25倍の魔法攻撃。攻撃22%低下（2ターン）。
・白昼の天光／MP33／再使用待ち1ターン：光属性1.75倍の魔法攻撃。防御低下中には威力1.45倍。
・巡る朝の祝福／MP31／再使用待ち3ターン：生存味方全体のHP24%回復。
・日輪の天蓋／MP32／再使用待ち3ターン：味方全体に最大HP20%の障壁、防御22%上昇（2ターン）。
攻略：回復と障壁で月冥を支え、連携のたび姉妹のMPを補う。回復阻害を重ねて片方に火力を集めたい。

専用ペア共鳴：今回3組、合計21組
同じ陣営で2人とも生存中、通常攻撃・固有技・支援技のあとに相方が連携する。
各キャラ1ラウンド1回、1組で最大2回。追加MPなし。連携から連携は再発動しない。
同じキャラの複数個体、同ラウンドの蘇生やセーブ再開では回数は増えない。
戦闘不能・捕獲・隔離・追加行動の封印で停止。敵も同じ連携を使う。

■ 双羽・紅糸乱舞（ニゼル＋シャルネ）
相方が単体へ物理1.20倍×3連撃、防御25%無視。出血中の標的には各打撃1.92倍。姉の出血から妹の双剣へつなぐ。

■ 双鐘・宵暁の赦し（フェルネ＋クラリス）
相方が敵全体へ2.30倍、防御20%無視（攻撃・魔力の高い方）。追撃後、生存味方全体の状態異常・弱体を浄化してHP10%回復。戦闘不能の復活や固有スキルの再使用待ち解除は行わない。

■ 双輪・日月巡環（ルナリア＋ソラリア）
相方が敵全体へ魔法2.60倍、防御30%無視。追撃後、姉妹2人のMPを最大MPの12%ずつ回復。MP回復阻害の影響を受ける。1組1ラウンド最大2回、複製個体では回数を増やせない。

双羽：ニゼルの出血からシャルネの追討へつなぐ。連撃中に敵が倒れたら次の敵へ切り替え、出血による追加威力を判定し直す。
双鐘：追撃後に生存味方を浄化し、その後に回復する。回復阻害・MP回復阻害も浄化対象。味方の強化を維持する。
戦闘不能の味方は浄化・回復対象に含めず、固有技の再使用待ちを戻すこともない。
双輪：追撃後に姉妹2人だけがMP12%を回復。最大MPを超えず、MP回復阻害を受ける。
戦闘中の使用回数は保存され、複製個体や再読み込みでMPを無限回収できない。
MP回復時は既存の魔法陣の処理を使うため、「魔力反転」の代償も適用される。

捕獲・育成
新7体も通常の捕獲結晶で仲間にできる。所持枠の空きが必要。
捕獲率上限はN65% / R55% / SR42% / SSR32% / UR24% / LR18% / 神話12%。
実際の成功率はHP・レベル差・状態異常・装備などに応じて変化する。
捕獲後も固有4技とペア連携を使える。手持ちの装備・魔法陣で育成し、敵専用装備は持ち越さない。
第一章の通常遭遇・通常召喚には混ざらない。
