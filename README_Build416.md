# ABYSS DOMINION — ⑤ 統合差し替え版

**Build416 / v3.1.95 / セーブ形式84**

今回の①〜⑤をまとめた差し替えZIPです。基準のBuild411へ、①操作・合成（412）、②魔法陣・キャラ表示（413）、④バランス実装（415）、今回の統合修正（416）を累積しています。③は設計工程です。①〜④を個別に入れ直す必要はありません。

## 差し替え方法

1. ZIPを展開し、**`index.html` と `src` の中身を、既存ゲームの同じ場所へ上書き**してください。Build411・412・413・415のいずれからも適用できます。
2. 既存の `src` や `assets` フォルダ全体は削除せず、ZIPに入っていないファイルを残してください。このZIPだけで新規設置する形式ではありません。
3. 更新後に再読み込みし、ホームの表示が **v3.1.95** になっていることを確認してください。セーブキーと形式は維持しており、セーブ初期化は不要です。ブラウザーのサイトデータを消す必要もありません。

`docs`・`tests`・`tools` は説明と検証用です。通常のゲーム公開には不要です。サーバー差し替えファイルはありません。

## 今回の追加修正

- スキルを素早く二度押したとき、待機処理の隙間でMPと行動を二重消費しないようにしました。
- 結果画面を開いている間に勝敗処理が重なっても、報酬・EXP・戦績を二重に加算しません。終了済み戦闘への遅れた入力も受け付けません。
- 通常戦闘の結果画面に、戦闘補正を外した後のHP・能力上昇値を表示します。
- 大きな戦闘補正を外す際、わずかに生き残っているキャラが丸め処理でHP0になる問題を修正しました。戦闘不能はHP0のままです。
- 敗北時は補正解除後に救出HPを設定し、「HP1で救出」と実際の状態を一致させました。
- 第二章は補正解除後に報酬を確定・保存し、再読み込み前後のHPを一致させました。保存失敗時の再試行も確認しています。

深淵・十神の基礎能力、成長、権能、スキルの性能は変更していません。④のランク・ペア・攻略用の調整値も維持しています。

## 開発者向け再実行

既存ゲームへ差し替え後、Node.js 24でリポジトリ直下から実行できます。

```bash
node --test tests/*.test.mjs
node tools/build416/render-budget.mjs
node tools/build416/online-smoke.mjs
node --max-old-space-size=384 --expose-gc tools/build416/replay-integration.mjs
```

戦闘検証ツールはソースのSHA-256を照合します。別ビルドへ変更した場合は、そのまま同じ結果として実行できません。代表シード照合では、旧検証の初回セーブ生成条件を `combat-replay-resolution.json` から読み込んで再現します。新たな勝率測定と、④の過去検証の再現は区別しています。
