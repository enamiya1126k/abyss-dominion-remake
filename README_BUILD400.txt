ABYSS DOMINION Build400 / v3.1.80
Build399へ上書きする差分パッチです。セーブ初期化は不要です。

導入
ZIPを展開し、中身を今のゲームフォルダーへ同じ階層で上書きしてください。
index.html・src・assetsをまとめて反映し、ページを再読み込みしてください。
ホームの表示版数はv3.1.80です。Build399までのファイルが必要です。
このZIPの受け渡しでは、公開サイトへのコミット・Push・公開更新は実行していません。

使い方
第二章解禁後、ホーム右上の歯車（設定）を押してください。
名前の設定の下に「ホームの風景」が追加されます。
好きな風景を押すと保存され、プレビューと「選択中」が切り替わります。
戻るとホームへ反映。アプリやページを開き直しても選択を保持します。
「環境モーション」でON／OFFを切り替えられます。この設定も保存します。
いつもの城下町にも、いつでも戻せます。

新しい5種類
1. 境界の森：水面の流れ、葉の揺れ、蛍。
2. 黒根の侵食域：篝火の揺らぎ、舞い上がる火の粉。
3. 深淵の回廊：流れる薄霧、漂う紫の光。
4. 天律の聖域：雲の流れ、旗の揺れ、光の粒。
5. 理の中枢：星環の巡り、脈打つ光、浮遊する粒。
既存の「はじまりの城下町」を含めて、合計6種類から選べます。
画像一覧HOME_SKINS_BUILD400.jpgは、左から上記1～5の順です。

解禁条件
第二章・第二章ガチャと同じ判定を使用します。
100階到達条件を満たし、勇者一行との最終決戦に勝利すると5種類を同時に解放します。
すでに第二章を解放しているセーブでも、そのまま選べます。
各地域の踏破や追加の通貨消費は不要です。
自動で背景は変更せず、自分で選ぶまでは今までの城下町を表示します。
第一章のプレイヤーには選択欄を表示しません。

見た目と動き
今のホーム背景のドット絵に合わせた、新しい縦長背景5枚を制作しました。
地面中央に仲間を並べる空間を残し、風景の動きは仲間やボタンの背面に配置しています。
背景と環境モーションは同じ座標で表示し、画面比率が変わっても位置がずれないようにしています。
動きは水面・葉・火・霧・旗・星などの局所的な演出です。
端末の「視差効果を減らす」が有効な場合は静止表示になります。
ページを隠したときは環境モーションを停止し、他の画面へ移ると監視を解除します。
背景読込に失敗した場合は城下町の静止画へ戻します。保存済みの選択は削除しません。

保存と互換性
選択とモーション設定はsettings.homeSkin400だけに記録します。
セーブのスキーマ版は84のまま。既存セーブへの強制初期化や新規の進行移行はありません。
保存に失敗した場合は元の選択へ戻し、エラーを表示します。
連続タップ中は重複保存を防ぎます。
不明なスキンIDや第二章未解禁のデータを読み込んだ場合は、従来の城下町を表示します。
戦闘・所持品・キャラ・装備・魔法陣・ガチャ・報酬の内容はBuild399と同じです。
