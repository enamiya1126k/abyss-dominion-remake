## 今回の変更

- 共闘レイドは最大99ラウンド。全滅、討伐、中断では従来どおり終了します。1日3回、ボスが6ラウンド目から攻撃するルールは継続します。
- サーバー更新時に継続中のオンライン挑戦は、追加の回数消費なしで上限99へ移行します。終了済みの挑戦結果は書き換えません。
- 新しく保存するオフライン挑戦も最大99ラウンドです。4体を手動操作しても記録を保存・再開・検証できます。
- **更新前に保存済みの挑戦券は最大10ラウンドのままです。** 途中の操作や送信待ちの結果を正しく再現するためです。一覧に上限と「更新前に保存した挑戦」を表示します。
- 敵味方のHP・MPは第一章・第二章に合わせて小さく表示し、カード幅に応じて全桁が収まるよう調整します。HP・MPの値は省略しません。
- 活躍表は、キャラごとの与ダメージと回復を横並びで確認できます。被ダメージ・蘇生・撃破は詳細を開いて読めます。最高殊勲の計算方法は継続します。
- レイドの終了理由・ボスへのダメージ・活躍表・送信状況・報酬状況を、一つの結果画面にまとめました。未送信、受付済み、期限切れを区別します。順位報酬を早期に確定したような表示にはしません。
- 編成・装備・スキル画面には、画像生成で制作した金属フレーム、紫水晶のボタン、魔法陣背景を使用しました。既存の4体配置、装備6枠、スキル枠、ナビ、操作位置とサイズを保っています。

召喚価格・提供割合、キャラ性能、装備・スキル効果、再戦レベル進行は変更していません。転生システムは追加していません。
