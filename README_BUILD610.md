# Build610 — 島の待機船・上陸地点の保存・ゲーム中止

Build609へ重ねる更新パッチ。アプリ3.1.289、ランナーズ通信ルール20。

## 暴走船

- 三つの島の出口に次の船を常時待機させる。最初の船の到着を待たずに乗り換えられる。
- 島を攻略し、参加者全員が待機船に乗ると1秒後に出航する。ソロは自分の乗船で出航する。
- 島で待つプレイヤーを、旧船の通過時に「乗り遅れ」として死亡させる処理を撤去する。
- 移動船と固定桟橋が同じ高さで重なっても、現在立っている地面を優先する。船に勝手に乗り移って運ばれる現象を防ぐ。
- 最初の上陸を保存する。死亡後は上陸した島の入口、攻略後は島の出口から再開する。攻略済みの状態と取得済みスターを維持する。
- 島の帰還足場に振り子が届かない位置へ移動する。船の接触そのものにダメージはない。
- 出航後に島へ飛び戻って取り残された場合も、死亡数を増やさずその島から再開する。

## プレイ中の終了操作

パーティーのミニゲーム画面のヘッダー右端に終了操作を追加する。

- 部屋主は「中止」。確認後、全員のゲームを中止して一覧へ戻す。部屋・参加メンバーは維持し、別ゲームを選択できる。
- 参加者は「退出」。確認後、自分だけパーティーから退出する。他の参加者のゲームは続く。
- ロビー・結果画面・パーティー一覧には追加しない。通常レース画面も対象外とする。
- サーバーで部屋主権限とゲームIDを検証し、古い画面から別のゲームを中止できないようにする。
- ゲーム終了時に既存のゲーム削除・参加費取消処理を使用する。結果や勝利報酬を生成しない。

## 確認

自動テスト285件通過。島で80秒待機した場合の死亡なし、固定桟橋の保持、1〜4人の待機船出航、島での復帰、攻略状態の保存、3航路のゴール解放を確認する。ゲーム中止の権限・古いIDの拒否・ゲーム削除・パーティー維持を確認する。旧来の通信・移動・ボス・ギミックの回帰テストも通過する。
