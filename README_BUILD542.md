## 新作：魔王城の爆弾リレー！

４人対戦、30秒×３ラウンド。空席はAI。全員同じ性能です。

| 操作 | 効果 |
| --- | --- |
| 床をタップ／指で行き先変更 | 障害物を避けて目的地へ移動 |
| 爆弾を置く | 2.5秒の導火線。同時に２個まで |
| けり返す | 近くの爆弾を自分から離れる方向へ。重なっている場合は向いている方向へ |
| 止まる | 現在の移動を中止 |
| キーボード | 矢印で移動、Spaceで設置、Kでキック、Escapeで停止 |

**蹴っても導火線は戻りません。** 蹴るたび爆風が伸び、最大４マスに。最後に蹴った人の攻撃になるため、残り１秒のお返しで逆転できます。移動中も別の指で設置・キックできます。

- 爆風は十字。柱は爆風を止め、箱は壊れるときだけ後ろを守ります。爆弾同士は連鎖爆発。
- 箱から出るシールドは爆風１回を防ぎます。落下は防げません。
- ひびのある床は爆風を受けると一時的に穴へ変化。18秒・24秒で外周が崩壊します。崩壊前には表示と床の色で予告します。
- 各回♡２個。吹き飛ばされた先が穴・崩壊した床なら脱落。次の回で全員復活します。
- 相手を倒すと＋１点、ラウンド勝利は＋３点。時間切れは生存者の残り♡が最多の人に勝利点。同数なら同時勝利。
- ３回の総得点 → 勝利数 → 撃破数で最終順位。同じなら同順位。自爆・単独落下に撃破点はありません。
- 切断・ホーム滞在中はAIが代行し、再接続で操作へ復帰。結果から再戦・一覧へ戻れます。

## ビジュアルと軽量化

画像生成の組み込みツールで、専用カバー、魔王城の背景、足場・柱・箱・爆弾のアトラス、基本４種の専用駒を新規制作。新作内だけで使用し、他のゲームの絵は変更していません。その他の相棒は元のキャラ表示を使います。

使用画像：`assets/bomb542/cover.webp`、`abyss.webp`、`atlas.webp`、`players.webp`。最終プロンプトは `docs/build542/art-prompts.json` に収録。

背景と足場をキャッシュし、描画解像度を最大1.5倍へ制限。入力・当たり判定はサーバー側、50ms刻み。配信は100msごと、保存は約２秒ごと／フェーズ変更時。画面の組み直しは状態が切り替わる場合に限定しています。
