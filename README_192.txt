ABYSS DOMINION REMAKE 192 差し替えパッチ

基準: 191完成版
バージョン: 2.11.75-build251

【192の修正内容】

1. 闇市場の高レベル魔物と価格
- 通常魔物は、階層の約3倍までのレベルなら従来どおりランダム価格で並びます。
- それを超える高レベル魔物には、レベル・レア度・商品の格に応じた最低価格を設定しました。
- Lv.9999級の魔物も出現できますが、性能に見合う非常に高い価格になります。
- UR・LRなどの装備や高レベル装備は、従来どおりランダムな掘り出し物として出現します。

2. 闇市場へ出さない限定魔物
- 深淵勢力・十神・シリアルコード限定・専用入手限定の魔物を闇市場の抽選から除外しました。
- 既に所持している魔物や、別の正規入手経路には影響しません。
- 通常のSR〜神話魔物は引き続き抽選されます。

3. 回復用品の連続購入
- ハイポーションなどを購入しても、闇市場の先頭へ戻らなくなりました。
- 表示位置を保ったまま、所持GOLD・所持数・残り購入数だけを更新します。
- 同じ商品を続けて押して購入できます。各商品10個までの上限は維持しています。

4. 深淵スロットの反復プレイ
- 同じ深淵裏街で、所持GOLDがある限り繰り返し回せます。
- 入場料の魔晶石100個は、その部屋で最初に回す時だけ必要です。
- 2回目以降は賭けるGOLDだけで遊べます。
- 直近20回の結果、総回転数、勝利数、累計収支を同じ画面で確認できます。
- 旧版ですでに1回回した部屋は入場料支払い済みとして引き継ぎ、再請求しません。
- AUTO探索はスロットを自動で回しません。連続賭けは必ず手動操作です。

期待還元率は約95.399%です。倍率・履歴・収支は画面内に明示されます。

【適用方法】

このZIPの中身を、191完成版の公開フォルダ直下へそのまま上書きしてください。
ZIP内には192で変更・追加したファイルだけが入っています。

オンラインサーバー側の変更はありません。通常はサーバー再起動不要です。
既存のセーブデータ・オンライン部屋・交換履歴はそのまま利用できます。

【確認項目】

- 同じ深淵裏街でスロットを2回以上続けて回せる
- 魔晶石100個は最初の1回だけ減り、以後はGOLDだけが増減する
- 直近20回の履歴と累計収支が表示される
- 旧版で挑戦済みの部屋でも再挑戦でき、魔晶石を再請求されない
- AUTO探索がスロットを勝手に回さない
- 闇市場へ深淵・十神・シリアル限定魔物が並ばない
- 階層の3倍を大きく超える魔物ほど最低価格が高くなる
- Lv.9999級の魔物が安価な事故商品にならない
- 装備のランダムな価格・レベル抽選は従来どおり
- 回復用品を連続購入しても表示位置が先頭へ戻らない
