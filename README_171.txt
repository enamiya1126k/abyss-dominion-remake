安全性と互換性:
- 他の端末からフレンドIDだけを使って現行セッションへ入ることはできません。現行キー更新直後の通信再試行に限り、直前キーも照合対象になります。
- 取引は同じ取引IDを使って再送し、端末側の受取済み記録で二重反映を防ぎます。
- 復旧待ちは自宅PCサーバーのメモリ上だけに保持します。PCまたはサーバーを終了すると消えます。
- 通常探索の階層、宝箱、ボス、報酬ルールは変更していません。
- 1人オンラインの通常探索同等性を維持しています。

差し替え方法:
- この171は、170から変更・追加されたファイルだけを収録するパッチです。
- ZIP内の「REPLACE_FILES」フォルダの中身を、170適用済みのゲーム本体へ階層を保ったまま上書きしてください。
- 「DELETE_FILES.txt」に記載がある場合だけ、対象の相対パスを削除してください。
- ゲーム本体と`online-server`側は、必ず同じ171の差し替えファイルを適用してください。
- 念のため170適用済みフォルダを複製してから差し替えることを推奨します。
