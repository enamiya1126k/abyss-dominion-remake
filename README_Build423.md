# Build423 / v3.1.102 差し替えパッチ

対象は Build422 / v3.1.101。ZIPの中身をゲームフォルダーへ同じ階層で上書きする。最上位に index.html、その下に src を置く。ゲーム全素材を含む単体配布版ではない。

## 変更内容

- 探索開始の第二章を「第4節・理の中枢」から右の＋で「第5節（最終戦）・原初の聖胎」へ進める。既存の「出発する」で入場する。中枢踏破後は、再開中の探索がなければ第5節を初期選択する。下部の独立した最終戦ボタンは削除した。
- 原初の聖胎の探索・挑戦画面・戦闘で、母の背面に金の多重光輪、十の紋章、光と粒子の装飾を追加した。会話中も母の背面に表示する。装飾は入力を受け付けない。動きを減らす設定ではアニメーションを止める。王室の部屋・移動・接触判定を引き続き使用する。
- 導入9会話、対面14会話、敗北後5会話、エンディング22会話へ改稿した。既存の第二章と同じ、人物が並び、話者を強調する会話画面で表示する。母、えなみ、より、ひで、りおん、リオネル、サイラーンが参加する。サイラーンは王座から記録鏡を通して参加する。
- 「記憶の間」に母の招待・対面・最終エンディングを追加した。敗北後の会話は読了した場合のみ追加する。通常は全14件、敗北後の回想を含む場合は15件となる。旧版の「筋書きのない明日」は「理の中枢・帰還報告」として第4節の結末に位置付けた。読了数は実際の記録から計算し、未読の既存エピソードを勝手に読了扱いにしない。
- Build422の母の読了・勝利・初回報酬記録を継承する。旧文面を途中まで読んでいた場合、そのエピソードの新しい会話を先頭から表示する。Build423内での中断は次の会話から再開する。回想からの閲覧は進行・報酬を変更しない。第三章を追加できる余韻を残した。

## 母の調整

旧版はHP700000、単体攻撃中心で、回復・防御の手番も消費していた。4人の通常行動とペア追撃に対して行動数が少なく、育成済みの返誓ペアの障壁と硝子ペアの回復で攻撃をしのぎやすかった。

新しい戦闘からLv5000、HP1400000、物理攻撃22000、魔力22000、防御6500、魔法防御7000、速度8000、MP720を使う。味方のレベル・編成に応じて敵の数値を変える処理は追加しない。母の基本行動は1ラウンド1回を維持する。

| 手番 | 行動 | 対処 |
| --- | --- | --- |
| 1 | 創世の金糸：全体への光魔法0.85倍、回復量45%低下・2ターン | 弱体解除で回復を戻し、次の全体攻撃の追加倍率を防ぐ |
| 2 | 十灯の帰路：全体への光魔法1.15倍、回復量低下中はさらに1.3倍 | 魔法防御・軽減を整える。先行できる場合はガードも有効 |
| 3 | HPが半分未満なら使用可能な6%回復・浄化、その他は8%HP障壁・20%軽減・浄化 | 部隊を立て直し、強化解除や回復阻害を使って攻める |

この3手を繰り返す。再使用待ち・再唱封印・MP不足に従い、使えないときは別の使用可能な技や通常攻撃へ切り替える。戦闘画面には周期の案内と、母のHP障壁残量を表示する。軽減には通常の強化効果を使い、母に二重の神域障壁を追加する旧処理は適用しない。

敵味方のペア発動・回復・追撃ルール、第一章・第二章の他の敵、味方専用補正、深淵・十神のキャラ性能は変更していない。

## 検証

自動テスト281件を実施し、全件成功した。対象は階層100の進行・再入場、温泉、手動スキル選択直後の閉鎖、自動戦闘、セーブ、既存のペア処理、母の撤退・再戦・報酬の重複防止、第5節への導線、途中会話保存、旧版読了記録、回想の読み取り専用性、キャラと装飾の出力順を含む。

既存の深淵・十神68プロファイルについて能力・MP・スキルを基準データと照合した。オンラインへの送信能力値にオフライン補正が混入しない既存テストも成功した。オンラインサーバーのコードは変更していない。

母の戦闘は実際の戦闘関数を用い、5編成×3育成段階×3乱数条件と、スクショと同じ4人・同じレベルの比較編成3戦、合計48戦を実施した。30勝18敗で、進行停止や40ラウンド上限到達はなかった。

Lv5500・LR装備6枠（装備Lv5500・+10）・指定のLv1魔法陣・自動操作で、次の3編成が3条件すべてで勝利した。

| 編成 | 勝利まで |
| --- | --- |
| セリア／カルミア／ロスティア／アルテア | 8〜10ラウンド |
| ネメシア／エヴェリア／アエリエル／ヴェスペラ | 3〜4ラウンド |
| ノエル／アウレ／イオネ／ノクティア | 11ラウンド |

スクショ比較用はセリアLv3670、カルミアLv3608、ロスティアLv10000、アルテアLv6905で3勝、8〜9ラウンドだった。終了時の平均HP残存率は約33〜38%だった。実際のユーザーセーブは取得しておらず、装備・魔法陣・強化状態までの完全再現ではない。最適な高火力編成では短期勝利も起こる。

検証ログと条件は docs/build423、再実行スクリプトは tools/build423 に収録した。

## 確認できていない範囲

ブラウザーからローカル版を開く試行が接続制限で失敗したため、iPhone Safari実機での見た目・タップ・フレームレートを確認したという扱いにはしない。コード上の装飾順序・非干渉、会話と導線の実関数を確認した。実オンライン接続試験も今回の実施範囲には含まれない。

既に戦闘中のセーブのHP・MPや行動順を強制再生成しない。新しい母の数値・3手の行動周期は、更新後に開始する戦闘で適用する。更新前から進行中の戦闘は旧数値を維持するが、同名スキルの更新後の内容は読み込まれる。
