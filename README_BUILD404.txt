ABYSS DOMINION — Build404 / v3.1.84
② 装備画面の改修

【適用方法】
Build403（v3.1.83）適用済みのゲーム用・差分パッチです。
ZIP内の index.html・src・assets を、ゲームの同じ場所へまとめて上書きしてください。
既存フォルダーそのものの削除やセーブ初期化は不要です。
このZIP単体では起動できません。Build403までの既存ファイルを残してください。
反映後に再読み込みし、ホームの表示が v3.1.84 になったことを確認してください。
オンラインサーバーの更新は不要です。

【今回の変更】
1. 第二章の装備獲得表示
宝箱・戦闘報酬・精鋭の限定装備に、装備そのもののアイコンを表示。
現在の装備レベル・強化値を反映した性能、オプション、固有効果などの備考を小さく併記。
通常所持・予備BOX・王装保管庫のどこへ入った装備も照合する。

2. スロット厳選
未鑑定の小さな◆に共通の空欄用スタイルが混ざる問題を解消。
鑑定済み◆のサイズ・配置を維持し、左から1～4段目それぞれの品質色を表示。
例：伝説・希少・希少・希少なら、金・青・青・青。
未鑑定の装備も、武器庫の「厳選」から初回抽選を開ける。

3. 一括ロック管理
武器庫・装備管理に「一括ロック管理」を追加。合成画面からも開ける。
種類・状態・レア度で絞り、表示中を全選択／N・R／同名／選択解除で選べる。
同名選択は、合成画面から開いたときに表示。
選択した装備をまとめてロック・解除できる。
お気に入りも解除したい場合だけ「解除時にお気に入りも解除する」をチェックする。
装備中・素材使用不可の装備は、ロック解除後も素材にはできない。
保存できない場合はロック状態を元へ戻す。

4. 専用の錠前素材
黒鉄と金のドット絵の錠前を新規作成し、ロック中の装備カード下角へ表示。
ロックを解除するとマークが消える。絵文字は使用していない。

5. 装備合成強化
黒・金の既存フレームへデザインを統一。強化対象と素材に装備アイコンを追加。
ロック・お気に入り・装備中・素材使用不可による除外数を表示する。
素材一覧の120件制限を取り除き、使用可能な装備をすべて選べるようにする。
本文だけをスクロールし、獲得EXP・強化後レベル・実行ボタンを別の下部欄へ配置する。
一括ロック管理から戻ると素材候補が更新され、使える選択とスクロール位置を引き継ぐ。
装備中の参照を再確認し、古い選択は拒否する。保存失敗時は素材と強化を元へ戻す。
