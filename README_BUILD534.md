## ゴミが釣れたら

ゴミの釣果は「＋○点で回収」のボタンで得点になります。５秒経過時・試合終了時も自動で回収されます。餌に変えたり、連鎖に使ったりはできません。連打で得点が二重に入らないことも検証しています。

通常抽選の「変わり種・ゴミ」枠は、追加前と同じ合計４％。その枠を既存の４種類と新しいゴミ８種類で分けます。ゴミばかり釣れる割合にはしていません。餌使用時や既存の固定連鎖をゴミへ置き換えることもありません。ヌシ・特殊ルアー・竿強化・距離や餌による育成は引き続き利用できます。

## 現実の魚について

無人島や海辺での学びにつながる、生息環境・生態・危険への気づきを入れました。食中毒、毒のトゲ、歯や突進によるけがを分けて表示しています。図鑑は採取・同定・食用判断の道具ではありません。

獲物数はゲーム内の項目数で、生物学的な種数とは異なります。重さ・得点・難易度・距離別の出現・餌連鎖はゲーム設定です。画像は生成したイメージで、現実の魚を見分ける根拠にはできません。
