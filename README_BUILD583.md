# Build583 — 早押し！魔王のイス取り

**Build582適用済みの本体へ上書きする差分。バージョン3.1.262。**

## 入れ方

1. 対戦を終了し、このZIPを展開する。
2. 中身をゲームのルートへ、フォルダ構成を保ったまま上書きする。
3. オンラインサーバー側も、`online-server/src/` と同階層の共有 `src/` の変更を適用して再起動する。
4. 全員が画面を再読み込みし、パーティー一覧の先頭にある「早押し！魔王のイス取り」を選ぶ。

本体だけの更新では遊べない。サーバーにも同じBuild583が必要。セーブデータの削除・初期化は不要。

## 遊び方

- ４人対戦。空席はAI。所持している相棒とプレイヤーカラーを使用する。
- 音楽中は待ち、「座れ！」の合図で空席をタップする。音OFFでも画面の合図で遊べる。
- 普通のイス100点、金のイス150点。１回に座れるイスは１つ。
- ほかの人に取られたら、別の空席を狙える。
- 音楽が止まる前に押すと、その回はフライングでお休み。持ち点は減らない。
- 全８回戦。毎回全員復帰。７・８回戦は得点２倍、最終回は金のイス１つ（300点）。
- 合計点で勝負。同点は同順位。終了後に「もう一度」または一覧へ戻れる。
- PCはイスをクリック、１〜３キー、またはTabで選んでEnter。切断・ホーム滞在中はAIが引き継ぐ。

## 検証

- 新ゲームの判定９項目、通信３項目、キャッシュ２項目を確認。
- 回転寿司・エレベーター・溶岩の通信回帰10項目を確認。合計24項目を通過。
- ４本のWebSocket接続による争奪・表示一致、偽装した時刻・重複入力・古い回への入力の拒否を確認。
- Chromiumのタッチ画面320×568／390×844／844×390で、ロビー、フライング、復帰、得点、再戦、音楽停止、横向き表示を確認。
- 本体の全288スタイルシートとimport mapを適用した画面でも３サイズで操作・表示を確認。
- iPhone Safari実機と公開サーバーへの反映後の動作は未確認。
