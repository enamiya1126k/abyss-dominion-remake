更新方法
このZIPはBuild391 / v3.1.71への上書き差分パッチです。
Build390以前なら、先にBuild391まで適用してください。
1. ZIPを展開し、中身を既存の abyss-dominion-remake フォルダーへコピー。
2. src・assetsなどを既存フォルダーに統合し、同名ファイルを上書き。
   srcの中へさらにsrcを作らないようにしてください。
3. GitHub Desktopで変更を確認し、コミット → Push origin。
4. 公開更新後にページを再読み込みし、v3.1.72を確認。
セーブ初期化は不要。戦闘中に更新した場合は、その戦闘を終えてから再探索へ入り直してください。

今回の魔物と固有技（MPは基本消費量）

N 栞の書姫ティレア
黒根の侵食域・再探索「飢えた根脈」（再訪で交代）
侵食された書庫から逃れた栞の精霊。羽根の短剣で呪文を書き足し、夢に迷う双子の帰る頁を守る。
・栞刃・墨霞の一筆／MP9／再使用待ち2ターン：風属性1.00倍。命中16%低下（2ターン）。
・帰り道の頁／MP14／再使用待ち3ターン：生存味方全体のHP15%回復。
・呪文の消し跡／MP12／再使用待ち3ターン：生存味方全体の状態異常と弱体を浄化。
・迷わぬ栞／MP12／再使用待ち3ターン：味方全体に最大HP10%の障壁、命中15%上昇（2ターン）。
攻略：低燃費で浄化と回復を担当。命中低下を治して支援役を先に崩そう。

・幻眠・夢渡りの扇／MP15／再使用待ち2ターン：闇属性0.80倍の魔法攻撃。75%で睡眠（1ターン）。
・宵霞の帳／MP17／再使用待ち2ターン：敵全体に闇属性0.75倍の魔法攻撃。攻撃15%低下（2ターン）。
・夢底への誘い／MP14／再使用待ち1ターン：闇属性1.20倍の魔法攻撃。睡眠中には威力1.50倍。
・夢繭の羽衣／MP16／再使用待ち3ターン：味方全体に最大HP12%の障壁、回避15%上昇（2ターン）。
攻略：睡眠が夢刈り連携の起点。睡眠耐性や姉への集中攻撃が有効。

専用ペア共鳴
同じ陣営で2人とも生存中、通常攻撃・固有技・支援技のあとに相方が追撃します。
各キャラ1ラウンド1回、1組で最大2回。追加MPなし。追撃から再発動しません。
複製個体・同ラウンドの蘇生・セーブ再開で使用回数は増えません。
戦闘不能・捕獲・隔離・追加行動封印で停止します。敵も同じ連携を使います。

■ 双夢・夢境刈り（モリナ＋エルミゼ）
相方が単体へ3.20倍、防御30%無視（攻撃・魔力の高い方）。睡眠中の標的には5.76倍。眠らせた直後の一撃を狙う双子の連携。

■ 双竜・天鎖解放（ドラシア＋リュシエ）
敵全体それぞれの解除可能な強化を1つ剥がし、相方が物理2.70倍、防御25%無視の追撃。姉妹に最大HP20%の障壁。解除対象は強化効果で、HP障壁や魔法陣そのものは破壊しない。

■ 双冠・夜明けの誓剣（ネメシア＋エヴェリア）
1回目は敵全体へ物理2.10倍、防御20%無視、全体HP10%障壁。同ラウンドにもう一方が連携すると「黒白の終剣」：全体3.80倍、防御35%無視、全体HP18%障壁。終剣の命中直前にHP35%以下の敵には6.08倍。各敵の残HPを個別に判定する。

双夢：姉が睡眠を入れ、妹が特効攻撃を選ぶAI。連携時点の睡眠を確認するため、浄化後に特効は残りません。
双竜：敵ごとに強化を1つ解除してから命中判定・攻撃へ進みます。HP障壁・魔法陣は解除対象に含みません。
双冠：同じラウンドの2人目で終剣へ変化。どちらから始めても発動し、各敵の残HPを命中直前に判定します。
2.1倍や6.08倍は技の威力係数で、最終ダメージは能力・属性・防御・軽減などの影響を受けます。
