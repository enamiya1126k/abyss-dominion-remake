# ABYSS DOMINION Build562 / v3.1.241

「運だけ大運動会」全40種類の説明・効果を照合し、お守りの持ち越し、余韻アンプの端数計算、横取りレンチの連続攻撃、装備画面の残数表示を修正しました。

**Build560またはBuild561に上書きする差分ZIPです。今回は本体とオンラインサーバーの両方を更新し、サーバーを再起動してください。** Build561のBGM修正も同梱しています。

## 修正内容

- お守りバルーン：未使用分を全部残し、毎回装備数ぶんを追加します。1個を装備し、使わなければ残数は1→2→3回。残り3回・装備2個なら次は5回。防いだ攻撃1発につき1回だけ消費します。
- 余韻アンプ：複数個を合計する前に端数を捨てていた計算を修正。前回321m・2個なら321mを加算します。倍率を掛け終わるまで半端な距離を保持します。
- 横取りレンチ：先の攻撃で装備が奪われた後は、その時点で奪える装備を持つ相手から狙い直します。今回装備・今回横取りした物は対象外で、奪った効果は次の回からです。
- 装備画面：攻撃前から攻撃後の残数を表示する問題を修正。補充は一斉公開時、消費は攻撃が届いた時に反映します。未使用のお守りと今回の補充予定、バリア・反射の残りを区別します。
- 成長倍率：画面がまだ今の回なのに、次の回の倍率を表示する問題を修正しました。
- 40種類の説明を手札・一覧・装備画面で統一。装備した回からか、次の回からか、重ねた数の扱い、防御や大技で何を消費するかを明記しています。

巨大な距離の上限追加や倍率の弱体化は行っていません。説明文を変えるだけで持ち越し問題を済ませず、サーバーの保存・消費処理を修正しています。

## 更新手順

1. 現在のBuild560/561プロジェクトに、ZIPのフォルダー階層を保って上書きしてください。
2. **オンラインサーバーも同じ更新済みソースで再デプロイ・再起動してください。** `online-server/src` の2ファイルだけでなく、そのサーバーが参照するルート側の `src/luck` も必要です。ZIPの配置を保って更新すれば揃います。
3. 本体を通常どおり公開し、各プレイヤーが再読み込みして **v3.1.241** を確認してください。
4. 新しく「運だけ大運動会」を開始してください。新サーバーは旧クライアントでの新規開始を拒否し、新クライアントは旧サーバーの場合に更新待ちを表示します。

セーブやサーバーの保存データを削除する必要はありません。既に確定した過去の結果は再計算しません。進行中で一斉公開済みの回も確定内容を保ち、次に計算する回から修正が適用されます。以前に失われたお守り残数は遡って復元しません。

こちらから公開サイトへの書き込み・デプロイは行っていません。
