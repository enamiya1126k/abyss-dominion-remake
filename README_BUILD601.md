# ABYSS DOMINION Build601

Build600に重ねる差分更新。アプリバージョンは3.1.280、魔界ランナーズの通信ルールは11。

## 更新方法

1. ZIPを展開し、Build600の同名ファイルに上書きする。
2. 本体とonline-serverの両方を更新し、サーバーを再起動する。
3. 参加者全員がゲームを再読み込みし、冒険を開始する。

ルールの変更を伴うため、更新前の進行中の冒険は準備画面へ戻る。本更新は公開サイトへの反映を実行していない。

## 動く壁

- 大きな昇降ブロックを、見た目と一致する厚さ145の立体足場として扱う。
- 上面に着地して乗り続けられる。下降・上昇の両方でキャラクターを運ぶ。
- 側面は壁として止まり、壁キックで登れる。
- 下からジャンプすると頭をぶつけて落ちる。接触だけではミスにならない。
- 下降中のブロックと下の足場の間に、キャラクターの高さ28未満しか残らない場合だけ押し潰しとなる。
- 凹みは退避場所として機能する。ブロックに隠れた宝石・属性は、ブロックが離れるまで描かない。

## 協力して集めるスター

全8コースに各3個、合計24個を配置する。各冒険の取得状況はチーム共通となる。

- 寄り道する高所、風や仲間ジャンプで渡る大きな空中の隙間、隠し部屋などに配置する。
- 各コースの1個は、別々の封印台に2人が同時に0.6秒乗ると解放される。
- 解放状態は維持されるため、台を離れてからスターを取りに行ける。
- 誰か1人が取れば全員の成果となる。死亡や再接続で取得済みスターは消えない。
- 画面に3つの星を表示し、結果画面でもチームの取得数を表示する。
- スターはゴールの必須条件にしない。1人用の本ルートを維持し、3個コンプリートは2人以上の目標とする。
- 新しく冒険を始めると、その冒険のスター取得状況はリセットする。

仲間の頭を踏んだ時の上向き速度を550から620へ変更する。仲間ジャンプの後は通常ジャンプを1回追加で使え、風の空中ジャンプも回復する。自分の画面でも同じ接触判定を予測する。

## 共通の旗と死亡表示

- 誰かが新しい旗まで到達すると、待機中の人を含め、全員の復活地点を直ちに更新する。
- 生存中の仲間は移動させない。次の落下・押し潰しから、共通の最新の旗で復活する。
- 旗は全員共通の点灯状態となり、画面にも現在の旗番号を表示する。
- 落下時の「↻」を「死亡○回」に変更する。上部のプレイヤー欄も死亡回数を表示する。
- 死亡は落下・押し潰しの回数。従来のミス数は敵・針などの接触も含み、順位の集計として維持する。結果画面では両方を表示する。

## コースの違い

一律に追加していた蒸気・針・敵の並びを整理する。蒸気を残すのは時計塔と魔王城の2コースのみとする。

| コース | 主な仕掛け・寄り道 |
| --- | --- |
| こもれびアドベンチャー | 樹上の星、仲間ジャンプ、乗れる昇降門、虫の群れ、森の番兵 |
| 風車の空中庭園 | 風と山の登り下り、通常ジャンプでは届かない空中の隙間、山頂の星 |
| つながるスイッチ遺跡 | 橋をつなぐ道、地下の星、対岸に分かれて踏む封印台、石の守護者 |
| カチコチ時計塔 | 回転する火の棒、崩落足場、昇降ブロック上の星、上下に分かれた封印台 |
| 潮騒の浮島 | 満ち引きする2つの海域、干潮時に狙う低い星、離れた島の封印台 |
| 氷晶の回廊 | 転がる氷塊が出る2区画、氷棚の星、滑る床と空中の遠回り |
| 蛍あかりの水晶洞 | 光で示す地下入口、隠し部屋と上段の星、上下の封印台 |
| 灰燼の魔王城 | 火の棒の上の宝物、長い空中の隙間、魔王と連携攻撃 |

寄り道の時間を確保するため、全コースの制限時間を6分とする。属性アイテムの数はBuild600の基本6個・一部隠し部屋に1個のままとする。

## ボスと隠し部屋

石の守護者・魔王は、予告と突進中に正面からの弾を盾で防ぐ。背後への攻撃、踏みつけ、攻撃後の休止中が突破口となる。

2人が1.5秒以内に交互に命中させると、追加2ダメージと1.4秒のよろめきが発生する。連携効果の再発生間隔は2.6秒。参加人数に合わせてHPを増やし、単独時は基本HPを使う。単独でも休止中は正面から攻撃できる。

隠し部屋の入口には、地上から見える宝石の列、欠けた光のアーチ、下へ流れる光を配置する。行き先を文章で説明する表示は追加しない。

`docs/build601/scene-preview.png`はゲームのCanvas描画を使った確認画像である。ブラウザー全体やiPhoneのスクリーンショットではない。iPhone Safari実機のタッチ操作・フレームレートは未確認である。
