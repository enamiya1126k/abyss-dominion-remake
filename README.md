## v2.1.0の主要内容

- 深淵の基礎戦闘能力を従来の10倍、十神を深淵の10倍へ更新。探索、奈落回廊、緊急戦、手動挑戦へ同じ正本を反映。
- 深淵・十神の手動挑戦を「投影体50%／投影体100%／顕現体50%／顕現体100%」の段階解禁へ変更。報酬は欠片1／3／5／10個、全対象共通で1日3戦。
- 奈落回廊を、法廷主へ歩いて接触して戦い、勝利後に奈落孔へ歩いて次の階へ進む方式へ刷新。戦闘前後の道具使用と途中帰還に対応。
- 4 VS 4を全50試練へ拡張。敵能力と報酬を指数成長させ、節目では高レア装備を保証。
- 魔晶石を支払う全費用を10倍へ統一。表示記号を専用ドット絵へ置換。
- 3日周期の武器／防具／アクセサリー／GOLD召喚と、7日間にランダムな1日だけ出現する深淵・十神「天変召喚」を追加。
- GOLD召喚へ99,999,999G（0.02%）を追加。通常・ゲリラの全レア度提供割合を画面内へ明記。
- モンスターの固有値を★1〜10へ拡張。同種族でも生まれ持った★が高い個体ほど強くなる。
- 通常装備を18種から54種へ拡張。武器30／防具12／アクセサリー12に専用ドット絵を割り当て、深淵・十神装備には固有アトラスを追加。
- 探索を50階ごとの属性環境へ変更し、その属性に合うモンスターを配置。属性相性ヘルプを追加。
- 探索HUDへ部隊戦力の大型表示、指数表記、4体分の簡易HP／MPバー、小型取得通知を追加。
- 闇市場を階層基準に縛られない混沌相場へ刷新。高Lv・高＋値・★10・深淵／十神などの極端な一点物が出現可能。
- ホームの重複4 VS 4導線を撤去し、試練画面へ集約。各種絵文字・記号を専用ピクセル素材へ置換。

## 起動方法

ES Modulesを使用するため、ファイルを直接開かずHTTPサーバーから起動してください。

```bash
python3 -m http.server 8080
```

ブラウザで`http://localhost:8080/`を開きます。静的ホスティングへは、このフォルダの中身をそのまま配置できます。

音響はブラウザの自動再生制限に従い、最初のタップ／クリック後に開始します。設定画面で音響ON/OFFとBGM／SE音量を変更できます。

## セーブ互換

- セーブキー：`abyss-dominion-remake-v001`（維持）
- `schemaVersion 1〜44`を`45`へ自動移行。
- 旧深淵・十神ID、旧★、装備、挑戦進行、探索／戦闘チェックポイントを正規化。
- ZIPを上書き配置しても、ブラウザのサイトデータを削除しない限り既存セーブを継続できます。
