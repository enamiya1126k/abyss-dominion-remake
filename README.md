## v2.0.0の主要内容

- Character Bibleを単一の正本とし、深淵7柱・十神10柱の人物像、戦闘思想、属性相性、状態耐性、パッシブ、覚醒条件を統合。
- 全17体へ固有基本技1＋権能4、合計85スキルを実装。敵AIと契約後の味方スキルが同じデータを参照。
- 全17体へ6部位ずつ、合計102個の固有装備と2／4／6部位セット効果を実装。
- 奈落回廊を17体の単独審理＋5つの複合回廊、全22戦として実装。22戦突破後は敵能力が周回ごとに`+50%`。
- 深淵・十神の手動挑戦門、人物・権能・装備資料、緊急戦、欠片、確定契約、固有装備生成を接続。
- 関連機能を100階で解放。顕現40%／60%／100%、緊急戦3%、10階クールダウン、勝利5欠片、敗北時10%で1欠片、契約50／150欠片に統一。
- ホーム、探索、戦闘、深淵、神域、勝利、敗北の7シーンBGMと主要SEを追加。外部音源や第三者サンプルは使用しない。
- 既存レイアウトと基本ゲーム性を維持し、設定画面へ音響ON/OFFとBGM／SE音量を追加。
- 旧IDを新Character Bible IDへ移行し、契約個体、欠片、装備、特殊戦、戦闘再開データを継承。

## 起動方法

ES Modulesを使用するため、ファイルを直接開かずHTTPサーバーから起動してください。

```bash
python3 -m http.server 8080
```

ブラウザで`http://localhost:8080/`を開きます。静的ホスティングへは、このフォルダをそのまま配置できます。

音響はブラウザの自動再生制限に従い、最初のタップ／クリック後に開始します。音が不要な場合は設定画面で無効化できます。

## セーブ互換

- セーブキー：`abyss-dominion-remake-v001`（維持）
- `schemaVersion 1〜43`を`44`へ自動移行。
- 旧深淵・十神ID、旧状態異常、旧戦闘速度、装備、探索／戦闘チェックポイントを正規化。
- 新規セーブの初期値はミニマップOFF、戦闘速度×1、音響ON、BGM 28%、SE 45%。

## 検証

```bash
find src -name '*.js' ! -name 'app.bundle.js' -print0 | xargs -0 -n1 node --check
node tests/gdd-v1-regression.mjs
```

検証対象には17体／85スキル／102装備／22戦、契約と装備生成、状態耐性、特殊報酬の冪等性、旧セーブ移行、画面テンプレート、モジュール参照、音響設定を含みます。
