## build145差し替え修正

- 試練の入口を段階解放へ変更。`4 VS 4`は最高50階、`奈落回廊`は最高100階、`深淵・十神`は最高150階で解放され、未到達時は必要階層を明示します。
- ホームの「パーティ」内へ、既存の部隊編成・ダンジョン・セーブを変更しない独立型「オンライン広場」を追加。専用サーバーが停止中でも従来ゲームは通常どおり遊べます。
- オンライン広場は1部屋最大4人。フレンドID、ルーム作成／参加、選択キャラ・魔法陣・表示名・位置・向きの同期、定型チャット、スタンプ、リーダー表示、相手の装備／戦力閲覧、追従、約15秒の切断復帰を実装しました。
- 自宅Windows PC向けのNode.jsサーバーを`online-server`へ同梱。初回セットアップ、個別起動、一括起動のBATと日本語ガイドを収録し、`127.0.0.1`待受＋Cloudflare Quick Tunnelで、ルーターのポート開放なしに友達を招待できます。
- オンラインサーバーは座標と公開プロフィールだけをメモリへ一時保持し、ゲームのセーブ／所持品を変更しません。PC停止時は部屋だけが消えます。

## 起動方法

ES Modulesを使用するため、ファイルを直接開かずHTTPサーバーから起動してください。

```bash
python3 -m http.server 8080
```

ブラウザで`http://localhost:8080/`を開きます。静的ホスティングへは、このフォルダの中身をそのまま配置できます。

音響はブラウザの自動再生制限に従い、最初のタップ／クリック後に開始します。設定画面で音響ON/OFFとBGM／SE音量を変更できます。

## セーブ互換

- セーブキー：`abyss-dominion-remake-v001`（維持）
- `schemaVersion 1〜53`を`54`へ自動移行。
- 旧深淵・十神ID、旧★、装備、挑戦進行、探索／戦闘チェックポイントを正規化。
- ZIPを上書き配置しても、ブラウザのサイトデータを削除しない限り既存セーブを継続できます。
