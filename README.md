## v2.4.0の主要内容

`v2.4.0`は130版を基準に、引き継ぎ監査で確定した管理コード、探索、戦闘AI、育成、チュートリアル、追加キャラクター、全方向素材、UI修正を統合した完成版です。

- シリアルを17種へ拡張し、GM支援・GM RESET専用経路、最高到達階を変えない1〜9998階出発権限を追加。
- 自動探索の戦闘結果を約1秒で閉じ、選択方針を保ったまま探索を再開。手動探索は従来動作を維持。
- 敵の内部MP、MP不足時の通常攻撃切替、蘇生・回復・解除・MP吸収・集中攻撃・隊列判断を追加。未来の行動予告は非表示。
- なつき度を最大1000・100刻みの段階効果へ拡張し、勝敗増減、合成継承、セーブ移行に対応。
- 1〜5階の段階チュートリアルと、初回／2回目敗北時の編成・装備・育成指南を追加。
- 文房具系12体と、おちゅき、ベチー、きあら、ロキシー、ミリム、アイ、エリス、金色の闇、開発使魔チャッピーを追加。
- 全248素材フォルダに8フレームを完備。詳細キャラは512px、簡素キャラは128px、深淵7柱・十神10柱は全て新規原画から512pxで再制作。
- 装備部位候補の不一致、巨大化する紫色の「？」、モバイル装備画面の横崩れを修正。

## v2.3.1の主要内容

`v2.3.1`は公開後に確認された表示崩れ・操作導線・試練回数・演出品質をまとめて修正した完成版です。探索4体HUD、装備画像の二重描画、奈落回廊の背景素材、属性絞り込み、日次挑戦回数、ダメージ表示余韻を中心に改善しています。

- 探索部隊HUDを名前・属性・HP／MP実数付き2×2カードへ統一し、収納時は探索領域を拡張。
- ミニマップと自動探索を小型・可動式へ変更し、自動方針を戦闘後も維持。
- 装備画像の重複レイヤーを撤去し、1装備につき1素材だけを描画。
- 編成候補の属性絞り込み、簡易通知、戦闘カードの状態表示を修正。
- 4 VS 4／奈落回廊を各1日10回へ変更し、敗北画面を刷新。
- 奈落回廊の部屋と奈落孔を新規画像素材へ置換し、敵中央・奈落孔奥の配置へ統一。
- ダメージを通常1.5秒、クリティカル1.8秒表示して演出の余韻を確保。
- 深淵スキルツリー導線を整理し、画面内の絵文字をピクセル素材へ置換。

## v2.3.0までの統合内容

`v2.3.0`は追加修正依頼を統合した完成版です。現在のレイアウトと基本ゲーム性を維持しながら、探索、戦闘、試練、奈落回廊、深淵・十神、音響、管理画面をまとめて仕上げています。アセット識別子も`2.3.0`へ更新し、旧JavaScript／CSSキャッシュを確実に破棄します。

- 探索部隊HUDをHP／MP数値付き2×2カードへ更新。ワンタップ開閉時は探索領域が自動拡張。

- 水場の使用済み素材を石枠完全一致で作り直し、使用前後で中身だけが空になる表示へ修正。
- 通常敵を最大4体編成へ拡張。10階ごとのボスを大幅強化し、深層ボスは眷属を含む最大4体編成で出現。

- 戦闘名をキャラクター上へ全表示し、撃破後も敵の前衛／後衛位置と大きさを固定。
- ダメージ数字へ高速スロット確定演出、攻撃種別カラー、クリティカル専用発光と表示余韻を追加。

- 4 VS 4を第50試練で止まらない無限ステージへ変更し、50以降へ深淵・十神編成を追加。
- 欠片から人物契約または専用装備顕現を行う「欠片祭壇」と専用勝利演出を追加。
- 提供された7曲を拠点・探索・通常戦・強敵戦・ボス戦・深淵戦・十神戦へ組み込み。
- 炎・氷・毒・ボス・深淵・十神の専用戦闘背景、属性共鳴、環境適性補正を追加。
- 探索HUDを2×2のHP／MP数値カードへ更新し、取得通知、水場、骨、資源画像を修正。

## 起動方法

ES Modulesを使用するため、ファイルを直接開かずHTTPサーバーから起動してください。

```bash
python3 -m http.server 8080
```

ブラウザで`http://localhost:8080/`を開きます。静的ホスティングへは、このフォルダの中身をそのまま配置できます。

音響はブラウザの自動再生制限に従い、最初のタップ／クリック後に開始します。設定画面で音響ON/OFFとBGM／SE音量を変更できます。

## セーブ互換

- セーブキー：`abyss-dominion-remake-v001`（維持）
- `schemaVersion 1〜48`を`49`へ自動移行。
