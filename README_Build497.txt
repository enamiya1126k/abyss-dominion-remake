【用水路防衛隊：網と水の演出を作り直し】
・画面を横切る軌跡線、家の前の点線、網を表す単純な線画を廃止。
・ロープと重りのある網素材を新規生成。投げる→開く→水しぶき→捕獲袋の演出。
・仲間の網は小さな色付きの布で区別。4人の一網打尽も同じ素材で統一。
・危険な敵と家の近くに赤い光を出し、HP表示と敵の残り回数を立体的な札に変更。
・一網打尽ボタン、4人の欄、開始カウントダウンの色・縁・陰影を調整。
・操作は敵をタップ、下部は一網打尽ボタンだけのまま。
・ゲームのルール、敵の経路、タップ範囲、入力間隔、スコアはBuild496と同じです。
・OSの「視差効果を減らす」等の動きを抑える設定にも対応。
