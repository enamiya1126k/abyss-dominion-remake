# Build584 — イス取り・欲ばりの金席

Build583 用の差分です。アプリバージョンは 3.1.263。

## 適用

1. 対戦が終わってから、ZIP 内のファイルを同じ場所へ上書きしてください。
2. 本体だけでなく online-server/src も更新してください。サーバーが参照する兄弟ディレクトリ src/chairs583 も更新が必要です。
3. オンラインサーバーを再起動し、参加者全員が画面を再読み込みしてください。

旧ルールの保存部屋はロビーへ戻します。Build583 のクライアントでは新しい対戦を開始できません。既存の画像は再配布していないため、必ず Build583 へ適用してください。

## 遊びの変更

- 普通席は音楽が止まった瞬間から取れて、100点を確保。
- 金席は STOP の0.8秒後に解禁。その後1.8秒かけて150→300点へ成長します（10点刻み）。取った時点の点数で確定します。
- 第2・5・6回は音楽中に席がシャッフル。第4回はすべて金席の黄金祭で、0.8／1.02／1.24秒後に順番に解禁します。
- 全8回。第7・8回は得点2倍、最終回は最大600点の1席勝負。
- AI も普通席を確保する行動と金を待つ行動を使い分けます。
- タップ操作はそのまま。フライングはその回失格。競り負けたら短い待機後に別の席を狙えます。

## 表示・演出

席への飛び込み、競り負けの反応、金席の成長ゲージと光、紙吹雪、首位の王冠、点数カウントアップ、全8回の得点表を追加。効果音OFFや動きを減らす設定でも遊べます。
