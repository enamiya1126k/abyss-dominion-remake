# Build451 / v3.1.130 — 魔物レース基本版

ホーム下部の「パーティー」から、合言葉で友達と遊ぶ魔物レースを開けます。

## 遊べる内容

- 参加者は4席。1〜4人で入室でき、部屋主が開始すると空席をAIが埋めます。
- システム選出4匹＋各参加者の1匹＝計8匹が出走。十神・深淵も手持ちから選べます。
- 育成レベル・装備・戦闘力・なつき度による走力差はありません。魔物種ごとの脚質・走力配分、芝/砂との相性、今回の調子を予想材料にします。脚質の「逃げ・先行・差し・追込」で走り方が変わります。
- 1匹ずつのパレードで調子や特徴を表示。番号で見たい魔物に切り替えることもできます。
- 馬券は1人1枚。「単勝」「二連複（順不同の1・2着）」「二連単（順番どおりの1・2着）」に対応。購入額は1〜1,000,000G、所持GOLDの範囲内で自由に入力できます。見送りも可能です。
- 倍率は出走条件から決まり、購入時に固定。表示払戻額には購入額を含みます。全員の予想は購入締切後に公開され、レース中も表示されます。
- ゴール後は全8匹の着順と、4人全員の馬券・購入額・払戻・優勝賞金・差引収支を表示します。AIの馬券は演出用で、人間の所持GOLDに影響しません。
- **自分の出走魔物が1着なら、馬券と別に5,000Gの優勝賞金。** 的中と優勝が重なった場合は両方を受け取れます。
- 出走した自分の魔物に、なつき度＋5（上限1,000）と、その魔物の現在レベルで必要なEXPの約2％（最低10EXP）。育成は本編に反映されますが、レースの走力には影響しません。
- 全員が選択したらパレードへ。未選択者は45秒後に手持ちの先頭を自動選出。パレードは最低16秒、購入締切は75秒です。未購入者は自動的に見送り。3秒の開始演出後、約28秒でレースが終了します。
- 結果画面で同じメンバーとの次のレース、または退室を選べます。レース進行中にホームへ戻ってもレースは進み、戻ると現在の状況を表示します。

本版は「① 遊べる基本版」です。生成画像を使った大幅な装飾や高度な実況・音響演出、追加券種、二倍賭けは含みません。

## 更新方法

Build450以前も含む累積上書きZIPです。既存のゲームフォルダーに展開して上書きしてください。**ゲーム本体とオンラインサーバーの両方を更新し、サーバーを再起動してください。** サーバー未更新時はレースの接続案内が表示されます。

表示バージョンは `v3.1.130`、セーブ形式は84のままです。以前の対戦、ホームの共闘レイド、部隊編成、装備などは引き継ぎます。既存の魔物画像を使用します。ZIPは既存環境への累積差分で、初期素材一式を含む独立したゲーム配布ではありません。

`online-server/data/` と利用中の永続データを削除・上書きしないでください。本ZIPにはアカウントや稼働データを含めません。

## サーバーのレース保存

レース記録は既定で `online-server` を作業ディレクトリにした場合の `./data/monster-races451.json` に保存します。`RACE_STATE_FILE` で保存先を指定できます。サーバーを更新・移動するときも、このファイルを他のオンライン保存データと一緒に引き継いでください。

購入前にゲーム側でGOLDと馬券の記録を保存し、サーバーが同じ受付IDを重複処理しない方式です。購入結果が不明な間はGOLDを保留し、再接続で受付を照会します。締切後に届いた未受付の馬券は返金記録を発行します。賞金・払戻・経験値をゲームに保存できた後で受取確認を送るため、切断や再読み込みで二重払いしません。保存失敗時は記録を残し、再試行します。

レースの着順はサーバーがパレード開始時に確定して保存し、購入状況を見て変更しません。着順や走行時間は購入中のクライアントには送信しません。進行中のレースは再起動後に続行します。未受取報酬は、ホーム画面でも再接続時に受け取れます。

GOLD・手持ち魔物の元データは従来どおり端末のセーブにあります。本版はサーバーが全本編所持品を管理する方式への移行や、不正改造への完全な対策ではありません。精算は購入した元のセーブ・オンラインIDで行ってください。
