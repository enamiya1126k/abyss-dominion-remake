# Build613 — 船必須の片道航海

Build612適用済み本体に重ねる更新パッチ。アプリ3.1.292、ランナーズ通信ルール23。

## 変更

- 船コースを全長8,000の連続した3海峡へ再設計。足場は島の上に限定し、海上の足場の連続を撤去。通常ジャンプも風の3段ジャンプも船の代わりにはならない。
- 船3隻は自動運行・片道のみ。到着後はその桟橋に停泊し、出発地へ戻らず、追加便も出ない。乗船人数やスター攻略で船を止めない。
- 初便はプレイ開始7秒後に出航。次の船は島の出口で初めから待機し、前の船の到着から16秒後、20秒後に出航する。残り時間をHUDと船の下に表示。
- 船上では低い横弾、高い横弾、落下弾を回避する。発射900ms前に攻撃位置と種類を表示し、予告後の追尾を行わない。低い弾はジャンプ、高い弾は船上に留まり、落下弾は左右へ移動して回避する。
- 船が出発桟橋から700以上離れ、本人も船から700以上後ろに残った場合、その人は脱落。他の人の位置・船・時刻を巻き戻さない。脱落者は観戦し、全員脱落なら結果画面から再挑戦できる。
- 島内の死亡は旗から復帰するが、すでに船に届かない場合は脱落する。全員での一時停止は航行時刻も止める。単独で待機した人のために他の人の航行は止めない。
- 中間地点でも場面切替、座標リセット、時計の再始動をしない。ゴール到達判定は引き続き船・スターと独立する。

## スター

1. 三連封印：高台の①→②→③を同じ人が8秒以内に踏む。途中に崩れる足場と回転炎がある。解除後に出口側のスターを回収し、16秒の出航猶予へ間に合わせる。
2. 番兵の砦：任意の上段開始台を踏んだ時だけ番兵2体を出現させる。12秒以内に両方倒す。時間切れなら番兵を撤去し、開始台から離れて戻れば再挑戦できるが、船は待たない。
3. 空中輪：最後の航路で同じ人が空中輪4つを順番に通る。部分的な進捗は死亡で消える。完了すると最後の島のスターを回収できる。

星なしでのクリアも可能。Build612の全7ボスの戦闘範囲・技・上空足場・ゲート右側修正は維持する。

## 検証

- `node --test tools/build613/*.test.mjs`：236件通過。片道・再便なし、船と陸の衝突、乗船追従、風の3段ジャンプでも海峡横断不可、乗り遅れと観戦終了、スターの順序・期限・再試行、全員停止／再開、個別ゴール、ボスなど既存機能を確認。
- `node tools/build613/sail-check.mjs`：本番の移動と被弾判定を使う操作シミュレーションで死亡0回・98.175秒で完走。無敵設定、座標ワープ、船の時刻変更は使用していない。
- `node tools/build613/rings-sail-check.mjs`：実際の船上攻撃を回避し、空中輪4つと最後のスターを取得して死亡0回で完走。自動操作の証跡であり、人による操作難度の保証ではない。
- `node tools/build613/island-route-check.mjs`：島の足場と次船への9経路を通常の移動処理で到達確認。経路ごとの検証であり、最初の2スターを含む無被弾通しプレイは未検証。
- 実際の描画処理・画像によるNative Canvas表示確認を6場面で実施。`docs/build613/voyage-preview.png`。アバターは同座標へ合成。日本語フォントがない検証環境のため、画像内の技名・案内文字の日本語表示は未確認。
- ブラウザー実行本体がないため、iPhone Safari実機、タッチ操作、複数端末での通信プレイは未確認。

旧船コースの「往復・陸路だけでクリア・旗で何度でも復帰」を前提とするテストは、今回の片道航海仕様のテストに置き換えた。全員停止、ゴールの独立、既存ボスの回帰は維持した。
