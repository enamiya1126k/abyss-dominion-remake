# ABYSS DOMINION Build564 / v3.1.243

GitHub `main` の `72c63563787f2ab5b2e519e86551065da7830ff4`（Build563 / v3.1.242）を基に作成した。

## 遊び方

- 上下に１つずつある相手チームのゴールへ、宝石パックを弾き込む。
- ２人ずつのチーム戦。空席はAIが埋め、切断・離席中もAIが引き継ぐ。
- 引いて離す操作、発射の力、勢いの持ち越し、1.25秒の再発射間隔はBuild563と同じ。
- コート全体を移動できる。味方へのパス、体当たり、壁・中央の回転棒を使うシュートが可能。
- １ゴール１点。最後の15秒は２点。90秒／150秒を選択でき、同点は引き分けになる。
- 得点は入ったゴールの反対側のチームへ加算する。パック全体がゴールラインを越えたときだけ成立し、オウンゴールにも対応する。
- ゴール後もキャラの位置と勢いを維持する。0.95秒後にパックが再登場する。
- 個人カラーを残し、チームは青の「◆ サファイア」と桃の「● ルビー」で識別する。画面上には自分の攻撃方向を表示する。
- 準備画面で空きのあるチームへ移れる。各チームの定員は２人。変更後は全員の準備確認を取り直す。再戦ではチーム分けを引き継ぐ。
- AIはパックに近い１人が攻撃し、もう１人が自陣側をカバーする。結果画面はチームの勝敗と個人のゴール・アシストを表示する。

## 更新手順

1. このブランチ／PRの変更を、上記GitHub最新版に反映する。差分ZIPを使う場合はBuild563に階層を保って上書きする。
2. **オンラインサーバー側にも `online-server/src` と、サーバーが参照するルートの `src` を反映し、再起動する。** 本体だけの更新では新ルールを開始できない。
3. 本体を通常の方法で公開する。参加者全員が再読み込みし、**v3.1.243** を確認する。
4. パーティーで「人間エアホッケー！」を選び、チーム・相棒・準備OKを確認して開始する。

旧ルールの進行中の部屋は準備画面へ戻る。旧本体との混在開始は拒否する。セーブ削除やアカウント初期化は不要である。
