## 遊び始める

「パーティー」→「カードすごろく」→部屋を作る／合言葉で参加→魔物を選ぶ→全員が「準備OK」→部屋主が開始。
人間は1〜4人。空いている席はAIが埋め、常に4人で対戦します。選んだ魔物の育成値による性能差はありません。
結果から同じメンバーでもう一度遊べます。「別のゲームを選ぶ」で、部屋・合言葉を維持したまま魔物レースへ切り替えられます。
途中参加した人は観戦し、次のゲームから参加します。

## 基本ルール

最初は速攻以外のカード3枚。手札上限なし。
手番は「1枚引く→速攻処理→移動前のカード→サイコロ→マス→移動後のカード／特殊能力→終了」。
タイミングの合うカードは何枚でも使えます。相手の手番には防御だけ割り込めます。
「合計出目＋2」は2マス分加算。「サイコロ2個追加」は通常の1個と合わせて3個です。
複数の効果は記載順に処理します。途中でゴールが確定した人はその時点で精算し、以後の効果の対象から外れます。

3人目がゴールした時点で終了。残りの1人を4着として精算します。
最終得点＝手札の印刷点＋特殊カードの印刷点＋特殊効果の加点＋到着ボーナス。
到着ボーナスは1着40点／2着20点／3着10点／4着5点。得点同点なら先着優先です。
ゴール済みの人は手番と得点を確定し、攻撃・交換の対象から外れます。出目の超過でもゴールできます。

## ABYSS向けに決めたバランス

- 目標時間20〜40分。実際の4人での所要時間は未計測です。
- マスによる追加移動は移動先のイベントなし。カードに明記した場合だけ発動します。そこからのマス移動は連鎖しません。
- 「必ず止まる」門は前進中に止まります。後退通過では停止しません。
- 絵柄は4種類を手札に隠して温存し、移動前に任意発動。4枚を捨て、各セットにつき各プレイヤー1回。
- 一度使用した実物のカードを回収しても、その同じ手番では再使用できません。
- サイコロは最大5個。追加ターンは連続2手番まで。一回休みの蓄積は最大2回。
- 「天才」は手札枚数分の1〜10マス移動。「強欲」は補充・破棄・自分の奪取枚数を2倍。得点、サイコロ、移動、支払コストは増えません。
- 「怪盗」は最初のゴール直前にだけ割り込み。すでに確定した着順や得点を変更しません。
- 「無念」の呪いはゴールに達すると20マス戻り、その呪い1枚を捨てます。
- 反射は1回で、相互に反射し続けることはありません。
- 選択・行動は75秒でAI代行。切断中は30秒後から代行します。再接続で操作を再開できます。
- 全員オフラインの間は自動進行を止めます。24時間活動のない部屋は期限切れになります。
- 全体85手番以降は、長引くほどサイコロ移動に加算して終了へ向かいます。

カードすごろくのカード、点数、呪い、特殊能力はこの対戦専用です。所持GOLD・アイテム・育成値を消費しません。今回は本編への報酬を設けていません。
本編セーブのキー・スキーマ（84）を維持しています。レースの受取・購入の処理は従来のものを使います。
すごろくの盤面、山札、手札、乱数、選択待ちは既存サーバー保存先 `RACE_STATE_FILE` 内の `boardRooms463` に分離して保存します。
相手の未確定の手札、山札の順序、乱数状態を通信で配布しません。操作はサーバーで本人・手番・選択番号・状態番号を検査します。
