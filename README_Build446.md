# Build446 / v3.1.125 — 戦力の上下配置と低戦力側の表示調整

Build445までを含む累積上書きZIPです。既存のゲームフォルダへ、フォルダ構成を維持して上書きしてください。新規インストール用のリポジトリ全体ではありません。

## ホームの表示

- 「戦力」を上段、数字を下段へ移し、数字に使える横幅を広げました。
- 既存の属性アイコンを左側に維持します。
- 7桁までは `1,999,999` のようにカンマ付きで全桁を表示します。8桁以上は従来の万・億・兆の表記を使います。
- 数字が枠の残り幅を超えたときだけ、必要な分だけ文字サイズを縮めます。「…」への置き換えをなくしました。
- 数値が短くなった場合は元の文字サイズへ戻ります。画面サイズ変更、ホームへの戻り、フォント読み込み後も再調整します。

## 低戦力側の調整

各キャラのBuild445の戦力を `P` として、10万未満だけ `四捨五入(P × P ÷ 100000)` にします。正の値の最小値は1です。10万以上はそのまま維持します。境界で値が逆転しない計算です。

| Build445の個人戦力 | Build446の個人戦力 |
|---:|---:|
| 10,000 | 1,000 |
| 30,000 | 9,000 |
| 50,000 | 25,000 |
| 100,000 | 100,000 |
| 324,558 | 324,558 |
| 420,812 | 420,812 |

参考画像の4人は `324,558 / 292,465 / 367,236 / 420,812`、合計は1,405,071のままです。総戦力は調整後の各キャラの合計です。到達階層だけで一律に下げる方式ではありません。

ホーム、編成、装備、探索、記録、オンラインランキングで同じ表示基準を使います。HP、攻撃力、戦闘のダメージなどの実際の能力は変わりません。

ランキングの保存値と戦闘用プロフィールは従来基準を保持し、表示・並び順を新基準へ換算します。未ログインのプレイヤーも換算対象です。旧・前回・今回のクライアントからの送信を検証して受け付けます。

過去の自己ベストは各メンバーの内訳が残っておらず、合計だけでは正確に再計算できません。「更新前の戦力記録」へ保存し、新基準の記録を現在の編成から始めます。さらに古い記録も保持します。

## 反映手順

1. ZIPを展開し、既存のゲームフォルダへ同じ構成で上書きする。
2. 本体とオンラインサーバーのファイルを更新する。サーバーを別フォルダへ置く場合は `src/core/PowerScale445.js` と `src/core/PowerScale446.js` を参照可能な同じ相対位置に配置する。
3. オンラインサーバーを再起動し、本体を公開する。
4. ゲームを再読み込みして `v3.1.125` を確認する。

今回は低戦力側の計算も調整したため、Build445を反映済みでもサーバー側の更新が必要です。古いサーバーのランキングには「旧基準」と表示します。セーブやサーバー保存データの削除は不要です。公開先への反映は行っていません。
