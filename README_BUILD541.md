## 更新方法

1. 今の本体と `online-server/data` をバックアップ。
2. ZIPの中身を本体フォルダーへ上書き。`src`・`assets`・`index.html`・`online-server`・新しいキャッシュファイルをまとめて反映。
3. online-serverを再起動。参加者全員が本体を再読み込みして、v3.1.220へ揃える。
4. 更新前から進行中のテトラポット・かくれんぼはロビーへ戻ります。相棒を確認し、準備OKを押し直してください。進行中の旧用水路は旧ルールで最後まで遊べます。次の試合から新ルールになります。

単独で起動する完全版ではありません。所持キャラ・セーブ・サーバー保存データは同梱していません。`docs`・`tests`・`tools` は説明と検証用です。

## テトラポット渡り — 先端を決めて、追い風ジャンプ

- 海底の岩や光が見える新しい海、濡れた石・苔・高低差が分かる足場、中継の灯台台座を画像生成で新規制作。
- カメラを寄せて、自分の位置を追う表示へ。右上「全体」で幅広いルートを見渡せます。照準中は自分と着地点が画面内に収まるようカメラが追従。フィールドの広さや自由なルートは維持。
- **違う足場の先端に３回続けて着地すると、次のジャンプが約1.35倍（520→700）に！** 金色のマークが３つそろうと追い風READY。着地のPERFECT演出を追加。
- 足場の胴に着地すると連続数リセット。落水でもリセット。中継では保持。小さなその場ジャンプではためられません。
- 引いた長さで距離を決め、離して跳ぶ操作は継続。着地点ガイドとサーバーは同じ計算を使用。
- 通常波は先端、大波は中継だけが安全。低い足場の水没、苔の滑り、接触判定、途中４中継、よりの「イージー！」も継続。
- 結果に先端着地の成功回数を表示。

## 魔王のかくれんぼ — 潜入・救出・脱出戦

**勝利条件が変わります。**

- 隠れる３人：館にある**３つの封印を解除し、庭門から１人でも脱出すればチーム勝利**。
- 鬼：全員を捕まえるか、180秒間脱出を阻止すると勝利。
- 封印のすぐ近くで約３秒止まると解除。複数人なら早まります。途中で離れると解除途中のゲージは徐々に戻ります。
- **身代わり**：今の家具を約５秒残し、もう一方の姿へ変身。18秒で再使用。移動先・スタミナは保持。
- **気配を探る**：鬼だけが使える能力。近い／この辺り／気配なしの３段階だけが届き、位置や名前は分かりません。20秒で再使用。
- **仲間を救出**：庭の檻の近くで約３秒止まると、捕まった仲間が復帰。１人につき１回。鬼が檻の近くにいる間は救出できません。全員が捕まった時点では鬼の勝利です。
- 封印・脱出口・檻の専用画像を追加。小地図に目印、画面外の目的地に案内、解除中の進捗を表示。
- AIは封印を分担し、鬼から逃げ、条件が合えば仲間を救出。鬼は封印・庭を巡回します。家具の角を経路が横切り、実際の移動で止まる不具合も修正。
- ２択のいつでも変身、15秒の移動スタミナ、30秒ごとの揺れ、最大３攻撃・10秒補充、移動しながら攻撃、鬼に仲間の位置を知らせない仕様は継続。

## 用水路防衛隊 — まとめ捕り・FEVER・合体大網

- **指で短くなぞり、離すと最大６匹に網を投げる**操作を追加。１匹をタップする操作もできます。敵の当たり判定はサーバー側で計算。
- 仲間が直前に網を当てた相手には威力＋1。
- **８連続捕獲で８秒間のFEVER**。網の威力＋1、捕獲得点２倍！ 2.2秒捕獲が途切れるか、家に攻撃を受けると連続数はリセット。
- **合体大網**：ゲージ32で募集開始。1.8秒以内に仲間もボタンを押すと参加。１人でも発射します。参加人数1/2/3/4でダメージ3/4/6/8、家の回復0/3/5/8。空席AIも参加。
- 巨大将軍に２人で続けて網を当てると**BREAK**。約3.5秒足止め＋与えるダメージ増加。次のBREAKまでクールダウンがあります。
- ミサイルの到達を1.3秒に延ばし、タップやなぞりで迎撃。AIも迎撃を援護。
- 新しい水門・水車小屋・透き通った水面の背景を制作。ボスの体力とBREAK、大網の参加人数、FEVERを見える形にしました。
- 結果に最高COMBO・一度に網を当てた最多数を追加。
