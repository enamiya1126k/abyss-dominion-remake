# ABYSS DOMINION Build363 / v3.1.43

Build362 適用済みのゲームに重ねる差し替えパッチです。
ZIP内のファイルを、同名ファイルと同じ階層へ上書きしてください。
公開後、設定画面のバージョンが v3.1.43 になっていることを確認してください。
オンラインサーバーの差し替えは不要です。

## プレイヤー名の変更

1. ホーム右上の歯車から「設定」を開きます。
2. 一番上の「プレイヤー名」に名前を入力し、「名前を保存」を押します。
3. ランキング・オンライン広場に共通の名前として反映されます。

全体ランキング上部の「名前を変更」からも、ランキングを開いたまま変更できます。
オンライン広場の「手帳」にある名前欄も、同じ名前を変更します。

- 16文字まで。空白だけの名前は保存できません。
- 前後の空白を取り除き、既存サーバーと同じ文字正規化を行います。
- 絵文字などは2文字分として数える場合があります。
- オフラインでも端末に保存し、再接続時にオンラインへ反映します。
- 現在の名前・フレンドID・進行・仲間・装備はそのままです。仲間のニックネームとは別の項目です。
- 日本語変換中の文字を送信せず、入力を確定して保存します。
- 保存に失敗した場合はエラーを表示し、変更前の名前を維持します。

## 検証

名前保存、再読み込み、既存データの継承、通信時のプロフィール更新、オフライン時の更新待ち、空欄・文字数・HTML文字の扱い、日本語変換中の誤保存防止を対象とする8テストが成功しました。

既存のランキングクライアント／接続表示の13テストは9成功・4失敗です。Build362にも同じ4件の失敗があり、今回の変更による追加失敗はありません。旧10000階を期待するテスト1件と、現在の接続処理に対応していない旧モック／期待値3件です。

変更後のJavaScript構文・相対importの参照先・ZIPの整合性も確認しています。
iPhone Safari実機・公開サーバー上での動作は未確認です。
