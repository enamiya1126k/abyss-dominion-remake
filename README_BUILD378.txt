第二章・完結までの続編と探索画面の修正

【適用方法】
このZIPはBuild377（v3.1.57）に対する差分です。単独では起動しません。
ZIPを展開し、中の index.html、src、assets を、既存ゲームの同じ場所に上書きしてください。
GitHub Pagesへ反映後、ゲームを再読み込みして v3.1.58 を確認してください。
セーブの初期化は不要です。オンラインサーバーの更新・再起動も不要です。
ゲームを削除して入れ直す必要はありません。

【今回の修正】
・盾の数字をHPと同じ文字クラスに統一。「盾 残量/最大容量」と表示。
  ゲージの割合もHPではなく盾の最大容量を基準にしました。
  最大容量は、その戦闘中に獲得した盾の最大値です。過剰回復の盾は上限値を記録します。
  盾がゼロになっても最大容量は保持。盾の強さ・吸収ダメージ自体は変更しません。
・第二章のマップボタン／ミニマップ本体／自動ボタンに第一章の共通ドラッグ処理を適用。
  第二章では約0.26秒長押ししてスライドすると配置変更。配置を保存します。
  マップボタンとミニマップは短くタップすると詳細マップが開きます。
  ドラッグ直後の誤タップを防ぎ、下部メニューに隠れない位置へ補正します。
・探索画面内の左上にあった空枠を撤去。現在地と目的は上部の表示で確認できます。
・戦闘後は第一章の活躍表 → 既存の勝利演出と報酬画面 → 封印／地域解放の専用画面。
  報酬と解放の説明を同じ枠へ詰め込まない流れに変更しました。

【第二章の続き】
境界の森（既存6区画）
  → 黒根の侵食域（6区画、目安Lv.1400）
  → 深淵の回廊（6区画、目安Lv.2000）
  → 天律の聖域（6区画、目安Lv.2800）
  → 理の中枢（6区画、目安Lv.3800）
  → 最終決戦・エンディング

各地域で二つの守護者を倒し、最深部への道を開きます。
移動、カメラ、通路、ミニマップは第一章と共通。地形と専用テクスチャで地域を区別します。
新しい4地域に計16の固定遭遇を追加。後半は深淵・十神の既存固有スキルを持つ複数の敵が登場。
攻撃役だけでなく回復・妨害役が加わるため、育てた部隊の編成・装備を試せます。
各戦闘のEXP・GOLDに加え、新地域では経験値パック（超）を獲得。
地域ボスから神話装備、初回踏破では魔晶石も獲得します。装備は保護して受け取ります。
満杯時は既存の報酬保管処理へ送ります。
苦戦したら前の地域を「再探索」して育成できます。

地域の初回入場と踏破後に、第一章と同じ6人の舞台・吹き出しで物語が進みます。
既存の序章と森の結末に続き、72行の新しい会話を追加しました。
最終地域の結末を読むと、そのままエンディングへ進みます。
エンディング読了後は、各地域に5段階の強化再戦を追加。
段階が上がるほど敵と報酬が強化され、5段階目は繰り返し挑戦できます。
強化再戦は物語をやり直さず、強敵の記憶と戦う扱いです。

【すでに境界の森をクリアしている場合】
ホーム下部「ダンジョン」から「黒根の侵食域」を選んでください。
森の討伐・封印・宝箱・既読記録は引き継ぎ、森の再クリアは必要ありません。
地域ごとに途中位置・討伐・宝箱の記録を保持し、行き先から再開できます。
「この地域を再探索」を選ぶと、その地域の敵と宝箱だけを再配置します。
仲間の育成、装備、地域の解放、物語の既読、初回報酬の受領記録は残ります。
進行中の戦闘がある間は、他地域へ切り替えたり再探索を始めたりできません。
