【適用】

ブラウザー本体とサーバーが参照する共有srcを両方更新し、Node.jsサーバーを再起動してください。

【同じキャベツを、さらに細かく】
既存8段階に、極小の粒・キャベツの雪・限界の極細の生成素材を追加。全11段階です。
0 / 2 / 5 / 9 / 15 / 23 / 35 / 50 / 70 / 110 / 175回の成功タップで段階が進みます。
109回なら従来の短い千切りではなく極みじん切り、150回なら粉雪のような状態になります。
段階の間も、成功タップ1回ごとに次の素材へ置き換わる領域を広げます。
半透明の2枚を重ねる合成をやめ、重複しない領域に表示するため二重写しになりません。
45秒を通して同じキャベツです。最終段階でも千切り・得点・欠片の飛散は続き、半玉に戻りません。
新素材の最初のセルは既存の細かさより粗いため使わず、細かい3セルだけを採用しています。

【まな板は、試合が終わるまで同じ1枚】
「切れ！」への復帰でも、次の「切るな！」でも、まな板を新品に交換しません。
禁止中の有効タップ1回ごとに、同じまな板への破損が積み重なります。
破損はサーバー保存・通信復帰・結果確定後も維持し、次の試合開始でのみ0に戻ります。
完全に壊れても、合法な千切りは続けられます。
減点は従来どおり「切るな！」1回につき−80点、下限0点。同じ合図中の追加破損は追加減点なし。
結果の「何枚粉砕」表記を、同じ1枚への誤打数・減点回数に変更しました。

【優勝者はキャベツの山頂へ】
生成したキャベツ山の上に、1位の魔物だけが立ちます。同点1位は全員が山に登ります。
山は最終ポイントが高いほど大きくなります。減点も反映し、0点では山を出しません。
スマホ画面からあふれないよう、山の表示サイズは得点に対して緩やかに増える方式です。
4人の収穫バーは最終ポイントに正比例します（800点の長さは1,600点の半分）。
グラムなど実測していない量は表示せず、得点相当の収穫として表示しています。
優勝者のまな板も破損状態のままです。自分の切った回数・最大コンボ・順位も残しています。
