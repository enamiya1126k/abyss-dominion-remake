## 反映手順

1. ZIPを展開し、同じフォルダ構成で全ファイルを上書きする。空フォルダへの展開では動作しない。
2. 本体の配信ファイルを更新する。
3. サーバー側にも `src` と `online-server/src` の変更を反映し、オンラインサーバーを再起動する。依存パッケージの追加はない。
4. 参加者全員が再読み込みし、v3.1.273 / Build594へ更新する。

ランナーズのルール番号を５へ更新した。旧クライアントとの混在開始を防止し、旧ルールの開催中ルームは準備画面に戻る。公開サイトへの反映・GitHubへのpushはこのZIP作成時点では行っていない。

## 人間だけの１〜４人

- ランナーズだけ、空席へのAI補充と離席・切断時のAI代行を廃止した。敵キャラクターは従来どおり出現する。
- １人でも開始でき、ゴール・結果表示は実際の参加人数に合わせる。
- 離席・切断中はそのプレイヤーを待機させ、入力・接触を停止する。戻ると共有の旗から再開する。待機中も制限時間は進む。
- 参加者全員のゴールでクリアする。切断した人が戻らない場合は制限時間で終了する。
- 空席のAIカラー設定をランナーズの画面から外した。他のミニゲームのAI補充・代行は変更しない。

## アイテムの使いどころ

| アイテム | 効果 | 使いどころ |
| --- | --- | --- |
| 火の紋章 | 14発。１発で敵３体まで貫通。木の障害物は２発で破壊 | 敵の集団を先に倒す。仲間全員の通り道を開く |
| 風の紋章 | 10発。空中でジャンプを押し直すと２段ジャンプ。１発消費、着地で再使用可能 | 落下から立て直す。敵を避けて高い補給路へ進む |
| 宝石 | ハート＋１、装備中の弾＋４、４秒間加速 | 難所の前後で回復・補給して先へ進む |

同じ紋章の再取得は弾を加算する。上限は火28発、風20発。宝石のハート回復は３個まで。宝石は各プレイヤーが１個につき１度だけ取れる。風の２段ジャンプは押しっぱなしでは発動せず、ジャンプをいったん離してもう一度押す。

紋章を逃しても、通常ジャンプ・壁キック・足場で完走できる。障害物の破壊は全員に共有する。仲間への射撃は従来どおり吹き飛ばしのみで、ハートを直接減らさない。
