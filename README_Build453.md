# Build453 / v3.1.132 — 魔物レース仕上げ版

「③ 遊んで仕上げる」を反映した累積上書きZIPです。

## 更新方法

**今回は、ゲーム本体とオンラインサーバーの両方を上書きし、サーバーを再起動してください。** 表示バージョンは `v3.1.132` です。Build452とは異なり、レースの報酬と通信処理にサーバー側の更新があります。

既存のゲームフォルダーへZIPの中身を展開して上書きし、ゲームを再公開してください。サーバーの稼働データ、特に `online-server/data/monster-races451.json` または `RACE_STATE_FILE` の指定先を引き継いでください。本ZIPにはアカウントや稼働データは含めていません。

更新前から進行していたレースは、保存された着順・倍率・旧報酬で精算します。新ルールは更新版から作成した新しい部屋に適用します。新ルールの部屋へ参加する友達も、ゲームを再読み込みしてください。

## 魔物の個性

- 通常魔物と十神・深淵の計334種類に対応し、22種類のレース特技を用意しました。
- スライムは「弾力ステップ」、ヤモリは「火花ダッシュ」、りおんは「風駆け」、時間の十神は「時渡り」など、魔物に合う走り方へ変更しました。
- 速さ・持久・器用の合計は全種類210。レベル・レア度・装備・なつき度で走力を上乗せしません。
- 芝では速さ、砂では持久を重視。得意コースと今回の調子が、予想の判断材料になります。
- 特技ごとに加速する時間帯があり、レース中は光と特技名で見せ場を表示します。走行位置は途中で逆戻りせず、サーバーが決めた着順どおりにゴールします。
- システム選出4匹は種族の重複を避けます。参加者同士が同じ魔物を選ぶことはできます。

魔物選択では脚質・得意コース・特技・能力配分を表示します。脚質で絞り込み、名前で検索できます。最初は24匹まで表示し、「さらに24匹を表示」で追加するため、手持ちが多い場合の初期描画も抑えています。

## 賞金・育成報酬

自分が出走させた魔物の着順に応じて、馬券とは別に受け取れます。

| 出走魔物の着順 | 出走賞金 | EXP | なつき度 |
| --- | ---: | ---: | ---: |
| 1着 | 8,000G | 現在レベルの必要EXPの約3％ | ＋8 |
| 2着 | 3,000G | 約2.5％ | ＋7 |
| 3着 | 1,000G | 約2.2％ | ＋6 |
| 4〜8着 | 0G | 約2％ | ＋5 |

EXPは最低10、なつき度は上限1,000です。自分の出走魔物1匹が対象です。購入せず応援する場合も、賞金・育成報酬を受け取れます。購入金額で育成報酬は増えません。入賞と馬券的中が重なった場合は両方を受け取れます。

単勝・二連複・二連単、1人1枚、購入額1〜1,000,000Gは継続します。倍率は今回の出走条件から計算し、購入時に固定します。払戻額には購入金額を含みます。差引収支は「払戻＋出走賞金−購入額」です。

配当は従来の理論還元率90％を基準とする計算を維持し、小数1桁へ切り下げます。計算される勝率と倍率の整合を点検し、特定の魔物や券種だけが常に有利になる補正は加えていません。20万レースの試算結果は `docs/build453/balance-results.json` にあります。

## 見た目・スマホ操作

- 金・紫の競技場入口と、砂コース専用の背景を画像生成で新規作成しました。芝・砂でレース、パレード、表彰台の景色が変わります。
- パレード、調子の仕草、カウントダウン、追い込み、全員の馬券、的中・収支発表はBuild452から引き継ぎます。
- 100／1,000／10,000Gの入力ボタンを追加しました。押した時点では購入せず、所持GOLD内の金額を入力するだけです。
- 結果に出走魔物の着順と育成報酬、実際に保存したEXPを表示します。
- 音のON/OFF、端末の動きを減らす設定、演出スキップ・再表示を引き継ぎます。

## 切断・復帰

- 待機中・結果画面で部屋主が30秒戻らない場合、接続中の参加者へ部屋主を引き継ぎます。レース中は進行と着順を保持します。
- 途中で画面を閉じても、再接続時に購入の受付・賞金・育成報酬を確認します。ホームにいる間も保留中の報酬を受け取れます。
- 結果後に接続中の参加者が受取を終えれば、同じメンバーで次の部屋へ進めます。切断中の人は新しい部屋の席から外れますが、前のレースの未受取報酬は保持されます。再参加する場合は合言葉で入り直せます。
- サーバー再起動後も、保存された出走条件・着順・馬券・未受取報酬を引き継ぎます。保存に失敗した購入・受取は元の状態へ戻して再試行します。

## 検証

レース・保存・既存の対戦に関する31テストと、334種類の走行・20万レースの試算を実施しました。ループバックの実サーバーへ独立した4ブラウザーを接続し、購入、WebSocket切断、サーバー全体の再起動、画面を閉じてからの受取、GOLD・育成の一致、重複受取防止を確認しました。

画面確認はChromiumによる幅320／393／709／1280px、最小320×568pxのスマホ・PCサイズです。4人の馬券を表示した状態で、最大桁数の払戻額と長いプレイヤー名も確認しました。実機Safariでの描画・音再生は未検証です。個別結果は `docs/build453/` に記録しています。

本版は既存環境用の累積上書き版です。Build452までのファイルを保持し、固定レイド runtime430/runtime443 は変更していません。セーブ形式は84のままです。初期素材すべてを含む独立したゲーム配布ではありません。

画像は組み込み画像生成を使用し、`assets/race453/gate.png` と `assets/race453/sand.png` に収録しました。プロンプトは `docs/build453/image-prompts.json` に記録しています。
