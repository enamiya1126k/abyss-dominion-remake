# ABYSS DOMINION Build425 / v3.1.104

今回の①「母の表示・十律輪の演出」の差し替え版です。Build424適用済みのゲームに、ZIP内の index.html と src を同じ階層へ上書きしてください。再読み込み後の表示バージョンは v3.1.104 です。

## 変更内容

- HP障壁を既存の盾ゲージと同じ形式へ変更。「HP障壁 36,000/96,000」のように現在値と最大容量を表示します。吸収後も最大容量を保持し、0になった状態も表示します。ゲージのために攻撃・障壁の計算は変更していません。
- 母が1体のときは敵側の2列・2段を使用し、通常の敵の約3倍の高さを目標に拡大します。画面幅、HPカード、状態表示、名前との間隔に合わせて上限を調整します。HPカード自体は拡大しません。
- 決戦前の魔法陣の位置指定が競合する問題を修正。キャラの可視領域の中心へ合わせ、左上にずれて見切れる原因を除きました。
- 十律輪はボスの背後の魔法陣そのものを拡大し、回転・減速・停止させます。停止時に発光と効果音を入れ、その後に技を発動します。戦闘画面を覆う専用ウィンドウは廃止しました。
- 回転前・回転中は次の結果を表示しません。数字が止まって初めて十神名と技名を表示し、そのラウンド中は発動済みの技として確認できます。
- ×1・×2・×4で演出時間を調整。動きを減らす設定では回転・拡大を省略します。演出中の画面再描画でも経過位置から継続し、終了・中断時に装飾を片付けます。
- キャッシュ指定を更新し、古い読み込み元からも修正版の表示処理を参照するようにしました。

## 確認

自動テスト312件が成功。差し替えZIPをBuild424へ展開した状態でも312件が成功しています。

検証対象は障壁の容量保持とゲージ、母の拡大上限、魔法陣の中心位置指定、10数字の停止角度、結果の先出し防止、倍速、動きを減らす設定、途中の画面再描画・中断、従来の戦闘とセーブ・報酬です。

通常ペア・別の通常編成・深淵／十神の3編成でBuild424と同条件の戦闘を比較し、勝敗、ラウンド数、与ダメージ、被ダメージ、回復、MP、障壁吸収の集計が一致しました。今回は十律輪の順番や威力、母の戦闘能力を変えていません。

表示については可視領域の座標計算とCSS優先順位を静的に検証しました。ブラウザー描画およびiPhone実機での表示・タッチ操作は未検証です。検証環境ではブラウザーがローカルページを開けないため、実機確認済みとはしていません。

詳細ログは docs/build425、テストと本体関数を用いる検証補助は tests と tools/build425 に入っています。
