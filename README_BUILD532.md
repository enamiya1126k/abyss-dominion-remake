# ABYSS DOMINION — Build532 / 3.1.211

Build531に重ねる差分更新です。釣りを「実在の魚との出会い」と「学び」を中心に拡張しました。

## 追加内容

- 獲物52→88種類。実在の生き物32種類、変わり種の落とし物4種類を追加。既存の獲物は削除していません。
- マサバ・マアジ・マイワシ・ヒラメ・マダコ・コウイカ・サンマ・ブリ。
- アユ・イワナ・ヤマメ・サクラマス・モクズガニ・カムルチーなど、水辺で知りたい生き物。
- トラフグ・ハナミノカサゴ・オニダルマオコゼ・アカエイ。食中毒の危険と毒のあるトゲを別の注意として表示。
- ピラルク・タマカイをヌシ級に追加。ヌシ級は6種類、専用を含むルアーは既存の6種類。
- コケまみれの招き猫・湖底の自転車・片っぽのスリッパ・小銭入りの財布。スリッパ→自転車→財布、招き猫→財布のゲーム用連鎖。
- 4種類の「出会いの傾向」を試合ごとに抽選。普通の魚の抽選は実在種を優先し、直近3匹を候補から外す（候補がなくなる場合と固定レシピ・ヌシは除外）。抽選テストでは実在種が約86%。変わり種の直接出現は約3%。
- 釣果カードに短い豆知識。準備・結果画面に分類ボタン付きのスクロール図鑑。出典リンクから現実の生態を確認できます。
- 36点分の専用画像を3枚の透明WebPアトラスにまとめました（合計約1.3MB）。小さな獲物はg単位で表示し、重量の丸めで0になる問題を防止。

## 学習情報とゲームの区別

名前・豆知識・注意事項は公的機関や水族館等の情報をもとに短く記述しています。各実在生物の出典は図鑑と `src/fishing/Knowledge532.js` に記載。

重量・得点・難易度・生息するゲーム内の位置・エサの連鎖はすべてゲーム設定です。連鎖による巨大化は現実の成長モデルではありません。淡水魚と海水魚が同じ湖に現れるのもゲームの演出です。ヤマメとサクラマスは同種の異なる生活型なので、88は生物学的な種数ではなく獲物の種類数です。

生成画像はイメージであり、現実の種の同定・食用判断には使用できません。安全を示す「食べられる」認定や調理・毒抜きの手順は実装していません。危険表示のない魚の安全も保証しません。

## 適用

1. 現在のBuild531一式をバックアップしてください。
2. このZIPを展開し、既存のゲームルートへ同じ相対パスで追加・上書きしてください。新規画像・JS・CSS・オフライン用ファイルも必要です。
3. `online-server` の変更も反映してサーバーを再起動してください。釣りの通信互換番号は6です。旧本体との混在を防ぐため、本体・サーバー双方の更新が必要です。
4. 全員が画面を再読み込みして入り直してください。新しい試合で魚の追加を確認できます。

外部サイトへのアップロード・デプロイは行っていません。これはフル版ではなくBuild531用パッチです。他のミニゲームの仕様は変更していません。
