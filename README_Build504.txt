ABYSS DOMINION Build504 / v3.1.183
Build503へ上書きする差分パッチです。本体とオンラインサーバーの両方を更新してください。

【今回の変更：ゴリラ大王の胸毛抜き】
・30本の毛を、胸筋の間とヘソ周辺へ集中。5本はニキビ風の毛です。
・普通の毛は痛さ+1、ニキビ毛は+2。表情用の痛さを全員分で蓄積します。
・我慢顔を8段階に変更：無表情→眉が動く→赤面→我慢→汗→歯を食いしばる→真っ赤→湯気。
  ターン交代で表情を初期化しません。ランダムな大げさな顔の切り替えは廃止しました。
・痛さは表情の演出です。痛さが満タンになるまで安全、というルールではありません。
  最初の1本でも、突然ドラミングすることがあります。
・ドラミングのあと、50％で「……今回は、許す。」、50％で本当に大激怒。
  セーフならその場で続行。抜いた毛は戻さず、残った毛から次の逆鱗を抽選します。
  普通の毛とニキビ毛で、ドラミング後の50％判定に差はありません。
・本気で怒った時だけ、強いドラミング・衝撃波・画面の揺れ・低音とともに全員が飛びます。
  引いた本人だけ、ほかの3人より長く大きく飛びます。
・非常に運よく30本すべてを抜き切った時は「全員、許された！」で終了します。
・ピンセットを担当プレイヤーの設定色に変更。付近に本人の魔物と名前を表示します。
  人間・AIとも、設定したブルー／グリーン／ピンク／オレンジを使用します。
・演出を減らす設定では、画面の揺れや大きな飛行を抑えます。

【抽選と進行】
50％判定はサーバー側の暗号学的乱数で決めます。演出の間は結果を公開しません。
連打・重複送信・再接続・サーバー再起動で抽選し直しません。
1ターン1〜3本、最初の50秒は時間非表示、最後の10秒だけ表示するルールは継続。
引き抜き・リアクション・ドラミングの間は、持ち時間を止めます。
結果の「もう一度」「ミニゲーム一覧へ戻る」は引き続き表示します。
GOLDや育成値への影響はありません。

【適用手順】
1. 現在のBuild503をバックアップします。
2. ZIPをすべて展開し、中身を既存のゲームフォルダーへ同じパスで上書きします。
   既存のファイルや素材は残してください。このZIP単体では起動できません。
3. ゲーム本体の公開ファイルを更新します。
4. オンラインサーバーも更新・再起動します。
   online-server/srcの3ファイルと、共有するsrcも更新してください。
   新規の src/gorilla/Rules504.js が必要です。
5. 全員で再読み込みし、v3.1.183を確認します。
6. ミニゲーム一覧に戻り、ゴリラのゲームを新しく開き直してください。
   更新前の502/503の試合は旧ルールで終了し、次の新規試合から504になります。
   504の新しい試合には、全員の本体更新が必要です。
