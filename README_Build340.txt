ABYSS DOMINION Build340 / v3.1.21
Build339 に上書きする差し替えファイルです。

適用
ZIP内の index.html と src フォルダを、Build339 の同じ場所へ上書きしてください。
ページを再読み込みし、ホームのバージョンが v3.1.21 になれば適用済みです。
セーブの初期化は不要です。tests フォルダは確認用で、配信には必須ではありません。

勇者ストーリー
・旅の10章に計80台詞、単独行動前の8場面に計64台詞を追加。
  野営地の帰還・撃退後、遭遇結果、最後の王室での会話も加筆しました。
・えなみの共感と論理、よりの勢いと聞き役、ひでの緻密さと抜け、
  りおんの商売気と仲間への思いを、旅先の出来事や後の会話につなげています。
・発言者だけを出演させる方式を改め、4人がその場にいるなら4人を表示。
  別行動中・道中撃退済みの勇者を通常の会話へ混ぜないようにしました。
  単独行動の遭遇結果は当人、玉座への報告はリオネルとサイラーンが出演します。
・人数が減った時の章、最後の一人の帰還、全員撃退の分岐を調整。
  無傷なのに傷を語る台詞、いない仲間が出迎える台詞も修正しました。
・古い回想の「ひで、単独行動」も登場人物を補修します。
  記録当時の生存情報、同じ周回の過去の場面・遭遇履歴から再構成し、
  現在の人数で過去の回想を書き換えないようにしています。
  古い記録に当時の状態や履歴が一切残っていない場合は、欠けた事実を完全には復元できません。
・回想の閲覧で報酬、遭遇結果、既読判定を再実行しません。
・長い台詞で人物名が隠れないように会話枠を配置。
  進行マークは折り返し、AUTOの台詞待ち時間は文章量に応じて調整しました。

仲間にした階層ボスの戦闘配置
・Build339の画像2倍表示を維持し、ホーム・探索のサイズ設定は継続します。
・戦闘では画像内の透明な余白を除いた見た目の足元と頭を基準に位置を調整。
・レア度と名前を頭上に置き、他の仲間の名前・ステータスと重なる場合は
  自分のステータス枠に専用の名前行を確保します。HPの上に文字を重ねません。
・複数の階層ボス、長い名前、画面幅の変化でも衝突を再確認します。

確認
・Nodeの機能テスト21項目合格。
  10章×16種類の生存状態、単独行動前の8場面、384通りの遭遇後分岐、
  負傷、別行動、古い回想、周回、王室の人数分岐、従来の2倍表示を確認。
・Chromiumで320 / 390 / 430 / 768px幅を確認。
  戦闘40条件（4つの編成位置と全員ボス、画像余白2種）で、
  名前と他者の名前・ステータスの交差なし、2倍表示維持、再配置のずれなし。
  11場面×4画面幅で4人の表示と長文・進行マークの収まりを確認。
・手元の差分から組み立てた検証画面を使用しています。
  旧版のCSS 77ファイルと黒鉄の剣王の元画像が手元にないため、
  戦闘は代替スプライトと透明余白を変えた検証画像でも確認しました。
  公開中の完全な画面、および実機Safariでの最終表示は未確認です。
