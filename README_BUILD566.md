# ABYSS DOMINION Build566 / v3.1.245

新ミニゲーム「よこどり！お宝クレーン」を追加した。カート・相撲の場外戦とは違い、狙う宝と発射のタイミングを選び、相手が回収している宝を奪い合う４人戦である。

GitHub main の Build563（`72c63563787f2ab5b2e519e86551065da7830ff4`）を基点に、Build564/565のエアホッケー更新を含む累積差分。Build563・564・565のいずれにも適用できる。既存の更新PR #2へ追加する。

## 遊び方

- 狙った場所をタップしてクレーンを発射。押したままなら照準を動かせる。離した場所へ伸び、最初に触れた宝をつかんで自動回収する。
- **手元に届くまで、相手の宝も横取りできる。** 最後に持ち帰った人だけが得点する。奪った宝をさらに奪われることもある。
- 金貨は１点、宝石は３点、宝箱は７点、大宝箱は12点。高価な宝ほど回収が遅く、横取りを狙われやすい。
- 赤い目と歯のあるミミックを持ち帰ると４点減り、1.2秒ひと休み。得点は０未満にならない。進路上のミミックを先につかむ事故も起きる。
- 90秒間。最後の15秒は大宝箱が出やすくなる。終了時に飛んでいるクレーンは回収まで見届ける（最大10秒）。同点は同順位。
- １〜４人で遊べる。空席と離席・切断中はAIが操作する。３人人間＋１人AIに対応。AIも同じ当たり判定・発射・得点ルールを使う。
- 全員の画面で自分は下側に表示。個人カラーと育てた相棒を使用。相棒による能力差はない。矢印キーで照準、スペース／Enterで発射も可能。

台、宝箱、ミミック、表紙の専用画像４点（WebP合計287,750バイト）。金属の爪、色付きケーブル、移動中の宝、横取りの通知、獲得点、噛まれる演出と効果音を実装した。動きを減らす端末設定に対応。スマホ縦・横画面で操作欄と盤面が収まる。
