# ABYSS DOMINION Build547 / v3.1.226

暴走ショッピングカートを、引っ張って離す操作に変更しました。

## 適用

1. Build546適用済みのプロジェクトに、ZIPの中身を上書きしてください。
2. フロント側の更新を公開先へ反映してください。
3. **サーバー側にも `src/` と `online-server/` の更新を反映し、online-serverを再起動してください。**
4. 参加者全員がゲーム画面を再読み込みしてください。

今回は入力の通信形式を変更しています。本体・サーバーの両方の更新が必要です。
旧形式の開催中カート対戦は、安全のため準備画面へ戻ります。カートの準備画面に戻ってから適用してください。
既存のセーブデータやサーバー保存データはパッチに含みません。

## 操作

- コースの空いている場所、カートの上、下部のパワー表示から引っ張れます。
- 飛ばしたい方向と**逆方向**に引き、離すと発進します。
- 短く引くと弱く、長く引くと強くなります。そのまま待っても強さは増えません。
- 引いたまま方向・強さを微調整できます。最初に触れた位置へ戻すとキャンセルします。
- 引いている間だけ、発進方向の矢印・停車目安を表示します。目安は他のカートとの衝突を含みません。
- 従来の方向バー・長押しボタンを外して、その分コースの表示を広げました。
- キーボードは上下キーで強さ、左右キーで方向、EnterまたはSpaceで発進、Escapeでキャンセルできます。

発進までの制限時間は従来どおり8.5秒です。時間切れ時は、その時点でサーバーに届いている引き加減で自動発進します。
未操作やキャンセル後は標準の強さで自動発進します。発進後は操作できません。
2本目の指、タッチ中断、ウィンドウの切り替え、画面回転、ラウンド切り替えは引っ張りをキャンセルします。

## 維持したもの

Build546の木の床、プレイヤーカラー、全5ラウンド、床の抵抗、衝突処理、金枠の得点、最後の得点2倍は維持しました。
発進方向は指の向きに対応するよう全方向を扱い、手前へ飛ばした場合も既存の壁の反射処理を使います。
他のミニゲームの操作・レイアウトは変更していません。

## 確認

- 引く長さと強さ、遠近感を考慮した方向、入力検証、重複発進、時間切れ、旧対戦の移行、全5コースの軌道予測など、9件のテストが成功。
- 実際のView・Controls・Renderer・CartCoordinatorを使い、ローカルWebSocketに接続した2つのブラウザーで発進強さの一致を確認。
- タップのみ、元へ戻す操作、タッチ中断、2本指、ウィンドウ切り替え、回転、ラウンド切り替え、コース外で指を離す操作、キーボードを確認。
- 最後の指の移動を間引いても、指が止まった後にサーバーへ届くことと、時間切れ発進がその強さを使うことを確認。
- 320×690、390×844、430×932、844×390のタッチ対応ブラウザーで表示を確認。実行エラー・不足アセットなし。

検証はChromiumのスマホ相当画面です。iPhone実機・公開サーバー全体での実地検証ではありません。
`tests/build547-cart-sling.test.mjs` と `docs/build547/` に結果を収録しました。
過去のカート入力テストも新しい通信形式に合わせて更新しています。全ミニゲームを含む旧テスト群の一括実行は、この差分環境では実施していません。

`BUILD547_MANIFEST.json` に各ファイルのサイズとSHA-256を記載しています。
