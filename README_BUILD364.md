# ABYSS DOMINION Build364 / v3.1.44

Build363に重ねる差し替えパッチです。ZIP内のファイルを同じ階層へ上書きしてください。
公開後は再読み込みし、設定画面で v3.1.44 を確認してください。サーバー更新は不要です。

## 戦闘画面

- 盾が0の場合、盾ゲージ自体を出力せず、HPとMPの間の予約スペースを除去。
- 盾がある場合だけ細い色付きゲージと残量を表示。
- バフ・デバフの2段固定、横方向への追加、はみ出し非表示を解除。
- 全効果をキャラ画像の手前へ折り返して表示。長い効果名も途中で省略しない。
- 「被ダメージ増加」を「被ダメ↑」に短縮。「ふんばり」なども短縮し、残りターン／回数を併記。
- 強化は水色、弱体・状態異常は赤系で区別。

## 詳細を開く操作（通常・勇者戦）

- 味方キャラ：タップで状態効果の詳細。
- 敵キャラ：最初のタップで攻撃対象を選択。選択中の敵を再タップすると詳細。
- 敵の行動中：敵キャラのタップで詳細。
- 状態表示：敵味方とも直接タップで詳細。
- 味方の詳細内「能力・装備・スキルを見る」で従来の個体情報も確認可能。
- 詳細は開いた時点の情報。盾の残量、勇者のふんばり、十神・深淵の特殊効果も表示。
- 閉じるボタン／×で閉じる。詳細内をタップするだけでは閉じない。

アニメーション中に戦闘DOMが差し替わってもタップを取りこぼしにくいよう、詳細操作はpointerdown時に受け付けます。キーボード操作にも対応しています。

敵味方の強さ、スキル効果、AI、報酬は変更していません。
