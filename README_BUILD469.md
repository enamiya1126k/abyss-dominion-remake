## 適用

1. Build468を適用済みのゲームのフォルダーへ、ZIPの中身を同じ階層のまま上書きします。既存フォルダー全体の置き換えや削除は不要です。
2. `online-server/src/` の2ファイルもオンラインサーバー側へ反映し、サーバーを再起動します。
3. フロント側を更新した後、参加する全員がゲーム画面を再読み込みします。バージョンは3.1.148です。

適用は進行中の対戦が終わってから行い、新しい対戦で遊んでください。古いクライアントから新ルールへの操作はサーバー側で拒否します。

## 変更した遊び方

- 最初にゴールした人がその場で優勝。ゴール後の手札点・特殊点・到着ボーナス計算を廃止。
- 手番は「山札をタップして1枚引く → カードか手動の覚醒能力を1回 → サイコロ・移動」。カードを使わず振ってもOK。移動後は自動で次の人へ。
- 通常のサイコロは2個。追加サイコロも同じ立体デザインで表示。上限5個。
- 防御と、引いた瞬間に自動発動する速攻は使用枠の外。手札に保持した速攻を自分で使う場合は1回分。
- 4枚完成シリーズは4種類をまとめて1回の使用。最初の手札3枚には絵柄が1枚入ります。
- 神殿は初回通過時に必ず止まり、未所持の絵柄を1種獲得。覚醒能力がなければ覚醒、あれば安全に1枚補充。
- 点数だけだったカードを、加速・補充・覚醒・絵柄獲得へ変更。「次のカードを強化」はその場で出目を強化。
- 普通の闇カードによる全手札破棄・手番強制終了を軽減。4枚完成は大きく進む／先頭を戻す切り札に。
- 「手札を5枚に調整」は廃止し、山札に1枚だけの安全な2枚ドローに変更。
- ゴール横取り能力は最下位からの出目加速へ変更。帰れない呪いはゴール到達時に6マス戻り、この種類の呪いを全部解除。
- 長期戦は60手番から徐々に加速。無操作の代行は45秒、切断時は30秒。

## 見やすさと操作

- 山札そのものをタップ。カードが束から出て、めくれて、手札に入ります。複数枚も順番に表示。
- 防御札が表になる瞬間に、盾・「防御成功」・「破棄2枚→0枚」などの結果を同時表示。反射も同じ場面で明示。
- 通常カードの演出には短い効果要約を表示。「効果を読む」で全文を確認できます。
- 「全体」を「全員」へ。全員の位置を囲む範囲に合わせて表示し、縮小時もコマと名前の大きさを維持。全員表示中は中央のサイコロを隠します。
- サイコロは6面を持つ立体。転がり・跳ね返り・減速のあと、サーバーで確定した面で止まります。待機時から結果まで同じ素材です。
- 月影の神殿・蒼晶の書庫・水晶の礼拝堂・熔岩の酒場・灰燼の城門・星冠の神殿を、背景の建物入口に配置。道を接続し、建物に合う効果を設定。
- 手札の開閉、整頓、写真カード、シリーズの重ね表示と完成絵柄は維持。
