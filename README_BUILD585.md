# Build585 — 魔王のせまりくる壁

Build584に上書きする差分。アプリバージョン3.1.264。

## 追加したゲーム

点数なしの４人サバイバル。全員に同じトゲ壁と予告が表示される。壁のすき間へ逃げ、最後に生き残った人が勝つ。１回ぶつかるとその試合では脱落し、復活しない。順位は脱落した順で決定する。同時脱落は同順位、最後の生存者たちが同時に倒れた場合は同率優勝。

- 画面下のパッドをなぞって移動。指を離すと停止。
- 床の目的地をタップして移動する操作も可能。PCは矢印／WASDキー。
- 赤い矢印が壁の方向、緑の帯がすき間を示す。
- 四方から壁が到来。時間とともに移動が速くなり、間隔とすき間が狭くなる。
- 空席はAI。相棒とプレイヤーカラーを反映し、全員の速度・当たり判定は共通。プレイヤー同士の衝突はない。
- 脱落後と途中参加は観戦。離席・通信切断中はAIが操作を引き継ぐ。脱落済みのキャラは再接続しても復活しない。
- 部屋主による再戦、一覧へ戻る操作、効果音OFF、動きを減らす設定に対応。

## 適用方法

1. 試合終了後、ZIP内のファイルを同じパスへ上書きする。
2. 本体に加え、online-server/srcも更新する。サーバー側から参照する兄弟ディレクトリsrc/walls585・src/partyなども同時に反映する。
3. オンラインサーバーを再起動し、参加者全員が画面を再読み込みする。

必要な既存素材はBuild584に含まれるため、必ずBuild584適用済みの環境へ重ねる。公開環境への反映は本ZIPの適用で行う。

## 検証

当たり判定、速度制限、同時脱落、復帰、４本のWebSocket、再戦、旧版拒否、キャッシュ、既存ゲームへの回帰を35テストで確認した。実画面モジュールと全290スタイルシートを読み込んだChromiumで、320×568／390×844／844×390の表示・タッチ操作・キャンセル・観戦・切断表示を確認した。

AI同士60試合のシミュレーションでは40.15〜74.125秒、中央値55.525秒で決着した。人間のプレイ時間を保証する数値ではない。iPhone実機Safari・実回線の遅延・公開環境へのデプロイは未検証。
