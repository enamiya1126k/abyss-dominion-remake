## 今回の変更

### 鬼：攻撃チャージと狭い視界

初期チャージは3回、上限も3回です。消費すると10秒ごとに1回分戻ります。満タン中の時間は蓄積しません。0回になっても負けず、追跡を続けながら補充を待てます。外しても当たっても1回消費し、同じ普通の置き物を何度も調べて消費することはできません。

鬼のカメラと視認範囲は隠れる側より狭くしました。離れた場所や壁・大きな家具の向こうにいるプレイヤーの位置は分かりません。鬼の地図には自分の位置だけを表示します。鬼はスタミナ無限です。

### 隠れる側：スタミナと仲間の位置

通常速度は鬼と同じ230。実際に15秒連続で動くとスタミナが尽き、移動速度が半分になります。停止すると0.6秒後から回復し、30%で通常速度に戻ります。空から満タンまでは約5.6秒です。壁に向かって進もうとして動いていない時間は消費しません。準備時間中も消費しません。

味方3人は、離れていてもお互いの位置を共有します。地図・ミニマップ・画面端の名前付きマーカーで確認できます。これらの味方座標は鬼の通信データには含めません。捕まった後も仲間を見守れます。

変身は準備中にランダム2択から選び、開始後は固定。生存している隠れる側全員が本番の30秒ごとに2.4秒揺れるルールは継続しています。

### 館・庭・森がひと続きのフィールド

2900×2900から4800×4400へ拡大しました。橋で分離した島々の構成をやめ、大きな館の外に庭と森が広がる連続した敷地に変更しました。

館内には大広間・書庫・食堂・寝室・厨房・貯蔵庫・回廊・書斎・玄関ホールの9区画。室内の扉、複数の外への出入口、館の周りの広い庭を利用して逃げ道を選べます。建物の寸法や張り出し、扉、自然の配置が毎回変わります。庭の舗装から外れた芝生や森の地面も歩けます。

小物は場所の用途に合わせて配置しました。例えば食堂はテーブルの周りに腰かけ、厨房は壁際に麻袋や魚かご、貯蔵庫は樽や木箱をまとめて配置します。森の床に瓶や家具を無作為に散らすことはしません。

新規生成素材：芝生・林床・石畳・寄木床、本棚・寝台・食卓・ソファ・机・かまど・食器棚・噴水・花壇・樹木・ベンチ、館のカバーイラスト。床模様、絨毯、壁、窓明かり、樹木の重なりも描画しています。

### 操作

画面上の移動スティックを撤去しました。

- 床をタップ：その場所へ障害物を避けて移動。
- 指を滑らせる：移動先を続けて更新。指を離しても最後の目的地へ進みます。
- 「止まる」：すぐ停止。隠れる側は休憩にも使えます。
- 地図を開いて床をタップ：離れた部屋や庭を目的地にできます。
- 鬼は置き物をタップして選び、近づいて「調べる」。
- PCの矢印・WASD操作も継続対応。

準備20秒、本番180秒。広い敷地を探索する時間を確保しました。鬼が3人全員を捕まえれば鬼の勝利、時間切れ時に1人でも生存していれば隠れるチームの勝利です。
