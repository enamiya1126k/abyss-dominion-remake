ABYSS DOMINION REMAKE release179 / build238

これは release178 に上書きする「差し替え部分だけ」の更新です。
ゲーム全体は含まれていません。

主な更新:
- 参加予定・未定のギルド遠征を開始30分前からゲーム内で案内
- 参加可能な集合が始まったら、交流ボタン・ギルドタブ・予定カードへ「集合中」を表示
- サーバー時刻基準の表示と、再接続しても同じ案内を繰り返さない端末内受領記録
- 主催者だけが使える「集合を終了」を追加（遠征予定と参加表明は残る）
- 交換の受渡し状態と未受取報酬を原子的なサーバー保存へ変更
- 片方だけ交換受取済みの直後にサーバーを再起動しても、未受取側だけを復旧
- 端末キー・再接続キーは平文保存せず、保存失敗時は配布前に停止
- 保存状態を /health で確認可能

適用方法:
1. 進行中の交換を終え、オンラインサーバーを停止します。
2. 更新前の `online-server/data` フォルダを別の場所へバックアップします。
3. ZIPを展開し、中の `abyss-dominion-remake-main` フォルダを開きます。
4. その「中身」を、release178適用済みの `abyss-dominion-remake-main` フォルダへ同じ階層で上書きします。
5. `online-server/data` フォルダと既存のJSON保存ファイルは削除しません。
6. オンラインサーバーを起動します。
7. ブラウザを再読み込みします。

注意:
- ZIP内の階層を崩さずに上書きしてください。
- 差分ZIPには画像・音声などのゲーム素材、`online-server/node_modules`、実際の`online-server/data/*.json`は含まれていません。
- 初回起動時に `online-server/data/settlements.json` が自動作成されます。交換・未受取報酬の復旧に使うため、更新やバックアップ時に保持してください。
- 遠征通知はゲーム内表示だけです。OS通知、通知音、自動入室、自動出発は行いません。
- 通知と集合終了だけでアイテム、GOLD、魔晶石、週間共闘Pt、活動履歴などの報酬は発生しません。
- オンライン通信はprotocol 1.16.0、`guilds.json`はversion 3、通常セーブはschema 58のままです。

詳しい仕様は BUILD238_GUILD_REMINDERS_AND_SETTLEMENT_DURABILITY_UPDATE.md を確認してください。
