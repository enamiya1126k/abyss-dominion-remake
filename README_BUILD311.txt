1. セーブ・再入場・旧データ保護

2. 100階進行・勇者決戦

   ・途中勇者戦の結果も保存完了まで画面を閉じず、再試行可能に変更
   ・勇者の残存HP、途中撃退、四結末、81〜100階の再踏破記録を再検証

3. 報酬の二重取得防止
   ・すでに所持しているボス専用装備から、対応する受取済み記録だけを復元
   ・通常装備欄、予備装備欄、ボス装備保管庫の三か所を対象に救済
   ・再読込や予言9日目の再踏破で、専用装備・欠片・GOLD・魔晶石を再配布しない
   ・未受取の報酬だけは一度だけ受け取れる状態を維持

4. iPhone Safari相当の表示・操作監査

   ・下部メニュー用の領域を探索画面内に予約し、ダンジョン画面との重なりを防止
   ・ストーリー／結末のスキップと主要操作を44px以上のタップ領域に統一

   ・自動攻略ボタンのドラッグ、画面内制限、位置保存を再確認

5. 表示素材・旧表記・キャッシュ
   ・実績35件は承認済み画像キーだけを使用し、保存済みの旧絵文字も画像へ復元
   ・固定canvas絵文字とCSSの文字記号を除去し、既存ピクセル素材または画像フォールバックへ統一
   ・現在読み込まれる画面とオンライン通知から、旧「10F／20F」式の表示を除去して「1階／2階」式へ統一
   ・オンライン挑戦階層、次階扉、踏破報酬の残存F表記も修正
   ・main.jsから到達する38モジュール・116 importのキャッシュ識別をbuild311へ統一
   ・履歴用で現在のindex.htmlから読み込まれない旧bundleは実行対象外
