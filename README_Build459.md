# Build459 / v3.1.138 — 距離・周回・近走成績となつき度

Build458までを含む累積上書き版です。既存ゲームとオンラインサーバーの同名ファイルへ上書きし、サーバーを再起動してください。セーブ・サーバーの保存データ・既存画像は残してください。ZIPには保存データやnode_modulesを含みません。

**新機能は更新後に作った新しい部屋から有効です。** ゲームとサーバーの両方を更新し、一度退出して新規作成してください。更新前の部屋は1000m・旧ルールを継続します。「もう1レース」だけでは旧ルールは切り替わりません。

## システム出走の詳細記事

出走予定の魔物に「詳細記事」ボタンを追加しました。魔物画像、能力、脚質、得意な馬場、特技、今回の距離で注目する能力、保存済みの近走成績を確認できます。閉じると元のスクロール位置に戻ります。

この段階は仮エントリーです。プレイヤーと重複した魔物は従来どおり交代します。当日の調子・人気・倍率は出走確定後のパレードで発表します。

## パレード

キャラの左右中央へ、大きな◀・▶ボタンを置きました。タップ・左右スワイプのどちらでも切り替えられ、8番の次は1番になります。縦スワイプは画面スクロールです。新聞、特技、近走履歴を読む間は自動紹介を停止します。

## 4種類の距離と芝・砂

| 距離 | 形状 | 特徴 |
| --- | --- | --- |
| 500m | 直線 | 速さ・序盤の加速 |
| 1000m | 直線 | 速さとスタミナ配分 |
| 1600m | 楕円・1周 | 器用さ・コーナーでの走り |
| 3000m | 楕円・2周 | 持久力・終盤の余力 |

部屋主が開始前に選びます。芝・砂と距離は別々に選べます。次のレースは距離を保持し、芝・砂は従来どおり交替します。予想が始まったあとは変更できません。

距離で能力評価とスタミナ消費が変わり、コーナーでは器用さが速さへ反映されます。特技・AIの叩くタイミングはレースの長さに合わせます。吸い付き走法の範囲は、従来の100mから新ルールではコース全長の10％になります。

周回レースでは楕円のコース上を実際の進行に合わせて走り、周回数・直線／コーナー・残り距離を表示します。「相棒を追う」で、自分の魔物の姿・順位・位置を追加表示できます。全体の順位、全員の馬券、5回の操作は維持しています。接戦のスロー再生も周回の位置へ対応しました。

表示時間は距離・条件・操作によって変わります。全334種類を含む試算では、500mが約13〜23秒、1000mが約19〜33秒、1600mが約26〜48秒、3000mが約37〜67秒でした。すべての将来の組合せでこの範囲になるという保証ではありません。

## 近走履歴

- 手持ちのカードへ「前走○着・馬場・距離」と、最近5走の着順を追加しました。左ほど新しい記録です。
- 選択した魔物の詳細では、距離・馬場別の出走数／勝利数／3着以内の回数、各レースの調子・疲労・タイムを確認できます。
- プレイヤーの記録は同種でも個体ごとに分けます。システム・AI出走は種類ごとに記録します。
- 記録は新ルールで完走したレースから蓄積します。過去の未保存レースの成績は作りません。
- 保存上限は各個体20走、アカウント全体で直近200件です。システム・AIも種類別20走、全体200件です。条件別の集計は表示中の保存記録が対象です。
- 結果確定時にサーバーへ保存し、自分の履歴は賞金・育成報酬と同じ一度だけの受取処理でセーブにも保存します。

## なつき度と指示への反応

| なつき度 | 表示 | 1レースで反応が遅れる確率 |
| --- | --- | --- |
| 0〜199 | 気まぐれ | 15％ |
| 200〜599 | 慣れてきた | 5％ |
| 600〜1000 | 息ぴったり | 0％ |

対象は最初の「ケツを叩く！」だけで、1レース最大1回です。「いうことを聞かない…！」と表示され、受け付けた加速が0.6秒遅れて発動します。回数とスタミナの消費は通常の1回分で、再送しても重複しません。残りの操作は待たずに続けられます。ゴール後に追加の加速は行いません。通信遅延は別途発生します。

なつき度を出走確定時に固定し、予測勝率にも反応の遅れを含めています。システム・AIのなつき度は0で、同じ確率・同じ5回の操作制限を使います。レベル・装備・レア度による走力強化は導入していません。

## 展開予想

出走表へ展開予想を追加しました。逃げ型が3匹以上なら、序盤のペースと消耗が増え、終盤の余力が重要になります。この変化も実際の走行と事前の予測へ共通で反映します。

MAX BET、7種類の馬券、購入時に固定する倍率、出走賞金、育成報酬、疲労と回復は継続します。💎での賭けは追加していません。
