# Build372 / v3.1.52 — ホーム画面アイコン

Build371適用済みのゲームフォルダーへ上書きする差分ZIPです。

## 内容
- 青いスライム・リオネルと黒金の王冠装飾に、金色のABYSS DOMINIONタイトルを入れた専用アイコンを作成。
- タイトルはABYSS／DOMINIONの2段構成。
- iPhoneホーム画面用のapple-touch-iconとブラウザー用アイコンを指定。
- サブディレクトリーのGitHub Pagesにも対応する相対パスを使用。
- ホーム画面の名称候補はABYSS DOMINION。
- アイコン画像はassets/icons/abyss-title-372.png。生成画像を加工せず格納。

## 適用
ZIP内を同じ場所に上書きし、普段の方法でWeb側を配信してください。サーバー側の変更や再起動は不要です。
Safariでサイトを再読み込みし、共有から「ホーム画面に追加」で新しいアイコンを確認してください。既存アイコンの自動更新は保証していません。先に既存アイコンやWebサイトデータを消去しないでください。
このパッチはセーブ保存方式・アプリ識別子・起動URL・全画面設定を変更していません。

## 確認
PNGの正方形サイズ、画像デコード、HTMLの参照先、GitHub Pages相対パス、差分ZIP内の画像格納を確認。実際のiPhoneへの追加は未検証です。
制作は組み込みimagegenを使用。最終プロンプト要旨：元の青いスライムと黒金装飾を維持し、上部にABYSS DOMINIONを重厚な金色セリフ体で追加。正方形、不透明、余計な文字やキャラクターを追加しない。
