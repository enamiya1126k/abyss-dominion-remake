# Build427 / v3.1.106 — ③ ホーム・ショップの整理

Build426 に上書きする差し替え版です。ZIPを展開し、同名ファイルをゲームのルートへ上書きしてください。ゲーム配信に必要な変更は `index.html` と `src/` に入っています。

## ホーム

- 下部の「ショップ」を「装備管理」に変更。既存の装備画面へ移動します。
- 左側の装備管理ボタンの位置に「共闘レイド」を追加。今回は入口のみで、押すと「開催準備中」を表示します。
- 下部の「パーティ」は「現在運営による調整中です。ご迷惑をおかけいたします。」と表示し、その先へ移動しません。
- 右側の「部隊編成」から、これまでどおり編成を変更できます。

共闘レイドの共有HP、1日3回の挑戦、ランキング、撃破報酬、オフライン結果の同期は、後続の依頼分です。

## 常設ショップの廃止と宝箱

ホームの常設ショップと購入処理を廃止しました。既存の所持品・GOLD・購入履歴は保持します。ダンジョン内の闇市場・深淵裏街は今回の廃止対象に含めません。

確認したところ、元の宝箱にはGOLD・装備などの抽選と、一部での薬草入手がありましたが、常設ショップの14商品すべてを抽選する処理はありませんでした。第一章・第二章のソロ探索の宝箱に、以下の消耗品抽選を追加しました。

| 対象の宝箱 | 追加で抽選する種類数 |
| --- | ---: |
| 第一章の通常宝箱・薬草系の箱など | 2種類 |
| 第一章の鍵付き宝箱・輝く宝箱・宝物庫内の宝箱 | 3種類 |
| 第一章の支配者の戦利品 | 3種類 |
| 第二章の通常宝箱 | 2種類 |
| 第二章の宝物庫の各宝箱 | 3種類 |

同じ宝箱の追加抽選では種類が重複しません。薬草・魔力水は1〜3個、上級回復薬・上級魔力水・浄化薬は1〜2個、その他は1個です。GOLDや装備などの従来報酬に追加されます。ミミックは対象外です。

抽選対象は「捕獲結晶」「薬草」「上級回復薬」「全体回復薬」「魔力水」「上級魔力水」「全体魔力水」「魔力全快薬」「全体魔力全快薬」「蘇生の葉」「浄化薬」「全体浄化薬」「万能霊薬」「全体万能霊薬」の14種類です。通常の回復薬を出やすく、全体全快などの強力な品を出にくくしています。具体的な重みは `src/core/ChestSupplies427.js` にあります。

獲得した品名と数量は宝箱の結果画面に表示します。第二章では帰還報告にも集計します。開封済みの宝箱への遡及配布は行わず、既存の開封記録・戦利品の受領記録で重複を防ぎます。オンライン探索のサーバー側の宝箱処理は今回変更していません。
