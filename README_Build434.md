王室の勇者4人との会話・個人戦を追加した、いつもの上書き用統合ZIPです。Build432の共闘レイド、Build433の十神の母の修正も含みます。

## 入れ方

1. いつものゲームフォルダーとセーブ、サーバーの `data/` をバックアップします。
2. ZIPを解凍し、**中身を全部、既存の `index.html` があるフォルダーへ上書き**します。既存フォルダーを削除する必要はありません。
3. いつもどおりGitHub Desktopからコミット・Pushして更新します。
4. サーバーを別の場所で動かしている場合は、停止してから同梱 `online-server/` と隣の `src/` も更新し、再起動します。すでにBuild433を適用済みなら、今回サーバー専用の追加作業はありません。
5. ゲームを再読み込みし、**v3.1.113** を確認してください。

**既存の `data/`・設定・セーブは保持してください。** このZIPに利用者の保存データは入っていません。`world-raid-offline434-sw.js` と `world-raid-offline434-assets.json` も一緒に更新します。

Build424以降に適用する累積更新版です。元のゲーム一式と既存画像は必要です。こちらから公開先への反映は行っていません。

## 王室：勇者一行への初勝利後

- えなみ・より・ひで・りおんの**体や名前をタップ**すると、その人の会話メニューが開きます。歩いて触れた場合も、触れた勇者を選びます。ドラッグはカメラ移動として扱います。
- **話す**：それぞれの台詞。初めて話した時だけ、各人から「経験値パック（超）×3」を受け取れます。
- **個人戦に挑む**：今の部隊4体と、選んだ勇者1人の手合わせ。相手はLv.1,000、既存の本人の技と6部位の専用装備を使用します。こちらの強さや4人戦の進行による自動補正はありません。
- 個人戦の**初勝利**で、その勇者の専用右手装備を1個獲得します。Lv.1,000・＋0。えなみは「創世のゲームパッド」など、既存の専用装備です。通常所持・予備BOXが満杯でも王装保管庫へ届きます。
- 個人戦は何度でも挑戦できます。初勝利報酬は各人につき1回で、会話の贈り物とは別記録です。
- 手合わせ開始時に部隊を全回復し、終了時はHP・MP・状態異常・回復アイテム・GOLDを手合わせ前へ戻します。勝利・敗北・撤退のいずれも同様です。
- 勝利後は既存の**活躍表 → 報酬画面**へ進み、王室へ戻ります。
- **勇者一行と再戦**：どの勇者のメニューからも、従来の4人戦へ進めます。Lv.1,000から500刻み、最大Lv.10,000の段階と報酬を維持します。個人戦でこの段階は進みません。
- **玉座**：結末の回想専用。ラベルをタップ、または近づいて回想できます。輪廻転生の選択肢は設けていません。

会話は既存の黒金の枠素材を使い、短い画面では内容を縦にスクロールできます。背景・キャラクター画像の差し替えはありません。初回の王室決戦の進行、道中の勇者の傷、第二章の進行は維持しています。
