# ABYSS DOMINION Build573 / v3.1.252

混沌の先に5種類の背景を追加しました。既存10種類と合わせて全15世界です。

| 到達距離 | 世界 |
| --- | --- |
| 10秭m（10^25） | 静寂の月面 |
| 1000秭m（10^27） | 金星の灼熱地表 |
| 10穣m（10^29） | 太陽の海 |
| 1溝m（10^32） | 星の墓場 |
| 1正m（10^40） | 宇宙の再誕 |

月は混沌の10倍から。最後の再誕は遠い隠し世界です。実際の天体間距離ではなく、ゲーム内の到達条件です。月面は写真調、金星は黄土色の岩石地表、太陽はプラズマ、星の墓場と宇宙の再誕は創作の宇宙景観です。実写素材ではありません。

自分の累計距離に従って変化します。距離が減ると前の背景へ戻ります。次の世界の一覧・予告はプレイ中に追加しません。新5背景は縦横比を維持した1枚のパノラマとして表示し、繰り返しの境目をなくしました。背景は固定で、キャラ・目盛り・速度演出が動きます。従来10背景の動きは維持します。
