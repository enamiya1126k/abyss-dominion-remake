## 第二章の戦闘

第二章の新規戦闘では、味方のみの「部隊の備え」（HP28倍・攻撃魔力12倍・防御魔防8倍・速度16倍、および段階追加倍率）を撤廃した。ペアの連携は既存の敵味方共通処理を維持する。条件、生存判定、回数、回復割合、妨害による停止は共通である。

補正撤廃に合わせ、第二章の遭遇データに含まれていた固定能力の膨張を整理した。調整は敵生成時に固定値として適用し、プレイヤーの編成・レベル・勝敗に連動する加減は行わない。最大HPと現在HPは旧値の1/14、攻撃魔力1/24、防御魔防1/12、速度1/5を基準とする。後半の宝物庫はHPさらに0.65倍、攻撃魔力0.5倍、防御魔防速度0.8倍。後半の地域ボスは攻撃魔力0.8倍とした。敵の装備・魔法陣・固有スキル・ペアは継続して働く。

更新前に保存された第二章の戦闘は、旧戦闘の能力・HP補正のまま終了させる。新仕様は次の新規戦闘から適用する。

第一章・王室・欠片試練・4対4・回廊の既存補正は、このパッチでは変更しない。深淵・十神のキャラクター定義・所有キャラの能力・専用技は変更しない。第二章に敵として配置された個体の固定遭遇能力は上記の対象となる。オンライン処理・サーバー・セーブスキーマは変更しない。

## 原初の聖胎

理の中枢（第二章の最終地域）踏破後、「探索開始 → 第二章 → 原初の聖胎・十神の母」から入場できる。既にクリアしたセーブでも同じ入口が現れる。新たにクリアした場合は既存の結末の後に導入会話が続く。

王室のEntity・Camera・経路探索・接触判定・30fps描画・移動操作を流用した20×30の専用1区画である。入口から中央で母と対面し、準備後に母へ触れて既存の手動／自動戦闘へ進む。奥の祭壇は結末・回想・再戦に使用する。編成・装備・拠点への導線を維持した。

### 原母イオネア

十神へ力を分け与えた母。子を失う恐れから世界を閉じた存在であり、決戦を通して「守ること」と「選択を奪うこと」の違いに向き合う。

Lv4200、HP700000、魔力22000、速度8000。光・闇の魔法、全体攻撃、回復、障壁、強化解除を既存のスキル処理で使用する。新しい戦闘ルールは追加していない。通常召喚・野生遭遇・捕獲の対象外である。

背景は黒曜石・古金・白い灯の聖域。キャラは銀髪、黒と象牙色の祭服、金の冠と糸を持つ。透過アトラスを既存レンダラーへ接続し、待機・歩行・攻撃・被弾・戦闘不能の各フレームを指定した。元画像の冠が上端に触れる1ポーズは使用せず、完全な待機ポーズへ差し替えた。

### 勝利・再戦・結末

初回勝利はGOLD300000、魔晶石1000。勝利→既存の活躍表→報酬→結末の順に表示する。再戦は同じ強さで、初回報酬を再付与しない。消耗品と入場前のHP・MPは決戦終了時に戻す。敗北・撤退後も再挑戦できる。

会話は導入4場面、対面9場面、敗北2場面、結末15場面。読んだ位置と完了を保存する。閉じた場合は続きから読める。世界の封鎖を解いて第二章を完結させ、母にも知らない場所からの短い返事を後日談に残した。第3章の実装・開始は含まない。通常の探索・育成は継続できる。

## 検証

271件の自動テストを実行。既存の操作・合成・進行・温泉・表示・オンライン互換・セーブ回帰、および新規の補正撤廃、敵味方ペア発動、母の実AI戦闘、実セーブ再読込、会話途中再開、決戦チェックポイント、報酬一度限り・消耗品とHP復元を確認した。

12遭遇 × 3編成 × 3乱数 = 108戦を既存戦闘処理で検証した。79勝、28敗、40ラウンド上限到達1戦。勝利を保証するテストではなく、編成差・敗北・長期戦を含む調整資料である。レベルは敵に合わせた1500〜6270、母は4200。LR汎用装備6枠とLv1魔法陣を使用した検証用編成であり、ユーザーのセーブを直接再現したものではない。

母は硝子＋返誓、黒白の竜姉妹＋支援編成で5〜7ラウンドの勝利を確認。他の検証編成では敗北も発生する。全編成が全相手へ自動で勝つ調整ではない。各戦の結果はdocs/build422/balance-audit.jsonに収録する。

実ブラウザーとiPhone Safariの描画・タップ・FPS確認は未実施。UIは生成HTMLと処理境界の検証であり、実機確認済みとは扱わない。
