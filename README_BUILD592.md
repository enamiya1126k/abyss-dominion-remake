## 変更内容

- キャラクター位置の描画と、ハート・残弾・案内などの更新を分離。情報表示は毎秒10回とし、位置描画は最大毎秒60回。カウントダウン等の同じHTMLを書き直さない。
- スマホ等のタッチ端末ではCanvasの内部解像度をCSSピクセルと同じにする。従来の1.5倍から、同じサイズなら描画ピクセル数を約56%削減。ボタンや文字はDOMのままなので端末解像度を維持する。離れた場所の粒子も描画しない。
- 他プレイヤーの表示は通信フレームの補間と最大50msの短い補外を使い、各人の物理演算を端末で重複して実行しない。自分の操作には従来の物理予測と補正を維持する。
- AIに「先行」「援護」「踏み役」を追加。待ち合わせ位置、出発タイミング、穴や敵へのジャンプ距離、射撃距離が異なる。「援護」は後ろ寄りで遠くの敵に攻撃し、「踏み役」は弾より踏みつけを優先する。仲間が射線上にいる時は射撃しない。待つ／走るが細かく切り替わらないよう余裕を設けた。プレイヤーがゴールするとAIは待つのをやめ、ゴールへ向かう。
- 左右操作を大きな一体型パッドへ変更。中央の継ぎ目もタッチでき、押したまま滑らせて方向を変更できる。中央のごく狭い範囲では直前の方向を保つ。指がパッドから少し外れても操作を継続し、大きく外れる／離す／取消／画面を隠すと解除する。
- 新しく押した時と方向変更時に8msの振動を要求する。65ms以内の重複を抑え、長押し中に繰り返さない。対応ブラウザには振動ON/OFFを表示。非対応ブラウザには「振動非対応」を表示する。音ON時は短いクリック音、ボタンは即座に色と沈み込みが変わる。
- 横向きでは攻撃とジャンプを右親指側にまとめる。

## 振動について

標準の `navigator.vibrate` が利用できる環境に限る。OSの設定、ハードウェア、ブラウザによって実際には振動しない場合がある。非対応環境のために別の権限を求めたり、隠したスイッチを操作したりする実装は行っていない。iPhone/Safari実機での触感は未確認。

仕様確認: https://developer.mozilla.org/en-US/docs/Web/API/Navigator/vibrate
