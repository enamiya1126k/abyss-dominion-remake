# Build515 — 〇×サバイバルの演出改良

v3.1.194 / Build514からの差分。

## 変更

- 〇×を床面の中央へ移動し、大きく表示。
- 残り「1」の間もキャラ1匹分＋余白を残す。0秒で約140msの急落、着地の揺れと砂埃を追加。
- 残り3・2・1を大きく表示し、数字の拡大と警告音で強調。0秒の衝撃音は通信の確定通知で二重に鳴らさない。
- マグマのしぶき・火の粒・煙を拡大し、高さと広がり、落下時の音を強化。
- 上昇時、古い壁は不透明なまま下へ流れて画面外へ消える。
- 崩れた側の床は復活させず、上の階にある別の床を画面上から入れる。次の壁も上から入り、次の問題の配置に連続してつながる。
- 全員脱落、最後の1人、20問目で終了する場合は、存在しない次の階を表示しない。

## 更新方法

1. Build514のゲームフォルダーをバックアップする。
2. ZIPの内容を同じ階層へ上書きし、本体の更新ファイルを公開先へ反映する。
3. ゲームを再読み込みしてv3.1.194を確認する。

**サーバーがBuild514であれば、本更新によるサーバーの更新・再起動は不要。** 新ルールの通信形式、移動速度、判定時刻、20問制、難易度、押し戻しはBuild514のまま。セーブを削除しない。Build513以前の場合は、先にBuild514の本体・サーバーを適用する。

## 確認結果

クイズの既存53項目＋新しい演出9項目、合計62項目成功。許可した変更対象以外の既存1,781ファイルはBuild514とSHA-256一致。ルールとサーバーのソースも変更していない。

iPhone Safariの実機表示・実際のタップ感・FPSは未確認。詳細は `docs/build515/verification.md`。
