# Build543 — 帰ってこい！暴走ショッピングカート

バージョンは v3.1.222。Build542適用済みの本体とサーバーに上書きする差分パッチ。
既存13ゲームのルール・物理・AI・画面・CSSは変更していない。共通パーティーに新作の接続先を追加した。

## 適用

1. 稼働中のゲームとサーバーのデータをバックアップする。
2. ZIPを展開し、Build542のプロジェクト直下へ同名ファイルを上書きする。
3. 本体をいつもの公開先に反映し、online-serverを再起動する。
4. 各参加者が画面を再読み込みする。パーティー一覧の最上段に「帰ってこい！暴走ショッピングカート」が追加される。

このZIPにはセーブデータ、online-server/data、環境変数ファイルを含まない。
公開サイトへの反映は行っていない。新旧の混在は本体・サーバーのバージョン判定で案内する。

## ルール

- ４人対戦。空席はAI。所持している相棒と指定プレイヤーカラーを使用する。相棒による性能差はない。
- 全５回。各回は３秒の開始合図の後、8.5秒以内に発進する。
- 下の大きなボタンを長押しし、離すと発進する。1.8秒で最大、最大以降は強さを維持する。発進後の操作はない。
- 待ってから押すことも可能。押す長さだけでなく、後から発進して追突を狙う駆け引きがある。
- 各車の進路は中央へ寄る。カート同士の衝突は速度と接触方向から計算する。止まったカートも押される。
- 奥に止まるほど１〜100点。駐車エリアに届かない場合と、車体の先が崖の線を越えた場合は０点。横の壁は跳ね返る。
- 得点は全車が止まるまで仮表示。全車停止１秒後に確定する。最終回のみ得点２倍。５回の合計で順位を決め、同点は同順位。
- 場外になっても、それまでの回の得点は失わない。次の回に全員が復帰する。スタート位置は毎回交代する。
- 無操作の時間切れは55%で自動発進。押し続けたままの時間切れは、その時点の強さで発進する。
- 指の操作中断、画面を離れた場合は押す操作を取り消す。通信切断・ホーム滞在中はAIが代行し、復帰後は未発進なら再び操作できる。
- キーボードではスペース長押し・離す。支援技術のクリックでは押す／離すを切り替えられる。

## 画面と演出

魔王城の市場、坂道、金属カートを画像生成で制作し、WebPで同梱した。
ゲーム内のカートに相棒を重ね、名前・足元・得点枠にプレイヤーカラーを反映する。
全員が発進するとカメラが駐車勝負へ寄る。追突の火花、カートの揺れ、場外の回転、得点の仮表示と確定、よりの「イージー！」を実装した。
背景はキャッシュして毎フレーム作り直さない。描画DPRは最大1.5。通信は100ms間隔、物理計算は25ms固定刻み。
画面が隠れている間は描画を止める。低減モーション設定も参照する。

生成ファイルは assets/cart543/cover.webp、track.webp、cart.webp。
生成方法と最終プロンプトは docs/build543/art-prompts.json に記録した。既存Build542の基本４体のキャラ画像も使用する。

## 検証

- 自動テスト59項目を通過。既存Build540〜542の45項目と、新作14項目。
- 長押し時間、キャンセル、発進後の入力禁止、停止車への追突、場外、横壁、衝突後の運動量、時間切れ、最終回２倍、同点順位、保存・再戦を確認。
- AIを30種類の乱数シードで５回戦まで動かし、得点・場外・衝突の発生と、有限時間での終了を確認。
- ローカルChromiumで320×568、390×844、430×932、844×390を確認。
- ２人のWebSocket接続で、独立した長押し、相手側への反映、色設定、切断時AIと復帰を確認。
- 実際のRaceClient451とパーティー用CSSを読み込んだ画面でも、定期更新中の長押し・発進・再戦・画面離脱時のキャンセルを確認。
- 既存各ゲームのコードとCSSがBuild542と同一であることをバイト比較した。共通クライアントとパーティーの追加分は差分パッチに含む。

検証記録は docs/build543/ 以下に同梱する。スクショは別ZIPで提供する。
カート同士の接触・場外のスクショは、再現用の配置から実際の物理計算と描画を動かした画面である。

この環境に完全な本体の初期ファイルは揃っていないため、ローカル確認では欠けている既存キャラカタログ／共通ポートレートのみ検証用データを使用する。
ゲーム本体・物理・AI・サーバー・生成素材は実装そのものを使用する。検証用データは tools/ 内に隔離し、本番から読み込まない。
iPhone実機Safariでの確認および公開サイト全体の動作確認は行っていない。
