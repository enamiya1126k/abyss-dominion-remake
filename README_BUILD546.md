## 暴走ショッピングカートの床

- 石タイルを四角く貼り付ける描画を撤去しました。
- 元の木の道に、屋外の日光・市場の映り込み・連続した木目がある背景を制作しました。
- 第2ラウンドと最終ラウンドは、それぞれの滑る区間に合わせた背景を使用します。
- 説明文を「ツヤのある木の床は滑る」に合わせました。
- 新しい背景が読み込み中・取得失敗の場合は、元の木の道を表示します。
- 背景は描画キャッシュに保存し、カートの毎フレーム描画と分けています。

操作、画面構成、得点、床の滑り具合、衝突判定、プレイヤーカラーはBuild545のままです。
他のミニゲームのコード・デザインは変更していません。

## 確認

実際のカート用View543・Renderer543・Rules543を読み込むローカル検証画面で確認しました。
状態は再現可能なローカル対戦データを使用しています。公開サーバー上の対戦・iPhone実機での確認ではありません。

- Chromium / タッチ対応画面 390×844、320×690、430×932、844×390。
- 第2・第5ラウンドの通常表示と追従ズーム。
- 第1・第3・第4ラウンドの背景は、旧版とのピクセル比較で一致。
- 方向指定、長押しからの発進、カート移動。
- 背景の遅延読込中の表示と、読み込み完了後の切り替え。
- 操作・物理・レイアウト関連ファイルはBuild545とバイト単位で一致。
- ブラウザーの実行エラー・不足アセットなし。

確認記録は `docs/build546/`、検証用コードは `tools/build546/` に収録しています。
背景の制作指示は `docs/build546/art-prompts.json` に記録しています。内蔵の画像生成を使用し、画像は `assets/cart546/wax.webp` と `assets/cart546/sale.webp` に格納しています。
