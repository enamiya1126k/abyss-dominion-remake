# Build418 / v3.1.97 — ② 探索・編成画面

①の Build417（v3.1.96）を適用済みのゲームへ上書きする差分ZIPです。

## 適用方法

ZIPの中身を、ゲームの `index.html` があるフォルダーへ同じ構成のまま上書きしてください。既存の assets などはそのまま必要です。フォルダーごとの削除・置換はしないでください。更新後はページを再読み込みし、ホームのバージョンが **v3.1.97** になっていることを確認してください。

セーブの初期化は不要です。セーブキー・形式（schema 84）は変更していません。

## 修正内容

- 第二章の回復の泉：HP・MP・状態異常を回復しながら、そのまま通過できます。回復のたびに探索画面を再生成して移動経路を失う処理を修正しました。
- 泉に立ったままの回復・保存の連発を防止。いったん離れて入り直すと再び回復できます。手動移動・自動探索ともに対応しています。
- 編成カード：説明の長さに合わせてカードと説明枠の高さが伸びます。「第二章装備・魔法陣の組み合わせ」の文字が固定枠からはみ出す原因を除去しました。
- スキル編集・交代・隊列から外すボタンを説明欄より上へ配置。ボタンの高さを44px以上とし、下部ナビゲーションまで考慮してスクロールの余白を確保しました。

第一章の温泉の利用回数・回復仕様、キャラクター能力・報酬・オンライン処理は変更していません。①の進行不具合修正を維持しています。
