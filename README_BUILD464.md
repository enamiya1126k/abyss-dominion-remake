# ABYSS Build464 — カードすごろくの操作・演出改善

Build463への累積更新です。APP_VERSION 3.1.143 / Save schema 84（変更なし）。

## 変わったところ

- マスに「2枚引く」「3マス進む」「2マス戻る」「1回休み」などの効果を直接表示。進行方向も矢印で表示し、タップすると従来どおり全文を読めます。
- スマートフォンは画面内に盤面・操作・手札を収める構成。横向き／画面サイズ変更時の追尾も補正します。
- 手札に属性色の枠、カードの厚み、軽い重なりを追加。触ると持ち上がり、タップでコンパクトな詳細画面を開きます。
- 今使えるカードは金色に光って浮遊。使えないカードは控えめに暗くし、「移動後に使う」「攻撃時に防御」「所持中に有効」など理由を表示。暗いカードも詳細を確認できます。
- 引いたカードや任意のカード処理が終わり、その段階で使えるカード・特殊能力がなければ、自動でサイコロ／次の手番へ進みます。強制休みも自動処理します。通常の手番開始の「カードを引く」は操作として残しています。
- 防御、攻撃対象、分岐、捨てる札、特殊カードの選択は自動で飛ばしません。自動処理はサーバーが判定します。
- 公開された基本カードは全員の画面で「共通裏面 → 回転して表面 → 効果・対象表示」。対象のプレイヤー枠／コマも強調します。
- 複数の発動を順番に再生。画面再描画で演出が最初からやり直されたり、最後のカード以外が消えたりしないようにしました。防御選択はカード紹介のあとに表示します。
- サイコロを転がす演出と、実際の出目・補正後の移動マス数を表示。コマ移動は出目紹介のあとに再生します。
- 画面効果を減らす設定では回転・浮遊を抑制。接続し直した時に過去のカード演出を大量再生しません。

カード116種類／山札335枚、カードの効果順、マップ構成、点数、到着ボーナス、秘密の手札、パーティー共有、魔物レース、RPG本体の所持金・育成データは維持しています。

## 適用方法

1. 既存のゲーム一式にこのZIPの中身を上書きします。これは累積更新ZIPであり、過去のベースにしか存在しないファイルを含む完全な単独配布版ではありません。
2. フロントエンドとオンラインサーバーの両方を更新します。サーバーにも共有の `src/sugoroku` と `online-server/src/SugorokuCoordinator463.js` が必要です。サーバーを再起動してください。
3. ブラウザを再読み込みして、Build464が適用されたことを確認します。

本番サイトへのデプロイは行っていません。
