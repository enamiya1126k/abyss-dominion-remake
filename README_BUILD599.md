## 今回の６点

- カクつき・瞬間移動：一時停止中に変わる開始時刻で補間履歴を繰り返し消していた処理を修正。入力履歴を48件に拡張し、バネ・踏みつけの計算をサーバーと画面側で共通化しました。
- 針山への攻撃：６属性すべての弾が針山を通り、重なっている敵にも届きます。プレイヤーに対する針山の壁判定・上からの接触判定は維持します。
- ホーム画面から復帰：接続前に押し出された再開要求を失わず、サーバーの処理確認まで再送します。通信が生きていれば接続を使い続け、応答が1.2秒ない場合は接続を張り直します。切断済みなら再接続の待ち時間を省きます。生存確認の待ち時間であり、全環境で1.2秒以内の復帰を保証するものではありません。待機中も本人は元の位置に表示します。
- 敵の踏みつけ：小さく跳ね、ジャンプを離して押し直すと空中でも通常ジャンプできます。風の空中ジャンプ回数も回復します。
- バネと移動の長押し：上から着地したときだけ跳ね、左右の長押しを保ったまま移動できます。地面付近でバネが繰り返し発動する処理を撤去しました。
- バネの横：絵に合わせた高さ28の壁として扱い、左右から入ろうとしても押し戻します。横から触れただけでは跳ねません。
