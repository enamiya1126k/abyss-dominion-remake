# ABYSS Build468 — 写真カードと4枚の絵柄

アプリ版 3.1.147 / セーブスキーマ84。Build467の全ファイルを引き継いだ累積更新ZIPです。既存プロジェクトへ上書きする更新で、単独起動用の完全な本体ではありません。

## 変更したところ

- より7枚・えなみ7枚・りおん9枚・ひで20枚、計43枚の写真をカードへ割り当てました。原写真のバイト列は変更せず収録。ゲーム上の枠内だけをCSSでトリミングし、通常カードの詳細では写真全体を表示します。写真の人物や背景をAIで描き直していません。
- 写真に合わせて基本カードの名前を変更。効果・点数・デッキ内枚数・カードIDはBuild467から維持しています。43枚すべてがカードまたはシリーズで参照されています。
- 4枚完成シリーズを縦に少しずらした束で表示。「所持3枚・2/4種類」のように、重複と絵柄の進行を区別します。束を開くと2×2の絵柄で足りないパーツと、各パーツの所持枚数を確認できます。
- 「天空の盟約」（旧・四勇者の肖像）と「闇を持つひで」は、それぞれ1枚の写真を4分割。同じ写真・同じ表示範囲を4つのパーツで共有し、4種類そろうとひとつの写真になる演出を表示します。
- 完成演出は手札の持ち主だけに表示。完成だけでカードを消費・発動しません。自分の移動前に「4枚を使って発動する」を選びます。各セット1人1回というルールも維持します。
- 「整理」を「整頓」へ変更。使える札 → 完成セット → 集めかけのセット → 通常札 → 防御・所持札の順で自動整頓。端末内のルールで即時に並べ、外部AIへ写真や手札を送信しません。長押しでシリーズごと移動でき、重複札も失われません。「広げる」では従来の絞り込み・並び順も利用できます。
- 相手選択をキャラクターの肖像・名前・残りマス・手札枚数が並ぶ横長の選択行へ変更。選択中の相手が光り、「この相手と交換する」などのボタンで確定します。
- カード詳細は写真 → 名前／ランク／点数 → 効果 → 使用条件の順へ整理。装飾を外縁へ移し、説明が重ならない余白を確保。長い内容はスクロールできます。
- 手札の常時上下運動を止め、使えるカードは枠の光で示します。タップしやすさと読みやすさを改善しました。

Build467までの道沿いのマップ、画像サイコロ、共通裏面、ドロー演出、覚醒、闇の速攻演出、複数捨て札、手札開閉、相手の非公開手札、AI戦の再開・終了を引き継いでいます。

## 適用

1. 現在のプロジェクトをバックアップする。
2. ZIPの中身を、既存プロジェクトの同じ場所へ上書きする。
3. オンラインサーバーとフロントエンドで共有する `src/sugoroku` も更新し、オンラインサーバーを再起動する。
4. 参加者全員がページを更新する。

公開サイトへの反映は行っていません。育成・GOLD・レース・セーブ仕様・マスの効果・カード効果は変更していません。
