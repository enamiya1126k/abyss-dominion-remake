# ABYSS DOMINION — Build535 / v3.1.214

Build534に重ねる差分更新。「魔獣ぶっとばし相撲」の演出・チャージ・アイテム・AI・結果画面を更新しました。

## 変更内容

- 成長時にキャラの左右へ出ていた括弧状の装飾を撤去し、頭上に小さなLv表示を追加。
- 磁石を金属・コイル・宝石の専用画像へ変更。吸引中は収束する輪と粒子を表示。
- 被弾してもチャージを継続。吹っ飛ばされている間も蓄積し、溜めた状態で離すとよろけ中でも反撃できます。場外・画面非表示・操作キャンセルでは解除。
- チャージ量に応じて炎状のオーラ・光・上昇粒子を強化。MAX到達時は一度だけ鋭い光と「キュピン」を意識した上昇音。その後も金色のオーラを維持。
- レベルに応じてチャージ容量・威力上限・蓄積速度を強化。ボタンに現在の威力上限を表示。
- 突進ガイドを半透明の軌道、縁取り、山形の先端へ変更。表示距離と実際の速度・継続時間は同じ計算を使用。
- 崩壊６秒前から外周石板が浮き、隙間と発光する亀裂、小片で予告。崩壊時は厚みのある石板が時間差で傾いて落下。文字に頼らず危険な帯を表示。
- 土俵が縮小した後はカメラを少し寄せ、残った土俵とキャラを見やすく調整。
- 新アイテム「踏ん張りの鉄靴」を追加。次に受ける体当たり１回の吹っ飛ばし・よろけを防いで消滅。２人からの同時攻撃でも１発分だけです。重複所持不可。
- 既存の土俵際の救済は、鉄靴と別枠で１試合に１度。鉄靴も救済も床の崩壊・自分からの落下は防ぎません。
- AIに採集重視・アイテム重視・決闘型・攻め重視の４傾向を追加。チャージ方向・レベル差・装備・外周を考慮し、人間かAIかで狙いを変えません。退避先も全員が原点へ向かわず、自分の近くの安全帯へ。攻め重視型は踏み込みを誤って落ちる可能性があります。
- 結果画面に専用の表彰台背景、勝者の大きな姿、４人分の順位・最終Lv・撃墜・命中・結晶・鉄靴の防御回数を追加。

強い一撃で序盤に終わりすぎないよう、AIは最初の18秒を採集中心とし、攻撃後も採集や移動を挟みます。100シードの４AI対戦はすべて最後の１体まで決着。平均63.06秒、最初の脱落は平均42.99秒、席別勝利数37／29／23／11でした。人間の勝率や実機の体感を示す数値ではありません。

## 適用

1. Build534適用済みのゲームをバックアップしてください。
2. ZIPの相対パスを保ち、既存ルートへ追加・上書きしてください。
3. **本体・online-serverを両方更新し、サーバーを再起動してください。** サーバーから参照するルートの `src/sumo/` も同時に反映します。
4. 全員が画面を再読み込みして入り直してください。相撲の通信互換番号は３です。旧本体は更新案内で止まります。

対戦がない時に更新してください。旧相撲データは位置・成長・脱落・経過時間・磁石・土俵際の救済を保持し、チャージは割合を引き継ぎます。RPGのセーブ形式は変更していません。

差分ZIPのため単独では起動できません。公開・デプロイ・実サーバー再起動は行っていません。
