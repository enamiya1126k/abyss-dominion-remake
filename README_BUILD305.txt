ABYSS DOMINION REMAKE - Build305 最終差し替えパッチ
====================================================

対象
----
Build304 を適用済みのゲーム一式へ上書きしてください。
セーブ形式は schema 75、アプリ表示は v3.0.5、オンラインサーバーは 1.16.0 です。

Build305：全体仕上げ監査
--------------------------

1. スマホ全画面・スクロール・ボタン
   - 汎用モーダルをセーフエリア対応の単一スクロールへ統一
   - 閉じるボタンを44px以上・上部固定にし、縦長画面でも常時操作可能
   - ホーム、探索、4対4、戦闘、編成、装備、持ち物などの主要操作領域を監査
   - 低い横画面でも画面全体をスクロールできるよう修正
   - タップできない表示の誤ったポインター表現と、重複したバージョン表示を整理
   - 致命的エラー画面もiPhoneのセーフエリアと長文スクロールに対応

2. 戦闘時間・AI・CT・MP
   - 戦闘バナーとダメージ表示の待ち時間を短縮し、手動戦闘の間延びを軽減
   - 敵の固有行動CTを、味方スキルと同じ「使用ラウンドを含めない」契約へ統一
   - 固有行動と通常行動が同じCTを二重に進めないよう修正
   - 自動戦闘の全体MP回復を、残量・消費率・味方全体の不足状況で判断
   - 状態異常回復を含む複合スキルも回復候補として正しく評価
   - オンライン戦闘演出を速度設定に連動し、終了後に残留タイマーを一括解除

3. 放置・4対4・レイド・宝箱の報酬監査
   - 放置報酬の序盤上限を4時間から8時間へ緩和し、以後を段階的に調整
   - 放置GOLDの加算を安全上限で飽和させ、巨大な旧データでも破損しないよう修正
   - 4対4は第1試練の GOLD×0.5・魔晶石25・EXP×1 を維持
   - 高試練の報酬暴走を抑え、GOLD×20・魔晶石100・EXP×20を上限化
   - 確定装備を第10=SR、第25=SSR、第40=UR、第50以降10区切り=LRへ整理
   - レイドは現在の人数補正・週次配布・再接続時の一度きり受取を回帰確認
   - オフライン支配者宝箱へ、残りカケラ枠1つにつき魔晶石5個を追加
   - ミミックの魔晶石も階層換算後の深度に合わせ、オンラインとの差を縮小

4. 表示・操作の整理
   - 資源欄の重複したヘルプ判定を廃止し、タップ時は正確な所持数を表示
   - 専用の資源ヘルプ導線は維持
   - 全画面シーン、探索HUD、戦闘コマンド、下部ナビの押下領域を統一
   - Build305用CSSを最終読込にし、旧画面の個別レイアウトを壊さず補正

5. 旧データ移行・二重取得防止
   - Build301〜304、snapshot v2／v1、旧1000階データを schema 75 へ救済
   - 壊れたschema、root型崩れ、不正階層を安全に正規化
   - 「8」と「08」など同一階の重複では、COMPLETE側の強い取得状態を保持
   - 数値だけ残った幽霊鍵、4本目の鍵、オンライン側の幽霊鍵を生成しない
   - 支配者宝箱のpartial／COMPLETE領収書を双方向照合し、再取得を防止
   - 最終決戦の中断状態だけを妥当な地点へ復旧し、通常探索など他の戦闘は保護
   - 同じセーブへ移行を繰り返しても結果が変わらないよう冪等化

6. オフライン・オンライン回帰
   - ゲストの階層、ボス、ホスト世界をローカル進行へ混入させない
   - 退出、切断、再接続後もHP・MP・未受取報酬を一度だけ復元
   - ゲスト退出後もホストだけが次階へ進み、ゲスト側の最大階は更新しない
   - 実WebSocketで4人接続、チャット、ヘルス確認、定員を通し確認
   - online-server/data と既存運用データには変更を加えない
