# Build569 / v3.1.248 — 魔王城の爆弾リレー

爆発までの秒数を見て直前に渡すだけになっていた遊びを、所持による加点と点を失うリスクのあるルールへ変更しました。Build568のエアホッケー視点・操作改善、Build567のキャベツ縦スライド、Build566のお宝クレーンを含む累積パッチです。

## 遊び方

- 全3ラウンド。開始時の爆弾数は1→2→3個。1人で複数持てます。
- 爆弾1個につき0.1秒で1点。2個なら毎秒20点、3個なら毎秒30点。飛んでいる間は加点しません。
- 前半6秒は「時計が消えるまで」の秒数を表示。その後4〜8秒の間で爆発します。単に既知の残り時間を隠す方式ではありません。後半の時間は爆弾ごとに異なります。
- 後半の正確な爆発時刻はサーバーだけで管理し、通信データにも含めません。音・点滅・ゲージでも残秒数を知らせません。
- 爆発すると脱落し、そのラウンドで得た点は0。前のラウンドの確定点は残ります。生還者には30点を加え、現在の点を確定します。
- 全爆弾がなくなるか、生存者が1人以下になるとラウンド終了。次の回は全員復活します。同時爆発による全滅にも対応しています。
- 初期配布は試合全体での「爆弾の延べ所持時間」が短い人から。同じなら初期配布回数、同数なら試合開始時にランダムに決めた席順で決定。初期配布は別々の人へ。機会の偏りを抑える補正であり、完全な均等配布を保証するものではありません。
- 爆発した人が別の未爆発の爆弾も持っていた場合、その爆弾は生存者のうち延べ所持時間が短い人へ移ります。
- 下の手持ち爆弾を選び、渡したい相手をタップ。受取後0.5秒は渡せません。爆弾ごとに待ち時間を管理します。パス飛行は0.18秒。

## 画面

濃い青緑と金縁の円卓、魔法陣、中央の大きな時計、番号と色を付けた爆弾、手持ち選択パネルへ更新しました。爆弾をキャラの足元へ配置し、顔に重ねません。複数持ちの加点速度と失う可能性がある「この回の点」を表示します。後半は一定周期の光だけになり、残秒数を示しません。低モーション設定にも対応します。
