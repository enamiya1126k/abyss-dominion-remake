ABYSS DOMINION REMAKE
Build306 UI・操作・表示整理 差し替えパッチ

============================================================
1. このパッチについて
============================================================

本パッチは、Build305を適用済みのゲーム本体へ直接上書きするための
差し替えパッチです。単体では起動できません。

リリース識別情報
  ・ゲームバージョン: 3.0.6
  ・ビルド: build306
  ・セーブスキーマ: 75（Build305から変更なし）
  ・オンライン通信プロトコル: 1.17.0
  ・オンラインサーバーパッケージ: 1.17.0

============================================================
2. Build306の対応範囲
============================================================

  ・探索画面の「戦利品の鍵」表示を小型化し、画面を遮らない位置へ整理
  ・自動攻略ボタンを小型化し、ドラッグ移動と位置保存に対応
  ・スマートフォンで下部メニューがゲーム画面へ重なる問題を修正
  ・戦闘中の属性説明を自動収納し、必要なときだけ確認できる表示へ整理
  ・戦闘画面で敵名や表示要素が重なる問題を修正
  ・実績表示の絵文字を廃止し、既存の画像素材による表示へ統一
  ・実績報酬の受け取りボタンを小型化
  ・全体戦力ランキングへログイン状況表示を追加
  ・旧10F単位の階層表記を、現在の1F単位の表記へ全面移行

本パッチはUI・操作・表示整理を目的としています。セーブデータの初期化、
オンラインデータの初期化、ゲーム進行の作り直しは行いません。

============================================================
3. 導入方法
============================================================

1) Build305適用済みのゲーム本体と online-server/data をバックアップします。
2) Build306パッチを展開します。
3) 展開した内容をBuild305のゲームルートへコピーし、同名ファイルを上書きします。
   フォルダーを一段深く入れ子にせず、index.html と src が既存のゲームルートへ
   直接重なる状態でコピーしてください。
4) オンライン機能を利用している場合は、オンラインサーバー側のファイルも
   同時に上書きし、サーバーを再起動してください。
5) ブラウザーを再読み込みします。旧表示が残る場合は、Safariを含むブラウザーで
   タブを閉じて開き直すか、キャッシュを無視した再読み込みを行ってください。

============================================================
4. ロールバック
============================================================

問題が発生した場合は、Build306を適用する前に保存したBuild305のバックアップを
ゲームルートへ戻してください。

セーブスキーマはBuild305と同じ75のため、Build306はセーブ形式の更新を要求しません。
ただし、コードとデータの組み合わせを確実に戻すため、作業前のバックアップは必ず
保持してください。online-server/data は通常そのまま利用できますが、オンライン側で
問題が発生した場合は、サーバー停止後に作業前のバックアップから復元してください。

============================================================
5. 注意事項
============================================================

  ・Build304以前へ直接適用しないでください。必ずBuild305直上へ上書きしてください。
  ・online-server/data と node_modules を削除したり、空のフォルダーで置き換えたり
    しないでください。
  ・オンライン機能ではクライアントとサーバーの通信プロトコルが一致する必要が
    あります。Build306クライアントとオンラインサーバー1.17.0をセットで更新して
    ください。
  ・クライアントだけ、またはサーバーだけを更新した状態では、バージョン不一致により
    オンライン接続を拒否します。
  ・ランキングのログイン状況はオンラインサーバーが保持する接続・最終活動情報を
    もとに表示します。サーバーへ接続できない間は最新状態へ更新されません。
  ・既存セーブを残したまま上書きできますが、配布前および適用前のバックアップを
    推奨します。
