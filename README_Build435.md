# ABYSS DOMINION — Build435 / v3.1.114

今回の修正をまとめた、いつもの上書き用統合ZIPです。Build432の共闘レイド、Build433の十神の母、Build434の王室修正も含みます。公開先への自動反映はしていません。

## 入れ方

1. ZIPを解凍します。
2. 中身を全部、いつものゲームの `index.html` があるフォルダーへ上書きします。元のフォルダーや画像は削除しないでください。
3. いつもどおりGitHub Desktopなどで更新内容を公開します。
4. ゲームを再読み込みして **v3.1.114** を確認してください。

既存のセーブ・設定・サーバーの `data/` は保持してください。念のため上書き前にゲームフォルダーをバックアップしてください。このZIPは利用者の保存データを含みません。

Build424以降のゲーム一式へ重ねる累積更新版です。単体起動用の全画像入りZIPではありません。すでにBuild434を適用していれば、今回サーバー側の追加作業はありません。それ以前から更新する場合のサーバー手順は同梱のBuild432〜434の案内に従ってください。

## 今回の修正

- **十神の母の部屋**：撃破後、結末をまだ読んでいなくても原母が残ります。入り直しても体・名前へのタップや歩行接触から再戦できます。原母の配置をタイトルと重ならない位置へ移しました。祭壇から結末の回想も可能です。
- **鍵表示と部隊表示**：原初の聖胎の「鍵3/3」を取り除き、「部隊状況を開く／閉じる」を操作できるようにしました。
- **共闘レイド**：ボスの姿・HP・挑戦ボタンをコンパクトにまとめました。カケラ交換所のダイヤアイコンを取り除きました。
- **今日の残り**：今日発行した未使用の保存済み挑戦も含めて表示します。3回保存した場合は、使用に応じて3→2→1→0へ減ります。前日発行の有効な挑戦権は別枠で表示。サーバーが予約時に1日3回の枠を消費する仕組みは維持しています。
- **レイド戦闘**：ブラウザーの表示領域に合わせて、戦場・ステータス・自動／速度・中断まで1画面に収めました。スキルやアイテム選択は、画面内の一時パネルで一覧だけスクロールできます。
- **戦力ランキング**：生成した専用の装飾枠を使った横長カード。上位3人は金・銀・銅、自分の行は青緑の枠で示します。キャラクターや順位、戦力、公開パーティーへのタップを維持しています。
- **召喚ページ**：画像生成で制作した祭壇と光の門のバナーに、既存のキャラクターや装備アイコンを重ねました。実際の召喚価格・提供割合・曜日・初回や無料の受取条件は変更していません。
- **勇者からの初回プレゼント**：台詞と専用の金色の紋章、アイテムと個数を見せる演出を追加。「受け取る」を押すまで付与されません。各人の経験値パック（超）×3は1度だけ。保存失敗時は再試行でき、受取済みの贈り物を見直しても再付与されません。
- **個人戦**：最初はLv1500。勝つごとに次は＋500、各勇者別に記録します。敗北・撤退では上がりません。既存の上限に合わせて最大Lv10000です。Build434のLv1000勝利済みデータは、報酬受取記録を残し、次はLv1500から始めます。旧バージョンで進行中のLv1000戦も継続できます。
- **勇者一行との再戦**：本編のLv1000戦への初勝利を進行記録に含め、次のLv1500を自動選択します。以降も勝つと次の＋500段階へ。勝利済みの低い段階を選び直した場合は、最高到達段階を進めません。
- **報酬とセーブ**：個人戦の初勝利装備は従来どおりLv1000・＋0で各人1度。個人戦と4人戦の進行は独立しています。転生のシステムや選択肢は追加していません。
