# ABYSS DOMINION Build536 / v3.1.215

新ミニゲーム「化けて隠れろ！ 魔王のかくれんぼ」をパーティー一覧に追加する更新パッチである。
適用元はBuild535であり、このZIP単独でゲーム全体を起動することはできない。

## 更新方法

1. 現在の本体・サーバーとセーブデータをバックアップする。
2. ZIP内のファイルを、既存のBuild535と同じ相対位置に上書きする。
3. `online-server`の更新も適用し、Node.jsサーバーを再起動する。
4. ブラウザの画面を再読み込みする。全参加者がBuild536に更新してから集合する。
5. ホーム下部の「パーティー」から「魔王のかくれんぼ」を選ぶ。

セーブキー・セーブ形式は変更しない。既存の所持魔物、育成、装備、資産は変更しない。
バージョンの古いサーバーや参加者では開始できないようにした。

## ルールと操作

- 鬼1人対、隠れる側3人で対戦する。足りない席にはAIが参加する。
- 部屋主は「おまかせ」「自分が鬼」「自分が隠れる」を開始前に選べる。
- 隠れる準備は8秒、対戦は90秒である。準備中、鬼には室内と隠れ場所を表示しない。
- 床をタップすると、その場所まで移動する。鬼が家具をタップすると選択し、調べられる距離まで自動で近づく。
- 鬼はランタンの周囲だけを確認できる。「調べる」で攻撃する。攻撃は12回であり、命中・空振りの両方で1回消費する。調査済みの家具は再攻撃できない。
- 鬼の「索敵」は2回であり、近くの隠れる側の気配を一時的に示す。再使用には14秒を要する。
- 隠れる側は宝箱、壺、椅子、樽、燭台、石像の6種類に変身できる。変身間隔は1.5秒である。
- 同じ場所に20秒いると青い気配が漏れる。家具1個分ほど移動すると気配の蓄積をリセットする。細かな左右移動だけではリセットしない。
- 隠れる側の「煙幕」は各2回であり、約3.6秒間、範囲内の家具を鬼から隠す。再使用には8秒を要する。
- 鬼が3人全員を捕獲すると鬼の勝利となる。90秒経過、または鬼の攻撃が尽きると隠れる3人チームの勝利となる。
- 捕まった後は仲間を観戦する。結果画面には「もう一度」「ミニゲーム一覧へ戻る」を配置した。
- 持ち込む魔物による能力差は設けない。相棒選択・名前・プレイヤーカラーは既存パーティーに接続する。
- 通信切断・ホーム滞在中はAIが代行する。再接続で本人の操作に戻る。

## ビジュアル

魔王城の室内、6種類の家具アトラス、魔王の立ち絵、表紙の4素材を画像生成で新規作成した。
生成素材のWebP合計は約1.51MBである。実際のゲーム画面に、ランタンの視界、気配、煙幕、捕獲演出、効果音を組み込んだ。
