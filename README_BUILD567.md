# Build567 — キャベツ千切りを縦スライドへ

本体 v3.1.246。Build566 のお宝クレーン、Build565 のエアホッケーを含む累積パッチです。

## 遊び方

- 作業台を上下になぞると包丁が追従。下まで切り下ろすと10点、上へ戻して次の一切り。
- 左右タップのボタンを廃止して、その面積を作業台に使用。横画面も画面内に収まります。
- PC はマウスの上下ドラッグ、または ↑ で持ち上げて ↓ で切る操作。
- 「切るな！」では手を止めます。持ち上げるだけなら安全。切り下ろすたびに −80点、まな板・テーブル・床の傷が残ります。
- 45秒、4人対戦、不足席のAI、10コンボの追加5点は従来どおりです。

## 切断と破片

切断面は包丁の下端の位置に合わせた2D描画マスクです。指の動きでその場で更新し、通信の応答を待ちません。切り終えた位置からキャベツの切れ端が飛び、重力、まな板への跳ね返り、回転、摩擦、静止までを小さな2Dシミュレーションで描きます。禁止中の一切りでは木片になります。

破片は最大40個。静止した破片の物理更新を省略し、古い破片は消去します。描画時間が継続して高いと自動で24個・低解像度に切り替わります。動きを減らす設定では破片を省略し、操作に必要な包丁の追従を残します。追加の物理エンジンや画像ダウンロードはありません。

## 対戦・更新

新規ルームは `controlVersion567:1`。サーバーは持ち上げ→切り下ろしの順序、入力時刻、連番、重複、古いルームを検証します。通信するのは連番・操作の種類・時刻だけで、破片や毎フレームの座標は送りません。左右タップの旧パケットでは新規ルームの得点を増やせません。

開始済みの旧ルームは従来の操作で完走し、次の試合から縦スライドになります。新規ルームの開始には全員の本体更新が必要です。

PR のファイルを反映するか ZIP を既存プロジェクトへ上書きし、フロントと `online-server` を合わせて更新してください。**オンラインサーバーの再起動が必要です。** このパッチの作成・PR更新だけでは公開サイトや稼働サーバーへ自動反映されません。
