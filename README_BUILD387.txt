適用先と更新方法
このZIPはBuild386 / v3.1.66へ上書きする差分パッチです。
単体で起動するゲーム一式ではありません。Build385以前の場合は先にBuild386を適用してください。
1. ZIPを展開し、中身を既存の abyss-dominion-remake フォルダーへコピー。
2. src・assetsなどを既存フォルダーへ統合し、同名ファイルを上書き。
   srcの中にもう一つsrcを作らないでください。
3. GitHub Desktopで変更を確認し、コミット → Push origin。
4. いつもの公開更新後に再読み込みし、v3.1.67を確認。
セーブ初期化は不要。所持魔物・装備・物語・鍵・宝物庫報酬を維持します。
新しい部隊に会うには、進行中の戦闘を終え、拠点からその地域の再探索へ入り直してください。
各地域の踏破後に再探索できます。倒した部隊へ再挑戦する場合も拠点から入り直します。

専用ペア共鳴：今回3組、合計9組
同じ陣営で2人とも生存中、通常攻撃・固有技・支援技のあとに相方が追撃。
各キャラ1ラウンド1回、1組で最大2回。追加MPなし。追撃から再発動しません。
同じキャラの複数個体や、同ラウンドの蘇生・セーブ再開では回数は増えません。
戦闘不能・捕獲・隔離・追加行動の封印で停止。敵も同じ効果を使います。

■ 白黒・綴命の契り（リッカ＋リンネ）
相方が敵全体へ物理2.20倍、生存味方全体に最大HP12%の障壁。
発動時に姉妹のどちらかがHP35%以下なら「白黒・繕命の奇跡」に変化！
全体3.10倍＋生存味方全体HP18%回復・HP18%障壁。
両方の生存が条件。姉妹以外の味方が瀕死でも変化せず、戦闘不能者は復活しません。
対策：回復阻害を入れ、低HPの一方を集中攻撃で倒す。

■ 氷紅・硝子の二重奏（セリア＋カルミア）
相方が敵全体へ魔法2.20倍、防御15%無視。生存味方全体HP10%回復。
速度低下と回避低下の両方がある敵には3.63倍へ強化！ 敵ごとに条件を判定。
対策：どちらかの弱体を消すと強化条件が崩れる。魔法防御と浄化が有効。

■ 終始・双冠の断罪（アエリエル＋ヴェスペラ）
最初の対象の解除可能な強化を1つ取り除いてから、1.25倍×3連撃、防御35%無視。
相方の攻撃・魔力の高い方を使用し、生存味方全体HP12%回復。
最初の敵を倒すと残りの打撃は別の生存敵へ。強化解除は1発動で1つまで。
対策：強化だけに頼らず、障壁・能力値と片方への集中攻撃で防ぐ。

共鳴は実際の装備・魔法陣・能力値・命中・防御・属性・障壁を使って計算します。
回復阻害は共鳴回復にも適用。障壁は残量と比較して大きい方へ更新し、無限加算しません。
対象は手持ち部隊の通常戦闘（第一章・第二章・王室など）。
サーバーで処理するオンライン戦闘へのペア共鳴は本弾には含みません。
