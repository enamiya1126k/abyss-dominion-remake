# Build570 / v3.1.249 — テトラポットの進行度・復帰修正

## 再現できた不具合

中継の島を踏まずに周囲の足場を進むと、通常のジャンプだけでゴールへ到達できるのに、中継判定だけが止まり、進行度37％の未ゴール扱いになる。ユーザー画像と同じ「座標はゴール、中継1、進行度37％」を再現した。突然移動した瞬間の通信記録はないため、その瞬間の原因までは断定していない。

旧版ではこの状態でも到着先を復帰用足場として保存でき、ゴール判定を満たさないままゴールに復帰できる経路もあった。

## 修正

- 中継の島に着地した場合に加え、その中継地点より先の足場へ正常に着地した場合も中継通過とする。
- 飛び越え中や落水中には通過扱いにしない。正規の着地処理だけで進行度・中継・ゴールを更新する。
- 未ゴール状態ではゴールを復帰先に使わない。保存された復帰先が現在の進行範囲より先の場合も、通過済みの中継へ戻す。
- ロビー説明を実際の中継判定に合わせて更新。
- ゴール順の順位決定、150秒制限、最初のゴールから20秒の締切は維持。

再現ルートは旧版で「中継1 / 37％ / 未ゴール」、新版で「中継5 / 100％ / 正式ゴール」となる。画面の中継数はゴールを含めず4/4で表示する。過去の試合結果は変更しない。

## 反映

Build569までを含む累積パッチ。本体・online-serverの両方を上書き更新し、サーバー再起動、全員の再読み込みが必要。サーバーの保存データは含まない。

通信ルール `tetraVersion539:5` / `rulesVersion:5`。旧ルールの進行中ルームは準備画面へ戻り、やり直しとなる。PR更新だけでは公開版には反映されない。
