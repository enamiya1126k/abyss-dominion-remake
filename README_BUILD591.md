# Build591 / v3.1.270 — 協力も、いたずらも。８つの冒険

Build590適用済みの本体へ上書きする差分ZIPである。

## 適用方法

1. ZIPを展開し、中身をプロジェクトのルートへ同じフォルダ構成で上書きする。本体の`src`、`online-server/src`、`index.html`、キャッシュ更新ファイルをすべて反映する。
2. 本体の配信ファイルを更新し、`online-server`を再起動する。依存パッケージの追加は不要である。
3. 参加者全員がページを再読み込みし、**v3.1.270 / Build591**にそろえる。

差分のため、空のフォルダへの展開では動作しない。Build590までを順番に適用した本体が必要である。以前のランナーズの保存済み部屋は準備画面へ戻り、全員の準備OKが解除される。

## 今回の変更

- 長押しでの文字選択・コピー用メニュー・画像ドラッグを、ゲーム画面とボタン内の文字を含めて抑制する。移動・ジャンプ・攻撃の同時操作、左右スライド、指を離した時・タッチ取消・画面切替時の入力解除に対応する。
- AIの大量の先読み計算を、周囲の穴・敵・壁・仕掛けの確認へ置き換える。足場・背景・敵の絵を再利用し、毎フレームの描画負荷を減らす。プレイヤー表示を座標レイアウト更新から移動変換へ変更し、通信位置の補間・補正を追加する。
- 敵の頭を横切った足の軌道で踏みつけを判定する。端をかすめる着地や速い落下にも対応する。踏まれた敵・攻撃で倒した敵は、その冒険中は復活しない。
- 全８ステージを４人の協力冒険へ統一する。個人順位・先着争いをなくし、全員ゴールを目標とする。最初のゴールによる時間短縮はない。
- 火・風の紋章を各ステージへ配置する。右下の攻撃ボタンで発射し、押し続けると一定間隔で連射する。PCはX／Kで攻撃する。
- ステージ選択を絵付きカードへ変更し、ゲーム中の背景・地形を共通の描画様式とステージごとの配色にそろえる。

## 自由な４人プレイ

仲間を踏むと高く跳べる。壁キックも使用できる。仲間の弾に当たると少し吹き飛ぶが、弾そのものではハートを失わない。吹き飛んで穴に落ちた場合は通常のミスとなる。連続で一方的に吹き飛ばされないよう、仲間の攻撃に対する短い保護時間を設ける。

各プレイヤーはハート３つで開始する。ミスすると共有のチェックポイントから再開する。ハートを使い切った場合も約2.2秒後にハート３つで復活する。脱落して長時間観戦する必要はない。空席・切断中はAIが操作し、操作中の仲間を大きく追い越さないよう待つ。ゴール済みのプレイヤーは仲間を観戦できる。

紋章の取得はプレイヤーごとに独立する。火の紋章は10発、風の紋章は８発である。発射間隔は火が0.42秒、風が0.58秒である。復帰時には紋章を失い、旗付近の紋章を取り直せる。
