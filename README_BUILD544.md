# Build544 — 暴走ショッピングカート 大改装

v3.1.223。Build543適用済みプロジェクトへ上書きする差分パッチ。
対象はショッピングカートのみ。ほかの13ゲームのルール・専用画面・CSSは変更していない。

## 適用

1. ZIPを展開し、Build543のプロジェクト直下へ同名ファイルを上書きする。
2. 本体をいつもの公開先に反映し、online-serverを再起動する。
3. 参加者全員が画面を再読み込みする。

本体とサーバーの両方が必要。公開サイトへの反映はこの作業では行っていない。
古いバージョンの参加者には更新を案内する。更新前の進行中カート戦は準備画面へ戻る。
セーブデータ・online-server/data・環境変数ファイルはZIPに含まない。

## 遊び方

下のボタンを長押し → 離して発進。操作はこれだけ。
強さは1.8秒で最大になる。開始合図の後、8.5秒以内なら好きなタイミングで押せる。
長押し中の白い輪は、ほかのカートに衝突しない場合の停車目安。
床や加速ベルトも計算に含むが、接触や通信タイミングで実際の位置は変わる。

全５回の路面が変わる：

| 回 | コース | 狙い方 |
| --- | --- | --- |
| 1 | はじめての坂 | 普通の床で力加減をつかむ |
| 2 | 床、磨きたて。 | 青い床はよく滑るので弱めに |
| 3 | ふかふか大通り | じゅうたんで減速するので強めに |
| 4 | 返品エクスプレス | ベルトで１度だけ加速する |
| 5 | 閉店セール | 滑る床＋加速ベルト。得点２倍 |

- 奥に止まるほど１〜100点。金枠に判定範囲が収まって止まれば、さらに＋50点。
- 金枠のボーナスは仮。追突で動きだしたり、金枠から押し出されたりすると失う。
- 海へ出るとその回は０点。前の回までの得点は残る。
- 全車が止まってから採点。５回の合計で順位を決める。同点は同順位。
- 最終回は金枠ボーナスも含めて２倍。金枠を複数回訪れても重複加点しない。
- 待ってから発進し、ほかの車にぶつける駆け引きは継続。発進後の操作なし。
- 無操作の時間切れは、その回の床に合わせた控えめな強さで自動発進する。
- 指の操作中断・画面を離れる操作は長押しを取り消す。切断時のAI代行と復帰、再戦も継続。
- 所持相棒と指定プレイヤーカラーを反映。相棒の性能差なし。スタート位置は交代する。

## ビジュアル

画像生成で海辺の市場と食材入りカートを新規制作し、WebPで同梱。
大きめのカート、指定色の旗と名前、床の見分け、停車予測線、金枠の発光、神駐車表示、加速の軌跡、追突で飛ぶ野菜とパン、海へ飛び出す演出を追加した。
全員の発進後はカメラが駐車勝負へ寄る。よりの「イージー！」も残している。

素材：assets/cart544/track.webp、assets/cart544/cart.webp。
生成方法はbuilt-in image_gen。最終プロンプトはdocs/build544/art-prompts.json。
既存の表紙と相棒画像は再利用する。

## 軽量化と検証

- 背景と床はキャッシュし、画面サイズやコースが変わった場合だけ作り直す。
- 停車予測は自分１台だけを計算し、同じ強さの再計算を避ける。実際の対戦状態を変更しない。
- 描画DPR上限1.5、25ms固定物理、100ms通信、非表示時の描画停止を維持。
- モーション低減設定では衝突の揺れ、飛び散る食材、落下の回転を抑制。
- 自動テスト69項目を通過。５コースの差、全４スタートから金枠へ届くこと、加速の重複禁止、仮加点・追突・最終回採点、旧版からの更新を含む。
- AIを60種類の乱数で５回戦まで動かし、全コースで金枠駐車・場外・得点が生まれることを確認。
- 320×568、390×844、430×932、844×390を確認。小画面でもスタート地点の名前を表示する。
- ２人のWebSocket接続で独立した長押し、相手画面への反映、指定色、切断時のAIと復帰を確認。
- 実際のRaceClient451とパーティー用CSS80枚を読み込んで操作・再戦を確認。
- ローカルChromiumのCPU速度を４倍遅くした計測でも、停車予測中の95パーセンタイル描画間隔は約16.7ms。これはこの検証環境の値で、実機の性能保証ではない。

記録はdocs/build544/内。接触・落下・金枠・床のスクショは、検証用の配置から実際の物理と描画を動かした画面。
通常の長押し・２人対戦・５回戦・再戦も別途検証している。

元プロジェクトの一部カタログと共通ポートレートがこの環境にないため、ローカル検証でのみtools/build539/catalog-fixture.mjsを使う。ゲーム本体・物理・サーバー・生成画像は実装そのもの。検証用データは本番から読み込まない。
iPhone実機Safariでの確認と公開サイト全体の検証は未実施。
