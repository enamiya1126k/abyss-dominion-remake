# ABYSS DOMINION Build525 / v3.1.204

「ぬし釣り大騒動」を拡張する、Build524適用済みプロジェクト向けの差分です。単独の完全版ではありません。

## 追加した遊び

- 獲物を５種類から**全32種類**へ。魚のほか、クラゲ・ウーパールーパー・カニ・長靴・ルアー・お宝なども登場します。種類ごとに専用の絵で釣り上がります。
- ヌシは**千年大鯰・ヌマオウ**へ刷新。基準420kg・720点の巨大な大鯰。大きな頭、長いひげ、苔・古い鎖をまとい、巨大な魚影と水のうねり、通常より長い釣り上げで登場します。釣り一覧とロビーのサムネイルも更新。
- **長靴から連鎖釣り**。「エサにして続ける」を押すと、釣れたものを実際に投げて次の獲物へ。長靴→大ヤドカリ→宝箱ミミック／鍵角ウナギ→王冠ガニ→深淵の宝箱。連鎖専用の獲物は通常の投げ入れでは釣れません。
- **黄金アロワナ**を追加。基準290点、釣り上げ時に金色の輝き。月冠キンギョを使った連鎖でも狙えます。
- **きらめくルアー**は基準５点。得点として確保するか、その場で使って継続できます。継続時は必ず大物候補（tier 2／3）を抽選し、その一匹は取り込み速度と糸の張りも有利になります。
- **アメリカザリガニ・ミドリガメ**はこのゲームの「エサ専用」枠。得点化・放流はできません。「エサにして続ける」で特殊な次の獲物へ進み、未選択でも５秒で自動継続します。投げ入れの締切後はエサとして回収します。

## 連鎖のルール

その場で継続した獲物は得点になりません。継続先を取り込んで確保すると、その一匹の得点に**連鎖１回につき12％**の加算ボーナス。最大６連鎖です。糸が切れる／逃がすと、その一連の未確保分は失います。既に確保した得点は失いません。

途中で得点として降りることもできます。通常の選択は５秒で自動確保。ヌシと最後のお宝は自動確保します。ストックする通常エサ（上限３個）と、釣果をその場で使う連鎖は別で、ストック満タンでも連鎖できます。

通常エサは次の新規投げ入れで使用し、大物候補と取り込みを有利にします。連鎖を始める時はストックを消費しません。120秒以降の新しい投げ入れ・連鎖開始は不可、既に掛かっている獲物は従来どおり最大10秒の取り込み時間があります。

## 適用

1. **Build524適用済み**の元プロジェクトへZIPの内容を相対パスのまま上書きします。
2. 本体の `src/`・`assets/`・`index.html`・新しいオフライン用ファイルを反映します。
3. `online-server/src/` も更新します。サーバーが参照するプロジェクトの `src/fishing/` も同時に反映し、**online-serverを再起動**します。
4. 参加者全員がページを再読み込みしてください。釣り通信は `fishingVersion524:2` になり、旧版クライアントの操作は拒否します。

保存済み対戦では、保持中の獲物と得点を保って連鎖用の状態を補完します。新しく掛かる獲物から追加抽選を使います。試合中の更新は避け、対戦が終わってから適用してください。

相撲・ブロック落とし・〇×・その他の完成済みゲームの専用ソース、素材、CSSは変更していません。共有部分の変更は釣りの対応版チェック、釣り一覧の画像・説明、更新用バージョン・キャッシュだけです。
