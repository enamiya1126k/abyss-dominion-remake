# Build452 / v3.1.131 — 魔物レース演出強化版

「② 演出を作り込む」を反映した累積上書きZIPです。ホーム下部の「パーティー」から魔物レースへ入れます。

## 今回の演出

- **出走パレード**：生成画像の競技場、スポットライト、登場演出。8匹を順に紹介し、番号を押すと好きな魔物を観察できます。
- **調子の仕草**：落ち着かない足踏み、重そうな揺れ、平常の呼吸、軽やかな足取り、絶好調の跳躍。調子は文字と5段階のバーでも確認できます。
- **出走**：ゲート、3・2・1のカウントダウン、スタートの合図、短い効果音。
- **レース**：歩行フレーム、砂ぼこり、先頭表示、先頭交代の実況、最後の直線での追い込み演出。着順はサーバーの結果に従います。
- **全員の馬券**：4人の予想・購入額・的中時の払戻額をレース中に表示。馬券をタップすると、その予想の魔物をコース上で強調します。「予想圏内」は途中経過で、的中確定ではありません。
- **着順・収支発表**：1〜3着の表彰台、的中スタンプ、優勝表示、4人全員の購入額・払戻・優勝賞金・差引収支。順番に発表し、金額がカウントアップします。
- **演出スキップ・再表示**：結果をすぐに確認したり、発表をもう一度見たりできます。再表示は受取済みの報酬に影響しません。
- **音・動きの設定**：♪ボタンでレースの効果音を切り替え。ゲーム全体の音設定・効果音量にも従い、画面を離れると効果音を停止します。端末の「視差効果を減らす」などの設定時は、動きを抑え、結果をすぐに表示します。

4人部屋、不足分のAI、システム4匹＋参加者4匹の計8匹、券種・倍率・購入上限、優勝賞金5,000G、出走によるEXPとなつき度、購入・精算の保存はBuild451を引き継いでいます。育成レベルや戦力はレースの速さに影響しません。

## 更新方法

既存のゲームフォルダーへZIPを展開して上書きし、ゲーム側を再公開してください。**①のBuild451サーバーを更新済みなら、今回はゲーム側の上書きだけでOKです。** サーバーのプログラムと保存方式はBuild451から変更していません。

Build450以前のサーバーを使っている場合は、同梱のBuild451対応サーバーも更新・再起動してください。詳細は `README_Build451.md` にあります。稼働中の永続データを保持してください。本ZIPにアカウント・稼働データは含めていません。

表示バージョンは `v3.1.131`。更新後、ゲームを再読み込みして確認してください。セーブ形式は84のままです。既存の対戦、ホームの共闘レイド、部隊編成、装備などを保持します。

これは既存環境用の累積上書き版です。過去の上書き内容をすべて含みますが、初期の全ゲーム素材を含む独立配布ではありません。
