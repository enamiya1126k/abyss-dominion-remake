# ABYSS DOMINION Build549 / v3.1.228

暴走ショッピングカートの衝突・発射・加速台・結果画面を更新した、Build548向け差分パッチ。

## 適用

1. 対戦を準備画面へ戻す。
2. Build548適用済みの本体へ、ZIP内のファイルを同じ場所に上書きする。
3. サーバーにも変更されたルートの `src/` と `online-server/` を反映する。
4. `online-server` を再起動する。
5. 参加者全員がゲーム画面を再読み込みする。

今回は本体・サーバーの両方の更新が必要。カートのルールと通信互換バージョンは5に更新した。
旧バージョンの開催中カート対戦は準備画面へ戻り、準備OKを解除する。
セーブデータ・アカウントデータ・サーバー保存データはパッチに含めていない。

## 遊びの変更

- 発射していない車にも当たり判定がある。相手に押されると、発射前でも位置がずれて移動する。
- 押されたことでは自分の発射権を消費しない。動きながら引いて離し、好きなタイミングで発射できる。
- 発射時は現在の速度に、引いた方向の加速をベクトルとして加える。同じ方向なら加速し、逆方向なら相殺する。
- 引っ張りをキャンセルしても、衝突で得た勢いは消えない。
- MAXの発射初速を12から36へ、従来の3倍にした。弱い引き加減は扱いやすく残し、強く引いた後半で大きく加速する。
- 壁と車同士の反発を強めた。壁に当たると金属音と火花を出す。
- 高速時は1回の物理更新を細かく分割し、未発射の車・壁・荷物をすり抜けないようにした。
- 未発射のまま海へ押された車は、その回は0点。発射を待たずに正常にラウンドを終了できる。
- AIと未操作時の自動発射は、新しい強さの曲線に合わせて再調整した。
- 発射できる時間は従来どおり8.5秒。全5ラウンド、金枠＋50点、最後の回の得点2倍は維持した。

## 見た目

- 「停車完了」のパネルが必ず手前に出るよう、フィールド内のキャラの表示順を分離した。
- ラウンド結果の表示中は、フィールドのキャラ・名前とコース説明を非表示にする。背景と得点カードが混ざらない。
- 結果表示中の下部も「仮」ではなく「今回 ＋○点」と表示する。
- 3桁の得点で「点」だけ改行される問題を修正した。
- 加速台を金属ローラー、厚みのある縁、留め具、点灯する側面へ描き直した。床と同じ遠近法で配置し、ローラーの表面を進行方向へ動かす。
- 移動中に引いても、グリップと矢印がカートの補間表示位置へ追従する。
- 停車位置・軌道の予測表示は引き続き出さない。

## 確認したこと

- 物理・入力テスト21件が成功。
- 未発射の車への衝突、発射権の保持、慣性への加算、キャンセル時の慣性保持、高速の正面衝突、壁の連続反射、荷物への衝突、加速台の1回だけの加速を確認した。
- 未発射のまま落下した場合のラウンド終了、AIを含む全5ラウンドの完了、旧ルールの準備画面への移行を確認した。
- 実際のView・Controls・Renderer・CartCoordinatorを使用した、2つのローカル接続ブラウザーで確認した。相手に押されている間も指を離さずに引き続け、その後の発射へ横方向の速度が残ることを双方で確認した。
- 320×690、390×844、430×932、844×390で操作と表示を確認した。結果画面はSafariのブラウザーUIを考慮した390×664でも確認した。
- 実行エラー・不足アセットは0件。インポートマップとオフラインキャッシュも更新した。

検証はChromiumのスマホ相当画面とカート専用ローカル接続で実施した。iPhone実機、公開環境、ゲーム本体全体の統合動作は未検証。
