ABYSS DOMINION REMAKE - Release 200
Version: 2.11.84 / build260

今回の内容
- ミミック階層（宝物庫）の出現率を0.5〜1.0%へ縮小
- 宝物庫のミミック率を15%へ縮小し、最大2体に制限
- ミミックを通常遭遇・ボス随伴候補から除外
- ミミックをHP5・回避24へ緩和し、討伐時は大量GOLD・EXP×8・魔晶石を獲得
- 通常宝箱を必ず役立つ報酬が出る内容へ刷新
- 鍵付き宝箱は神話装備確定、装備Lvは階層の1.8〜2.4倍
- オフラインと共同探索で宝箱・ミミック抽選を共通化
- 共同探索の宝箱装備で強化値（+）も正しく受け取れるよう対応
