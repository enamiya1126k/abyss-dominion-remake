Build304：予言・勇者侵攻・最終決戦の整理
-------------------------------------------

1. 勇者一行が日ごとに接近
   - 1日10階、全10日として進軍位置と残り日数を表示
   - えなみ・より・ひで・りおんの4人を日別演出に表示
   - 100階の支配者討伐後に魔王城へ到着
   - 演出表示前にアプリを閉じても、その日の演出を失わないよう修正

2. 表示文言・情報階層の整理
   - 探索ヘッダーを「予言N日目・N階」に統合
   - 区間名、攻略数、現在属性の役割を分離
   - ホームに勇者侵攻度と現在地を表示
   - 勝利後は「勇者軍撃退／迎撃完了」へ切替
   - 100階突破後はホームから最終決戦へ再挑戦可能

3. 最終決戦を現在パーティへ一本化
   - 8将の別編成、控え交代、魔王型選択を廃止
   - 現在パーティ4体 対 勇者4人で開始
   - 4体未満の場合は、その場から編成画面へ移動可能
   - 決戦開始時のみ現在パーティを全回復

4. 敗北後のみ固定サイラーン戦
   - 現在パーティが勝利：完全勝利
   - 現在パーティが敗北：固定の魔王サイラーンが出撃
   - 第一戦で倒した勇者は復活しない
   - 生存勇者のHPと装備・能力構成を数値そのままで引き継ぐ
   - サイラーン勝利：逆転勝利／サイラーン敗北：敗北

5. セーブ・旧データ救済
   - 旧8将・旧魔王型の保存項目を削除
   - 旧最終決戦中のセーブは元パーティとHP/MPへ安全に復元
   - 決戦開始／サイラーン交代の瞬間に中断しても元パーティを救済
   - 通常探索、奈落回廊、階層ボスなど別の戦闘セーブは変更しない
   - 一時生成したサイラーンの残留・重複を除去

6. iPhone向け表示
   - 最終決戦モーダルを単一スクロールへ修正
   - 決戦開始ボタンを画面下に維持
   - 勇者侵攻表示の最小文字サイズを引き上げ
