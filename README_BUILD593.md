## 見た目

- 全８ステージに新しい背景を用意。森、空中庭園、遺跡、時計塔、海、氷、水晶洞、火山城で景色を変える。ステージ選択にも同じ世界の絵を使用する。
- 地面・浮く足場に厚み、草や雪の縁、土や石の模様、明暗を加える。地形の上端は実際の衝突面と合わせる。
- 敵を丸みと陰影のある見た目へ、攻撃アイテムを発光する結晶へ変更する。
- 上部の大きな見出し・進捗バー・重複した案内を整理し、キャラクターとコースが見える範囲を広げる。ハートは専用の図形で表示する。
- 自分の目印を明るくし、限定キャラ等の大きな画像もプレイヤー枠内へ収める。

## 操作

- 左右を明確な矢印へ変更し、大きな一体型パッドを維持する。ジャンプは右端の大きな丸ボタン、攻撃はその隣に配置する。
- 左右は指を置いたまま方向を切り替えられる。攻撃とジャンプも、指を離さずボタン間を滑らせて切り替えられる。複数の指による同時押しも維持する。
- 移動方向を変えた時のカメラの大きな横移動を抑える。
- 画面の回転・表示領域変更で押しっぱなしが残らないよう入力を解除する。
- 長押しの文字選択・コピーの抑制と、対応ブラウザでの短い振動は維持する。振動APIを持たないブラウザでは振動ボタンを表示しない。

## 原因を修正した箇所

本体共通の記号装飾処理が、ランナーズの矢印を旗アイコンへ、ハートを別のアイコンへ置き換えていた。さらに更新側が同じ文字を書き戻すため、変換と再配置を繰り返していた。

ランナーズの画面を既存の装飾除外指定に合わせ、操作矢印とハートを専用SVGに変更した。本体共通の処理そのものや他のミニゲームには変更を加えていない。検証には本体の装飾処理をそのまま取り出したものを組み込んだ。

## 軽量化

大きな背景をCanvasで毎フレーム描き直さず、１枚の読み込み済み画像をブラウザの合成処理で移動する。動く地形や敵は別のCanvasへ描く。背景は１ステージ約87〜164KB、選択画面用画像は約21〜33KB。全16画像で約1.24MB。遊んでいるステージの背景のみを読み込む。

比較検証の390×844画面ではコース表示部分が高さ523pxから632pxへ約21%拡大した。CPUを４倍遅くしたChromiumで、前後ともフレーム間隔中央値16.7ms（約60fps）。詳細・検証条件は `docs/build593/VALIDATION.txt` に記録する。
