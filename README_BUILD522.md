# ABYSS Build522 / v3.1.201

Build521適用済みのプロジェクトへ重ねる差分です。単独の完全版ではありません。

ブロック落としサバイバルの、逃げる側の描画と長押し入力を改善しました。ゲームビジュアル、レイアウト、操作ボタンの配置・大きさ、20段のフィールド、通常2段／超ジャンプ4段・15秒、AIと勝敗判定は変更していません。画像追加もありません。

## 修正

- 通信受信のたびに表示時刻が動く処理を、単調に進む時計と緩やかな補正へ変更。通信間隔の揺れによる巻き戻りを抑えます。
- 自キャラの表示位置とカメラの注視位置を統一。他キャラは実際のサーバー時刻の間隔で補間します。
- 移動予測では、押した／離した時刻を保ち、サーバーが受け取った長押し方向も保持します。勝敗や衝突の最終判定は引き続きサーバーです。
- 毎フレームのDOM検索、同じサイズ・クラス・属性の再設定を削減。ボタン位置の取得は押し始めとサイズ変更後だけにしました。
- 背景・積み上げ済みブロックのキャッシュから、画面に見える部分だけを転送。同じサイズ通知ではキャッシュとカメラを作り直しません。
- このゲームの操作領域で、ボタン内の文字やSVGを含む選択・長押しメニュー・ドラッグを抑止。タッチのネイティブ動作も対象ボタン内で止めます。ジャンプとの同時押し、指の滑らせ操作、押し離し・キャンセル・画面離脱による解除は維持しています。
