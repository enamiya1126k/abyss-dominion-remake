# ABYSS DOMINION Build514 — 〇×サバイバル「最後の足場」改修

バージョン: v3.1.193 / 適用元: Build513。
このZIPは差分更新。Build513適用済みのゲームフォルダーへ同じ階層で上書きする。

## 変更内容

- 床の任意の地点をタップして歩く。台の中の位置も自由に選べる。中央の橋を渡って左右を行き来する。目的地に光の目印を表示する。
- 左〇・右×の間へ、金装飾の石の隔壁が上から降りる。壁に12秒の残り時間を表示する。
- 0秒時点の実際の足元で正誤判定する。移動先を選んだだけでは反対側に到着した扱いにしない。
- 閉鎖時に中央の壁の幅に重なっていた場合は、最後にいた安全な側へ押し戻す。壁で直接脱落はしない。
- 何もタップしない場合も、その場の台で判定する。最初は左右2人ずつ。次の問題では生存した台から始める。
- 不正解の台は崩落し、キャラが落ちた側の下からマグマのしぶきと煙が上がる。
- 正解の台はキャラと一緒に少し持ち上がる。背景の下降、細かな揺れ、上昇音でエレベーターの移動を表現する。答えが×なら右の×台が上がる。
- 問題欄を黒い石板と金の装飾の枠に変更。「第◯問」を大きく表示する。問題と解説は演出中も画面上部に固定する。
- 最大20問へ延長。1〜6問目は難易度1、7〜13問目は難易度2、14〜20問目は難易度3。既存の12ジャンル・120問を使う。同じ試合内で重複しない。
- 最後の1人で優勝、全員脱落は勝者なし。20問後に複数残れば同時優勝する。
- キーボードでは左右矢印・O/X・1/2から各台へ歩ける。画面の動きを減らす設定では、揺れ・スクロール・しぶき等を抑制する。

## 適用手順

1. 現在のゲームとオンラインサーバーをバックアップする。
2. ZIPを展開し、Build513のゲームフォルダーへ同じ階層で上書きする。セーブデータや既存の画像フォルダーを削除しない。
3. 本体の `index.html`、`src`、新規 `assets/quiz514`、`world-raid-offline514-*` を含む更新分を公開先へ反映する。
4. **オンラインサーバーも更新し、再起動する。** `online-server/src` とサーバーが参照する共有 `src/quiz`、`src/party` などを同じ更新内容にする。サーバーだけを別フォルダーへコピーしている場合は共有ソースも更新する。
5. 全員がゲームを再読み込みし、v3.1.193になったことを確認する。パーティー → 〇×サバイバルから開始する。

本体・サーバーの片方だけでは新ルールを開始できない。旧クライアントとの混在開始は拒否する。
Build513で進行中だった〇×サバイバルだけは、サーバー更新後に相棒選択のロビーへ戻して「準備OK」から再開する。他のゲーム・所持品・アカウントの状態を消去しない。Build514同士では途中の座標・移動経路・問題順を保存して再起動できる。
