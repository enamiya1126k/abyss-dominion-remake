# ABYSS DOMINION Build441 / v3.1.120

Build440までを含む累積上書きZIPです。Build424以降の既存プロジェクトのルートへ展開してください。新規インストール用の全素材ZIPではありません。

## 今回の変更

- ホームの属性相関図を、お知らせ・部隊編成バナーの中央に合わせました。枠は追加せず、既存の丸い属性アイコンと相性ルールを使用しています。
- レイド入口にも金・銀・銅のランキングカードとキャラ画像を表示。主表示は設定済みプレイヤー名です。名前変更後は順位取得時に既存の貢献記録の表示名も更新します。旧クライアントの参加者の過去名は、その参加者が更新版で接続・順位取得するまで残る場合があります。
- 専用武器を他キャラも装備可能にしました。本人以外には基本ステータス・通常のランダムオプションが適用され、固有の固定効果・付与スキル・本人専用セット効果は発動しません。専用防具・アクセサリの装備制限は従来どおりです。
- 自動装備は本人の専用装備を優先。他メンバーの専用武器を先取りせず、本人のおすすめ操作で借用中の武器を戻せます。ただし基本評価が最強候補の75%未満の専用装備への大幅な弱体化は避けます。装備変更では各メンバーのHP/MP割合を維持します。
- 新規ガチャ排出レベルを訂正：装備は最高到達階層×10〜20、魔物は×10〜15（両端を含む整数抽選）。100階なら装備Lv.1000〜2000、魔物Lv.1000〜1500です。通常・曜日・専用装備・深淵・十神・第二章召喚が対象。所持済みのレベルは変更しません。
- 第一章探索を第二章と同じ毎秒5マスへ変更しました（従来7.5マス）。
- 第二章の魔法陣8種類を画像生成で新作。鏡糸連環陣・夢喰封花陣・双誓共鳴陣・天鎖護誓陣・終冠星律陣・異彩協奏陣・百禍織刻陣・澄明蓄魔陣です。透過WebPを装備一覧・ホーム・戦闘・オンライン表示に使用し、効果・価格・所持状態は維持しています。
- 通常戦闘とオンライン戦闘に斬撃・属性別の粒子／軌跡・会心演出を追加。対応する大技では魔法陣も重なります。追加演出は戦闘の待ち時間や乱数に干渉せず、1画面1枚の描画面・同時4エフェクトまで。動きを減らす設定にも対応します。

## 適用

1. 既存プロジェクト・プレイヤーのセーブ・サーバーのデータをバックアップします。
2. ZIPをプロジェクトのルートへ上書きし、普段と同じ方法で公開します。
3. オンラインサーバーにも同梱された変更ファイルを反映し、プロセスを再起動します。`online-server/data/`・秘密鍵・環境変数は上書きしません（ZIPに含みません）。ランキング名の修正にはクライアントとサーバーの両方の更新が必要です。
4. ゲームを再読み込みして v3.1.120 を確認します。

セーブキー・スキーマ84を維持。既存の所持品、魔法陣、ランキングのダメージ、報酬、オフライン挑戦権を残します。凍結された `src/worldRaid/runtime430/` は変更していません。レイドHP5000万や前回までのUI更新も含みます。

## 検証と素材

`docs/build441/` にテスト結果、スマホ画面、生成プロンプト、素材情報と更新ファイル一覧を収録。`tests/build441.test.mjs` は専用武器の貸し借り、固有効果の非発動、保存復元、自動装備、召喚レベル、ランキング名を確認します。

画面確認はローカルChromium・テストデータで実施。iPhone Safari実機の描画性能は未確認です。今回のZIP作成作業では公開サイト／稼働中サーバーへのデプロイは行っていません。
