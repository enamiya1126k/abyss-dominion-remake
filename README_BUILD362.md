# Build362 / v3.1.42：99階出発用GMコード

Build361へ、このZIPの中身をフォルダー構成ごと上書きして再読み込みしてください。セーブ初期化は不要です。

GMコード：AD-GM-99F-4N8Q

設定のGMコード入力欄に入力後、ホーム→ダンジョン→出発階層で99を指定してください。
1〜99階まで出発先を選べるようになります。自動で99階へ移動するコードではありません。
最高到達階・今周回の進行・ボス討伐・ストーリー・報酬はコード入力では変更しません。仲間、装備、経験値、GOLD、💎、所持品の配布もありません。出発後の戦闘や取得物は通常どおり保存されます。
繰り返し入力可能です。以前に99階より先を解放している場合、その権限は下げません。
輪廻中にGM権限で出発した階層のボス撃破が、過去記録の修復処理で取り消されないよう調整しています。

コード認証・無関係なデータの不変・繰り返し入力・既存権限の維持・不正コード拒否・輪廻中のGM出発階層のボス討伐保持を確認しました。iPhone実機での操作確認は未実施です。
