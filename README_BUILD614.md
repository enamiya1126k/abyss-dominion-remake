# Build614 — 魔界ランナーズを選択できない不具合の修正

Build613適用済み本体へ重ねる修正パッチ。アプリ3.1.293。

## 原因と修正

パーティーのゲーム選択画面だけが、Build610時点の通信ルール20を要求していた。Build613のサーバーが返す正しい通信ルール23を非対応と判断し、「サーバーのBuild610更新・再起動が必要です」と表示して選択を止めていた。

選択画面の判定を現在の通信ルール23へ修正する。実際に本体・サーバーが不一致の場合は引き続き停止する。古い番号に誘導する案内文も修正する。

通信ルールは23のままで、Build613サーバーと互換。船・ボス・コース・操作のルールは変更していない。既存の古い読み込みURLも修正版へ解決し、オフラインキャッシュをBuild614へ切り替える。

## 適用

1. Build613適用済み本体へ、このZIP内のファイルを同じ位置に上書きする。
2. 本体を公開している場所へ反映した後、参加者全員が画面を再読み込みする。
3. サーバーがBuild613へ更新済みなら、今回サーバーの再更新は不要。未更新の場合は、先にBuild613パッチのサーバー側と共有srcを適用して再起動する。

こちらから公開サイト・本番サーバーへの反映は行っていない。

## 検証

- 修正前の実際の`partyClick462`を実行し、現在版でのゲーム選択・部屋作成前の選択・準備の操作が失敗することを再現した。追加12テスト中5件失敗。
- 修正後は追加12件すべて通過。現在のルールを持つサーバーに対する選択要求が送信され、準備OKへ進めること、旧版や未対応版は拒否されることを確認した。
- 船・ボスなど既存回帰とキャッシュ更新の確認も含め248件通過。
- 選択テストは本番のクリック処理をVMで実行し、その操作で使わない表示・ウォレット依存だけをスタブ化した。ブラウザーやiPhone Safari実機でのタップ操作、公開中サーバーへの接続は未確認。
