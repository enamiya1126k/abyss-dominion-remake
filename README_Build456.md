# Build456 / v3.1.135 — 操作できる魔物レース

Build455までを含む累積上書きZIP。既存ゲームの同名ファイルへ上書きしてください。
**ゲームとオンラインサーバーの両方を更新し、サーバーを再起動してください。**
保存データは削除しません。ZIPにサーバーの保存データ・node_modulesは含めていません。
公開サイトへの反映はこのZIPの適用後です。

## 更新後の遊び方

更新後に新しい部屋を作ると新ルールになります。更新前の部屋では購入済み馬券・結果を守るため旧ルールを維持します。旧部屋の「もう1レース」も旧ルールです。一度退室して、新しい部屋を作ってください。

1. 部屋主が芝・砂コースを選び、各プレイヤーが魔物を選択。不足席はAIが参加します。
2. パレードで調子・疲労・適性・特技と、その魔物の新聞記事を確認。自動紹介は停止・再開できます。
3. 単勝・複勝・二連複・ワイド・二連単・三連複・三連単から、馬券を1枚購入。見送りもできます。
4. レース中、自分の出走魔物に「ケツを叩く！」を最大5回。タイミングは自由です。
5. 結果画面で着順、各自の馬券・収支、出走賞金と育成報酬を発表します。
6. 同じ部屋で次のレースを始めると芝・砂が交互に切り替わります。開始前なら部屋主が変更できます。

## 今回の変更

- 芝の競技場を新規制作。緑の芝・土煙・加速・妨害・障壁などをコースと状態に合わせて表示します。パレードの既存背景は維持します。
- 新聞記事をパレードの各魔物の直下へ配置。調子、得意コース、連戦疲労、逃げ型の数を踏まえた読みどころを掲載します。全8匹の比較は折り畳みで確認できます。
- 馬券7種類。複勝は3着以内、ワイドは2匹とも3着以内、二連複は上位2匹を順不同、三連複は上位3匹を順不同で的中。二連単と三連単は順番も一致する必要があります。
- 魔物特技は追い風、ぬかるみ、魔法障壁、吸い付き走法の4系統。種類ごとに固定で、レース中に実際の速度やスタミナへ作用します。
- 加速は1回につき1.4秒間＋18％、スタミナ−10、操作間隔は最低2.2秒。最大5回。スタミナが20未満になると走る速さが徐々に落ち、10未満では叩けません。AIにも同じ回数・消費・待ち時間を適用します。
- 操作できるのは自分の出走魔物だけです。馬券に選んだ他人の魔物を直接操作することはできません。
- 事前に着順を決める方式から、サーバーが200ミリ秒刻みで走行を計算する方式に変更。操作が走る距離と着順に反映されます。
- 接戦では全匹ゴール後、ゴール前の短いスロー再生を表示。演出が結果を変更することはありません。
- プレイヤー同士以外のキャラ重複防止、レース専用疲労、出走賞金・EXP・なつき度は引き継ぎます。育成レベルや装備はレースの強さに使いません。

## 予想と倍率

人気は今回の事前予測順位で、購入人数による人気ではありません。
同じ走行計算で1,024回の試走を行い、標準の5回操作を想定して勝率と倍率を見積もります。実際のレースは別の乱数で進み、プレイヤーの操作でも変わります。表示は確定した確率や着順ではありません。

倍率は購入時固定。払戻は購入額を含みます。例えば1,000G・2.0倍の的中払戻は2,000G、馬券の利益は1,000Gです。出走賞金は別に加算します。
新ルールでは試走分布に基づく倍率を使います。旧Build455の「最大勝率80％」「理論払戻率90％以下」は旧ルールの説明であり、操作できる新ルールには適用しません。

## 通信と保存

受付済みの操作、走行中の状態、馬券、乱数の状態をサーバーへ保存します。通信復帰・サーバー再起動後も同じレースから再開します。切断中は追加操作ができませんが、レースは進みます。未確認の操作は同じ番号で再送し、重複受付を防ぎます。

賞金・払戻・育成報酬は従来の受取記録で二重受取を防止します。結果演出の再生では再加算しません。レース画面から離れていた参加者も、復帰後に受け取れます。

## 検証

自動テスト、4人の実WebSocket接続、レース途中のサーバー再起動、切断と復帰、馬券購入・加速・払戻、スマホ幅とタッチスクロールを検証しています。詳細は `docs/build456/` に収録します。

実機iPhone Safariでの確認は未実施です。Chromiumのモバイル・タッチ環境で検証しています。検証環境に未取得の既存魔物画像があるため、その画像自体の再監査は対象外です。画像参照は既存のままです。

保存形式84と固定runtime430・runtime443は維持しています。
