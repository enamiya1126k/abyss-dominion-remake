ABYSS DOMINION REMAKE release174 / build233

これは release173 に上書きする「差し替え部分だけ」の更新です。
ゲーム全体は含まれていません。

主な更新:
- 最大20人の永続ギルド
- ギルド作成、ID検索、加入申請、フレンド招待
- マスター／幹部／メンバーの権限とメンバー管理
- 再接続・再起動後も残るギルドチャット
- 週間共闘ポイント、個人貢献、ギルドレベル
- フレンドとギルドをまとめたiPhone対応「交流」パネル

適用方法:
1. release173 適用済みのゲームフォルダを開きます。
2. このZIP内のファイルとフォルダを、そのゲームフォルダへ同じ階層で上書きします。
3. `online-server/data` フォルダと既存のJSON保存ファイルは削除しません。
4. オンラインサーバーを再起動します。
5. ブラウザを再読み込みします。

注意:
- ZIP内の階層を崩さずに上書きしてください。
- `online-server/data/guilds.json` は初回利用時に自動作成されます。
- `online-server/data/friends.json` を含む既存のオンライン保存データはそのまま利用します。
- 差分ZIPに実際の `online-server/data/*.json` は含まれていません。
- 出席を除くギルド活動は、2人以上が参加したオンラインプレイだけを加算します。
- 週間目標やギルドレベルからアイテム、GOLD、魔晶石などの報酬は発生しません。
- 通常探索、所持品、既存セーブデータは変更しません。

詳しい仕様は BUILD233_GUILDS_UPDATE.md を確認してください。
