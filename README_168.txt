ABYSS DOMINION 168 完成版

基準:
- abyss-dominion-remake-main-167.zip
- 内部ビルド: build227
- オンライン通信プロトコル: 1.14.0

今回の中心実装:
1. 2人以上の共同探索だけに出現する本格共闘ボスを3体追加
2. ボスごとに異なる連携課題を実装
   - 雷鎖牙獣・ライガルム: 2人以上で攻撃
   - 凍鏡騎王・グラシエル: 2人以上で防御
   - 虚環門主・アルカノス: 攻撃役と支援役に分かれて行動
3. 挑戦前確認、専用戦闘HUD、成功・失敗表示、既存モンスター画像による探索表示を追加
4. 共闘ボスを捕獲不可にし、捕獲ボタンも事前に無効化
5. 敗北しても探索を終了せず、HP25%・MP20%で同じ場所から再挑戦可能
6. 参加人数別の固定追加報酬と二重受取防止を実装
7. 切断中は既存のAI代理を継続し、再接続後に戦闘状態・未受取報酬を復元
8. 共闘ボス撃破では通常探索の階層、通常ボス撃破、階層解放を変更しない

ソロ探索について:
- 1人オンラインでは共闘ボス、共闘ギミック、共闘追加報酬を生成しません。
- 10階ごとの通常階層ボス階にも共闘ボスを重ねません。
- 「1人オンライン = オフライン通常探索とほぼ同じ」を維持しています。

報酬:
- 2人: 魔晶石3個
- 3人: 魔晶石4個
- 4人: 魔晶石5個
- 100階以上: 捕獲結晶1個
- 共闘ボスから装備、深淵の鍵、階層解放は発生しません。
- 撃破後に現れる豪華共鳴宝箱は従来どおり別報酬です。

起動上の注意:
- ゲーム側と online-server 側は、必ずこの168に同梱された組み合わせを使用してください。
- 旧サーバーは通信プロトコルが一致しないため接続できません。
- 既存セーブ形式は維持しており、167のセーブをそのまま使用できます。
