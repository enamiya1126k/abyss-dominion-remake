ABYSS DOMINION Build332
依頼内容・整合性修正アップデート

【適用元】
Build331

【主な変更】
・予言画面の左上に崩れないSVG戻るボタンを採用しました。
・勇者一行の観測記録に、4人それぞれの専用画像、実際の使用スキル、発動条件、攻略対策を表示します。
・深淵／十神の手動挑戦を全17体で照合し、選択した支配者本人から戦闘が始まるよう修正しました。
・深淵スキルツリーの階層条件と前提ルート条件を廃止し、所持GOLDが足りれば全ノードを直接購入できます。
・ボス名を戦闘画面の上部とHPカード内へ明瞭に表示し、長い正式名も省略しません。
・階層ボスが元種族のR表示になる不整合を修正し、ボス本人の識別情報を戦闘まで保持します。
・通常敵を進行度に応じた複数編成へ変更し、階層ボス戦には1〜3体の護衛が参加します。
・自動攻略を「現在区画の回収→未探索区画→取り残し→ボス→出口」の順に固定し、同じ入口の往復を抑止します。
・オンライン集会所のレイド受付に重なっていた紫色の「長押し」ボタンだけを撤去しました。
・ゲーム初期化時に、週間レイド情報と同時にギルド所属、役職、申請、招待、出席情報もサーバー側で削除します。
・旧セーブ互換のため SAVE_SCHEMA_VERSION は 84、オンラインプロトコルは 1.17.0 のままです。

【適用方法】
1. Build331 のプロジェクトへ、このZIPの内容を同じ階層で上書きしてください。
2. Web側を再配置し、ブラウザキャッシュを更新してください。
3. online-server/server.js と online-server/src 以下の同梱ファイルもサーバーへ上書きしてください。
4. online-server を再起動してください。ギルド初期化は Build332 サーバーの応答を確認できた場合だけ実行されます。
