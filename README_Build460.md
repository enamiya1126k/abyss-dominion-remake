## 周回レース

- キャラと番号札を分離し、8匹が密集しても重ならないように表示します。キャラの下にある色付きの点が実際の走行位置で、線が対応するキャラにつながっています。表示上の分散で走行距離・着順は変わりません。
- 「全体」はコース全景、「自動拡大」は全8匹の位置が画面に収まる範囲で最大2.25倍まで拡大します。全体に広がると自動で引きます。
- 「拡大表示」はブラウザ内の表示領域を広く使います。順位、実況、5回の叩く操作を残し、通常表示に戻すボタンを右上に置いています。横向きにも対応します。ブラウザのアドレスバーを消す機能ではありません。
- 通常表示に戻すと元のスクロール位置へ戻ります。結果画面へ進むと拡大表示を解除します。キーボードのEscapeでも戻せます。
- 金色の枠は自分の魔物、紫の光は応援中の馬券の魔物です。

## 出走準備・詳細記事

- 距離選択を約半分の高さに縮小。4距離、直線／1周／2周、選択中の距離の特徴は残しています。
- システム出走はスマホで2列のカードに整理。名前、姿、脚質、得意な馬場、速さ・持久・器用の数値を開かずに確認できます。
- 詳細記事はコンパクトな顔と名前、3本の能力バー、今回の馬場・距離、新聞、注目ポイント、特技、近走記録へ整理しました。
- 詳細の閉じるボタンはスクロール中も上部に残ります。閉じると出走準備の元の位置へ戻ります。
