Build353適用済みゲーム用・追加依頼をまとめた修正差分

ZIPの中身を、既存ゲームのindex.htmlとsrcが並ぶ場所へ同じ階層で上書きする。
index.htmlを含めて反映し、v3.1.34になれば反映完了。セーブ削除・サーバー更新は不要。
未納品だった自動戦闘・アイテム画面修正も、このZIPに含む。

1. 自動戦闘OFFの保持
戦闘中にOFFにした設定を次回戦闘にも使用する。
自動攻略の移動は続けるが、自動戦闘を強制ONにしない。
勇者遭遇と保存した戦闘の再開でも設定を尊重する。
再び自動ボタンをONにすると、以後は自動戦闘になる。

2. アイテムの閉じる操作・外観
閉じるボタンを一覧の外側・上部に置き、アイテム一覧だけスクロールする。
パネルを画面下部に固定し、画面高の60%以内へ収める。
タッチ開始時にも閉じる操作を受け付ける。閉じてもアイテムやターンを消費しない。
紫の丸いボタンを、既存装飾枠を使った黒地・金縁へ変更する。
オンライン応急薬一覧と対象選択でも、上部の閉じる・戻るボタンを使用する。
新しい画像素材は不要。

3. 魔法陣の装備連動
このキャラを自動装備：装着可能な魔法陣も自動装備する。
全員を自動装備：部隊順に魔法陣も割り当てる。
未使用か本人が使用中で、解禁済みの現物から高レベルを優先。同レベルなら現在の魔法陣を維持する。
他の仲間の魔法陣を奪わず、現物を複製・購入・強化しない。
このキャラの装備解除／全員の装備解除：魔法陣も所持品へ戻す。
魔法陣だけ装備している場合でも解除できる。
EXP・装備を引き継いで交代：同じ現物ID・レベルの魔法陣も交代先へ引き継ぐ。
引き継がない交代では魔法陣を移さず、現物は所持品に残す。
装備ボタンや交代画面の見た目は変更していない。

4. 装備変更候補
誰かが装備中のアイテムを候補から除外する。本人の別部位で装備中の品も対象。
装備側の装着先記録と魔物側の装備枠を両方確認し、装着先記録が欠けた品も除外する。
