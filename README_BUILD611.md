# Build611 — 船に縛られない、ひと続きの島めぐり

Build610適用済み本体へ重ねる更新パッチ。アプリ3.1.290、ランナーズ通信ルール21。

## 変更

- ゴールに到達すればクリアとなる。船の位置、到着、乗船人数、島の攻略状況を条件にしない。
- 船は時間に従って自動で往復する足場となる。全員乗船待ち、攻略待ち、乗り遅れによるやり直しを撤去する。船を逃しても陸路で進行できる。
- 全長6,800の1本のコース内を連続して進む。中継地点での再配置、画角リセット、タイマー再始動、入力解除を行わない。
- 3区間の地形を個別に再設計する。
  - 砲撃岩礁：起伏のある岩礁、崩れる橋、高台の鍵と宝星への寄り道。
  - 水門工場：蒸気とプレスの下道、番兵と宝星の上道、昇降足場、逆向きベルト。
  - 嵐の灯台：上昇気流と高所ルート、低い海岸ルート、消える足場と受け止め足場、ノコギリと振り子。
- 鍵・番兵・封印箱の攻略は、それぞれの宝星を解放する任意の寄り道となる。
- 復帰地点は7か所。着地した旗を共有し、死亡した本人だけがそこから復帰する。生存中の仲間、船の時刻、取得済みスター、攻略済みの状態を維持する。
- 船の航路を岩壁の内部に重ならない位置へ配置する。船が固定桟橋に触れても、桟橋上のプレイヤーを勝手に運ばない。
- 前回追加したミニゲームの中止・退出ボタンを維持する。

## 適用

1. Build610適用済み本体へ、このZIP内のファイルを同じ位置に上書きする。
2. `online-server/src`と、サーバーが参照する共有`src`も更新し、サーバーを再起動する。
3. 参加者全員が画面を再読み込みする。本体とサーバーの通信ルールが一致しない場合は更新案内を表示する。

GitHub・公開サイト・本番サーバーへは反映していない。

## 検証

- 自動テスト205件通過。船・寄り道の状態に依存しないゴール、1〜4人の個別ゴール、全船の連続した往復、桟橋で120秒待機、区間境界での入力・位置・カメラ予測の連続性、個別復帰、停止・再開、通信バージョン、既存コースの回帰を確認した。
- 実際の移動処理を使用し、陸路と高所の分岐45か所を、特殊能力・仲間ジャンプ・船への着地なしで移動できることを確認した。証跡は`docs/build611/route-witnesses.json`に記録した。この確認は区間ごとの地形確認であり、無被弾での通しプレイを保証するものではない。
- 実際の描画処理と画像素材を使い、3区間の地形・分岐・船・仕掛けをネイティブCanvasで表示確認した。
- この環境にはブラウザー実行本体がないため、ブラウザーでの操作確認は実施していない。iPhone Safari実機、複数人の実機通信による通しプレイも未確認である。
