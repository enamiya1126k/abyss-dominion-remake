# ABYSS DOMINION Build604

Build603に重ねる差分更新。アプリ3.1.283、魔界ランナーズ通信ルール14。

## 更新方法

1. ZIPを展開し、Build603の同名ファイルに上書きする。新しいファイルとフォルダーも追加する。
2. 本体とonline-serverの両方を更新し、サーバーを再起動する。
3. 参加者全員がページを再読み込みする。

旧版で開始した魔界ランナーズは準備画面へ戻る。Build604同士では再接続時の進行を維持する。セーブのキー・スキーマは変更しない。公開サイトへの反映は行っていない。

## 大砲・雷・敵

- 属性マークの砲弾を専用の金属弾へ変更した。表示直径は25から40へ拡大した。攻撃1発で破壊できる。
- 大砲は近いプレイヤーの方向と高さを追う。発射280ms前から狙いを固定する。台座を固定し、砲身の旋回と発射時の反動を描画する。発射後の弾は直進する。
- 雷の壁を専用の連続した放電に変更した。上下の放電装置、危険範囲の予告、通電中の強い光を表示する。
- 通路の雑魚敵を追加し、斧投げ兵を配置した。650msの構えの後、回転する斧を放物線状に投げる。斧も攻撃1発で破壊できる。

## ボスと死亡

- ボスの体力表示を「HP・現在値/最大値・色付きバー」へ変更した。従来と同じ86×14の枠内に収めた。
- 頭を踏めるのは攻撃後の休止中と気絶中に限定した。防御中は頭上に武器を掲げ、踏まれた後は跳び退いて反撃する。ダメージ受付に500msの間隔を設けた。
- 通常被弾も、吹き飛ぶ・消える・旗から復帰する死亡へ統一した。1回だけカウントし、700ms後に復帰する。復帰後は1.6秒の無敵時間を設けた。土の盾が防いだ攻撃、凍結、仲間からの軽い押し出しでは死亡数を増やさない。

## 氷・水場

- 落下氷には天井側の発生装置、転がる氷には射出口を配置した。攻撃1発で割れる。
- 氷がプレイヤーに当たると3秒間凍結する。外から攻撃されると氷が割れ、操作に戻れる。解凍直後は600ms保護する。敵も凍る。
- 氷は箱や固い壁に当たると消える。箱はそのまま残る。
- 波の接触ダメージをなくした。水中の横移動速度は1/2となり、ジャンプで抜け出せる。水面を透ける曲線と波紋で描画し、四角い画像の切り貼りをなくした。

## スター

3つの枠をコースの左からの順番に固定した。3つ目だけを取った場合は3枠目だけを点灯する。取得状況は全員で共有する。

| コース | 星の追加条件 |
| --- | --- |
| 森・スイッチ遺跡 | 2人で封印台を踏む |
| 空中庭園 | 3つの光の輪を順番に通る |
| 時計塔・海岸 | 1つの台座を起動し、6秒以内に星へ到達する |
| 氷雪・深海の氷獄 | 氷の敵を蹴り、台座まで運ぶ |
| 水晶・雷鳴の機関城 | 3つの的を攻撃する |
| 魔王城・終焉の星喰い城 | 3体の番兵を倒す |

既存の探索・上段・地下の星と11コースの主要ルートを維持した。運搬用の氷を壊したり遠くへ飛ばした場合は、1.8秒後に戻り再挑戦できる。スターはゴールの必須条件ではない。

## 確認

自動テスト178件成功。4人の実WebSocket通信と再接続、6場面のCanvas描画を確認した。iPhone Safari実機での操作と全コースの通しプレイは未確認である。詳細は `docs/build604/QA.md` に記録した。

新素材は組み込み画像生成機能で制作した。最終アセットは `assets/runners604/cannonball.webp`、`electric-wall.webp`、`axe.webp`。生成プロンプトは同フォルダーの `SOURCES.json` に記録した。
