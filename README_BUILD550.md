# ABYSS DOMINION Build550 / v3.1.229

Build549へ適用する差分パッチ。パーティーに「人間ピンボール大運動会」「ポンコツ改造グランプリ」を追加する。

## 適用

1. 本体をBuild549まで適用済みの状態にする。
2. 開催中の対戦を終了し、ZIP内のファイルを同じ場所へ上書きする。
3. サーバーにもルートの `src/` と `online-server/` の変更を反映する。画像・CSS・index.htmlは本体へ反映する。
4. `online-server` を再起動する。
5. 参加者全員がゲーム画面を再読み込みする。

本体とサーバーの両方の更新が必要。新ゲームの通信互換バージョンは `ricochetVersion550: 1`。
アカウント、セーブ、サーバー保存データ、認証情報は含まない。既存データの初期化は不要。
公開環境へのアップロードやデプロイは実施していない。

## ２つの新ゲーム

| 項目 | 人間ピンボール大運動会 | ポンコツ改造グランプリ |
| --- | --- | --- |
| 勝敗 | ピン・宝箱・投資の合計得点 | 各回の最長前進距離の合計 |
| フィールド | 真鍮と深緑の閉じたピンボール盤 | 自分を追うカメラで進む工房の街道 |
| 能力 | 反射倍率、充電、友情コイル、サイコロ、宝袋、投資など12種 | ロケット、バネ、鉄板、追突ターボ、車輪、電池など12種 |
| 逆転 | 衝突と倍率・出目の掛け算、次回の充電放出 | 重量と反発、遅れて点火するロケット、次回への投資 |

- ４人対戦。不足席はAI。パーティーの選択キャラとイメージカラーを使う。
- ８回／16回を部屋主が選ぶ。再戦時も回数設定を引き継ぐ。
- 各ラウンドの３択から１つを装着。同じ能力は４個まで重ねられる。
- 選択は最大12秒。全員が選ぶとカウントダウンを経て対戦へ進む。
- 発射権は各回１回。引いた長さで強さ、方向で発射方向が決まる。6.5秒で自動発射する。
- 発射前の相手にも衝突する。押された速度は消えず、自分の発射を加算する。
- 元の位置へ戻す、指のキャンセル、画面切り替えなどでは発射しない。着地点・未来の軌道予測は表示しない。
- 各回の走行・連鎖は14.5秒で採点。能力と充電を次の回へ引き継ぐ。
- 能力の効果は実際の衝突・得点・走行へ適用する。見た目も装甲・バネ・ロケット・電池などで変わる。
- 上部の選手欄から全装備・個数・効果を確認できる。
- 切断、退出、ホーム滞在中はAIが代行する。復帰時は同じ能力・得点・発射状態へ戻る。
- 同点は同順位。結果画面は「もう一度」「ミニゲーム一覧へ戻る」に対応する。

## 見た目と動作

- 専用の表紙２点と、透過された改造GPの車体を生成して同梱した。
- 盤面、壁、ピン、加速台、装着パーツ、短い発射方向の矢印はCanvasで描画する。衝突判定と同じ座標を使う。
- 連続する衝突に金属音、火花、実際に通った軌跡、得点の表示を付けた。
- ラウンド結果では盤面のキャラ・名前を隠し、結果パネルとの前後関係を固定した。
- 新ゲームの状態はサーバーを正とする。入力の本人・ラウンド・順序・強さ・方向・能力候補を検証する。
- 他人の未選択の能力候補、乱数の種、AIの発射予定を公開状態に含めない。
- 高速移動時は物理更新を細分化し、すり抜けを防ぐ。連続加速時も速度には安全な上限を設けた。
- 移動・得点は最大20回／秒の状態配信とクライアント側の補間で表示する。描画解像度はDPR 2まで。
- 画面を隠した間は描画と効果音を休止する。動きを減らす設定では軌跡と点滅を抑える。

## 検証

- 新ゲームのルール・操作・パーティー・メイン通信経路24件、既存カート21件、合計45件の自動テストが成功した。
- 両ゲームについて８回／16回の完走、能力持ち越し、同点順位、時間切れ、AI参加を確認した。
- 実際のView・入力・Renderer・新Coordinatorを使い、４つのブラウザーをWebSocketで接続して確認した。
- 準備、３択、発射、引いている最中の他人からの追突、慣性を残した発射、４画面の得点・能力の一致を確認した。
- 320×690、390×664、390×844、430×932、844×390で表示を確認した。
- 選択、対戦、途中結果、最終結果、再戦、一覧へ戻る、切断代行、キーボード操作、拡大抑止、操作キャンセルを確認した。
- 対象２ゲームの実行エラー、不足画像、サーバーエラーは０件。
- バージョン、importmap、オフラインキャッシュを更新した。

検証はローカルChromiumを使用した。iPhone実機、Safari実機、公開環境、ゲーム本体全体の統合動作は未検証。
差分環境に含まれない既存ミニゲーム・財布機能は、専用検証環境内だけで代替処理に置き換えた。
パーティー処理とメイン通信のルーティングは本番ファイルを使用したが、全既存ゲームのサーバー依存関係を一括起動した検証ではない。
本番ファイルへ検証用の代替処理を追加していない。

## 再検証

node --test tests/build550-ricochet.test.mjs tests/build550-party.test.mjs tests/build550-main-wire.test.mjs tests/build547-cart-sling.test.mjs tests/build549-cart-physics.test.mjs

`tools/build550/browser-qa.mjs` が専用サーバーをローカルに起動・終了する。実アカウントや実サーバーには接続しない。

各能力の数値は `src/ricochet550/Catalog550.js`、実処理は `Rules550.js`、検証記録は `docs/build550/` に収録した。
生成素材のプロンプトと使用方法は `docs/build550/asset-prompts.md` に収録した。
