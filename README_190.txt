ABYSS DOMINION REMAKE 190 差し替えパッチ

基準: 189完成版
バージョン: 2.11.73-build249

【190の修正内容】

1. 回復・蘇生スキルのMPバランス
- 敵用の割合MPコストが契約後もそのまま使われ、高Lvで小回復がMP200～300になる問題を修正しました。
- 回復量と対象範囲に応じた、プレイヤー用の割合MP上限を追加しました。
- 自分の現在HPを分ける蘇生は「HP1%蘇生」ではなく、実効果どおり「現在HP50%を分けて蘇生」と表示します。
- 純粋な自己回復ボス技が1HPしか回復しない変換不具合を修正しました。
- 攻撃＋自己回復のボス技は、攻撃性能と命中後回復の両方を保持します。

2. オフライン／切断時の自動戦闘AI
- HPが6割程度残っている段階で回復を連打しないようにしました。
- 緊急回復、2体以上の負傷、実際に回復できる量、MP効率を見て技を選びます。
- 緊急時以外は、使用後に最大MPの約20%を残します。
- 回復アイテムはHP25%以下、ガードはHP18%以下を目安に絞りました。
- オンライン切断時AIも、最低HPの味方・全体回復・蘇生対象を正しく選びます。

3. オンライン戦闘のダメージ表示順
- 撃破時に敵が先に消える問題を修正しました。
- 攻撃動作 → ヒット／ダメージ数字 → HP減少 → 撃破演出 → 消滅、の順で表示します。
- 最終HPが0の敵も、撃破演出が終わるまでは画面上に保持します。

4. ミミック階層の出現率
- 特殊な宝物／ミミック階層を約3.5～12%から、約1.5～3%へ下げました。
- 通常宝箱の個数・種類・通常探索の宝箱挙動は変更していません。
- オフラインとオンラインの特殊階層率を同じ式へ統一しました。
