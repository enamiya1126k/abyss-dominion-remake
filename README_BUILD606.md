# ABYSS DOMINION Build606

Build605に重ねる差分更新。アプリ3.1.285、魔界ランナーズ通信ルール16。

## 修正

ガード表示中のボスの頭を上から踏んだ場合、死亡せず、上と外側へ弾かれるよう変更した。プレイヤーの死亡数・ボスのHPは変化しない。弾かれた直後のボス本体との接触は300ms保護し、跳ねた瞬間に再接触して死亡することを防ぐ。追加ジャンプも可能である。

ガードが解けた休止・気絶中は、従来どおり踏みつけで2ダメージを与える。ボスの横や下からの通常接触、および別の攻撃や障害物は引き続き危険である。HP・攻撃間隔・ステージ構成は変更しない。

操作側の予測とサーバーの両方に同じ反発処理を適用した。「ガードに弾かれた！」の通知と効果音を追加した。

## 更新

1. Build605に、このZIPの中身を同じフォルダー構成で上書きする。新規ファイルも追加する。

3. 参加者全員が再読み込みする。

旧版で開始した魔界ランナーズは準備画面へ戻る。セーブのキー・スキーマは変更しない。公開サイトへの反映は行っていない。
