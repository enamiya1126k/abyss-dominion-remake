# Build596 / v3.1.275 — 接地の修正と、動く蒸気・ゴールゲート

**Build595適用済み環境への差分です。ZIPを同じフォルダ構成で上書きし、ブラウザーを再読み込みしてください。オンラインサーバーの再起動は不要です。**

## 変更点

- キャラ・敵・トゲ・看板が地面から浮いて見える問題を修正。透明画像の外枠ではなく、絵の歩ける面を当たり判定の高さへ合わせた。地面の厚さに依存しない共通の表面を使う。
- 小さい足場、細い足場、壁の上も同じ基準で接地。動く足場では、自分・仲間・足元の影を同じ時刻の位置へ合わせる。横移動する足場に乗る仲間も、通信補間の遅れで置き去りにならない。
- 氷の地形を画像生成で新しく制作。途中で別の端の絵を貼る処理を外し、つなぎ目をなくした。縦長画面でも地面の下に隙間が出ない厚さを用意する。
- 蒸気を生成した透過素材へ交換。噴出口は地面に固定し、予兆の小さな煙、噴出中の上昇・膨張・消散、停止直後の薄い残り煙を描く。危険な範囲と噴出タイミングは従来のルールに従う。
- ゴールゲートの中で光が渦を巻き、光の粒が流れる。ゴールしたキャラは約0.65秒で門へ吸い込まれ、光の輪が広がる。クリア表示と観戦へのカメラ切替は演出を見せてから行う。
- ゲートを障害物より奥に描き、門の手前の木箱を見えるようにした。

画像はWebP、地形と演出用の小さな画像は読み込み時に合成して再利用する。画面外の演出を描かず、毎フレームの画像生成・読み込み・大きなぼかし処理を使わない。端末の「動きを減らす」設定では渦や吸い込みを省略する。

参加は人間だけの１〜４人。AI補充・AI代行はなし。８コース・難度・ジャンプ・攻撃アイテム・ハート・共有救助のルールはBuild595と同じ。ルール番号は６を継続し、サーバーの処理とデータ形式は変更していない。
