# ABYSS DOMINION Build513 — 〇×サバイバル「最後の足場」

バージョン: **v3.1.192-build513** / 適用元: **Build512**

## 追加内容

ミニゲーム一覧の先頭に「〇×サバイバル」を追加しました。1〜4人で参加し、空席はAIが埋めます。参加費はありません。魔物の能力値による有利・不利はありません。

- 問題を読み、左の〇または右の×へ移動。全員の移動を共有します。
- 1問12秒。締め切りまでは何度でも変更できます。全員が選んでも時間は短縮しません。
- 巨大な石壁が迫り、残り5秒から鼓動、最後の3秒で壁が小さく振動。問題文は固定表示です。
- 締め切りで移動をロック。短い静止のあと、誤答側の足場が砕け、そこにいたプレイヤーが落下します。
- 誤答・未選択は即脱落。最後の1人が優勝。全員同時に脱落した場合は勝者なしです。
- 最大10問。10問を終えて複数人が残った場合は同時優勝です。
- 動物・食べ物・地理・宇宙・天気・からだ・音楽・ゲーム・スポーツ・歴史・算数・ことばの12ジャンル、120問。1試合内ではジャンルが重ならないように抽選します。
- 同じパーティーの直近30問を避けます。結果画面では、出題済みの問題・正解・短い解説・出典を見返せます。
- AIにも誤答や迷って移動する行動があります。人の最後の選択を見て正答へ追随するAIではありません。
- 接続が切れた場合は最後に受理された選択を維持。再接続時に試合へ復帰します。途中参加は観戦し、次の試合から参加できます。

## 操作

〇／×の移動ボタンをタップしてください。キーボードでは左右矢印、O／X、1／2にも対応しています。「音 ON／OFF」で効果音を切り替えられます。端末の「視差効果を減らす」設定では、揺れや落下の移動アニメーションを抑えます。

## 適用手順

**今回は本体とオンラインサーバーの両方を更新し、サーバーを再起動してください。** フロントだけの更新では新ゲームは開始できません。

1. 現在のBuild512一式と、オンラインサーバーの永続データをバックアップします。
2. ZIPの中身を、既存プロジェクトの同じ相対パスへ上書きします。これは差分ZIPです。既存プロジェクトを削除したり、このZIPだけで置き換えたりしないでください。
3. 公開側へ `index.html`、変更された `src/`、`assets/quiz513/`、`world-raid-offline513-sw.js`、`world-raid-offline513-assets.json` を反映します。
4. オンラインサーバー側にも `online-server/src/` の変更と共通の `src/` の変更を反映します。新しい `online-server/src/quiz/Questions513.js` と `src/quiz/Rules513.js` の配置を確認してください。
5. オンラインサーバーを再起動します。全員が本体を再読み込みしてから、新ゲームを開いてください。

問題集はサーバー用です。クライアントは現在の問題文だけを受信し、正解と解説は判定後に受信します。問題集はブラウザー用モジュールから参照せず、オフライン保存対象にも追加していません。サーバー用ディレクトリを公開サイトへ配信する必要はありません。

既存の運だけ大運動会、ゴリラの胸毛抜き、用水路、キャベツ、魔物レース、カードすごろくのゲームルール・演出画像は変更していません。
