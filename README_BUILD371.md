# Build371 / v3.1.51 — ランキングの公開装備情報

Build370適用済みのゲームフォルダーへ上書きする差分パッチです。

## 適用手順
1. オンラインサーバーを停止する。
2. ZIPの内容をゲームフォルダーの同じ位置に上書きし、Web側を普段の方法で配信する。
3. オンラインサーバーを再起動する。online-server/src/PlayerPowerRanking.js も更新が必要。
4. 自分と公開対象のプレイヤーがゲームを再読み込みし、サーバーへ接続する。
5. ランキングの公開パーティーで「情報を更新」を押す。

セーブデータやランキングの保存ファイルは削除しないでください。公開・サーバー操作はこのZIP作成時には行っていません。

## 修正
- 編成・装備の変更が繰り返されても、公開データ送信の30秒待ちを毎回やり直さないよう修正。送信時点の最新編成を送る。
- 装備IDの数値／文字列の差を吸収して、所持装備・控え装備・ボス装備保管庫から公開装備を解決する。
- 装備情報が完全に送られたか、一部未解決か、旧データで不明かを送信・保存・取得の全経路で保持。
- 未受信の装備を「装備なし」と断定せず、「装備情報の更新待ち」と表示。
- 空の装備メッセージが画像用34px列に押し込まれ、細長く見切れるレイアウトを修正。
- 公開パーティーに最終更新日時と「情報を更新」を追加。

## 限界・原因について
画像では相手のキャラと戦力は取得できています。現行コードに他人の装備を一律に隠す制限はありません。相手の実セーブ／稼働中サーバーの保存データは取得していないため、その相手が本当に無装備なのか、旧版で装備を送信できなかったかは断定していません。
サーバーに一度も送られていない装備の名前や数値は復元できません。相手本人が最新版で接続し、公開情報を再送する必要があります。「情報を更新」はサーバーに保存済みの情報を再取得する操作で、オフラインの相手を強制接続する操作ではありません。
