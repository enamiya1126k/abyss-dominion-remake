# ABYSS DOMINION — Build439 / v3.1.118

Build438までの変更を含む累積上書きZIPです。今回の追加依頼を反映しています。

## 更新方法

1. 現在のゲームフォルダーとセーブをバックアップします。
2. ZIPの中身を既存のゲームフォルダーに上書きします。既存素材、セーブ、サーバーの `data/` と設定ファイルは残してください。
3. `online-server/` と同階層の `src/` も更新し、通常の方法でNodeサーバーを再起動します。レイドランキングのキャラクター表示にサーバー更新が必要です。
4. 公開先を更新して再読み込みします。表示バージョンは **3.1.118** です。

このZIPはゲーム本体の全素材を含む単独起動版ではありません。公開中のゲームには自動反映されません。

## 今回の変更

- 欠片交換には従来の欠片に加えて、階層ボス5個、深淵10個、十神15個の深淵の鍵が必要です。本体・各装備の交換それぞれに適用し、不足時は選べません。
- モンスター育成画面の既存なつき度欄に「結晶で育成」を追加しました。捕獲結晶100個で「なつき度＋20」または「習得済みスキルの経験値＋20」を選べます。上限直前は1ポイントあたり5個で残り分だけ消費し、上限到達後は消費しません。実戦のスキル使用回数・装備SLOTは変わりません。探索・戦闘中は利用できません。
- 召喚回数の手入力上限を、魔晶石と所持枠から算出する最大回数に変更しました。通常料金では魔晶石10,542個で234回（10,530個消費）です。1・10・20・30・50・100回の既存ボタンは維持しています。
- 新しく召喚する装備はLv.1〜最高到達階層×2、魔物はLv.1〜最高到達階層×1.5（小数点以下切り捨て）から抽選します。最高100階なら装備Lv.1〜200、魔物Lv.1〜150です。通常・特別・曜日・深淵・第二章の召喚へ適用し、既存所持品のレベルや欠片契約報酬のレベルは変わりません。
- 大量召喚の結果一覧を50件ずつ表示します。第二章の神話抽選で対象外の原母が混ざり抽選に失敗する不具合も修正し、既存の70体・ランクごとの確率を保ちました。
- レイドランキングを戦力ランキングと同じカード形式にしました。上位3位は金・銀・銅、順位はメダル中央に表示します。累計ダメージ・同順位処理・報酬計算は保っています。部隊情報のない過去記録には紋章を表示します。
- 戦力記録は「全体ランキング」を最初に開きます。「自分の記録」への切り替えはそのまま使えます。
- モンスター育成を黒と金の装飾に統一し、生成画像の黒曜石メダルを肖像背景へ使用しました。既存パネルの寸法と配置を保っています。
- 役割から仲間を探す際、習得済み・未設定のスキルも同等に候補へ含めます。詳細から設定するSLOTを選択でき、仲間を編成に追加できます。4枠埋まっている場合は交代相手を選びます。探索中は閲覧のみです。

交換・通常の回数指定召喚・捕獲結晶育成・おすすめからの編成変更は、保存に失敗した場合、資源・獲得物・設定をまとめて復元します。

4対4・奈落回廊のゲームルールと報酬は変更していません。以前依頼された紫ボタンの統一、別SLOTのスキル表示、レイドのHP/MP表示縮小と6段階速度はBuild438の変更として同梱しています。
