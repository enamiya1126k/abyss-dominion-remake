# Build595 / v3.1.274 — 絵のある足場、滑らかな操作、手応えのある冒険

**Build594適用済み環境への差分パッチです。本体とオンラインサーバーの両方を更新し、サーバーを再起動してください。**

## 適用

1. ZIP内のファイルを、既存の本体と同じフォルダ構成で上書きする。単体の空フォルダでは動作しない。
2. 本体の配信ファイルと、サーバーで参照する `src` / `online-server/src` を更新する。
3. オンラインサーバーを再起動し、全参加者が再読み込みする。依存パッケージの追加はない。

表示バージョンは v3.1.274 / Build595。ランナーズのルール番号は６。旧クライアントとの混在開始を防止し、旧ルールの開催中ルームは準備画面へ戻す。公開サイトへの反映やGitHubへのpushは、このパッチ作成時点では行っていない。

## 見た目

画像生成で11種類の透過素材を新規制作した。草・遺跡・氷晶・溶岩の足場、地上の甲虫、空中のガーゴイル、火と風の紋章、ゴールの門、トゲ、壊せる木箱に使用する。足場は角丸ブロックから岩・草・氷の質感へ変更。既存の８世界の背景に組み合わせ、攻撃ボタンにも装備中の紋章を表示する。

追加画像は合計約498KBのWebP。元の巨大PNGはゲームへ同梱しない。現在の地形と共通スプライトを先に読み込み、開始カウント中に地形を最大48枚の描画キャッシュへ合成して再利用する。素材の生成プロンプト・ハッシュは `docs/build595/ART_PROMPTS.md`。

## 動き

- ランナーズ専用の単調増加する時計を使用。通信が到着するたびに時刻を書き換えていた処理を外し、通信間隔のばらつきによる逆戻りを防ぐ。
- 未確定の操作を送信時刻順に再現する。25msの共通物理ステップを保ち、表示位置はステップ間を補間する。
- 動く足場を25ms刻みの位置から連続した時刻の位置へ変更。画面更新はブラウザの描画タイミングに合わせ、HUDは従来どおり間引く。
- 毎回作り直していた固定地形の情報を再利用する。画像は生成済みWebPと描画キャッシュを使い、背景の大画像を毎フレームCanvasに転写しない。

左右の指滑らせ、複数指の同時押し、長押しで高さが変わるジャンプ、コピー・選択防止は維持。短い8ms振動は対応ブラウザでのみ使用し、押しっぱなしでは連打しない。iPhone Safariなど、振動APIを提供しない環境での物理的な振動は保証しない。

## 難度とアイテム

全８コース・各６エリアの長さを維持したまま、通り道へトゲ、各コース７体の飛行敵、細く速く動く足場を配置。後半には幅235の深い穴と幅62の昇降足場を追加した。通常ジャンプ１回では渡れず、途中の足場への着地か風の二段ジャンプが必要になる。穴の手前に風、次の木箱区間に火の紋章を置いた。地上敵の巡回も速くした。

- ハート３から開始。ミスで１つ失い、共有の旗から再開。ハート０で自動補充される仕組みは廃止した。
- １人プレイはハート０、協力プレイは走れる仲間が全員いなくなると終了。全員がゴールするとクリア。
- 倒れた仲間は、生存者が**新しい**旗または未開通のスイッチへ到着するとハート１で救助。通過済みの旗だけでは繰り返し復活できない。
- 火は３体まで貫通し、木の障害物を２発で破壊。迂回用の段差と壁キックも使える。風は弾１発で空中ジャンプを１回追加し、着地すると再使用可能。
- 宝石のハート＋１・弾＋４・４秒加速は維持。参加者への弾はハートを減らさず、少し吹き飛ばす。
- 森・城は240秒、他は210秒。チェックポイント間隔も広げた。正確な配置と個数は `docs/build595/COURSES.json`。

参加は人間だけの１〜４人。空席補充・切断代行のAIは入らない。敵キャラクターは出現する。他のミニゲームのAI仕様は変更しない。

## 確認

自動テスト40件、４つの実WebSocketクライアント、１〜４人表示、スマホ縦横３サイズ、実入力の二段ジャンプと上段への着地を確認した。新しい穴は全８コース・昇降６位相で、風なしの足場経由ルートを検証した。これは新難所の到達可能性の確認であり、人間が全コースを通しで攻略したという意味ではない。

20〜120msの配送揺れを入れた直進テストでは、旧版で発生した３回の逆向き移動が０回になった。ジャンプの遅延応答、着地後の収束も確認した。CPU４倍低速のChromium測定と具体的な結果は `docs/build595/VALIDATION.txt` に記載する。iPhone実機・Safariでの動作は未確認。
