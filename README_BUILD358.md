# ABYSS DOMINION Build358 / v3.1.38

Build357に上書きする差し替えパッチです。

## 反映方法

ZIPを展開し、`index.html`・`src`・`online-server`などを、同名のファイルがあるゲームのルートへ上書きしてください。新規ファイルも含めて反映します。通常の更新方法で公開し、画面を再読み込みして v3.1.38 を確認してください。

通信サーバーを運用している場合は、共有の `src` と `online-server` の両方を更新し、サーバーを再起動してください。セーブ削除は不要です。既存の進行状況、配布コード、所持品は維持します。

## 1. 戦闘アイテム

アイテム選択後の対象選択が戦闘画面の背面に出ていた構造を変更しました。黒と金の戦闘パネル内で「アイテム選択 → 対象選択 → 使用」が完結します。

- 「戻る」「閉じる」を押してもアイテムや行動は消費しません。
- 在庫、対象の状態、行動中のキャラを再確認し、連打による二重消費を防ぎます。
- HP回復、MP回復、蘇生、状態異常解除、全体アイテム、自動緊急回復を確認しています。

## 2. 階層で遭遇する十神の補正

80〜100階の階層ボスとして出現する十神を調整しました。80階では、従来の生成後能力に対して HP60%、物理・魔法攻撃30%、物理・魔法防御65%、速度80% を適用します。100階へ向けて段階的に HP80%、攻撃60%、防御85%、速度90% へ上がります。

入手後の育成能力、任意の試練、深淵の基礎能力にはこの階層補正を掛けません。新技の効果・MP消費・CTは敵味方で共通です。

同じ階層・同じ十神／深淵への再挑戦では、魔法陣の有無・種類・レベルが変わらないようにしました。十神・深淵のキャラ画像は階層ボスと同じ拡大処理で通常の約2倍にし、名前・HP表示と分けて配置します。

## 検証と確認範囲

- 今回の変更と既存の勇者・GM配布・表示を含む重点テスト：71件成功。
- 最終編集後、アイテム操作と階層補正・サイズの10件を再実行し成功。
- 変更したJavaScriptの構文と、更新対象モジュールのキャッシュ更新参照を確認。
- 通信戦の既存回帰テスト：74件中73件成功。残る1件は魔法陣の初期シールドを5,000と期待するテストに対し5,143となる既存の不一致で、未変更のBuild357でも同じ失敗を確認しました。
- アイテムは実際の描画・イベント登録・回復関数を使うテスト環境で確認。通信戦は実際のRoom／Team／Raidの行動解決処理で確認しました。
- iPhone／Safari実機でのタッチ操作・描画確認は未実施です。

80階の比較モデルでは、通常育成を想定したLv800・LR4体・強化+3・GM装備能力の45%の編成は40戦中11勝から27勝、GM配布編成は37勝から40勝になりました。これは実際の生成・攻撃計算を使う比較用モデルで、ユーザーのセーブや全ての戦闘演出・複合効果を完全再現したものではありません。実プレイの勝率を保証する数値ではありません。

再演・模倣は共通処理によって通常技の攻撃・回復・強化などを再現します。一部の専用追撃や遅延効果など、元の技固有の処理まで完全に同一再現するものではありません。
