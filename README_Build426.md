# ABYSS DOMINION Build426 / v3.1.105

今回の差し替えは依頼②「母の追加能力・難易度調整」です。Build425を適用済みのゲームへ、ZIP内のファイルを同じ場所に上書きしてください。index.html と src をまとめて差し替えます。公開後に画面を再読み込みすると、バージョン表示は3.1.105になります。

## 追加した能力

- **万命の産声**：母のHPが攻撃で減ると、空き枠へランダムに1体召喚します。母を含め最大4体。通常攻撃・スキル・連携を含む1行動につき1体まで。多段攻撃でも追加召喚は増えません。毒などの継続ダメージ、反撃、反射、残響では召喚しません。障壁などでHPダメージが0になった場合も召喚しません。
- 召喚敵は既存8種から抽選。Lv.2,500〜4,500、武器・防具・装飾品の種類、SSR〜LRのレアリティ、装備Lv.600〜1,800、強化値+0〜10が変化します。強さには85〜115%の個体差があります。既存の敵AI・装備の能力計算を使い、召喚体の耐久力は専用補正で調整しています。抽選済みの内容をセーブへ保存します。
- 召喚されたラウンドは行動せず、**次ラウンドから**既存の速度順で行動します。召喚直後から攻撃対象には選べます。捕獲・個別ドロップはありません。
- **原母のふんばり**：1戦につき1回だけ、致死ダメージをHP1で耐えます。継続ダメージや直接HPを減らす技でも同じです。多段攻撃の残りの一撃まで無敵になる効果ではありません。
- 母を倒して召喚敵が残っている場合、**倒した次のラウンドから5ラウンド**の猶予があります。5ラウンド目の終了処理までに召喚敵を全滅させれば勝利。残っていれば母が**最大HPの30%（480,000）で1度だけ復活**します。
- 復活時にふんばりは戻りません。再び母を倒した後の再復活もありません。母が倒れている間は十律輪と新たな召喚が止まります。召喚敵の通常蘇生で母を早く復活させることもできません。
- 戦闘画面下に「母の復活まで あと○ラウンド」を表示します。召喚敵には「召喚・次Rから」、母にはふんばりの残り表示を付けました。決戦前の説明も更新しています。

## 引き継ぎ

ふんばり・復活の使用履歴、残りラウンド、召喚敵の個体・装備・行動開始ラウンドを戦闘セーブで引き継ぎます。Build425以前から進行中の母戦は、開始時の旧ルールで再開します。新能力は更新後に新しく始めた母戦から適用します。

母の基本能力（HP1,600,000・魔力14,000・速度8,000）と十律輪の威力はBuild425を継続。今回の難易度上昇は召喚と生存・復活能力によるものです。初回報酬・ホームスキン、消耗品の返却、所持キャラクターの能力、通常探索・オンライン共闘のルールは変更していません。
